Revealed Comparative Advantage (RCA) Analysis
ការវិភាគសន្ទស្សន៍អត្ថប្រយោជន៍ប្រៀបធៀបដែលបានបង្ហាញ (RCA)		 ងាយស្រួលក្នុងការគណនាដោយប្រើប្រាស់ទិន្នន័យពាណិជ្ជកម្មសកលដែលមានស្រាប់។ ជួយបង្ហាញយ៉ាងច្បាស់ពីទីតាំងប្រកួតប្រជែងនៃផលិតផលរបស់ប្រទេសមួយធៀបនឹងទីផ្សារពិភពលោក។ មិនបានឆ្លុះបញ្ចាំងពីតម្លៃបន្ថែមពិតប្រាកដ (Value-added) ដែលប្រទេសនោះទទួលបានទេ។ សូចនាករអាចមានភាពលម្អៀងខ្ពស់ដោយសារទំហំនាំចេញដ៏ធំរបស់ក្រុមហ៊ុនបរទេស (FDI) ដែលគ្រាន់តែមកតម្លើងជាជាងផលិត។ សូចនាករ RCA សម្រាប់ទំនិញបច្ចេកវិទ្យាខ្ពស់របស់វៀតណាមបានកើនឡើងពី ០.៥១ ក្នុងឆ្នាំ ២០០៩ ដល់ ២.០១ ក្នុងឆ្នាំ ២០២១ ដែលបង្ហាញពីការទទួលបានអត្ថប្រយោជន៍ប្រៀបធៀបក្នុងកម្រិតមធ្យម។
Domestic Value-Added and Processing Share Assessment
ការវាយតម្លៃលើតម្លៃបន្ថែមក្នុងស្រុក និងចំណែកនៃដំណើរការតម្លើង (Gia công/Assembly)		 វាស់វែងគុណភាពនៃការនាំចេញបានយ៉ាងសុក្រឹត ដោយផ្តោតលើផលប្រយោជន៍សេដ្ឋកិច្ចជាក់ស្តែងដែលធ្លាក់មកលើកម្លាំងពលកម្ម និងរដ្ឋាភិបាលក្នុងស្រុក។ ទាមទារទិន្នន័យលម្អិតស៊ីជម្រៅអំពីខ្សែសង្វាក់ផ្គត់ផ្គង់ តម្លៃវត្ថុធាតុដើមនាំចូល និងរចនាសម្ព័ន្ធកម្មសិទ្ធិរបស់ក្រុមហ៊ុននាំចេញ (ក្នុងស្រុក vs បរទេស) ដែលពិបាកក្នុងការប្រមូល។ ទោះបីជាទំហំនាំចេញធំ តម្លៃបន្ថែមក្នុងស្រុករបស់វៀតណាមមានត្រឹមតែប្រហែល ៣០% ប៉ុណ្ណោះ ដោយក្រុមហ៊ុន FDI គ្រប់គ្រងការនាំចេញគ្រឿងអេឡិចត្រូនិចរហូតដល់ ៩៨%-៩៩%។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះមិនតម្រូវឱ្យមានឧបករណ៍ Hardware ស្មុគស្មាញទេ ប៉ុន្តែទាមទារការប្រមូលទិន្នន័យពាណិជ្ជកម្មកម្រិតម៉ាក្រូយ៉ាងម៉ត់ចត់ និងជំនាញវិភាគស្ថិតិសេដ្ឋកិច្ច។

  • Dataset: ទិន្នន័យពាណិជ្ជកម្មបន្ទាប់បន្សំពីធនាគារពិភពលោក (World Integrated Trade Solution - WITS) ទិន្នន័យអគ្គនាយកដ្ឋានគយ និងស្ថិតិជាតិសម្រាប់រយៈពេលវែង (១០ ឆ្នាំឡើងទៅ)។
  • Software: កម្មវិធីវិភាគទិន្នន័យស្ថិតិ និងសេដ្ឋកិច្ច (ដូចជា Stata, R, កម្មវិធី Python ឬយ៉ាងហោចណាស់ Microsoft Excel សម្រាប់ចងក្រងរូបមន្ត RCA)។
  • Expertise: ចំណេះដឹងស៊ីជម្រៅផ្នែកសេដ្ឋកិច្ចអន្តរជាតិ ទ្រឹស្តីពាណិជ្ជកម្ម និងការវិភាគខ្សែសង្វាក់តម្លៃសកល (Global Value Chains)។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះផ្អែកលើសំណុំទិន្នន័យនាំចេញ និងរចនាសម្ព័ន្ធសេដ្ឋកិច្ចរបស់ប្រទេសវៀតណាមពីឆ្នាំ ២០០៩ ដល់ ២០២២ ដែលមានឥទ្ធិពលយ៉ាងខ្លាំងដោយលំហូរទុនវិនិយោគបរទេស (FDI) ពីកូរ៉េ និងចិនទៅលើវិស័យអេឡិចត្រូនិច។ សម្រាប់កម្ពុជា បរិបទនេះមានតម្លៃជាមេរៀនប្រវត្តិសាស្ត្រដ៏ល្អ ពីព្រោះកម្ពុជាក៏កំពុងឆ្លងកាត់ដំណាក់កាលពឹងផ្អែកលើការនាំចេញតាមរយៈការដំឡើង (Assembly) និងការកាត់ដេរពីក្រុមហ៊ុន FDI ស្រដៀងគ្នា។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រ និងការរកឃើញនៅក្នុងឯកសារនេះមានសារៈសំខាន់ខ្លាំងណាស់ក្នុងការយកមកកែសម្រួលប្រើប្រាស់ដើម្បីតម្រង់ទិសគោលនយោបាយសេដ្ឋកិច្ចរបស់កម្ពុជា។

  • វិស័យកាត់ដេរ ស្បែកជើង និងកាបូប (Garment, Footwear, and Travel Goods): អនុញ្ញាតឱ្យអ្នកស្រាវជ្រាវវាស់វែងថាតើ កម្ពុជាពិតជាទទួលបានតម្លៃបន្ថែមក្នុងស្រុកប៉ុន្មានភាគរយពិតប្រាកដ បន្ទាប់ពីដកថ្លៃនាំចូលវត្ថុធាតុដើម (ក្រណាត់ നൂល) ពីប្រទេសចិន ឬវៀតណាម។
  • តំបន់សេដ្ឋកិច្ចពិសេស (SEZs ដូចជាតំបន់សេដ្ឋកិច្ចពិសេសក្រុងព្រះសីហនុ និងតំបន់សេដ្ឋកិច្ចពិសេសតាយសេងបាវិត): ជួយរដ្ឋាភិបាលវាយតម្លៃថាតើការទាក់ទាញរោងចក្រដំឡើងកង់ ឬគ្រឿងបន្លាស់រថយន្តនៅទីនោះ មានការផ្ទេរបច្ចេកវិទ្យា (Technology Transfer) ដែរឬទេ ឬត្រឹមតែទាញយកផលប្រយោជន៍ពីកម្លាំងពលកម្មថោក។
  • ក្រុមប្រឹក្សាអភិវឌ្ឍន៍កម្ពុជា (CDC) និងក្រសួងពាណិជ្ជកម្ម (MoC): អាចប្រើប្រាស់សូចនាករ RCA ដើម្បីតាមដានពីការវិវឌ្ឍនៃការធ្វើពិពិធកម្មការនាំចេញរបស់កម្ពុជា ទៅកាន់ផលិតផលថ្មីៗដែលមានតម្លៃបន្ថែមខ្ពស់ និងវាយតម្លៃប្រសិទ្ធភាពនៃច្បាប់វិនិយោគថ្មី។

ការប្តូរការយកចិត្តទុកដាក់ពី 'បរិមាណនាំចេញសរុប' ទៅជា 'បរិមាណតម្លៃបន្ថែមក្នុងស្រុក' គឺជាគន្លឹះយុទ្ធសាស្ត្រតែមួយគត់ ដើម្បីជួយកម្ពុជាគេចផុតពីអន្ទាក់ចំណូលមធ្យម និងអភិវឌ្ឍឧស្សាហកម្មប្រកបដោយចីរភាព។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ប្រមូលទិន្នន័យពាណិជ្ជកម្មកម្រិត HS Code (Data Extraction): ទាញយកទិន្នន័យនាំចេញ-នាំចូលរបស់ប្រទេសកម្ពុជារយៈពេល ១០ ឆ្នាំចុងក្រោយ ដោយចូលប្រើប្រាស់មូលដ្ឋានទិន្នន័យ World Integrated Trade Solution (WITS) ឬ UN Comtrade ដោយផ្តោតលើកូដទំនិញជាក់លាក់ (HS 2-digit ដល់ 6-digit)។
  2. គណនាសូចនាករគុណភាពនាំចេញ RCA (Compute Export Metrics): ប្រើប្រាស់កម្មវិធី Excel ឬ Python/R scripts ដើម្បីគណនាសូចនាករ Revealed Comparative Advantage (RCA) សម្រាប់មុខទំនិញសំខាន់ៗរបស់កម្ពុជា ដើម្បីកំណត់ថាតើផលិតផលណាខ្លះដែលមានប្រៀបខ្លាំងធៀបនឹងសកលលោក។
  3. ស្រាវជ្រាវពីតម្លៃវត្ថុធាតុដើមនាំចូល (Value-Chain Mapping): ប្រមូលទិន្នន័យពីអគ្គនាយកដ្ឋានគយ និងរដ្ឋាករកម្ពុជា (GDCE) អំពីទំហំនាំចូលវត្ថុធាតុដើម (Intermediate goods) ដែលបម្រើឱ្យការនាំចេញ ដើម្បីគណនារក Domestic Value-Added Ratio ប្រហាក់ប្រហែល។
  4. វាយតម្លៃឥទ្ធិពលនៃការវិនិយោគបរទេស (FDI Dependency Assessment): ប្រមូលទិន្នន័យពី CDC ដើម្បីប្រៀបធៀបចំណែកទីផ្សារនាំចេញរវាងក្រុមហ៊ុនក្នុងស្រុក (Local SMEs) និងក្រុមហ៊ុនបរទេស (FDI) ព្រមទាំងវាយតម្លៃកម្រិតនៃការប្រើប្រាស់បច្ចេកវិទ្យា។
  5. ចងក្រងអនុសាសន៍គោលនយោបាយ (Formulate Policy Recommendations): សរសេររបាយការណ៍សង្ខេប (Policy Brief) ជូនភាគីពាក់ព័ន្ធ ដោយផ្តោតលើការស្នើសុំឱ្យមានការអភិវឌ្ឍ Supporting Industries (ឧស្សាហកម្មគាំទ្រក្នុងស្រុក) និងការបណ្តុះបណ្តាលធនធានមនុស្សផ្នែក STEM ជាជាងការពឹងផ្អែកលើកម្លាំងពលកម្មជំនាញទាប។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Revealed Comparative Advantage (RCA) សូចនាករសេដ្ឋកិច្ចដែលវាស់វែងថាតើប្រទេសមួយមានប្រៀប ឬភាពខ្លាំងជាងគេក្នុងការនាំចេញផលិតផលជាក់លាក់ណាមួយធៀបនឹងចំណែកទីផ្សារពិភពលោកសរុប។ ដូចជាការប្រៀបធៀបពិន្ទុមុខវិជ្ជាគណិតវិទ្យារបស់សិស្សម្នាក់ធៀបនឹងពិន្ទុមធ្យមរបស់សិស្សទូទាំងប្រទេស ដើម្បីដឹងថាគាត់ពិតជាមានប្រៀបលើមុខវិជ្ជានេះមែនឬអត់។
Domestic Value-Added តម្លៃពិតប្រាកដដែលបានបង្កើតឡើងនៅក្នុងស្រុកសម្រាប់ផលិតផលនាំចេញ បន្ទាប់ពីដកថ្លៃដើមនៃវត្ថុធាតុដើម ឬគ្រឿងបន្លាស់ដែលបាននាំចូលពីបរទេសចេញរួច។ ដូចជាអ្នកទិញគ្រឿងផ្សំពីផ្សារតម្លៃ ៣ដុល្លារ មកធ្វើនំលក់បាន ៥ដុល្លារ ដូច្នេះតម្លៃបន្ថែម (Value-Added) ដែលអ្នកបង្កើតបានគឺ ២ដុល្លារ។
Foreign Direct Investment (FDI) ការវិនិយោគដោយផ្ទាល់ពីក្រុមហ៊ុន ឬស្ថាប័នបរទេសមកកាន់ប្រទេសមួយទៀត ដើម្បីបង្កើតរោងចក្រ ក្រុមហ៊ុន ឬមូលដ្ឋានផលិតកម្ម។ ដូចជាអ្នកជិតខាងមកបោះទុនជួលដីរបស់អ្នកដើម្បីសង់រោងចក្រ ហើយជួលអ្នកភូមិឱ្យធ្វើការនៅទីនោះ។
Assembly / Processing Trade សកម្មភាពឧស្សាហកម្មដែលរោងចក្រក្នុងស្រុកគ្រាន់តែទទួលយកវត្ថុធាតុដើម ឬគ្រឿងបន្លាស់ពីបរទេសមកតម្លើង ឬកែច្នៃក្នុងកម្រិតទាប (តម្លៃបន្ថែមទាប) រួចនាំចេញទៅវិញ។ ដូចជាគេឱ្យកង់ឡាននិងតួឡានមកអ្នក ហើយអ្នកគ្រាន់តែមួលខ្ចៅផ្គុំវាចូលគ្នា រួចយកទៅឱ្យគេវិញ ដោយទទួលបានតែថ្លៃឈ្នួលពលកម្ម។
Global Value Chain បណ្តាញនៃសកម្មភាពផលិតកម្មសកល ដែលរាល់ដំណាក់កាលនៃការបង្កើតផលិតផលមួយ (ពីការរចនា ការផលិតវត្ថុធាតុដើម ការតម្លើង ដល់ការលក់) ត្រូវបានបែងចែក និងធ្វើឡើងនៅប្រទេសផ្សេងៗគ្នា។ ដូចជាទូរស័ព្ទមួយគ្រឿង ដែលរចនានៅអាមេរិក ទិញអេក្រង់ពីកូរ៉េ តម្លើងនៅចិន ហើយលក់នៅជុំវិញពិភពលោក។
Supporting Industries ឧស្សាហកម្មដែលផ្តោតលើការផលិតគ្រឿងបន្លាស់ សម្ភារៈវេចខ្ចប់ ឬវត្ថុធាតុដើមបឋម ដើម្បីផ្គត់ផ្គង់ដល់រោងចក្រធំៗផ្សេងទៀតសម្រាប់ផលិតជាផលិតផលសម្រេច។ ដូចជារោងចក្រផលិតឡេវអាវ ឬរ៉ូត ដែលផ្គត់ផ្គង់ជាប្រចាំឱ្យរោងចក្រកាត់ដេរអាវធំ។
High-tech Exports ការនាំចេញផលិតផលដែលទាមទារការស្រាវជ្រាវនិងអភិវឌ្ឍន៍ខ្ពស់ (R&D) ការច្នៃប្រឌិត និងបច្ចេកវិទ្យាទំនើបក្នុងការផលិត ដូចជាកុំព្យូទ័រ ទូរស័ព្ទ និងបន្ទះឈីបអេឡិចត្រូនិច។ ការលក់ទំនិញដែលតម្រូវឱ្យប្រើប្រាជ្ញា បច្ចេកទេស និងម៉ាស៊ីនទំនើបៗបំផុតដើម្បីផលិត មិនមែនគ្រាន់តែពឹងផ្អែកលើកម្លាំងមនុស្ស ឬធនធានធម្មជាតិនោះទេ។

៦. ប្រធានបទពាក់ព័ន្ធ (Further Reading)

អត្ថបទដែលបានបោះពុម្ពនៅលើ KhmerResearch ដែលទាក់ទងនឹងប្រធានបទនេះ៖

  • គោលនយោបាយទាក់ទាញការវិនិយោគផ្ទាល់ពីបរទេសរបស់ម៉ាឡេស៊ីក្នុងដំណើរការសមាហរណកម្មសេដ្ឋកិច្ចអន្តរជាតិ - ស្ថានភាពជាក់ស្តែង បទពិសោធន៍ និងលទ្ធភាពអនុវត្តនៅវៀតណាម
