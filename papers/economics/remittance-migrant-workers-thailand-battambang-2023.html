វិធីសាស្ត្រ (The Methodology)៖ ការស្រាវជ្រាវនេះប្រើប្រាស់វិធីសាស្ត្រពិពណ៌នា ដោយផ្អែកលើការប្រមូលទិន្នន័យបរិមាណនិងគុណភាពតាមរយៈការស្ទង់មតិ និងការសម្ភាសន៍ដោយផ្ទាល់ជាមួយគ្រួសារគោលដៅ។

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • កត្តាជំរុញចម្បងនៃការចំណាកស្រុកទៅប្រទេសថៃគឺកង្វះឱកាសការងារក្នុងស្រុក (៩៣,៥%) ការស្វែងរកប្រាក់ចំណូលប្រសើរជាងមុន (៨៨,៥%) និងភាពក្រីក្រក្នុងគ្រួសារ (៦២,៣%)។
  • ពលករចំណាកស្រុកភាគច្រើនបម្រើការងារក្នុងវិស័យសំណង់ (៣៥,៥%) ម្ហូបអាហារ/ភេសជ្ជៈ (៣០,៧%) សេវាកម្ម (១៨,០%) និងឧស្សាហកម្ម (១៣,៨%) ដែលសុទ្ធសឹងជាប្រភេទការងារគ្មានជំនាញ និងងាយរងគ្រោះ។
  • ប្រាក់បង្វិលជាមធ្យមទទួលបានត្រឹមតែ ៩៥,៤៧ ដុល្លារអាមេរិកក្នុងមួយខែ ហើយត្រូវបានប្រើប្រាស់ជាចម្បងសម្រាប់ទិញអាហារ (៣៥,៩៨ ដុល្លារ) ការអប់រំកូន (២២,០៥ ដុល្លារ) និងការថែទាំសុខភាព (៨,៤៥ ដុល្លារ) ដែលបង្ហាញពីការពឹងផ្អែកខ្ពស់លើប្រាក់បង្វិលរបស់គ្រួសារដែលមានប័ណ្ណក្រីក្រ (ID Poor)។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

Descriptive Statistical Analysis
ការវិភាគស្ថិតិបែបពណ៌នា		 ងាយស្រួលក្នុងការសង្ខេប និងបង្ហាញទិន្នន័យប្រជាសាស្ត្រ មូលហេតុនៃការចំណាកស្រុក និងប្រភេទការងារបានយ៉ាងច្បាស់លាស់។ មិនអាចបង្ហាញពីទំនាក់ទំនងស៊ីជម្រៅ ឬភាពពាក់ព័ន្ធរវាងអថេរ (Variables) ផ្សេងៗបញ្ជាក់ពីហេតុនិងផលបានឡើយ។ រកឃើញថាមូលហេតុចម្បងនៃការចំណាកស្រុកគឺកង្វះការងារក្នុងស្រុក (៩៣,៥%) ហើយពលករភាគច្រើនធ្វើការក្នុងវិស័យសំណង់ (៣៥,៥%)។
Chi-square Test Analysis
ការវិភាគដោយប្រើតេស្ត Chi-square		 មានប្រសិទ្ធភាពក្នុងការស្វែងរកទំនាក់ទំនងយ៉ាងច្បាស់លាស់រវាងអថេរជាក្រុម (Categorical variables) ដូចជាស្ថានភាពក្រីក្រនិងការទទួលប្រាក់បង្វិល។ ទាមទារទំហំគំរូទិន្នន័យធំគ្រប់គ្រាន់ ហើយបង្ហាញត្រឹមតែទំនាក់ទំនងប៉ុណ្ណោះ មិនអាចបញ្ជាក់ពីទំនាក់ទំនងជាហេតុនិងផល (Causation) បានទេ។ បញ្ជាក់ពីទំនាក់ទំនងយ៉ាងជិតស្និទ្ធ (p-value = 0.015) រវាងគ្រួសារដែលមានប័ណ្ណក្រីក្រ (ID Poor) និងការពឹងផ្អែកខ្ពស់លើការទទួលប្រាក់បង្វិល។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះទាមទារធនធានចម្បងលើការចុះប្រមូលទិន្នន័យផ្ទាល់នៅតាមមូលដ្ឋាន និងការប្រើប្រាស់កម្មវិធីកុំព្យូទ័រសម្រាប់វិភាគទិន្នន័យ។

  • Software: កម្មវិធី SPSS (Statistical Package for Social Science) សម្រាប់បញ្ចូល សម្អាត និងវិភាគទិន្នន័យស្ថិតិ។
  • Dataset / Fieldwork: ការចុះធ្វើកម្រងសំណួរសម្ភាសន៍ដោយផ្ទាល់ជាមួយគ្រួសារចំនួន ៣៥៥ នៅក្នុងស្រុកសង្កែ ខេត្តបាត់ដំបង ដែលចំណាយពេលចំនួន ២ខែ។
  • Methodology: ការប្រើប្រាស់វិធីសាស្ត្រជ្រើសរើសគំរូតាមបែបតជាបន្តបន្ទាប់ (Snowball sampling technique) ដើម្បីស្វែងរកគ្រួសារគោលដៅ។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងតែនៅក្នុងស្រុកសង្កែ ខេត្តបាត់ដំបង ដោយប្រើវិធីសាស្ត្រ Snowball sampling ដែលអាចធ្វើឱ្យទិន្នន័យមានភាពលម្អៀងទៅលើបណ្តាញអ្នកស្គាល់គ្នា (Network bias) និងមិនតំណាងឱ្យពលករចំណាកស្រុកទូទាំងប្រទេសកម្ពុជានោះទេ។ ម្យ៉ាងវិញទៀត ទិន្នន័យនេះផ្អែកលើការឆ្លើយតបរបស់មាតាបិតាដែលនៅផ្ទះ មិនមែនជាទិន្នន័យផ្ទាល់ពីពលករឡើយ ដែលអាចនាំឱ្យមានការប៉ាន់ស្មានប្រាក់ចំណូល ឬការចំណាយខុសពីការពិតខ្លះ។ ទោះជាយ៉ាងណា របកគំហើញនេះមានតម្លៃណាស់សម្រាប់ឆ្លុះបញ្ចាំងពីការពឹងផ្អែករបស់គ្រួសារក្រីក្រលើប្រាក់បង្វិលនៅតំបន់ជនបទ។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

លទ្ធផលនៃការស្រាវជ្រាវនេះមានសារៈសំខាន់សម្រាប់ការរៀបចំគោលនយោបាយគាំពារសង្គម និងការបង្កើតឱកាសសេដ្ឋកិច្ចនៅតំបន់ជនបទក្នុងប្រទេសកម្ពុជា។

  • ក្រសួងការងារ និងបណ្តុះបណ្តាលវិជ្ជាជីវៈ (MoLVT) និងក្រសួងសង្គមកិច្ច: អាចប្រើប្រាស់ទិន្នន័យនេះដើម្បីរៀបចំគោលនយោបាយគាំពារពលករចំណាកស្រុក និងផ្តល់ជំនួយគាំទ្រចំគោលដៅដល់គ្រួសារមានប័ណ្ណក្រីក្រ (ID Poor) ដែលងាយរងគ្រោះដោយសារបំណុល។
  • គ្រឹះស្ថានមីក្រូហិរញ្ញវត្ថុ និងធនាគារ: អាចយល់ដឹងពីលំហូរនៃប្រាក់បង្វិល (Remittances) និងតម្រូវការឥណទានរបស់ប្រជាជននៅជនបទ ដើម្បីបង្កើតសេវាកម្មហិរញ្ញវត្ថុដែលមានការប្រាក់ទាប សមស្របសម្រាប់ការកាត់បន្ថយសម្ពាធបំណុល។
  • អង្គការក្រៅរដ្ឋាភិបាល (NGOs) នៅខេត្តបាត់ដំបង និងខេត្តជាប់ព្រំដែន: អាចយករបកគំហើញនេះទៅរៀបចំគម្រោងបណ្តុះបណ្តាលវិជ្ជាជីវៈ និងបង្កើតការងារក្នុងស្រុក ដើម្បីកាត់បន្ថយការធ្វើចំណាកស្រុកដោយបង្ខំដោយសារភាពក្រីក្រ។

សរុបមក ការសិក្សានេះផ្តល់ជាភស្តុតាងជាក់ស្តែងដើម្បីជួយរដ្ឋាភិបាល និងស្ថាប័នពាក់ព័ន្ធរៀបចំយុទ្ធសាស្ត្រកាត់បន្ថយការពឹងផ្អែកខ្លាំងលើការធ្វើចំណាកស្រុកដែលមានហានិភ័យ និងលើកកម្ពស់សេដ្ឋកិច្ចមូលដ្ឋាន។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាទ្រឹស្តី និងស្រាវជ្រាវឯកសារពាក់ព័ន្ធ: ចាប់ផ្តើមដោយការអានទ្រឹស្តីពាក់ព័ន្ធនឹងការធ្វើចំណាកស្រុក ដូចជា New Economics of Labour Migration (NELM) និងប្រមូលឯកសារស្រាវជ្រាវចាស់ៗអំពីលំហូរប្រាក់បង្វិលនៅប្រទេសកម្ពុជា។
  2. រៀបចំកម្រងសំណួរ និងកំណត់វិធីសាស្ត្រជ្រើសរើសគំរូ: បង្កើតកម្រងសំណួរសម្ភាសន៍ (Questionnaire) ដែលផ្តោតលើប្រភពចំណូល ការចំណាយ និងការជំពាក់បំណុល ដោយប្រើប្រាស់វិធីសាស្ត្រជ្រើសរើសគំរូដូចជា Snowball Sampling ឬ Stratified Sampling សម្រាប់តំបន់គោលដៅ។
  3. ចុះប្រមូលទិន្នន័យមូលដ្ឋាន (Fieldwork): ចុះទៅកាន់សហគមន៍ផ្ទាល់ដើម្បីធ្វើការសម្ភាសន៍ជាមួយក្រុមគ្រួសារគោលដៅ ដោយត្រូវធានាពីក្រមសីលធម៌នៃការស្រាវជ្រាវ (Research Ethics) ជាពិសេសនៅពេលសាកសួរព័ត៌មានរសើបដូចជាការជំពាក់បំណុល។
  4. សម្អាត និងវិភាគទិន្នន័យដោយប្រើកម្មវិធី SPSS: បញ្ចូលទិន្នន័យដែលប្រមូលបានទៅក្នុងកម្មវិធី SPSS ឬ Stata រួចធ្វើការសម្អាតទិន្នន័យ និងអនុវត្តការវិភាគស្ថិតិបែបពណ៌នា រួមជាមួយនឹងតេស្ត Chi-square ឬ Regression Analysis ដើម្បីរកទំនាក់ទំនងរវាងអថេរ។
  5. ចងក្រងរបាយការណ៍ និងផ្តល់អនុសាសន៍គោលនយោបាយ: សរសេរសង្ខេបលទ្ធផលដែលទទួលបានដោយប្រៀបធៀបជាមួយទ្រឹស្តី និងផ្តល់នូវអនុសាសន៍ជាក់ស្តែង (Actionable recommendations) សម្រាប់អ្នកធ្វើគោលនយោបាយ ឬអង្គការដៃគូអភិវឌ្ឍន៍។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Remittance (ប្រាក់បង្វិល ឬប្រាក់បញ្ញើ) ចំនួនទឹកប្រាក់ដែលពលករចំណាកស្រុកទទួលបានពីការធ្វើការនៅក្រៅប្រទេស ឬក្រៅតំបន់ រួចផ្ញើត្រឡប់មកកាន់ក្រុមគ្រួសាររបស់ពួកគេនៅស្រុកកំណើត ដើម្បីជួយទ្រទ្រង់ជីវភាពប្រចាំថ្ងៃ។ ដូចជាកូនប្រុសស្រីទៅធ្វើការនៅភ្នំពេញ ឬប្រទេសថៃ ហើយផ្ញើលុយតាមភ្នាក់ងារវីង (WING) មកឱ្យឪពុកម្តាយនៅឯស្រុកកំណើតដើម្បីទិញម្ហូបនិងសងបំណុល។
3D jobs (ការងារប្រភេទ 3D - កខ្វក់ គ្រោះថ្នាក់ និងលំបាក) ប្រភេទការងារ (Dirty, Dangerous, and Difficult) ដែលពលករក្នុងស្រុកភាគច្រើនមិនចង់ធ្វើ ដោយសារវាមានហានិភ័យខ្ពស់ដល់សុខភាព និងទាមទារកម្លាំងកាយខ្លាំង ដែលភាគច្រើនធ្លាក់ទៅលើពលករចំណាកស្រុកដែលមានជំនាញទាប។ ដូចជាការងារលីសែងនៅការដ្ឋានសំណង់ ឬការងាររោងចក្រទឹកកក ដែលជនជាតិម្ចាស់ស្រុកគេចវេះមិនចង់ធ្វើ ហើយទុកឱកាសនេះឱ្យពលករចំណាកស្រុកពីប្រទេសផ្សេង។
ID Poor status (ស្ថានភាពប័ណ្ណក្រីក្រ ឬប័ណ្ណសមធម៌) ការវាយតម្លៃ និងផ្តល់ប័ណ្ណសម្គាល់ដោយរដ្ឋាភិបាលកម្ពុជា ជូនដល់គ្រួសារដែលមានជីវភាពខ្វះខាតពិតប្រាកដ ដើម្បីឱ្យពួកគេទទួលបានការគាំពារសង្គម ជំនួយហិរញ្ញវត្ថុ និងសេវាសុខាភិបាលដោយឥតគិតថ្លៃ។ ដូចជាសំបុត្រអាទិភាពពីរដ្ឋ ដែលអនុញ្ញាតឱ្យអ្នកមានជីវភាពខ្វះខាតអាចទៅពិនិត្យជំងឺនៅមន្ទីរពេទ្យរដ្ឋដោយមិនបាច់បង់ប្រាក់។
Push and pull factors (កត្តាជំរុញ និងកត្តាទាក់ទាញ) ទ្រឹស្តីនៃការធ្វើចំណាកស្រុក ដែលពន្យល់ពីមូលហេតុដែលមនុស្សផ្លាស់ទីលំនៅ ដោយកត្តាជំរុញ (Push) គឺជាការលំបាកនៅស្រុកកំណើត (ដូចជាគ្មានការងារ) ចំណែកកត្តាទាក់ទាញ (Pull) គឺជាឱកាសល្អៗនៅប្រទេសគោលដៅ (ដូចជាប្រាក់ខែខ្ពស់)។ ដូចជាភាពរាំងស្ងួតនៅស្រុកកំណើតរុញច្រានយើងឱ្យចាកចេញ (Push) ខណៈរោងចក្រនៅខេត្តផ្សេងដែលមានប្រាក់ខែល្អទាញទម្លាក់យើងឱ្យទៅធ្វើការទីនោះ (Pull)។
Snowball sampling technique (វិធីសាស្ត្រជ្រើសរើសគំរូតាមបែបតជាបន្តបន្ទាប់) វិធីសាស្ត្រជ្រើសរើសអ្នកចូលរួមក្នុងការស្រាវជ្រាវ ដោយសុំឱ្យអ្នកដែលត្រូវបានសម្ភាសន៍រួច ជួយណែនាំបន្តទៅកាន់អ្នកផ្សេងទៀតដែលស្ថិតក្នុងស្ថានភាពស្រដៀងគ្នា ដែលជួយឱ្យអ្នកស្រាវជ្រាវងាយស្រួលរកក្រុមគោលដៅដែលលាក់មុខ ឬពិបាករក។ ដូចជាការរមៀលដុំព្រិលពីលើភ្នំចុះក្រោម ដែលកាន់តែរមៀលវាកាន់តែធំ ពោលគឺតាមរយៈការស្គាល់ម្នាក់ នាំឱ្យយើងបន្តទៅស្គាល់អ្នកផ្សេងទៀតជាបន្តបន្ទាប់។
New Economics of Labour Migration - NELM (សេដ្ឋកិច្ចវិទ្យាថ្មីនៃការធ្វើចំណាកស្រុក) ទ្រឹស្តីសេដ្ឋកិច្ចដែលពន្យល់ថា ការសម្រេចចិត្តធ្វើចំណាកស្រុកមិនមែនជារឿងរបស់បុគ្គលតែម្នាក់ដើម្បីស្វែងរកប្រាក់ខែខ្ពស់នោះទេ តែវាជាយុទ្ធសាស្ត្ររួមរបស់គ្រួសារទាំងមូលដើម្បីកាត់បន្ថយហានិភ័យហិរញ្ញវត្ថុ និងបង្កើនប្រភពចំណូលច្រើនច្រក។ ដូចជាកសិករម្នាក់ដាំដំណាំច្រើនមុខក្នុងពេលតែមួយ ដើម្បីការពារកុំឱ្យខាតបង់ធ្ងន់ធ្ងរនៅពេលមានជំងឺរាតត្បាតលើដំណាំណាមួយ។
Chi-square test (តេស្តស្ថិតិ Chi-square) វិធីសាស្ត្រវិភាគស្ថិតិដែលគេប្រើប្រាស់ជាទូទៅក្នុងការស្រាវជ្រាវ ដើម្បីពិនិត្យមើលថាតើអថេរពីរ (ឧទាហរណ៍ ការមានប័ណ្ណក្រីក្រ និងការជាប់បំណុល) ពិតជាមានទំនាក់ទំនងពាក់ព័ន្ធគ្នាយ៉ាងជាក់លាក់ ឬគ្រាន់តែជារឿងចៃដន្យ។ ដូចជាការយកទិន្នន័យមកថ្លឹងថ្លែងតាមរូបមន្តគណិតវិទ្យា ដើម្បីបញ្ជាក់ថាតើអ្នកញ៉ាំផ្អែមច្រើន និងអ្នកកើតជំងឺទឹកនោមផ្អែម ពិតជាមានទំនាក់ទំនងគ្នាជាប់លាប់ឬក៏អត់។
