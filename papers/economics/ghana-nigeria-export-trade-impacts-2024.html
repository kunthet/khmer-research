១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការសិក្សានេះមានគោលបំណងវាយតម្លៃពីផលប៉ះពាល់នៃពាណិជ្ជកម្មនាំចេញរវាងប្រទេសហ្គាណា និងនីហ្សេរីយ៉ា ទៅលើកំណើនសេដ្ឋកិច្ចជាតិ និងផលិតផលក្នុងស្រុកសរុប (GDP) របស់ប្រទេសហ្គាណា។

វិធីសាស្ត្រ (The Methodology)៖ ការស្រាវជ្រាវនេះបានប្រើប្រាស់ទិន្នន័យស៊េរីពេលវេលា (Time series) ពីធនាគារពិភពលោក និងតារាងទិន្នន័យពីអង្គការ OECD ដើម្បីធ្វើការវិភាគតាមគំរូសេដ្ឋកិច្ចកម្រិតម៉ាក្រូ។

  • ការវិភាគធាតុចូល-លទ្ធផល (Input-Output Analysis) ដោយប្រើប្រាស់តារាងឆ្នាំ ២០១៨ របស់ OECD
  • វិធីសាស្ត្រសាកល្បង Autoregressive Distributed Lag (ARDL) bound testing
  • ស្ថិតិពិពណ៌នាលើទិន្នន័យសូចនាករអភិវឌ្ឍន៍ពិភពលោក (WDI)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • កំណើន ១% នៃការនាំចេញរវាងហ្គាណា និងនីហ្សេរីយ៉ា នាំឱ្យ GDP ជាក់ស្តែងរបស់ហ្គាណាកើនឡើង ០,១០១៧% ក្នុងរយៈពេលវែង។
  • ល្បឿននៃការកែតម្រូវ (Speed of adjustment) ឆ្ពោះទៅរកតុល្យភាពសេដ្ឋកិច្ចរយៈពេលវែងដំណើរការក្នុងអត្រា ៤២,១៨% ក្នុងមួយរយៈពេល។
  • ផលប៉ះពាល់សរុបតាមរយៈទំនាក់ទំនងនៃវិស័យកសិកម្ម និងកម្មន្តសាលមានទំហំចន្លោះពី ១៥១,៥៨៥ ទៅ ១៩០,១៣៩ លានសេឌី ក្នុងឆ្នាំ ២០១៧ និង ២០១៨។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Input-Output (I-O) Analysis
ការវិភាគធាតុចូល-លទ្ធផល		 អាចវាយតម្លៃផលប៉ះពាល់ទាំងដោយប្រយោល និងដោយផ្ទាល់ទៅលើគ្រប់វិស័យសេដ្ឋកិច្ច។ ផ្តល់រូបភាពច្បាស់លាស់ពីទំនាក់ទំនងអន្តរវិស័យ (Backward/Forward linkages) នៅក្នុងខ្សែសង្វាក់ផលិតកម្ម។ ទាមទារទិន្នន័យតារាង I-O ដែលមានភាពស្មុគស្មាញ និងចំណាយពេលយូរក្នុងការចងក្រង ហើយជាទូទៅមិនត្រូវបានធ្វើបច្ចុប្បន្នភាពរៀងរាល់ឆ្នាំនោះទេ (ឧទាហរណ៍ ប្រើទិន្នន័យឆ្នាំ២០១៨)។ កំណត់បានថាវិស័យកសិកម្ម និងកម្មន្តសាលមានឥទ្ធិពលសរុបរហូតដល់ ១៩០,១៣៩ លានសេឌី (cedis) ក្នុងឆ្នាំ២០១៨ និងបង្ហាញពីកម្រិតនៃការសាយភាយឥទ្ធិពលក្នុងសេដ្ឋកិច្ច។
Autoregressive Distributed Lag (ARDL) Bound Testing Model
គំរូសាកល្បង ARDL (ការតម្រែតម្រង់ដោយស្វ័យប្រវត្តិជាមួយការពន្យារពេលចែកចាយ)		 មានភាពបត់បែនខ្ពស់ និងស័ក្តិសមបំផុតសម្រាប់ទិន្នន័យស៊េរីពេលវេលា (Time Series) ដែលមានកម្រិតថេរចម្រុះ [I(0) និង I(1)] ព្រមទាំងអាចវាស់ស្ទង់ទំនាក់ទំនងទាំងរយៈពេលខ្លី និងវែង។ មិនអាចប្រើប្រាស់បានទេប្រសិនបើទិន្នន័យមានកម្រិតថេរលំដាប់ទី២ [I(2)] ឬខ្ពស់ជាងនេះ ហើយត្រូវការទិន្នន័យស៊េរីពេលវេលាដែលមានប្រវែងគ្រប់គ្រាន់ដើម្បីឱ្យលទ្ធផលត្រឹមត្រូវ។ រកឃើញថាកំណើន ១% នៃការនាំចេញផ្តល់កំណើន ០,១០១៧% ដល់ GDP ក្នុងរយៈពេលវែង ដោយមានល្បឿននៃការកែតម្រូវរកតុល្យភាពវិញក្នុងអត្រា ៤២,១៨% ក្នុងមួយរយៈពេល។

ការចំណាយលើធនធាន (Resource Cost)៖ ការអនុវត្តវិធីសាស្ត្រក្នុងការសិក្សានេះពឹងផ្អែកជាចម្បងលើទិន្នន័យម៉ាក្រូសេដ្ឋកិច្ចលម្អិត និងកម្មវិធីកុំព្យូទ័រផ្នែកស្ថិតិ ដោយមិនទាមទារឧបករណ៍ផ្នែករឹងកម្រិតខ្ពស់នោះទេ។

  • Software: កម្មវិធី EViews សម្រាប់ការវិភាគស៊េរីពេលវេលា (ARDL) និងកម្មវិធីគណនាម៉ាទ្រីសដូចជា Microsoft Excel, R ឬ Python សម្រាប់ការគណនា Leontief inverse matrix ក្នុងគំរូ I-O។
  • Dataset: ទិន្នន័យម៉ាក្រូសេដ្ឋកិច្ចដូចជា GDP, អត្រាកំណើននៃការនាំចេញ, អតិផរណា ពីធនាគារពិភពលោក (WDI) និងតារាង I-O ពីអង្គការ OECD ឬស្ថាប័នស្ថិតិជាតិ។
  • Expertise: អ្នកស្រាវជ្រាវត្រូវមានចំណេះដឹងស៊ីជម្រៅផ្នែក Econometrics (ការធ្វើតេស្ត Stationarity, Cointegration) និងទ្រឹស្តីសេដ្ឋកិច្ចកម្រិតម៉ាក្រូ។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងដោយផ្តោតលើពាណិជ្ជកម្មទ្វេភាគីរវាងប្រទេសហ្គាណា និងនីហ្សេរីយ៉ា ដែលស្ថិតនៅតំបន់អាហ្វ្រិកអនុសាហារ៉ា ដោយប្រើប្រាស់ទិន្នន័យតាមពេលវេលាពីស្ថាប័នអន្តរជាតិ។ ទោះបីជាបរិបទភូមិសាស្ត្រខុសគ្នា ប៉ុន្តែទម្រង់សេដ្ឋកិច្ចរបស់ប្រទេសកំពុងអភិវឌ្ឍន៍ដែលពឹងផ្អែកលើការនាំចេញផលិតផលកសិកម្ម និងធនធានធម្មជាតិគឺមានភាពស្រដៀងគ្នាខ្លាំងទៅនឹងកម្ពុជា។ បញ្ហានៃការប្រើប្រាស់ទិន្នន័យ I-O ឆ្នាំចាស់ (២០១៨) ក៏ជាបញ្ហាប្រឈមទូទៅនៅក្នុងប្រទេសកំពុងអភិវឌ្ឍន៍រួមទាំងកម្ពុជា ដែលទាមទារការប្រុងប្រយ័ត្នពេលបកស្រាយលទ្ធផលក្នុងបរិបទបច្ចុប្បន្ន។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រ និងការរកឃើញនៅក្នុងឯកសារនេះមានតម្លៃជាយុទ្ធសាស្ត្រយ៉ាងខ្លាំងសម្រាប់អ្នករៀបចំគោលនយោបាយ និងអ្នកស្រាវជ្រាវសេដ្ឋកិច្ចនៅកម្ពុជា។

  • ពាណិជ្ជកម្មកសិកម្មកម្ពុជា-តំបន់ (Cambodia-Regional Agricultural Trade): គំរូ ARDL នេះអាចត្រូវបានអនុវត្តផ្ទាល់ដើម្បីវាស់ស្ទង់ឥទ្ធិពលនៃការនាំចេញកសិផលរបស់កម្ពុជា (ដូចជា ស្រូវ ដំឡូងមី ស្វាយចន្ទី) ទៅកាន់ប្រទេសជិតខាងដូចជា វៀតណាម និងថៃ ថាតើវាជះឥទ្ធិពលកម្រិតណាដល់ GDP រយៈពេលវែងរបស់កម្ពុជា។
  • យុទ្ធសាស្ត្រអភិវឌ្ឍន៍វិស័យកម្មន្តសាលនៅកម្ពុជា: ក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ អាចប្រើប្រាស់ការវិភាគ I-O Analysis (Forward/Backward Linkages) ដើម្បីកំណត់អត្តសញ្ញាណថា តើការវិនិយោគក្នុងតំបន់សេដ្ឋកិច្ចពិសេស (SEZ) ណាមួយ ដែលមានឥទ្ធិពលសាយភាយ (Multiplier effect) ខ្ពស់បំផុតដល់សេដ្ឋកិច្ចជាតិ។

សរុបមក ការអនុវត្តវិធីសាស្ត្រស្រាវជ្រាវនេះនឹងជួយពង្រឹងការសម្រេចចិត្តផ្អែកលើទិន្នន័យ (Data-driven policymaking) សម្រាប់ការចរចាពាណិជ្ជកម្មសេរី និងរៀបចំយុទ្ធសាស្ត្រកំណើនសេដ្ឋកិច្ចរបស់កម្ពុជា។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃ Econometrics សម្រាប់ស៊េរីពេលវេលា: និស្សិតត្រូវចាប់ផ្តើមរៀនពីមូលដ្ឋានគ្រឹះនៃ Time Series Analysis ជាពិសេសការធ្វើតេស្ត Unit Root Test (ADF) និង Cointegration ដោយប្រើប្រាស់ EViews ឬ R (urca package) ដើម្បីស្វែងយល់ពីលក្ខណៈនៃទិន្នន័យ។
  2. ប្រមូលទិន្នន័យម៉ាក្រូសេដ្ឋកិច្ចកម្ពុជា: ស្វែងរក និងទាញយកទិន្នន័យ I-O Table របស់កម្ពុជាពីគេហទំព័រ ADB (Asian Development Bank) រួមជាមួយទិន្នន័យសេដ្ឋកិច្ចម៉ាក្រូពី World Bank Open Data និង National Institute of Statistics (NIS) របស់ប្រទេសកម្ពុជា។
  3. អនុវត្តការវិភាគធាតុចូល-លទ្ធផល (I-O Analysis): រៀនពីរបៀបគណនា Leontief Inverse Matrix និងសន្ទស្សន៍ Multipliers សម្រាប់វាស់ស្ទង់ Backward និង Forward Linkages ដោយប្រើប្រាស់ Microsoft Excel ឬ Python (NumPy និង Pandas packages) ដើម្បីកំណត់វិស័យដែលមានសក្តានុពល។
  4. កសាងគំរូ ARDL សម្រាប់តេស្តគោលនយោបាយសេដ្ឋកិច្ច: ប្រើប្រាស់កម្មវិធី EViews ឬ Stata ដើម្បីកសាង និងដំណើរការគំរូ ARDL Bounds Test រកទំនាក់ទំនងរយៈពេលខ្លី និងវែង រវាងបរិមាណនាំចេញរបស់កម្ពុជានិងកំណើនសេដ្ឋកិច្ច រួចសរសេររបាយការណ៍ផ្តល់អនុសាសន៍។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Input-Output (I-O) Analysis (ការវិភាគធាតុចូល-លទ្ធផល) វិធីសាស្ត្រគណិតវិទ្យាក្នុងការវិភាគម៉ាក្រូសេដ្ឋកិច្ច ដែលប្រើប្រាស់តារាងម៉ាទ្រីសដើម្បីបង្ហាញពីភាពអាស្រ័យគ្នារវាងវិស័យផ្សេងៗនៃសេដ្ឋកិច្ចជាតិ ថាតើលទ្ធផលផលិតកម្មនៃវិស័យមួយបានក្លាយជាធាតុចូលនៃវិស័យមួយទៀតយ៉ាងដូចម្តេច។ ដូចជាការមើលរូបមន្តធ្វើនំដែលបង្ហាញថាម្សៅពីម៉ាស៊ីនកិនស្រូវ ក្លាយជាវត្ថុធាតុដើមផ្ទាល់សម្រាប់ហាងនំប៉័ង ហើយហាងនំប៉័ងលក់នំទៅឱ្យកម្មកររោងម៉ាស៊ីនកិនស្រូវវិញ។
Autoregressive Distributed Lag (ARDL) bound testing (ការធ្វើតេស្តសាកល្បង ARDL) ជាគំរូស្ថិតិសេដ្ឋកិច្ច (Econometric model) ដែលត្រូវបានប្រើសម្រាប់វិភាគ និងវាស់ស្ទង់ទំនាក់ទំនងសេដ្ឋកិច្ចទាំងរយៈពេលខ្លី និងរយៈពេលវែងរវាងអថេរ (ដូចជាការនាំចេញ និង GDP) ទោះបីជាទិន្នន័យទាំងនោះមានកម្រិតថេរ (stationarity) លាយឡំគ្នា [I(0) និង I(1)] ក៏ដោយ។ ដូចជាការតាមដានមើលថាតើការហាត់ប្រាណថ្ងៃនេះ (រយៈពេលខ្លី) និងការហាត់ប្រាណប្រចាំខែ (រយៈពេលវែង) ជះឥទ្ធិពលរួមគ្នាដល់សុខភាពរបស់អ្នកយ៉ាងដូចម្តេចខ្លះ។
Backward Linkage (ទំនាក់ទំនងខ្សែសង្វាក់ថយក្រោយ) យន្តការសេដ្ឋកិច្ចដែលបង្ហាញពីការដែលកំណើននៃវិស័យមួយ បានជំរុញកំណើនដល់វិស័យផ្សេងទៀតដែលផ្គត់ផ្គង់វត្ថុធាតុដើមឱ្យខ្លួន។ ឧទាហរណ៍ កំណើនការនាំចេញភេសជ្ជៈ ជំរុញឱ្យមានតម្រូវការទិញស្ករ និងផ្លែឈើកើនឡើងពីវិស័យកសិកម្ម។ ដូចជាពេលភោជនីយដ្ឋានមានភ្ញៀវច្រើន ពួកគេត្រូវទិញបន្លែ និងសាច់កាន់តែច្រើន ដែលធ្វើឱ្យកសិករ និងអ្នកលក់នៅផ្សារលក់ដាច់តាមហ្នឹងដែរ។
Forward Linkage (ទំនាក់ទំនងខ្សែសង្វាក់ទៅមុខ) យន្តការសេដ្ឋកិច្ចដែលបង្ហាញពីការដែលផលិតផលកើនឡើងនៃវិស័យមួយ បានជំរុញកំណើនដល់វិស័យផ្សេងទៀតដែលយកផលិតផលរបស់ខ្លួនទៅកែច្នៃ ឬប្រើប្រាស់បន្ត។ ឧទាហរណ៍ កំណើនក្នុងវិស័យកសិកម្ម ផ្តល់វត្ថុធាតុដើមថោក និងច្រើនសម្រាប់រោងចក្រកែច្នៃម្ហូបអាហារ។ ដូចជារោងម៉ាស៊ីនកិនស្រូវផលិតអង្ករបានច្រើននិងថោក ធ្វើឱ្យរោងចក្រផលិតនំស្រួយមានវត្ថុធាតុដើមគ្រប់គ្រាន់ដើម្បីពង្រីកផលិតកម្មរបស់ខ្លួន។
Leontief inverse matrix (ម៉ាទ្រីសច្រាសឡេអុងទីវ) រូបមន្តគណិតវិទ្យាក្នុងការវិភាគ Input-Output ដែលវាស់ស្ទង់ផលប៉ះពាល់សរុប (ទាំងផ្ទាល់ និងប្រយោល) ទៅលើគ្រប់វិស័យទាំងអស់នៅក្នុងសេដ្ឋកិច្ច នៅពេលមានការផ្លាស់ប្តូរតម្រូវការចុងក្រោយមួយឯកតា (ឧទាហរណ៍ ការកើនឡើងការនាំចេញ ១ដុល្លារ)។ ដូចជាការប្រើម៉ាស៊ីនគិតលេខពិសេសដើម្បីទស្សន៍ទាយថាតើការបញ្ជាទិញឡានមួយគ្រឿង នឹងបង្កើតការងារនិងចំណូលប៉ុន្មានកន្លែងទាំងនៅក្នុងរោងចក្រផលិតកង់ រោងចក្រដែក និងរោងចក្រកញ្ចក់។
Cointegration (សមាហរណកម្មកាក់កប ឬ តុល្យភាពរយៈពេលវែង) លក្ខណៈផ្នែកស្ថិតិសេដ្ឋកិច្ចដែលបញ្ជាក់ថាអថេរពីរ ឬច្រើន (ទោះបីជាងាករេចុះឡើងមិនទៀងទាត់ក្នុងរយៈពេលខ្លី) មានទំនាក់ទំនងចងភ្ជាប់គ្នា និងផ្លាស់ទីស្របគ្នាក្នុងទិសដៅតែមួយប្រកបដោយតុល្យភាពក្នុងរយៈពេលវែង។ ដូចជាម្ចាស់ និងសត្វឆ្កែដែលដើរលេងជាមួយគ្នា ទោះឆ្កែរត់ចុះរត់ឡើងឆ្វេងស្តាំ (រយៈពេលខ្លី) តែទីបំផុតវាត្រូវចងដោយខ្សែ និងធ្វើដំណើរទៅកាន់គោលដៅតែមួយជាមួយម្ចាស់ (រយៈពេលវែង)។
Error Correction Model / ECM (គំរូកែតម្រូវកំហុស) យន្តការគណិតវិទ្យានៅក្នុងគំរូសេដ្ឋកិច្ច (ជាពិសេស ARDL) ដែលវាស់ស្ទង់ពីល្បឿននៃការកែតម្រូវរបស់ប្រព័ន្ធសេដ្ឋកិច្ច ត្រឡប់មករកតុល្យភាពរយៈពេលវែងវិញ បន្ទាប់ពីមានការប៉ះទង្គិច (Shock) ឬគម្លាតណាមួយក្នុងរយៈពេលខ្លី។ ដូចជាទែម៉ូស្តាត (Thermostat) ក្នុងម៉ាស៊ីនត្រជាក់ ដែលវាស់ថាតើសីតុណ្ហភាពខុសពីការកំណត់ប៉ុន្មាន រួចកែតម្រូវល្បឿនម៉ាស៊ីនត្រជាក់ដើម្បីឱ្យសីតុណ្ហភាពបន្ទប់ត្រឡប់មកធម្មតាវិញយ៉ាងលឿន។
Power of Dispersion Index / PDI (សន្ទស្សន៍អំណាចនៃការសាយភាយ) រង្វាស់នៅក្នុងការវិភាគ I-O ដែលបង្ហាញថាតើបម្រែបម្រួលនៃតម្រូវការនៅក្នុងវិស័យមួយ មានឥទ្ធិពលរុញច្រាន ឬសាយភាយ (Backward linkages) ខ្លាំងប៉ុនណាទៅលើគ្រប់វិស័យដទៃទៀតជារួម។ ដូចជាការគប់ដុំថ្មចូលក្នុងផ្ទៃទឹក សន្ទស្សន៍ PDI គឺជារង្វាស់ទំហំរលកទឹកដែលសាយភាយចេញពីចំណុចកណ្តាលទៅកាន់ផ្ទៃទឹកជុំវិញ។
