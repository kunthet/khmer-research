១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការសិក្សានេះវាយតម្លៃថាតើកត្តាហានិភ័យទីផ្សារមានឥទ្ធិពលយ៉ាងណាទៅលើដំណើរការហិរញ្ញវត្ថុរបស់ក្រុមហ៊ុនម្ហូបអាហារ និងភេសជ្ជៈដែលបានចុះបញ្ជីនៅប្រទេសវៀតណាម ក្នុងបរិបទនៃការប្រែប្រួលសេដ្ឋកិច្ចនិងអតិផរណា។

វិធីសាស្ត្រ (The Methodology)៖ ការស្រាវជ្រាវនេះបានអនុវត្តការវិភាគទិន្នន័យបន្ទះ (Panel data analysis) ដោយប្រៀបធៀបគំរូសេដ្ឋកិច្ចមាត្រចំនួនបីផ្សេងគ្នាដើម្បីវាស់ស្ទង់ទំនាក់ទំនងរវាងហានិភ័យនិងប្រាក់ចំណេញ។

  • ការប្រមូលទិន្នន័យបន្ទះ (Panel Data Collection) ពីក្រុមហ៊ុនចំនួន ៤៧ ក្នុងចន្លោះឆ្នាំ ២០០៨ ដល់ ២០២២ ស្មើនឹង ៧០០ សង្កេតកាល។
  • ការធ្វើតេស្តសម្មតិកម្មដោយប្រើប្រាស់គំរូ Ordinary Least Squares (OLS), Fixed Effect Model (FEM), និង Random Effect Model (REM)។
  • ការប្រើប្រាស់ Hausman test ដើម្បីកំណត់យកគំរូ REM ជាមួយនឹង Robust standard errors ថាជាវិធីសាស្ត្រដែលស័ក្តិសមបំផុត។

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • កម្រិតអានុភាពហិរញ្ញវត្ថុ (Degree of financial leverage) និងអត្រាអតិផរណាមានឥទ្ធិពលវិជ្ជមានទៅលើទិន្នផលលើទ្រព្យសកម្ម (ROA) និងរឹមប្រាក់ចំណេញសុទ្ធ (Net profit margin)។
  • អនុបាតតម្លៃសៀវភៅធៀបនឹងតម្លៃទីផ្សារ (Book-to-market ratio) បង្ហាញពីការជះឥទ្ធិពលអវិជ្ជមានយ៉ាងសំខាន់ ដែលធ្វើឱ្យ ROA ធ្លាក់ចុះ ០.០១០% សម្រាប់រាល់ការកើនឡើង ១%។
  • អនុបាតសាច់ប្រាក់ (Cash ratio) និងទំហំក្រុមហ៊ុន (Company size) មានទំនាក់ទំនងស្របគ្នាទៅនឹងដំណើរការហិរញ្ញវត្ថុ ខណៈអនុបាតបំណុលធៀបនឹងប្រាក់ចំណូលមានទំនាក់ទំនងច្រាស។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Ordinary Least Squares (OLS) Model
គំរូការ៉េអប្បបរមាធម្មតា		 ងាយស្រួលយល់ និងជាវិធីសាស្ត្រមូលដ្ឋានគ្រឹះដ៏ល្អសម្រាប់ការចាប់ផ្តើមវិភាគទំនាក់ទំនងរវាងអថេរ។ មិនបានគិតបញ្ចូលនូវលក្ខណៈពិសេស ឬភាពខុសគ្នារវាងក្រុមហ៊ុននីមួយៗ ដែលអាចនាំឱ្យមានលម្អៀងក្នុងលទ្ធផលប្រសិនបើមាន Heteroskedasticity។ ត្រូវបានប្រើជាគំរូគោល ប៉ុន្តែត្រូវបានច្រានចោលបន្ទាប់ពីធ្វើតេស្ត Breusch-Pagan LM ដោយសារតែវាមានភាពមិនប្រក្រតីនៃវ៉ារ្យ៉ង់ (Heteroskedasticity)។
Fixed Effect Model (FEM)
គំរូឥទ្ធិពលថេរ		 អាចគ្រប់គ្រងលើអថេរដែលមិនអាចសង្កេតបាន និងមានលក្ខណៈថេរតាមពេលវេលាសម្រាប់ក្រុមហ៊ុននីមួយៗ ជួយកាត់បន្ថយការលម្អៀង។ មិនស័ក្តិសមប្រសិនបើអថេរឯករាជ្យមិនមានការប្រែប្រួលច្រើនតាមពេលវេលា ហើយមិនអាចប៉ាន់ស្មានឥទ្ធិពលនៃអថេរដែលថេរតាមពេលវេលាបានទេ។ មិនត្រូវបានជ្រើសរើសសម្រាប់ការសិក្សានេះទេ ដោយសារតែលទ្ធផលនៃ Hausman Test បង្ហាញពីតម្លៃ P-value ធំជាងកម្រិតអត្ថន័យដែលបានកំណត់។
Random Effect Model (REM) with Robust Standard Errors
គំរូឥទ្ធិពលចៃដន្យ ជាមួយនឹងកំហុសស្តង់ដាររឹងមាំ		 អនុញ្ញាតឱ្យមានការសន្និដ្ឋានទូលំទូលាយសម្រាប់ចំនួនប្រជាជនគោលដៅទាំងមូល និងត្រូវបានកែសម្រួលដើម្បីដោះស្រាយបញ្ហា Heteroskedasticity ប្រកបដោយប្រសិទ្ធភាព។ ទាមទារការសន្មត់ដ៏តឹងរ៉ឹងថា មិនមានទំនាក់ទំនងរវាងកំហុសចៃដន្យរបស់ក្រុមហ៊ុននីមួយៗ និងអថេរពន្យល់ (Explanatory variables) នោះទេ។ ជាគំរូដែលត្រូវបានជ្រើសរើសចុងក្រោយ ដោយបង្ហាញថា កម្រិតអានុភាពហិរញ្ញវត្ថុ និងអតិផរណាមានឥទ្ធិពលវិជ្ជមាន ខណៈអនុបាត Book-to-market ជះឥទ្ធិពលអវិជ្ជមានទៅលើដំណើរការហិរញ្ញវត្ថុ។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះពឹងផ្អែកជាចម្បងលើទិន្នន័យបន្ទះ (Panel Data) ពីរបាយការណ៍ហិរញ្ញវត្ថុ និងកម្មវិធីកុំព្យូទ័រសម្រាប់ដំណើរការវិភាគសេដ្ឋកិច្ចមាត្រ។

  • Software: ទាមទារកម្មវិធីវិភាគស្ថិតិដូចជា Stata, R, ឬ EViews សម្រាប់ដំណើរការតេស្ត OLS, FEM, REM, Hausman និង LM Test។
  • Dataset: ទិន្នន័យហិរញ្ញវត្ថុប្រវត្តិសាស្ត្ររបស់ក្រុមហ៊ុនចំនួន ៤៧ ក្នុងរយៈពេល ១៥ឆ្នាំ (២០០៨-២០២២) ដែលត្រូវទាញយកពីផ្សារមូលបត្រ (HOSE និង HNX)។
  • Expertise: ចំណេះដឹងស៊ីជម្រៅផ្នែកសេដ្ឋកិច្ចមាត្រ (Econometrics) ហិរញ្ញវត្ថុសាជីវកម្ម និងការបកស្រាយរបាយការណ៍ហិរញ្ញវត្ថុ។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះប្រមូលទិន្នន័យផ្តាច់មុខពីក្រុមហ៊ុនម្ហូបអាហារ និងភេសជ្ជៈធំៗដែលបានចុះបញ្ជីនៅលើផ្សារមូលបត្រវៀតណាម ក្នុងរយៈពេលនៃការរីកចម្រើនសេដ្ឋកិច្ច និងវិបត្តិ COVID-19។ លទ្ធផលនេះអាចមានភាពលម្អៀងទៅរកក្រុមហ៊ុនខ្នាតធំដែលមានរចនាសម្ព័ន្ធហិរញ្ញវត្ថុរឹងមាំ និងងាយស្រួលទទួលបានទុនពីទីផ្សារ។ សម្រាប់ប្រទេសកម្ពុជា ដែលវិស័យចំណីអាហារភាគច្រើនគ្រប់គ្រងដោយសហគ្រាសធុនតូចនិងមធ្យម (SMEs) ការអនុវត្តអថេរទាំងនេះត្រូវធ្វើការសម្របសម្រួលទៅតាមទំហំទីផ្សារ និងកម្រិតនៃការទទួលបានឥណទានក្នុងស្រុក។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

ទោះបីជាបរិបទទីផ្សារមូលបត្រវៀតណាមមានទំហំធំជាងកម្ពុជាក្តី ប៉ុន្តែវិធីសាស្ត្រនិងអថេរដែលប្រើប្រាស់ក្នុងការសិក្សានេះមានតម្លៃយ៉ាងខ្លាំងសម្រាប់ការវាយតម្លៃសុខភាពហិរញ្ញវត្ថុនៅកម្ពុជា។

  • ផ្សារមូលបត្រកម្ពុជា (CSX): អ្នកវិភាគនិងវិនិយោគិននៅផ្សារមូលបត្រកម្ពុជា អាចប្រើប្រាស់គំរូ REM នេះដើម្បីវាយតម្លៃហានិភ័យទីផ្សាររបស់ក្រុមហ៊ុនក្នុងស្រុក និងធ្វើការសម្រេចចិត្តវិនិយោគដោយផ្អែកលើអនុបាតចំណេញ (ROA, ROE) និងកម្រិតអានុភាពហិរញ្ញវត្ថុ។
  • សហគ្រាសធុនតូច និងមធ្យម (SMEs) ក្នុងវិស័យចំណីអាហារ: ម្ចាស់អាជីវកម្មនៅកម្ពុជាអាចរៀនសូត្រពីរបៀបគ្រប់គ្រងអនុបាតបំណុលធៀបនឹងប្រាក់ចំណូល (Debt-to-revenue) និងសារៈសំខាន់នៃការរក្សាសាច់ប្រាក់អប្បបរមា ដើម្បីទប់ទល់នឹងហានិភ័យអតិផរណា ឬការធ្លាក់ចុះសេដ្ឋកិច្ច។
  • ស្ថាប័នហិរញ្ញវត្ថុ និងធនាគារពាណិជ្ជ: ធនាគារក្នុងស្រុកអាចប្រើប្រាស់កត្តាដែលបានបង្ហាញក្នុងឯកសារនេះ (ដូចជាសូចនាករហានិភ័យទីផ្សារ និងទំហំក្រុមហ៊ុន) ដើម្បីវាយតម្លៃហានិភ័យឥណទាន មុនពេលអនុម័តកម្ចីពាណិជ្ជកម្មដល់សហគ្រាសផ្នែកកសិ-ឧស្សាហកម្ម។

ជារួម ការសិក្សានេះផ្តល់នូវក្របខណ្ឌវាយតម្លៃហានិភ័យដ៏រឹងមាំមួយ ដែលអ្នកស្រាវជ្រាវ និងភាគីពាក់ព័ន្ធនៅកម្ពុជាអាចយកទៅអនុវត្តដើម្បីបង្កើនភាពធន់ និងប្រសិទ្ធភាពប្រាក់ចំណេញរបស់ក្រុមហ៊ុននានាក្នុងបរិបទសេដ្ឋកិច្ចមិនប្រាកដប្រជា។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះសេដ្ឋកិច្ចមាត្រ និងហិរញ្ញវត្ថុសាជីវកម្ម: និស្សិតត្រូវស្វែងយល់ឱ្យបានច្បាស់អំពីអថេរហិរញ្ញវត្ថុដូចជា ទិន្នផលលើទ្រព្យសកម្ម (ROA), ទិន្នផលលើមូលធន (ROE) និងកម្រិតអានុភាពហិរញ្ញវត្ថុ (DFL) ដោយប្រើប្រាស់សៀវភៅសិក្សា ឬវគ្គសិក្សាតាមអ៊ីនធឺណិត។
  2. ប្រមូល និងសម្អាតទិន្នន័យបន្ទះ (Panel Data): ប្រមូលទិន្នន័យហិរញ្ញវត្ថុប្រចាំឆ្នាំរបស់ក្រុមហ៊ុនដែលបានចុះបញ្ជីនៅលើផ្សារមូលបត្រ CSX ឬទិន្នន័យពីធនាគារជាតិកម្ពុជា NBC រួចរៀបចំទិន្នន័យជាទម្រង់ Panel data ដោយប្រើកម្មវិធី Microsoft Excel។
  3. អនុវត្តការវិភាគសេដ្ឋកិច្ចមាត្រ: នាំចូលទិន្នន័យទៅកាន់កម្មវិធីវិភាគដូចជា Stata ឬ R Studio រួចដំណើរការកូដដើម្បីបង្កើតគំរូ OLS Model, Fixed Effect Model, និង Random Effect Model។
  4. ធ្វើតេស្តរោគវិនិច្ឆ័យ (Diagnostic Tests): ដំណើរការ Hausman Test ដើម្បីសម្រេចជ្រើសរើសរវាង FEM និង REM និងធ្វើតេស្ត Breusch-Pagan LM Test ដើម្បីត្រួតពិនិត្យភាពប្រែប្រួលនៃវ៉ារ្យ៉ង់ (Heteroskedasticity) មុននឹងសម្រេចយកគំរូចុងក្រោយដែលមាន Robust Standard Errors។
  5. បកស្រាយលទ្ធផល និងទាញយកអនុសាសន៍: បំប្លែងលទ្ធផលនៃមេគុណ (Coefficients) និងកម្រិតអត្ថន័យ (P-values) ទៅជាយុទ្ធសាស្ត្រអាជីវកម្មជាក់ស្តែង ឧទាហរណ៍ដូចជាការណែនាំក្រុមហ៊ុនឱ្យកាត់បន្ថយបំណុល ឬការផ្លាស់ប្តូររចនាសម្ព័ន្ធដើមទុនជាដើម។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Degree of financial leverage (DFL) (កម្រិតអានុភាពហិរញ្ញវត្ថុ) ជារង្វាស់ដែលបង្ហាញពីកម្រិតនៃការប្រើប្រាស់បំណុល (ការប្រាក់ថេរ) របស់ក្រុមហ៊ុនដើម្បីបង្កើតប្រាក់ចំណេញប្រតិបត្តិការ។ វាបង្ហាញពីភាពរសើបនៃប្រាក់ចំណេញក្នុងមួយហ៊ុនទៅនឹងការប្រែប្រួលនៃប្រាក់ចំណេញមុនការប្រាក់និងពន្ធ។ ដូចជាការប្រើប្រាស់ដងថ្លឹងដើម្បីលើកវត្ថុធ្ងន់ៗ បើយើងខ្ចីលុយគេមកវិនិយោគបានចំណេញ នោះយើងនឹងចំណេញកាន់តែច្រើន តែបើខាតក៏ខាតធ្ងន់ធ្ងរដែរ។
Book to market ratio (BPR) (អនុបាតតម្លៃសៀវភៅធៀបនឹងតម្លៃទីផ្សារ) គឺជាអនុបាតដែលប្រៀបធៀបតម្លៃទ្រព្យសកម្មសុទ្ធរបស់ក្រុមហ៊ុនដែលបានកត់ត្រាក្នុងបញ្ជីគណនេយ្យ (តម្លៃសៀវភៅ) ជាមួយនឹងតម្លៃក្រុមហ៊ុនដែលកំពុងចរាចរទិញលក់លើទីផ្សារភាគហ៊ុន (តម្លៃទីផ្សារ)។ ដូចជាការប្រៀបធៀបតម្លៃដើមនៃផ្ទះមួយដែលអ្នកបានសាងសង់ ជាមួយនឹងតម្លៃដែលអ្នកទិញហ៊ានឱ្យនៅលើទីផ្សារបច្ចុប្បន្ន។
Gearing ratio (GEAR) (អនុបាតអានុភាព ឬ អនុបាតបំណុល) ជារង្វាស់ហិរញ្ញវត្ថុដែលប្រៀបធៀបទំហំបំណុលសរុបរបស់ក្រុមហ៊ុនទៅនឹងមូលធនសរុប (ទុនម្ចាស់ហ៊ុន) ដើម្បីវាយតម្លៃហានិភ័យហិរញ្ញវត្ថុនិងរចនាសម្ព័ន្ធដើមទុន។ ដូចជាការថ្លឹងថ្លែងថាតើក្នុងអាជីវកម្មមួយ មានលុយខ្លួនឯង (ដើមទុន) ប៉ុន្មាន និងមានលុយជំពាក់គេប៉ុន្មាន។
Panel data (ទិន្នន័យបន្ទះ) ជាប្រភេទឈុតទិន្នន័យដែលរួមបញ្ចូលទាំងទិន្នន័យកាត់ទទឹង (Cross-sectional) និងទិន្នន័យតាមពេលវេលា (Time-series) ពោលគឺការតាមដានអង្គភាព ឬក្រុមហ៊ុនដដែលៗ ក្នុងរយៈពេលជាច្រើនឆ្នាំជាបន្តបន្ទាប់។ ដូចជាការថតរូបសិស្សម្នាក់ៗក្នុងថ្នាក់ជារៀងរាល់ឆ្នាំតាំងពីថ្នាក់ទី១ ដល់ទី១២ ដើម្បីតាមដានការលូតលាស់របស់ពួកគេម្នាក់ៗផង និងប្រៀបធៀបរវាងសិស្សផ្សេងៗគ្នាផង។
Random effect model (REM) (គំរូឥទ្ធិពលចៃដន្យ) ជាគំរូស្ថិតិក្នុងសេដ្ឋកិច្ចមាត្រសម្រាប់វិភាគទិន្នន័យបន្ទះ ដែលសន្មតថាភាពខុសគ្នារវាងអង្គភាពនីមួយៗ (ឧ. ក្រុមហ៊ុន) គឺចៃដន្យ និងមិនមានទំនាក់ទំនងជាមួយអថេរពន្យល់នៅក្នុងគំរូនោះទេ។ ដូចជាការសន្និដ្ឋានថា កត្តាពិសេសៗរបស់សិស្សម្នាក់ៗ (ដូចជាហ្សែន ឬទេពកោសល្យពីកំណើត) គឺកើតឡើងដោយចៃដន្យ និងមិនពាក់ព័ន្ធនឹងម៉ោងដែលពួកគេខិតខំរៀនសូត្រនោះទេ។
Hausman test (ការធ្វើតេស្ត Hausman) ជាវិធីសាស្ត្រធ្វើតេស្តសម្មតិកម្មនៅក្នុងសេដ្ឋកិច្ចមាត្រ ដើម្បីជួយអ្នកស្រាវជ្រាវសម្រេចចិត្តថាត្រូវជ្រើសរើសប្រើប្រាស់គំរូឥទ្ធិពលថេរ (Fixed Effect) ឬគំរូឥទ្ធិពលចៃដន្យ (Random Effect) សម្រាប់ការវិភាគទិន្នន័យ។ ដូចជាឧបករណ៍វាស់កម្រិតទឹក ដែលប្រាប់ជាងសំណង់ថាតើគួរប្រើវិធីសាស្រ្តមួយណាទើបត្រឹមត្រូវបំផុតសម្រាប់បាតស៊ីម៉ងត៍នេះ។
Heteroskedasticity (ភាពមិនថេរនៃវ៉ារ្យ៉ង់ ឬ អេតេរ៉ូស្កេដាស្ទីស៊ីតេ) ជាបាតុភូតក្នុងស្ថិតិដែលបង្ហាញថាកម្រិតនៃការប្រែប្រួល (វ៉ារ្យ៉ង់) នៃកំហុសសំណល់ (Error terms) មិននៅថេរទេនៅពេលដែលតម្លៃនៃអថេរឯករាជ្យប្រែប្រួល ដែលអាចធ្វើឱ្យការប៉ាន់ស្មានលទ្ធផលមិនសុក្រឹត។ ដូចជាការបាញ់ព្រួញទៅកាន់ផ្ទាំងស៊ីប កាលណាយើងឈរកាន់តែឆ្ងាយ គម្លាតនៃគ្រាប់ព្រួញដែលខុសគោលដៅរាយប៉ាយកាន់តែធំទៅៗ មិននៅប្រមូលផ្តុំគ្នាដូចពេលឈរជិតនោះទេ។
Return on assets (ROA) (ទិន្នផលលើទ្រព្យសកម្ម) ជាសូចនាករវាស់ស្ទង់ប្រាក់ចំណេញរបស់ក្រុមហ៊ុនទាក់ទងនឹងទ្រព្យសកម្មសរុបរបស់វា ដែលបង្ហាញពីប្រសិទ្ធភាពរបស់ថ្នាក់ដឹកនាំក្នុងការប្រើប្រាស់ទ្រព្យសកម្មទាំងនោះដើម្បីបង្កើតប្រាក់ចំណូល។ ដូចជាការវាស់ស្ទង់ថាតើអ្នកបើកបរឡានឈ្នួលម្នាក់ អាចរកលុយបានប៉ុន្មានពីឡានមួយគ្រឿងដែលគាត់កំពុងប្រើប្រាស់រាល់ថ្ងៃ។
