២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Autoregressive Distributed Lag (ARDL) Model
គំរូ Autoregressive Distributed Lag (ARDL) សម្រាប់វិភាគទំនាក់ទំនងរយៈពេលខ្លី និងវែង		 អាចវិភាគទិន្នន័យដែលមានលក្ខណៈចម្រុះកម្រិត (I(0) និង I(1)) និងមានប្រសិទ្ធភាពខ្ពស់ក្នុងការកំណត់ទំនាក់ទំនងទាំងរយៈពេលខ្លីនិងរយៈពេលវែង។ វាស័ក្តិសមសម្រាប់ទំហំសំណាកតូច ឬមធ្យម។ មិនអាចប្រើប្រាស់បានទេ ប្រសិនបើមានអថេរណាមួយស្ថិតក្នុងកម្រិតស្ថិរភាព I(2)។ វាទាមទារឱ្យមានការកំណត់ Lag Length ត្រឹមត្រូវដើម្បីទទួលបានលទ្ធផលដែលមិនលម្អៀង។ ស្វែងរកឃើញទំនាក់ទំនងតុល្យភាពរយៈពេលវែង ដោយមានមេគុណកែតម្រូវកំហុស (Error Correction Coefficient) ស្មើនឹង -១,១៤ (សម្រាប់តួកគី) និង -០,៣២ (សម្រាប់អ៊ីរ៉ង់)។
Unit Root Tests (ADF and PP)
ការធ្វើតេស្តឫសឯកតា (Augmented Dickey-Fuller និង Phillips-Perron) ដើម្បីពិនិត្យស្ថិរភាពទិន្នន័យ		 ជួយបញ្ជាក់ពីស្ថិរភាពនៃទិន្នន័យស៊េរីពេលវេលា និងជៀសវាងបញ្ហានៃការវាយតម្លៃខុស (Spurious Regression) មុនពេលឈានដល់ការវិភាគគំរូ។ អាចមានភាពទន់ខ្សោយ ឬខ្វះប្រសិទ្ធភាពក្នុងការចាប់យកភាពមានស្ថិរភាព ប្រសិនបើទំហំសំណាកទិន្នន័យមានចំនួនតិចពេក។ អថេរភាគច្រើនមានស្ថិរភាពនៅកម្រិតភាពខុសគ្នាទី១ (First Difference) ដែលអនុញ្ញាតឱ្យអនុវត្តគំរូ ARDL បន្តបាន។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះតម្រូវឱ្យមានទិន្នន័យម៉ាក្រូសេដ្ឋកិច្ចប្រវត្តិសាស្ត្ររយៈពេលវែង និងកម្មវិធីកុំព្យូទ័រជំនាញសម្រាប់វិភាគទិន្នន័យសេដ្ឋកិច្ចមាត្រ។

  • Dataset: ទិន្នន័យស៊េរីពេលវេលាត្រីមាស (Quarterly Time Series Data) ពីឆ្នាំ ២០០៣ ដល់ ២០២៣ រួមមាន ផលិតផលក្នុងស្រុកសរុប អតិផរណា ការផ្គត់ផ្គង់ប្រាក់ និងទំហំពាណិជ្ជកម្មទ្វេភាគី។
  • Software: កម្មវិធីសេដ្ឋកិច្ចមាត្រកម្រិតខ្ពស់ដូចជា EViews, Stata ឬ R ដើម្បីធ្វើតេស្ត Unit Root, Cointegration និងដំណើរការគំរូ ARDL។
  • Expertise: ចំណេះដឹងស៊ីជម្រៅផ្នែកម៉ាក្រូសេដ្ឋកិច្ចអន្តរជាតិ និងសេដ្ឋកិច្ចមាត្រស៊េរីពេលវេលា (Time-series Econometrics) ដើម្បីអាចបកស្រាយមេគុណកែតម្រូវកំហុស (ECT)។

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះពឹងផ្អែកទាំងស្រុងលើទិន្នន័យម៉ាក្រូសេដ្ឋកិច្ចរបស់ប្រទេសអ៊ីរ៉ាក់ (២០០៣-២០២៣) ដែលជារដ្ឋពឹងផ្អែកលើការនាំចេញប្រេង (Rentier State)។ ទោះបីជាកម្ពុជាមិនមែនជាប្រទេសនាំចេញប្រេងក្តី ក៏កម្ពុជាមានបញ្ហាអតុល្យភាពរចនាសម្ព័ន្ធស្រដៀងគ្នា ដូចជាការពឹងផ្អែកខ្លាំងលើការនាំចូលទំនិញប្រើប្រាស់ និងវត្ថុធាតុដើមពីប្រទេសជិតខាង ទន្ទឹមនឹងភាពទន់ខ្សោយនៃវិស័យកែច្នៃកសិកម្ម និងឧស្សាហកម្មក្នុងស្រុក។

  • ការវិភាគជញ្ជីងពាណិជ្ជកម្ម កម្ពុជា-ថៃ និង កម្ពុជា-វៀតណាម: កម្ពុជាមានឱនភាពពាណិជ្ជកម្មធំជាមួយប្រទេសជិតខាងទាំងពីរនេះ។ វិធីសាស្ត្រនេះអាចយកមកប្រើដើម្បីស្វែងយល់ពីកត្តាជំរុញ (ដូចជាអតិផរណា, ការផ្គត់ផ្គង់ប្រាក់, និងផលិតកម្មក្នុងស្រុក) ដែលធ្វើឱ្យឱនភាពនេះបន្តកើនឡើងក្នុងរយៈពេលវែង។
  • គោលនយោបាយកាត់បន្ថយការនាំចូលកសិផល: ស្រដៀងនឹងបរិបទអ៊ីរ៉ាក់ កម្ពុជាអាចប្រើគំរូនេះដើម្បីវាស់ស្ទង់ថា តើការកើនឡើងនូវផលិតកម្មកសិកម្មក្នុងស្រុក អាចជួយកាត់បន្ថយទំហំនាំចូល និងកាត់បន្ថយឱនភាពពាណិជ្ជកម្មបានក្នុងកម្រិតណា។

ការអនុវត្តវិធីសាស្ត្រសេដ្ឋកិច្ចមាត្រនេះ នឹងផ្តល់ជាភស្តុតាងវិទ្យាសាស្ត្ររឹងមាំជូនអ្នករៀបចំគោលនយោបាយកម្ពុជា ក្នុងការតម្រង់ទិសការវិនិយោគទៅលើវិស័យផលិតកម្ម ដើម្បីពង្រឹងឯករាជ្យភាពសេដ្ឋកិច្ចជាតិ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ជំហានទី១៖ សិក្សាមូលដ្ឋានគ្រឹះនៃសេដ្ឋកិច្ចមាត្រស៊េរីពេលវេលា: និស្សិតត្រូវស្វែងយល់ពីទ្រឹស្តីមូលដ្ឋានរួមមាន Stationarity, Cointegration, និងការធ្វើតេស្ត Unit Root (ADF, PP) រួមទាំងយន្តការនៃគំរូ ARDL តាមរយៈសៀវភៅ ឬវគ្គសិក្សាអនឡាញ។
  2. ជំហានទី២៖ ប្រមូលទិន្នន័យម៉ាក្រូសេដ្ឋកិច្ចរបស់កម្ពុជា: ទាញយកទិន្នន័យប្រវត្តិសាស្ត្រ (ឧទាហរណ៍៖ ២០ ឆ្នាំចុងក្រោយ) ដែលមានទម្រង់ជាទិន្នន័យប្រចាំត្រីមាសឬប្រចាំឆ្នាំ អំពី ផសស អតិផរណា ម៉ាសប្រាក់ (M2) និងទំហំពាណិជ្ជកម្មទ្វេភាគី ពីគេហទំព័ររបស់ វិទ្យាស្ថានជាតិស្ថិតិ (NIS), ធនាគារជាតិរៀនកម្ពុជា (NBC) ឬ World Bank Open Data។
  3. ជំហានទី៣៖ អនុវត្តការវិភាគទិន្នន័យជាមួយកម្មវិធី: ដំឡើងនិងរៀនប្រើប្រាស់កម្មវិធីសេដ្ឋកិច្ចមាត្រ ដូចជា EViews ឬកូដនៅក្នុង RStudio (e.g., package 'ARDL') ដើម្បីបញ្ចូលទិន្នន័យ និងធ្វើតេស្ត Unit Root Test លើអថេរនីមួយៗ។
  4. ជំហានទី៤៖ ដំណើរការគំរូ ARDL និងការធ្វើតេស្តត្រួតពិនិត្យភាពត្រឹមត្រូវ: ដំណើរការ ARDL Bounds Test ដើម្បីរកមើលទំនាក់ទំនងរយៈពេលវែង រួចធ្វើការប៉ាន់ស្មាន Error Correction Model (ECM)។ កុំភ្លេចធ្វើតេស្តរោគវិនិច្ឆ័យ (Diagnostic Tests) ដូចជា Breusch-Godfrey LM Test និង CUSUM Test ដើម្បីបញ្ជាក់ពីស្ថិរភាពគំរូ។
  5. ជំហានទី៥៖ សរសេររបាយការណ៍ និងអនុសាសន៍គោលនយោបាយ: បកស្រាយលទ្ធផលមេគុណនីមួយៗ ថាតើកត្តាណាខ្លះដែលជះឥទ្ធិពលខ្លាំងដល់ឱនភាពពាណិជ្ជកម្ម រួចសរសេរជាអនុសាសន៍ជាក់ស្តែងសម្រាប់ស្ថាប័នពាក់ព័ន្ធ ដូចជាក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ ក្នុងការគាំទ្រឧស្សាហកម្មក្នុងស្រុក។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Structural Imbalances (អតុល្យភាពរចនាសម្ព័ន្ធ) ស្ថានភាពសេដ្ឋកិច្ចដែលពឹងផ្អែកខ្លាំងលើវិស័យតែមួយ (ដូចជាវិស័យប្រេងកាត) ខណៈវិស័យស្នូលផ្សេងទៀត (ដូចជាកសិកម្ម និងឧស្សាហកម្ម) មានភាពទន់ខ្សោយ ដែលធ្វើឱ្យសេដ្ឋកិច្ចជាតិងាយរងគ្រោះពីវិបត្តិខាងក្រៅ និងមិនមានចីរភាពយូរអង្វែង។ ដូចជារទេះដែលមានកង់ម្ខាងធំ កង់ម្ខាងតូច ដែលធ្វើឱ្យពិបាករុញទៅមុខដោយរលូន និងងាយក្រឡាប់។
Rentier State (រដ្ឋពឹងផ្អែកចំណូលពីធនធានធម្មជាតិ / រដ្ឋជួល) ប្រទេសដែលទទួលបានចំណូលជាតិភាគច្រើនពីការជួល ឬលក់ធនធានធម្មជាតិរបស់ខ្លួន (ដូចជាប្រេងកាត) ទៅឱ្យបរទេស ជាជាងបានមកពីការផលិតទំនិញ ឬសេវាកម្មក្នុងស្រុក ដែលជារឿយៗបណ្តាលឱ្យផលិតកម្មក្នុងស្រុកចុះខ្សោយ។ ដូចជាគ្រួសារមួយដែលរស់នៅយ៉ាងស្រួលដោយសារប្រាក់ឈ្នួលជួលដីកេរ ជំនួសឱ្យការខិតខំធ្វើការងាររកស៊ីប្រកបមុខរបរដោយខ្លួនឯង។
Autoregressive Distributed Lag / ARDL Model (គំរូ ARDL) វិធីសាស្ត្រស្ថិតិសេដ្ឋកិច្ចមាត្រដែលប្រើសម្រាប់វិភាគទំនាក់ទំនងរវាងអថេរផ្សេងៗ ទាំងក្នុងទំហំឥទ្ធិពលរយៈពេលខ្លី និងរយៈពេលវែង ជាពិសេសនៅពេលដែលទិន្នន័យមានកម្រិតស្ថិរភាពខុសគ្នា (I(0) និង I(1))។ ដូចជាឧបករណ៍គណនាដើម្បីមើលថា តើទម្លាប់ញ៉ាំអាហារកាលពីឆ្នាំមុន និងឆ្នាំនេះ ជះឥទ្ធិពលរួមគ្នាដល់សុខភាពរបស់យើងនៅថ្ងៃអនាគតយ៉ាងដូចម្តេចខ្លះ។
Cointegration Test by Bounds Test (ការធ្វើតេស្តសមាហរណកម្មដោយវិធីសាស្ត្រ Bounds Test) ការធ្វើតេស្តសេដ្ឋកិច្ចមាត្រដើម្បីបញ្ជាក់ថា ទោះបីជាអថេរសេដ្ឋកិច្ចពីរឬច្រើនប្រែប្រួលខ្លាំងក្នុងរយៈពេលខ្លីយ៉ាងណាក្តី ប៉ុន្តែពួកវាមានទំនាក់ទំនងតុល្យភាព ដែលតែងតែដើរស្របគ្នានៅក្នុងរយៈពេលវែង។ ដូចជាសត្វឆ្កែនិងម្ចាស់ដែលដើរលេងជាមួយគ្នា ទោះឆ្កែរត់ចុះឡើងឆ្វេងស្តាំ (រយៈពេលខ្លី) តែទីបំផុតវានៅតែដើរតាមម្ចាស់វាជានិច្ច (ទំនាក់ទំនងរយៈពេលវែង)។
Error Correction Coefficient / CointEq (មេគុណកែតម្រូវកំហុស) សូចនាករនៅក្នុងគំរូសេដ្ឋកិច្ច ដែលបង្ហាញពីល្បឿននៃការវិលត្រលប់ទៅរកភាពមានតុល្យភាពរយៈពេលវែងវិញ បន្ទាប់ពីមានការរំខាន ឬបម្រែបម្រួលណាមួយក្នុងរយៈពេលខ្លី (តម្លៃអវិជ្ជមានបញ្ជាក់ពីអត្ថិភាពនៃតុល្យភាពនេះ)។ ដូចជារ៉ឺស័រដែលទាញលាតហើយ វាតែងតែទាញរծឹបត្រលប់មករកប្រវែងដើមរបស់វាវិញក្នុងល្បឿនណាមួយ។
Economic Exposure Index (សន្ទស្សន៍នៃការសាយភាយសេដ្ឋកិច្ច) រង្វាស់ដែលបង្ហាញពីកម្រិតនៃការពឹងផ្អែករបស់សេដ្ឋកិច្ចជាតិទៅលើទីផ្សារបរទេស ដោយគណនាពីផលបូកនៃការនាំចេញនិងការនាំចូល ចែកនឹងផលិតផលក្នុងស្រុកសរុប (GDP) របស់ប្រទេសនោះ។ ដូចជាការវាស់មើលថា តើហាងលក់ចាប់ហួយមួយពឹងផ្អែកលើការទិញទំនិញពីអ្នកផ្គត់ផ្គង់ក្រៅស្រុកកម្រិតណា ដើម្បីយកមកលក់បន្ត។
Broad Money Supply (ការផ្គត់ផ្គង់ម៉ាសប្រាក់ទូលំទូលាយ / M2) បរិមាណទឹកប្រាក់សរុបដែលកំពុងចរាចរនៅក្នុងសេដ្ឋកិច្ច រួមទាំងសាច់ប្រាក់សុទ្ធ ប្រាក់បញ្ញើដែលអាចដកបានភ្លាមៗ និងប្រាក់បញ្ញើមានកាលកំណត់ ដែលជះឥទ្ធិពលដល់អំណាចទិញ និងអតិផរណា។ ដូចជាបរិមាណឈាមសរុបដែលកំពុងរត់ក្នុងសរសៃឈាមនៃរាងកាយសេដ្ឋកិច្ចទាំងមូល ដែលកំណត់ពីកម្លាំងក្នុងការទិញទំនិញនិងសេវាកម្មផ្សេងៗ។
Unit Root Test (ការធ្វើតេស្តឫសឯកតា) ដំណើរការសាកល្បងនៅក្នុងសេដ្ឋកិច្ចមាត្រ ដើម្បីពិនិត្យមើលថា តើទិន្នន័យស៊េរីពេលវេលាមានលក្ខណៈថេរ (Stationary) ឬប្រែប្រួលគ្មានព្រំដែនតាមពេលវេលា (Non-stationary) ដើម្បីជៀសវាងការទាញសេចក្តីសន្និដ្ឋានខុស។ ដូចជាការពិនិត្យមើលគ្រឹះផ្ទះឱ្យបានរឹងមាំ និងមានលំនឹង មុននឹងចាប់ផ្តើមសាងសង់ជាន់ទីពីរពីលើវា។
