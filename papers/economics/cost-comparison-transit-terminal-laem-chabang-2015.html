Direct Transportation without Transit Terminal (Baseline)
ការដឹកជញ្ជូនផ្ទាល់ដោយមិនឆ្លងកាត់ចំណតផ្អាកទំនិញ (Baseline)		 មិនតម្រូវឱ្យម្ចាស់រថយន្តបង់ថ្លៃសេវាចំណត និងមិនចាំបាច់មានការផ្ទេរឬរង់ចាំនៅទីតាំងកណ្តាលឡើយ។ ប្រឈមនឹងការកកស្ទះចរាចរណ៍យ៉ាងធ្ងន់ធ្ងរនៅតំបន់កំពង់ផែ (រហូតដល់ ៦ ម៉ោង) ដែលបណ្តាលឱ្យចំណាយលើប្រេងឥន្ធនៈ និងពេលវេលាកើនឡើងខ្ពស់ខ្លាំង។ ចំណាយសរុប (VOC + VOT) មានចន្លោះពី ៧៩៧ ទៅ ១,៣០១ បាតក្នុងមួយគ្រឿង អាស្រ័យលើកម្រិតនៃការកកស្ទះ (១០% ទៅ ៧០%)។
Transportation using Transit Terminal (Proposed)
ការដឹកជញ្ជូនដោយឆ្លងកាត់ចំណតផ្អាកទំនិញ (Transit Terminal)		 ជួយកាត់បន្ថយបរិមាណរថយន្តនៅតំបន់កំពង់ផែ កាត់បន្ថយការកកស្ទះ សន្សំសំចៃពេលវេលា និងកាត់បន្ថយការចំណាយប្រតិបត្តិការយានយន្ត (VOC) យ៉ាងមានប្រសិទ្ធភាព។ តម្រូវឱ្យមានការបង់ថ្លៃសេវាសម្រាប់ចំណត (៥០ ទៅ ២០០ បាតក្នុងមួយគ្រឿង) និងត្រូវការការរៀបចំហេដ្ឋារចនាសម្ព័ន្ធចំណតបន្ថែម។ ចំណាយសរុបថយចុះមកនៅត្រឹម ៥៦៩ ទៅ ៧១៩ បាតក្នុងមួយគ្រឿង ដែលជួយសន្សំការចំណាយប្រចាំឆ្នាំពី ៩៤៧.៥ លាន ទៅ ២.៤ ពាន់លានបាត។

ការសិក្សានេះត្រូវបានធ្វើឡើងនៅតំបន់កំពង់ផែ Laem Chabang ប្រទេសថៃ ដោយផ្តោតលើទិន្នន័យរថយន្តដឹកទំនិញធុនធ្ងន់ (១១,៣៨៦ គ្រឿង/ថ្ងៃ)។ ការគណនាតម្លៃនៃពេលវេលា (VOT) និងចំណាយប្រតិបត្តិការ (VOC) គឺផ្អែកលើស្តង់ដារសេដ្ឋកិច្ចរបស់ថៃ ដែលតួលេខទាំងនេះអាចមានភាពខុសគ្នាពីបរិបទកម្ពុជា។ យ៉ាងណាក្តី គំរូនៃការវាយតម្លៃនេះអាចយកមកកែច្នៃប្រើប្រាស់បានយ៉ាងល្អសម្រាប់សិក្សាពីបញ្ហាចរាចរណ៍នៅកម្ពុជា។

វិធីសាស្ត្រនៃការប្រើប្រាស់ចំណតផ្អាកទំនិញ (Transit Terminal) និងការវិភាគបណ្តាញនេះ មានអត្ថប្រយោជន៍យ៉ាងខ្លាំងសម្រាប់ការរៀបចំប្រព័ន្ធភស្តុភារកម្មនៅកម្ពុជា។

  • កំពង់ផែស្វយ័តក្រុងព្រះសីហនុ (PAS) និងកំពង់ផែស្វយ័តភ្នំពេញ (PPAP): អាចអនុវត្តគំរូនេះដើម្បីសិក្សាពីការបង្កើត Dry Port ឬចំណតរង់ចាំនៅតំបន់ជាយក្រុង ដើម្បីកាត់បន្ថយការកកស្ទះរថយន្តកុងតឺន័រដែលសម្រុកចូលកំពង់ផែដោយផ្ទាល់។
  • ច្រកទ្វារព្រំដែនអន្តរជាតិ (បាវិត និង ប៉ោយប៉ែត): ប្រើប្រាស់ការវិភាគនេះដើម្បីវាយតម្លៃការចំណាយ និងផលចំណេញក្នុងការបង្កើតតំបន់ Transit Terminal សម្រាប់រថយន្តដឹកទំនិញឆ្លងកាត់ព្រំដែន ដើម្បីដោះស្រាយការកកស្ទះលើផ្លូវជាតិលេខ១ និងលេខ៥។
  • ការរៀបចំផែនការហេដ្ឋារចនាសម្ព័ន្ធ Logistics Hubs: ស្ថាប័នរដ្ឋអាចប្រើប្រាស់កម្មវិធីវិភាគបណ្តាញភូមិសាស្ត្រ ដើម្បីកំណត់ទីតាំងសាងសង់មជ្ឈមណ្ឌលភស្តុភារកម្ម ដោយពឹងផ្អែកលើការវិភាគពេលវេលា ចម្ងាយ និងចំណាយប្រេងឥន្ធនៈ។

ការស្វែងយល់ពីចំណុចតុល្យភាព (Equilibrium Point) រវាងការបង់ថ្លៃសេវាចំណត និងការសន្សំចំណាយលើការពន្យារពេល នឹងជួយឱ្យអ្នកធ្វើគោលនយោបាយកម្ពុជាអាចរៀបចំផែនការដឹកជញ្ជូនដែលមានប្រសិទ្ធភាពខ្ពស់។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ការប្រមូល និងរៀបចំទិន្នន័យភូមិសាស្ត្រពាក់ព័ន្ធ: ប្រមូលទិន្នន័យបណ្តាញផ្លូវថ្នល់ ទិន្នន័យចរាចរណ៍ និងទីតាំងចំណុចគោលដៅ (កំពង់ផែ ឬច្រកព្រំដែន) ដោយប្រើប្រាស់កម្មវិធី ArcGIS ឬ QGIS សម្រាប់រៀបចំសំណុំទិន្នន័យភូមិសាស្ត្រ (Geodatabase)។
  2. ការបង្កើតបណ្តាញចរាចរណ៍ (Network Topology): ប្រើប្រាស់មុខងារ Topology នៅក្នុង ArcGIS Catalog ដើម្បីភ្ជាប់ខ្សែផ្លូវនីមួយៗឱ្យទៅជាបណ្តាញជាប់គ្នា (Network Dataset) និងត្រួតពិនិត្យកែកំហុស (Dangle Nodes) ដើម្បីធានាថាផ្លូវមិនដាច់ពីគ្នា។
  3. ការគណនាចំណាយ និងពេលវេលាធ្វើដំណើរ: កំណត់រូបមន្តគណនាចំណាយប្រតិបត្តិការយានយន្ត (VOC) និងតម្លៃនៃពេលវេលា (VOT) ទៅក្នុងប្រព័ន្ធ រួចធ្វើការប៉ាន់ស្មានពេលវេលាពន្យារពេល (Delay Time) ដោយផ្អែកលើទិន្នន័យកកស្ទះជាក់ស្តែង។
  4. ការវិភាគស្វែងរកផ្លូវល្អបំផុត (Shortest/Best Route Analysis): ប្រើប្រាស់ឧបករណ៍ Network Analyst Extension (មុខងារ New Route) ដើម្បីវិភាគរកផ្លូវដែលប្រើប្រាស់ពេលវេលា និងចំណាយតិចបំផុត រវាងចំណុចចាប់ផ្តើម និងចំណុចបញ្ចប់ (Port/Terminal)។
  5. ការក្លែងធ្វើតុល្យភាពចរាចរណ៍ និងសេណារីយ៉ូ (Equilibrium & Scenario Testing): សិក្សាពីទ្រឹស្តី User Equilibrium នៅក្នុងការបែងចែកចរាចរណ៍ (Traffic Assignment) និងបង្កើតសេណារីយ៉ូប្រៀបធៀបការចំណាយរវាង "ករណីប្រើប្រាស់ចំណត (Transit Terminal)" និង "ករណីមិនប្រើប្រាស់ចំណត"។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Transit Terminal ទីតាំង ឬចំណតសម្រាប់ឱ្យរថយន្តដឹកទំនិញចូលចតរង់ចាំ មុននឹងបន្តដំណើរចូលទៅកាន់កំពង់ផែ ដើម្បីកាត់បន្ថយការកកស្ទះចរាចរណ៍នៅតំបន់ផែផ្ទាល់។ ដូចជាបន្ទប់រង់ចាំសម្រាប់ភ្ញៀវមុនពេលចូលជួបពេទ្យ ដើម្បីកុំឱ្យមានការកកស្ទះក្នុងបន្ទប់ពិនិត្យជំងឺ។
Vehicle Operating Cost (VOC) ការចំណាយសរុបដែលកើតឡើងក្នុងកំឡុងពេលប្រតិបត្តិការយានយន្តលើដងផ្លូវ ដូចជា ថ្លៃប្រេងឥន្ធនៈ ការថែទាំ សំបកកង់ និងការសឹករិចរិល។ លុយដែលយើងត្រូវចំណាយរាល់ពេលដែលយើងបញ្ឆេះម៉ាស៊ីន និងបើករថយន្ត (ថ្លៃសាំង ថ្លៃប្តូរប្រេងម៉ាស៊ីន ជាដើម)។
Value of Time (VOT) តម្លៃសេដ្ឋកិច្ចដែលត្រូវបានកំណត់លើពេលវេលាដែលចំណាយក្នុងការធ្វើដំណើរ ឬការរង់ចាំ ដែលអាចបម្លែងជាទំហំទឹកប្រាក់ដែលបាត់បង់ដោយសារការពន្យារពេល។ គោលការណ៍ "ពេលវេលាជាមាសប្រាក់" ដែលគិតថាបើយើងខាតពេល១ម៉ោងឈប់ស្ងៀម តើយើងខាតលុយប៉ុន្មានដែលអាចយកពេលនោះទៅរកបាន។
Network Analysis ការប្រើប្រាស់កម្មវិធីកុំព្យូទ័រ (ជាពិសេសប្រព័ន្ធ GIS) ដើម្បីវិភាគបណ្តាញផ្លូវថ្នល់ក្នុងការស្វែងរកផ្លូវដែលខ្លីបំផុត លឿនបំផុត ឬចំណាយតិចបំផុតពីរទីតាំងមួយទៅទីតាំងមួយទៀត។ ដូចជាការប្រើកម្មវិធី Google Maps ដើម្បីស្វែងរកផ្លូវដែលលឿនជាងគេ និងមិនសូវមានការកកស្ទះ។
Traffic Assignment ដំណើរការនៃការប៉ាន់ស្មាន និងបែងចែកបរិមាណចរាចរណ៍ (ចំនួនយានយន្ត) ទៅតាមខ្សែផ្លូវផ្សេងៗនៅក្នុងបណ្តាញផ្លូវថ្នល់ ដោយផ្អែកលើពេលវេលា និងចំណាយធ្វើដំណើរ។ ដូចជាការបង្ហូរទឹកចូលក្នុងបំពង់ជាច្រើន ដោយទឹកនឹងហូរទៅរកបំពង់ណាដែលធំទូលាយ និងមិនសូវស្ទះមុនគេ។
Equilibrium នៅក្នុងបរិបទចរាចរណ៍ វាគឺជាស្ថានភាពដែលអ្នកបើកបរទាំងអស់ជ្រើសរើសផ្លូវដ៏ល្អបំផុតរៀងៗខ្លួន រហូតដល់គ្មានអ្នកណាអាចចំណេញពេលបន្ថែមទៀតដោយការប្តូរទៅផ្លូវផ្សេង ធ្វើឱ្យចរាចរណ៍មានភាពមានតុល្យភាព។ ដូចជាពេលតម្រង់ជួរទិញឥវ៉ាន់ បើមនុស្សឃើញជួរមួយខ្លី គេនឹងរត់ទៅជួរនោះ រហូតដល់ជួរទាំងអស់មានប្រវែងស្មើៗគ្នា ហើយលែងមានអ្នកចង់ដូរជួរ។
Topology នៅក្នុងប្រព័ន្ធភូមិសាស្ត្រ GIS វាគឺជាការកំណត់ក្បួនច្បាប់ទំនាក់ទំនងរវាងខ្សែផ្លូវ ដើម្បីធានាថាផ្លូវនីមួយៗពិតជាតភ្ជាប់គ្នាត្រឹមត្រូវតាមកូអរដោណេ (មិនដាច់ ឬត្រួតស៊ីគ្នាខុសប្រក្រតី)។ ដូចជាការភ្ជាប់បំណែកល្បែងផ្គុំរូប (Jigsaw) បើគែមវាមិនស៊ីគ្នាត្រឹមត្រូវទេ យើងមិនអាចមើលឃើញរូបភាព ឬបន្តដំណើរទៅមុខបានឡើយ។

៦. ប្រធានបទពាក់ព័ន្ធ (Further Reading)
