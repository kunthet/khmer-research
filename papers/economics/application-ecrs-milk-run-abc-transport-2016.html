Conventional Manual Process / Unoptimized Routing
ដំណើរការធ្វើឯកសារដោយដៃ / ការរៀបចំផ្លូវមិនទាន់ប្រសើរ		 ងាយស្រួលយល់ និងមិនទាមទារការផ្លាស់ប្តូរទម្លាប់ការងារថ្មី។ រថយន្តនីមួយៗទទួលខុសត្រូវតែលើអ្នកផ្គត់ផ្គង់របស់ខ្លួន។ ចំណាយពេលច្រើនក្នុងការធ្វើឯកសារ (១២០ នាទី)។ មានការខ្ជះខ្ជាយចម្ងាយផ្លូវនិងប្រេងឥន្ធនៈដោយសារការរត់រថយន្តទទេដើម្បីប្រគល់កេសទទេត្រឡប់ទៅវិញ។ ចំណាយពេល ១២០ នាទីសម្រាប់ឯកសារ និងមានការខ្ជះខ្ជាយចម្ងាយផ្លូវ ២.៥៣០ គីឡូម៉ែត្រក្នុងមួយខែ (បូកបញ្ចូលទាំងពីរខ្សែ)
ECRS-Optimized Process & Milk Run Rearrangement

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

បច្ចេកទេស ECRS និងប្រព័ន្ធការរៀបចំផ្លូវ Milk Run នេះមានសក្តានុពលខ្ពស់ក្នុងការយកមកអនុវត្តដើម្បីបង្កើនប្រសិទ្ធភាពវិស័យឡូជីស្ទីកនៅកម្ពុជា។

  • Phnom Penh Special Economic Zone (PPSEZ): ក្រុមហ៊ុនផលិតកម្មអាចប្រើប្រាស់ប្រព័ន្ធ Milk Run ដើម្បីប្រមូលវត្ថុធាតុដើមពីអ្នកផ្គត់ផ្គង់ផ្សេងៗគ្នានៅក្នុងតំបន់សេដ្ឋកិច្ចពិសេសបញ្ចូលគ្នាក្នុងរថយន្តតែមួយ ដើម្បីកាត់បន្ថយការកកស្ទះ និងថ្លៃដើមប្រតិបត្តិការ។

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. វិភាគបញ្ហាដោយប្រើដ្យាក្រាមឆ្អឹងត្រី: ប្រមូលទិន្នន័យបញ្ហាដែលធ្វើឱ្យរាំងស្ទះប្រតិបត្តិការ (ឧ. ការរង់ចាំយូរ ការរត់ឡានទទេ) រួចប្រើប្រាស់ Fishbone Diagram (Cause and Effect Diagram) ដើម្បីស្វែងរកឫសគល់នៃបញ្ហាទាំងនោះ។
  2. អនុវត្តគោលការណ៍ ECRS លើឯកសាររដ្ឋបាល: ពិនិត្យមើលលំហូរឯកសារបច្ចុប្បន្ន។ លុបចោល (Eliminate) ជំហានដែលមិនចាំបាច់ ហើយប្រើប្រាស់កម្មវិធី Microsoft Excel ឬ Google Sheets ដើម្បីបញ្ចូលគ្នា (Combine) និងធ្វើឱ្យដំណើរការងាយស្រួល (Simplify) ដូចជាការចេញ Truck Control Sheet ដោយស្វ័យប្រវត្តិ។
  3. រៀបចំខ្សែផ្លូវដឹកជញ្ជូនឡើងវិញ (Rearrange Routes): ប្រើប្រាស់ទិន្នន័យពី GPS tracking ដើម្បីវាយតម្លៃចម្ងាយ និងពេលវេលាឡើងវិញ។ រៀបចំប្រព័ន្ធឆ្លាស់វេនគ្នា (Swapping routes) សម្រាប់រថយន្តដឹកជញ្ជូន Milk Run ដើម្បីប្រគល់កេសទទេទៅកាន់ទីតាំងដែលជិតបំផុត ជៀសវាងការរត់ឡានទទេក្នុងចម្ងាយឆ្ងាយ។
  4. តាមដាន និងវាស់ស្ទង់ប្រសិទ្ធភាពការងារ: កត់ត្រាពេលវេលា និងចម្ងាយផ្លូវក្រោយពេលអនុវត្តបច្ចេកទេសថ្មី។ ធ្វើការប្រៀបធៀបទិន្នន័យនេះជាមួយទិន្នន័យចាស់ ដើម្បីគណនា Cycle Time ដែលបានកាត់បន្ថយ និងបរិមាណចម្ងាយ Kilometers ដែលបានសន្សំសំចៃ រួចកែតម្រូវបន្តប្រសិនបើចាំបាច់។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
ECRS គោលការណ៍កែលម្អការងារក្នុងផលិតកម្មនិងឡូជីស្ទីក ដែលផ្តោតលើជំហានចំនួន ៤ គឺ៖ លុបបំបាត់ចោល (Eliminate) ជំហានដែលមិនចាំបាច់, បញ្ចូលគ្នា (Combine) នូវការងារដែលអាចធ្វើរួមគ្នាបាន, រៀបចំឡើងវិញ (Rearrange) នូវលំដាប់លំដោយការងារ, និងធ្វើឱ្យសាមញ្ញ (Simplify) ដើម្បីងាយស្រួលអនុវត្តនិងសន្សំសំចៃពេលវេលា។ ដូចជាការរៀបចំបន្ទប់ឱ្យមានសណ្តាប់ធ្នាប់ ដោយបោះចោលរបស់អត់ប្រយោជន៍ ដាក់របស់ប្រើប្រាស់ចូលគ្នាតាមប្រភេទ រៀបចំកន្លែងថ្មី និងធ្វើឱ្យងាយស្រួលរក។
Milk Run ប្រព័ន្ធដឹកជញ្ជូនដែលរថយន្តមួយគ្រឿងធ្វើដំណើរតាមខ្សែផ្លូវមួយ (Route) ដើម្បីទៅទទួលយកទំនិញឬវត្ថុធាតុដើមពីអ្នកផ្គត់ផ្គង់ច្រើនកន្លែងមកកាន់រោងចក្រតែមួយ ក្នុងពេលវេលាកំណត់ច្បាស់លាស់ ដែលជួយកាត់បន្ថយថ្លៃដើមដឹកជញ្ជូននិងការកកស្ទះ។ ដូចជាឡានក្រុងសាលារៀន ដែលបើកទៅទទួលសិស្សតាមផ្ទះផ្សេងៗគ្នាតាមដងផ្លូវតែមួយ រួចដឹកយកមកសាលាតែម្តង ជាជាងឱ្យសិស្សម្នាក់ៗជិះឡានរៀងខ្លួនមក។
Fishbone Diagram ដ្យាក្រាមរាងដូចឆ្អឹងត្រី ដែលគេប្រើសម្រាប់ប្រមូលផ្តុំគំនិត និងវិភាគស្វែងរកឫសគល់នៃបញ្ហា (ក្បាលត្រី) ដោយបំបែកជាមែកធាងមូលហេតុធំៗ និងតូចៗ (ឆ្អឹងត្រី) ដើម្បីងាយស្រួលរកដំណោះស្រាយកែតម្រូវ។ ដូចជាការគូសផែនទីបង្ហាញផ្លូវទៅរកប្រភពនៃជំងឺ ដោយក្បាលត្រីជាជំងឺ ហើយឆ្អឹងនីមួយៗជារោគសញ្ញាឬមូលហេតុដែលបង្កឱ្យមានជំងឺនោះ។
Cycle Time រយៈពេលសរុបដែលប្រើប្រាស់ដើម្បីបញ្ចប់វដ្តនៃដំណើរការការងារណាមួយ ពីចំណុចចាប់ផ្តើមរហូតដល់ចំណុចបញ្ចប់ (ឧទាហរណ៍ ពេលវេលាសរុបក្នុងការរៀបចំនិងចេញឯកសារគ្រប់គ្រងរថយន្តដឹកជញ្ជូន)។ ដូចជាពេលវេលាដែលយើងចាប់ផ្តើមលាងអង្ករដាំបាយ រហូតដល់បាយឆ្អិនអាចដួសញ៉ាំបាន។
Backhaul ការធ្វើដំណើរត្រឡប់មកវិញរបស់រថយន្តដឹកជញ្ជូន។ ប្រសិនបើវាជាការរត់ត្រឡប់មកវិញដោយគ្មានផ្ទុកទំនិញ (Empty Backhaul) នោះវាចាត់ទុកថាជាការខ្ជះខ្ជាយថវិកា ប្រេងឥន្ធនៈ និងពេលវេលា។ ដូចជាការជិះតាក់ស៊ីទៅផ្សារមានអ្នកជិះ តែពេលតាក់ស៊ីត្រឡប់មកវិញអត់មានម៉ូយ ដែលធ្វើឱ្យខាតសាំងទទេ។
Waste សកម្មភាព ដំណើរការ ឬការប្រើប្រាស់ធនធានទាំងឡាយណា (ដូចជាពេលវេលា ចម្ងាយផ្លូវ ការរង់ចាំ ការធ្វើឯកសារស្ទួន) ដែលមិនបានបង្កើតតម្លៃបន្ថែមដល់ផលិតផល ឬសេវាកម្មទាល់តែសោះ នៅក្នុងខ្សែសង្វាក់ផ្គត់ផ្គង់។ ដូចជាការបើកទឹកចោលពេលកំពុងដុសធ្មេញ ដែលជាការខាតបង់ធនធានដោយមិនមានប្រយោជន៍អ្វីសោះ។
Empty Package កេស ឬរ៉ាកែត (Rack) ទទេដែលប្រើរួចរាល់នៅក្នុងរោងចក្រផលិត ហើយត្រូវដឹកត្រឡប់ទៅឱ្យអ្នកផ្គត់ផ្គង់វិញ ដើម្បីវេចខ្ចប់ទំនិញសម្រាប់ជុំដឹកជញ្ជូនបន្ទាប់ (Returnable Packaging)។ ដូចជាការយកសំបកដបទឹកបរិសុទ្ធទទេៗ ត្រឡប់ទៅដូរយកទឹកពេញពីក្រុមហ៊ុន ឬតូបលក់ទំនិញវិញ។
