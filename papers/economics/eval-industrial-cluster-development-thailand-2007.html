១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការសិក្សានេះវាយតម្លៃពីធាតុចូល ដំណើរការ និងលទ្ធផលនៃចង្កោមឧស្សាហកម្មចំនួន ២២ ដែលទទួលបានការគាំទ្រពីនាយកដ្ឋានជំរុញឧស្សាហកម្មនៃប្រទេសថៃក្នុងកំឡុងឆ្នាំ ២០០៦-២០០៧ ដើម្បីកំណត់បញ្ហាប្រឈមក្នុងការគ្រប់គ្រង និងប្រសិទ្ធភាពសេដ្ឋកិច្ច។

វិធីសាស្ត្រ (The Methodology)៖ ការស្រាវជ្រាវនេះបានប្រើប្រាស់គំរូវាយតម្លៃ CIPP (បរិបទ ធាតុចូល ដំណើរការ ផលិតផល) រួមជាមួយនឹងការវិភាគសេដ្ឋកិច្ច ដើម្បីវាយតម្លៃប្រសិទ្ធភាព និងភាពស័ក្តិសិទ្ធិរបស់គម្រោង។

  • គំរូវាយតម្លៃ CIPP (CIPP Evaluation Model)
  • ការវិភាគតម្លៃបច្ចុប្បន្នសុទ្ធ និងអនុបាតផលប្រយោជន៍-ចំណាយ (NPV and Benefit-Cost Ratio Analysis)
  • អត្រាផលចំណេញផ្ទៃក្នុងផ្នែកសេដ្ឋកិច្ច (Economic Internal Rate of Return - EIRR)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ចង្កោមឧស្សាហកម្មចំនួន ៦ ក្នុងចំណោម ២២ ត្រូវបានរកឃើញថាមានដំណើរការអភិវឌ្ឍន៍ប្រកបដោយភាពស័ក្តិសិទ្ធិ និងប្រសិទ្ធភាពខ្ពស់ បើទោះបីជាមានការខ្វះខាតផ្នែកគ្រប់គ្រង និងថវិកាក៏ដោយ។
  • គម្រោងជារួមទទួលបានភាពចំណេញផ្នែកសេដ្ឋកិច្ច ដោយមានតម្លៃបច្ចុប្បន្នសុទ្ធ (NPV) ប្រមាណ ២៤,៦ លានបាត អនុបាតផលប្រយោជន៍-ចំណាយ (BCR) ១,៥ និងអត្រាផលចំណេញ (EIRR) ៤៣,៥%។
  • ការសិក្សាបានស្នើឡើងនូវយុទ្ធសាស្ត្រចំនួន ៤ រួមមានការធ្វើផែនការរួមបញ្ចូលគ្នា ការប្រើប្រាស់ចំណេះដឹងជាមូលដ្ឋាន និងការបង្កើតភ្នាក់ងារគាំទ្រដើម្បីធានាការអភិវឌ្ឍចង្កោមឧស្សាហកម្មប្រកបដោយចីរភាព។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
CIPP Evaluation Model
គំរូវាយតម្លៃ CIPP (បរិបទ ធាតុចូល ដំណើរការ លទ្ធផល)		 ផ្តល់ការវាយតម្លៃគ្រប់ជ្រុងជ្រោយតាំងពីដំណាក់កាលរៀបចំផែនការរហូតដល់ការអនុវត្ត និងជួយកំណត់រកបញ្ហាប្រឈមផ្នែកគ្រប់គ្រងគម្រោង។ ពឹងផ្អែកយ៉ាងខ្លាំងលើទិន្នន័យគុណវិស័យ (Qualitative) និងការយល់ឃើញរបស់អ្នកចូលរួម ដែលអាចមានភាពលម្អៀង។ រកឃើញថាមានតែចង្កោមឧស្សាហកម្មចំនួន ៦ ប៉ុណ្ណោះក្នុងចំណោម ២២ ដែលមានដំណើរការអភិវឌ្ឍន៍ល្អប្រសើរ។
Economic and Financial Analysis (CBA)
ការវិភាគប្រសិទ្ធភាពសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ (NPV, BCR, EIRR)		 ផ្តល់រង្វាស់ជារូបិយប័ណ្ណយ៉ាងច្បាស់លាស់ពីប្រាក់ចំណេញ និងភាពស័ក្តិសមនៃការវិនិយោគរបស់រដ្ឋ ឬឯកជន។ មានការលំបាកក្នុងការគណនា ឬវាស់វែងផលប្រយោជន៍ប្រយោល (Indirect benefits) ដូចជាការកើនឡើងនូវចំណេះដឹង ឬបណ្តាញទំនាក់ទំនង។ ទូទាំងគម្រោងទទួលបានតម្លៃបច្ចុប្បន្នសុទ្ធ (NPV) ផ្នែកសេដ្ឋកិច្ច ២៤,៦ លានបាត, អនុបាត (BCR) ១,៥ និងអត្រាផលចំណេញ (EIRR) ៤៣,៥%។

ការចំណាយលើធនធាន (Resource Cost)៖ ការវាយតម្លៃនេះទាមទារធនធានមនុស្សច្រើនសម្រាប់ការចុះប្រមូលទិន្នន័យផ្ទាល់ និងអ្នកជំនាញខាងសេដ្ឋកិច្ចដើម្បីធ្វើការវិភាគគណនេយ្យភាពគម្រោង។

  • Human Resources: ត្រូវការអ្នកស្រាវជ្រាវ (អ្នកជំនាញវាយតម្លៃគម្រោង និងសេដ្ឋកិច្ចវិទូ) និងភ្នាក់ងារចុះប្រមូលទិន្នន័យនៅតាមតំបន់គោលដៅ។
  • Data Collection: ទាមទារការស្ទង់មតិ និងសម្ភាសន៍បុគ្គលិករដ្ឋ និងអ្នកតំណាងសហគ្រាសយ៉ាងតិច ១០នាក់ ក្នុងមួយចង្កោម (សរុបអ្នកចូលរួមជាង ៣៣០ នាក់)។
  • Software: ត្រូវការកម្មវិធីវិភាគទិន្នន័យស្ថិតិ និងហិរញ្ញវត្ថុ សម្រាប់ការគណនារូបមន្ត NPV, BCR, និង EIRR។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងនៅក្នុងប្រទេសថៃ លើចង្កោមឧស្សាហកម្មចំនួន ២២ ជាមួយនឹងការគាំទ្រថវិកាពីរដ្ឋាភិបាលដោយផ្ទាល់។ សម្រាប់ប្រទេសកម្ពុជា ទិន្នន័យនេះអាចមិនឆ្លុះបញ្ចាំងទាំងស្រុងទេ ដោយសារសហគ្រាសធុនតូច និងមធ្យម (SMEs) នៅកម្ពុជាភាគច្រើនអាចមានកម្រិតបច្ចេកវិទ្យា ធនធានហិរញ្ញវត្ថុ និងយន្តការគាំទ្រពីរដ្ឋទាបជាងប្រទេសថៃ។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រវាយតម្លៃនេះមានប្រយោជន៍ខ្លាំងណាស់សម្រាប់រាជរដ្ឋាភិបាល និងអង្គការនានាក្នុងការវាយតម្លៃប្រសិទ្ធភាពនៃកម្មវិធីគាំទ្រសហគ្រាសនៅកម្ពុជា។

  • ក្រសួងឧស្សាហកម្ម វិទ្យាសាស្ត្រ បច្ចេកវិទ្យា និងនវានុវត្តន៍ (MISTI): អាចប្រើប្រាស់គំរូនេះដើម្បីវាយតម្លៃប្រសិទ្ធភាពនៃការគាំទ្ររបស់រដ្ឋ ទៅលើចង្កោមសិប្បកម្ម ឬសហគ្រាសធុនតូច និងមធ្យមនៅកម្ពុជា។
  • ចង្កោមឧស្សាហកម្មកសិកម្ម (Agro-industry clusters) ខេត្តបាត់ដំបង និងសៀមរាប: អាចប្រើដើម្បីវាស់វែងការរីកចម្រើន និងភាពចំណេញនៃការចងក្រងគ្នារបស់រោងម៉ាស៊ីនកិនស្រូវ ឬសហគមន៍កែច្នៃផលិតផលកសិកម្ម។
  • ដៃគូអភិវឌ្ឍន៍ (Development Partners) និង NGOs: អាចប្រើការវិភាគ EIRR និង BCR ដើម្បីវាស់វែងភាពចំណេញផ្នែកសេដ្ឋកិច្ចសង្គម មុននឹងសម្រេចចិត្តបន្តការផ្តល់មូលនិធិ ឬពង្រីកគម្រោង។

ការរួមបញ្ចូលគ្នារវាងគំរូវាយតម្លៃគុណភាព (CIPP) និងការវិភាគប្រសិទ្ធភាពហិរញ្ញវត្ថុ នឹងជួយធានាថារាល់អន្តរាគមន៍គាំទ្រ SMEs នៅកម្ពុជាមានភាពតម្លាភាព និងចំគោលដៅ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាទ្រឹស្តី CIPP ឱ្យបានស៊ីជម្រៅ: ស្វែងយល់ពីរបៀបវាយតម្លៃបរិបទ ធាតុចូល ដំណើរការ និងលទ្ធផល ដោយអានឯកសារណែនាំរបស់ Stufflebeam's CIPP Evaluation Model ដើម្បីរៀបចំក្របខណ្ឌវាយតម្លៃគម្រោងនានា។
  2. ការរចនាកម្រងសំណួរ (Questionnaire Design): បង្កើតកម្រងសំណួរស្ទង់មតិដោយប្រើប្រាស់ KoboToolbox ឬ Qualtrics ដើម្បីប្រមូលទិន្នន័យប្រតិបត្តិការ (ចំណាយ-ចំណូល) និងការយល់ឃើញពីម្ចាស់សហគ្រាសនៅក្នុងចង្កោមនីមួយៗ។
  3. ការវិភាគសេដ្ឋកិច្ច (Cost-Benefit Analysis): ប្រមូលទិន្នន័យថវិកា ហើយអនុវត្តការគណនា NPV, BCR, FIRR, និង EIRR ដោយប្រើកម្មវិធី Microsoft Excel ឬ Python (NumPy Financial library)។
  4. ការវិភាគទិន្នន័យគុណវិស័យ (Content Analysis): ប្រើប្រាស់កម្មវិធី NVivo ឬ ATLAS.ti ដើម្បីវិភាគចម្លើយសម្ភាសន៍ស្វែងរកចំណុចខ្សោយក្នុងការគ្រប់គ្រង កង្វះខាតថវិកា និងកម្រិតនៃការចូលរួមរបស់សមាជិកចង្កោម។
  5. ការរៀបចំយុទ្ធសាស្ត្រ និងអនុសាសន៍: សរសេររបាយការណ៍សង្ខេប ដោយយោងលើទិន្នន័យដែលរកឃើញ ដើម្បីបង្កើតជាយុទ្ធសាស្ត្រជាក់ស្តែង (ឧទាហរណ៍៖ ស្នើឱ្យបង្កើត Cluster Development Agent) ជូនដល់ស្ថាប័នពាក់ព័ន្ធ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
CIPP Model ជាគំរូវាយតម្លៃគម្រោងទូលំទូលាយមួយដែលផ្តោតលើទិដ្ឋភាព៤សំខាន់គឺ៖ បរិបទ (Context) ធាតុចូល (Input) ដំណើរការ (Process) និងផលិតផល ឬលទ្ធផល (Product) ដើម្បីតាមដាន វាយតម្លៃ និងកែលម្អការអនុវត្តគម្រោងតាំងពីដើមដល់ចប់។ ដូចជាការវាយតម្លៃលើការចម្អិនម្ហូប ដោយពិនិត្យមើលតាំងពីមុខម្ហូបដែលត្រូវធ្វើ(បរិបទ) គ្រឿងផ្សំ(ធាតុចូល) របៀបចម្អិន(ដំណើរការ) និងរសជាតិម្ហូបដែលឆ្អិនហើយ(លទ្ធផល)។
Industrial Cluster ការប្រមូលផ្តុំនៃក្រុមហ៊ុនអាជីវកម្ម អ្នកផ្គត់ផ្គង់ ស្ថាប័នហិរញ្ញវត្ថុ ស្ថាប័នស្រាវជ្រាវ និងសាកលវិទ្យាល័យដែលស្ថិតនៅទីតាំងភូមិសាស្ត្រជិតៗគ្នា និងមានទំនាក់ទំនងគ្នា ដើម្បីសហការ បង្កើនផលិតភាព និងបង្កើនភាពប្រកួតប្រជែងលើទីផ្សារ។ ដូចជាផ្សារមួយដែលលក់តែគ្រឿងបន្លាស់ឡាន មានទាំងជាងជួសជុល ហាងលក់គ្រឿងបន្លាស់ និងកន្លែងបង្រៀនជាងឡាននៅជិតៗគ្នា ធ្វើឱ្យអតិថិជនងាយរកសេវាកម្ម រីឯអ្នកលក់ក៏លក់ដាច់ជាងមុនដោយសារជួយគាំទ្រគ្នា។
Net Present Value (NPV) ជាតម្លៃបច្ចុប្បន្នសុទ្ធនៃការវិនិយោគ ដែលគណនាដោយយកតម្លៃបច្ចុប្បន្ននៃលំហូរសាច់ប្រាក់ចំណូលរំពឹងទុកនាពេលអនាគត ដកនឹងតម្លៃបច្ចុប្បន្ននៃការចំណាយ ឬទុនវិនិយោគ ដើម្បីវាយតម្លៃថាគម្រោងនោះបង្កើតប្រាក់ចំណេញឬខាតបង់។ ដូចជាការគិតទុកជាមុនថា បើយើងចំណាយលុយទិញម៉ាស៊ីនដេរ១គ្រឿងថ្ងៃនេះ តើ៥ឆ្នាំទៀតលុយដែលរកបានពីម៉ាស៊ីននេះ បើគិតជាតម្លៃលុយក្នុងថ្ងៃនេះ ចំណេញឬអត់។
Benefit Cost Ratio (BCR) ជាអនុបាត ឬសមាមាត្ររវាងផលប្រយោជន៍សរុប (ទាំងផលប្រយោជន៍ផ្ទាល់និងប្រយោល) ធៀបនឹងការចំណាយសរុបនៃគម្រោង ដែលបង្ហាញពីប្រសិទ្ធភាពសេដ្ឋកិច្ចនៃការវិនិយោគ (បើធំជាង ១ គឺមានន័យថាចំណេញ)។ ដូចជាការប្រៀបធៀបថា បើយើងចំណាយទុន១ដុល្លារ តើយើងទទួលបានផលប្រយោជន៍ត្រឡប់មកវិញប៉ុន្មានដុល្លារ។
Economic Internal Rate of Return (EIRR) ជាអត្រាផលចំណេញផ្ទៃក្នុងផ្នែកសេដ្ឋកិច្ច ដែលវាស់វែងពីប្រាក់ចំណេញ ឬផលប្រយោជន៍សរុបដែលសង្គមជាតិទាំងមូលទទួលបានពីគម្រោងណាមួយ ដោយរាប់បញ្ចូលទាំងផលប៉ះពាល់ជាវិជ្ជមានលើការបង្កើតការងារ និងកំណើនសេដ្ឋកិច្ច។ ដូចជាការវាស់វែងថា តើការសាងសង់ស្ពានមួយខ្សែនេះ ផ្តល់ចំណេញប៉ុន្មានភាគរយដល់សេដ្ឋកិច្ចអ្នកភូមិទូទៅ មិនមែនគិតត្រឹមតែចំណូលពីថ្លៃលក់សំបុត្រឆ្លងស្ពាននោះទេ។
Financial Internal Rate of Return (FIRR) ជាអត្រាផលចំណេញផ្ទៃក្នុងផ្នែកហិរញ្ញវត្ថុ ដែលវាស់វែងពីប្រាក់ចំណេញជាសាច់ប្រាក់សុទ្ធសាធដែលស្ថាប័នវិនិយោគ ឬម្ចាស់គម្រោងទទួលបានដោយផ្ទាល់ ដោយមិនគិតបញ្ចូលពីផលប្រយោជន៍ផ្នែកសង្គមឡើយ។ ដូចជាការគិតលេខរបស់ថៅកែរោងចក្រ ថាតើគាត់នឹងចំណេញប៉ុន្មានភាគរយពីការបោះទុនរកស៊ីនេះ ចូលហោប៉ៅគាត់ផ្ទាល់ ដោយមិនខ្វល់ពីផលចំណេញអ្នកជុំវិញខ្លួន។
Cluster Development Agent (CDA) ជាភ្នាក់ងារ ឬបុគ្គលឯកទេសដែលដើរតួជាអ្នកសម្របសម្រួល ដើម្បីជួយជំរុញ ចងក្រង និងគាំទ្រដល់អាជីវកម្មនានាក្នុងចង្កោមឧស្សាហកម្ម ឱ្យមានទំនុកចិត្ត កិច្ចសហប្រតិបត្តិការ និងអាចអភិវឌ្ឍយុទ្ធសាស្ត្ររួមគ្នា។ ដូចជាអ្នកកាត់ចំណង ឬមេអណ្តើក ដែលជួយផ្សារភ្ជាប់ក្រុមហ៊ុនផ្សេងៗដែលមិនធ្លាប់ធ្វើការជាមួយគ្នា ឱ្យស្គាល់គ្នា ទុកចិត្តគ្នា និងរកស៊ីរួមគ្នាដើម្បីភាពរីកចម្រើនទាំងអស់គ្នា។
