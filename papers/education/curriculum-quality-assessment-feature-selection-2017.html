  • គណៈកម្មាធិការទទួលស្គាល់គុណភាពអប់រំនៃកម្ពុជា (ACC): អាចប្រើប្រាស់វិធីសាស្ត្រ Feature Selection នេះ ដើម្បីកាត់បន្ថយសូចនាករវាយតម្លៃដែលមិនសូវសំខាន់ ជួយសម្រួលដល់ដំណើរការត្រួតពិនិត្យ និងកាត់បន្ថយការងាររដ្ឋបាលដ៏ស្មុគស្មាញរបស់សាកលវិទ្យាល័យទូទាំងប្រទេស។
  • សាកលវិទ្យាល័យភូមិន្ទភ្នំពេញ (RUPP): ការិយាល័យធានាគុណភាពផ្ទៃក្នុង (IQA) អាចអនុវត្តគំរូនេះដើម្បីព្យាករណ៍ពិន្ទុគុណភាពនៃដេប៉ាតឺម៉ង់នីមួយៗមុនពេលការវាយតម្លៃផ្លូវការ ដើម្បីរៀបចំយុទ្ធសាស្ត្រកែលម្អបានទាន់ពេលវេលា។
  • វិទ្យាស្ថានបច្ចេកវិទ្យាកម្ពុជា (ITC): អាចផ្តោតលើគុណលក្ខណៈចម្បងៗដែលគំរូបានរកឃើញសម្រាប់មុខជំនាញវិទ្យាសាស្ត្រ និងបច្ចេកវិទ្យា (ដូចជាគុណភាពសាស្ត្រាចារ្យណែនាំសារណា និងការបែងចែកថវិកា) ដើម្បីពង្រឹងគុណភាពអប់រំវិស្វកម្ម។

ការអនុវត្តគំរូនេះអាចជួយស្ថាប័នអប់រំកម្ពុជាសន្សំសំចៃពេលវេលា កាត់បន្ថយការិយាធិបតេយ្យ និងផ្តោតការវិនិយោគលើសូចនាករដែលពិតជាជម្រុញគុណភាពអប់រំយ៉ាងពិតប្រាកដ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីសូចនាករធានាគុណភាពអប់រំនៅកម្ពុជា: និស្សិតត្រូវប្រមូលឯកសារស្តង់ដារវាយតម្លៃរបស់ក្រសួងអប់រំ (MoEYS) ឬគណៈកម្មាធិការ ACC (ដូចជាចំនួនសាស្ត្រាចារ្យបរិញ្ញាបត្រជាន់ខ្ពស់/បណ្ឌិត ធនធានបណ្ណាល័យ) ដើម្បីយកមកធ្វើជាលក្ខណៈ (Features) មូលដ្ឋានសម្រាប់គំរូ។
  2. ប្រមូល និងរៀបចំទិន្នន័យ (Data Pre-processing): ប្រើប្រាស់កម្មវិធី Microsoft Excel ដើម្បីកត់ត្រាទិន្នន័យកម្មវិធីសិក្សានៅក្នុងសាកលវិទ្យាល័យខ្លួនឯង ដោយសម្អាតទិន្នន័យទទេរ (Missing Values) និងបំប្លែងទិន្នន័យទៅជាទម្រង់ CSV (Comma Delimited) សម្រាប់ត្រៀមបញ្ចូលទៅក្នុងកម្មវិធីវិភាគ។
  3. អនុវត្តការជ្រើសរើសលក្ខណៈពិសេស (Feature Selection): ទាញយកនិងដំឡើងកម្មវិធី WEKA។ រៀនប្រើមុខងារ Attribute Selection ដោយសាកល្បងប្រើ Wrapper Method (MLP) និង Filter Method (CFS) ដើម្បីរកមើលថាតើសូចនាករអប់រំណាដែលមានឥទ្ធិពលជាងគេ។
  4. ហ្វឹកហាត់ និងវាស់ស្ទង់ប្រសិទ្ធភាពគំរូ: នៅក្នុងកម្មវិធី WEKA ដដែល ត្រូវប្រើប្រាស់ Algorithms ដូចជា Multilayer Perceptron (MLP) និង Support Vector Machine (SVM) ជាមួយបច្ចេកទេស 5-Fold Cross Validation ដើម្បីវាស់ស្ទង់ភាពត្រឹមត្រូវ (Accuracy) របស់គំរូ។
  5. បកស្រាយលទ្ធផលសម្រាប់ថ្នាក់ដឹកនាំ: សរសេររបាយការណ៍សង្ខេបអំពីគុណលក្ខណៈសំខាន់ៗដែលនៅសេសសល់ (ឧទាហរណ៍៖ ប្រាក់ខែសាស្ត្រាចារ្យធៀបនឹងថវិកាសរុប) ដើម្បីផ្តល់ជាអនុសាសន៍ដល់ព្រឹទ្ធបុរសក្នុងការកែលម្អគុណភាពកម្មវិធីសិក្សាឱ្យចំគោលដៅនិងចំណេញថវិកា។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Feature Selection ដំណើរការជ្រើសរើសយកតែគុណលក្ខណៈ ឬអថេរណាដែលសំខាន់មានឥទ្ធិពលបំផុតពីក្នុងចំណោមទិន្នន័យចម្រុះជាច្រើន ដើម្បីយកមកប្រើក្នុងការវាយតម្លៃ ឬសាងសង់ម៉ូដែលដែលជួយឱ្យម៉ូដែលដំណើរការលឿននិងសុក្រឹតជាងមុន។ វាដូចជាការរើសយកតែគ្រឿងផ្សំសំខាន់ៗ៤ឬ៥មុខដើម្បីធ្វើម្ហូបមួយចានឱ្យឆ្ងាញ់ ដោយបោះចោលគ្រឿងផ្សំរាប់សិបមុខទៀតដែលមិនចាំបាច់។
Multi-Layer Perceptron (MLP) ជាប្រភេទក្បួនកុំព្យូទ័រ (Algorithm) បណ្តាញសរសៃប្រសាទសិប្បនិម្មិត ដែលមានស្រទាប់បញ្ជូនព័ត៌មានកំបាំង (Hidden Layers) ច្រើនជាន់ ដើម្បីរៀនស្គាល់ទម្រង់ទិន្នន័យដែលស្មុគស្មាញ និងធ្វើការព្យាករណ៍លទ្ធផល។ វាប្រៀបដូចជាក្រុមអ្នកវិភាគជាច្រើនជាន់ថ្នាក់ ដែលថ្នាក់ក្រោមមើលទិន្នន័យព្រាងៗ រួចបញ្ជូនទៅថ្នាក់កណ្តាល រហូតដល់ថ្នាក់លើបំផុតធ្វើការសម្រេចចិត្តនិងសន្និដ្ឋានយកចម្លើយចុងក្រោយ។
Wrapper Method វិធីសាស្ត្រក្នុងការជ្រើសរើសលក្ខណៈពិសេស (Feature) ដោយយកក្បួន Algorithm មកសាកល្បងបង្វិល (Train) ផ្ទាល់ជាមួយបណ្តុំ Feature នីមួយៗរាប់សិបដង ដើម្បីស្វែងរកបណ្តុំមួយណាដែលម៉ូដែលនោះប្រើទៅទទួលបានភាពត្រឹមត្រូវខ្ពស់បំផុត។ ដូចជាការឱ្យកីឡាករម្នាក់សាកល្បងពាក់ស្បែកជើងរាប់សិបគូ រួចរត់សាកល្បងម្តងមួយៗ ដើម្បីរកមើលថាតើស្បែកជើងគូណាដែលធ្វើឱ្យគាត់រត់បានលឿនជាងគេបំផុត។
K-fold Cross Validation វិធីសាស្ត្រវាស់ស្ទង់ភាពត្រឹមត្រូវរបស់ម៉ូដែល ដោយបែងចែកទិន្នន័យជា K ផ្នែកស្មើៗគ្នា រួចឆ្លាស់គ្នាយកមួយផ្នែកទៅធ្វើជាវិញ្ញាសាសាកល្បង (Test) និងផ្នែកផ្សេងទៀតទៅបង្រៀនម៉ូដែល (Train) រហូតដល់គ្រប់ផ្នែកទាំងអស់ត្រូវបានតេស្តសាកល្បងទើបយកលទ្ធផលមកគិតមធ្យមភាគ។ វាដូចជាការរៀនត្រៀមប្រឡង ដោយបែងចែកមេរៀនជា៥ជំពូក រួចឆ្លាស់គ្នាយកជំពូកនីមួយៗធ្វើជាវិញ្ញាសាសាកល្បងសមត្ថភាពខ្លួនឯង រហូតដល់ចេះចាំច្បាស់លាស់ទាំងអស់។
Support Vector Machine (SVM) ជាបច្ចេកទេស Machine Learning មួយប្រភេទដែលប្រើសមីការគណិតវិទ្យាដើម្បីគូសបន្ទាត់ ឬបង្កើតប្លង់បែងចែកក្រុមទិន្នន័យ (Classes) ឱ្យដាច់ពីគ្នា ដោយរក្សាគម្លាតសុវត្ថិភាព (Margin) រវាងក្រុមនីមួយៗឱ្យបានធំបំផុតតាមដែលអាចធ្វើទៅបាន។ ដូចជាការគូសបន្ទាត់ព្រំដែននៅកណ្តាលផ្លូវធំមួយ ដើម្បីខណ្ឌចែករថយន្តដែលរត់ទៅមុខនិងរថយន្តដែលរត់មកបញ្ច្រាសទិសកុំឱ្យមានឱកាសប៉ះទង្គិចគ្នា។
Confusion Matrix តារាងម៉ាទ្រីសដែលកត់ត្រាសង្ខេបលទ្ធផលបង្ហាញពីចំនួនដងដែលម៉ូដែលព្យាករណ៍ត្រូវពិតប្រាកដ និងចំនួនដងដែលវាទាយខុស (False Positive / False Negative) ធៀបនឹងទិន្នន័យជាក់ស្តែង ដើម្បីវាយតម្លៃប្រសិទ្ធភាពម៉ូដែល។ វាប្រៀបដូចជាតារាងកត់ត្រាចំនួនលើកដែលអ្នកទាយត្រូវ ឬទាយខុសពេលលេងល្បែងទាយកាក់ (ក្បាល ឬ ប៉ះ) ដើម្បីសន្និដ្ឋានថាអ្នកពិតជាពូកែទាយកម្រិតណា។
Mean Square Error (MSE) រង្វាស់គណិតវិទ្យាសម្រាប់វាស់កម្រិតលម្អៀងរបស់ម៉ូដែល ដោយយកផលដកនៃតម្លៃជាក់ស្តែងនិងតម្លៃដែលម៉ូដែលទាយបាន មកលើកជាការ៉េ រួចរកមធ្យមភាគ ដែលតម្លៃនេះកាន់តែតូចបញ្ជាក់ថាម៉ូដែលកាន់តែមានភាពសុក្រឹត។ វាប្រៀបដូចជារង្វាស់នៃកម្រិតភាពខុសគ្នារវាងពិន្ទុដែលអ្នកស្មានថាខ្លួនឯងនឹងទទួលបានមុនពេលប្រឡង ធៀបទៅនឹងពិន្ទុពិតប្រាកដដែលអ្នកទទួលបានក្រោយពេលប្រឡងរួច។
