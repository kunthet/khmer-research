១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ឯកសារនេះដោះស្រាយបញ្ហាកង្វះការចូលរួមរបស់និស្សិតនៅក្នុងថ្នាក់រៀនមុខវិជ្ជាវិស្វកម្ម ដោយប្រៀបធៀបប្រសិទ្ធភាពនៃការបង្រៀនបែបប្រពៃណីជាមួយនឹងវិធីសាស្ត្ររៀនសូត្រសកម្ម (Active Learning)។

វិធីសាស្ត្រ (The Methodology)៖ ការស្រាវជ្រាវនេះបានអនុវត្តវិធីសាស្ត្ររៀនសូត្រសកម្មដោយផ្តល់ឱ្យនិស្សិតម្នាក់ៗនូវអថេរខុសៗគ្នាក្នុងការដោះស្រាយបញ្ហាវិស្វកម្ម ដើម្បីជំរុញការពិភាក្សានិងការគិតស៊ីជម្រៅ។

  • ការដោះស្រាយបញ្ហាក្នុងថ្នាក់ដែលមានអថេរខុសៗគ្នា (Individualized In-Class Problem Solving)
  • ការប្រៀបធៀបទិន្នន័យនៃការដាក់ស្នើកិច្ចការ (Submission Data Assessment) ចំនួនបីឆមាស

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • នៅក្នុងការបង្រៀនថ្នាក់រៀនបែបប្រពៃណី (ឆមាសទី១) អត្រានៃការចូលរួមរបស់និស្សិតមានជាមធ្យមត្រឹមតែ ៧១,៤% ប៉ុណ្ណោះ។
  • ការអនុវត្តការរៀនសូត្រសកម្មក្នុងឆមាសទី២ បានបង្កើនអត្រាចូលរួមរបស់និស្សិតដល់ ៨២,៥%។
  • នៅក្នុងឆមាសទី៣ ការរៀនសូត្រសកម្មបានបន្តបង្កើនការចូលរួមរបស់និស្សិតរហូតដល់អត្រា ៨៧,៥% ដែលបង្ហាញពីប្រសិទ្ធភាពខ្ពស់នៃវិធីសាស្ត្រនេះ បើទោះជាវាទាមទារពេលវេលាច្រើនជាងមុនក៏ដោយ។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Traditional Classroom Teaching
ការបង្រៀនក្នុងថ្នាក់រៀនបែបប្រពៃណី		 ចំណាយពេលតិចក្នុងការបង្រៀននៅក្នុងថ្នាក់ និងអាចគ្របដណ្តប់ខ្លឹមសារមេរៀនបានច្រើនក្នុងរយៈពេលខ្លី។ និស្សិតខ្វះការចូលរួម ដោយគ្រាន់តែស្តាប់ និងកត់ត្រាដោយគ្មានការពិភាក្សា ដែលធ្វើឱ្យពិបាកក្នុងការវាស់ស្ទង់ការយល់ដឹងពិតប្រាកដ។ អត្រាចូលរួមរបស់និស្សិតមានជាមធ្យមត្រឹមតែ ៧១,៤% ប៉ុណ្ណោះ។
Active Learning (Individualized Problem Solving)
ការរៀនសូត្រសកម្ម (ការដោះស្រាយបញ្ហាដែលមានអថេរខុសៗគ្នា)		 ជំរុញឱ្យមានការពិភាក្សាយ៉ាងសកម្មរវាងនិស្សិតនិងសាស្ត្រាចារ្យ ធ្វើឱ្យនិស្សិតយល់មេរៀនបានច្បាស់ ឆាប់រហ័ស និងចំណាយពេលតិចក្នុងការរំលឹកមេរៀនប្រឡង។ ទាមទារពេលវេលាច្រើនជាងមុននៅក្នុងថ្នាក់រៀនសម្រាប់ការអនុវត្តមួយជំហានៗ និងតម្រូវឱ្យសាស្ត្រាចារ្យមានការយកចិត្តទុកដាក់ខ្ពស់លើសិស្សម្នាក់ៗ។ អត្រាចូលរួមរបស់និស្សិតកើនឡើងដល់ ៨២,៥% (ក្នុងឆមាសទី២) និង ៨៧,៥% (ក្នុងឆមាសទី៣)។

ការចំណាយលើធនធាន (Resource Cost)៖ ការអនុវត្តវិធីសាស្ត្រនេះមិនទាមទារធនធានបច្ចេកវិទ្យាខ្ពស់នោះទេ ប៉ុន្តែវាទាមទារការរៀបចំទុកជាមុនពីសំណាក់សាស្ត្រាចារ្យ និងពេលវេលាបន្ថែមនៅក្នុងថ្នាក់សិក្សា។

  • Instructor Expertise and Preparation: សាស្ត្រាចារ្យត្រូវចំណាយពេលរៀបចំទម្រង់លំហាត់ដែលអនុញ្ញាតឱ្យមានការផ្លាស់ប្តូរអថេរ (Variables) និងមានសមត្ថភាពក្នុងការសម្របសម្រួល (Facilitate) ជួយដោះស្រាយបញ្ហាផ្សេងៗគ្នារបស់និស្សិតក្នុងពេលតែមួយ។
  • Classroom Time: ទាមទារពេលវេលាច្រើននៅក្នុងថ្នាក់ ដើម្បីធានាថានិស្សិតទាំងអស់បញ្ចប់ជំហានគណនានីមួយៗមុននឹងបន្តទៅជំហានបន្ទាប់។
  • Learning Materials: តម្រូវឱ្យមានសៀវភៅសិក្សា ឬតារាងទិន្នន័យ (Data Tables / Interpolating Plots) សម្រាប់ឱ្យនិស្សិតប្រើប្រាស់ក្នុងការជ្រើសរើសទិន្នន័យមកគណនាដោយខ្លួនឯង។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. រៀបចំទម្រង់លំហាត់ដែលមានអថេរជម្រើស (Design Variable Problems): គ្រូបង្រៀនត្រូវជ្រើសរើសលំហាត់ដែលមានទម្រង់ដោះស្រាយរួមមួយ ប៉ុន្តែអនុញ្ញាតឱ្យសិស្សជ្រើសរើសលេខដោយចៃដន្យនៅក្នុងចន្លោះដែលបានកំណត់ (ឧទាហរណ៍៖ កម្លាំងពី 1750-2200 lb, ល្បឿនពី 1150-1750 rpm) ដើម្បីធានាថាសិស្សម្នាក់ៗមានលំហាត់ផ្ទាល់ខ្លួន។
  2. អនុវត្តការបង្រៀនជាជំហានៗរួមគ្នា (Step-by-Step Parallel Solving): សាស្ត្រាចារ្យត្រូវដោះស្រាយបញ្ហានៅលើក្តារខៀនដោយប្រើអថេរផ្ទាល់ខ្លួន (Instructor's variables) ខណៈពេលដែលនិស្សិតត្រូវធ្វើការគណនាស្របគ្នាដោយប្រើអថេររបស់ពួកគេសម្រាប់ជំហាននីមួយៗ ដោយមិនបន្តទៅមុខលឿនពេកទេ។
  3. ជំរុញការពិភាក្សា និងធ្វើជាអ្នកសម្របសម្រួល (Facilitate Peer Discussion): ផ្តល់ពេលវេលាសមស្របនៅចន្លោះជំហាននីមួយៗ ដើម្បីឱ្យនិស្សិតអាចពិភាក្សា ផ្ទៀងផ្ទាត់ទិន្នន័យជាមួយសៀវភៅ ឬសួរដេញដោលគ្នាទៅវិញទៅមក។ សាស្ត្រាចារ្យដើរតួជាអ្នកតាមដាន និងជួយពន្យល់នៅពេលសិស្សជួបការលំបាក។
  4. ប្រមូលកិច្ចការក្នុងថ្នាក់ដើម្បីវាស់ស្ទង់ការចូលរួម (In-Class Work Collection): តម្រូវឱ្យនិស្សិតប្រគល់ក្រដាសគណនារបស់ពួកគេនៅចុងម៉ោង ដើម្បីវាយតម្លៃការយល់ដឹង និងយកទិន្នន័យនោះមកគណនាជាភាគរយនៃការចូលរួមជាក់ស្តែង។ អាចប្រើប្រាស់កម្មវិធីដូចជា Google Classroom សម្រាប់ការថតបញ្ជូនកិច្ចការយ៉ាងរហ័ស។
  5. កែតម្រូវយុទ្ធសាស្ត្រសម្រាប់ថ្នាក់សិស្សច្រើន (Scale for Larger Class Sizes): សម្រាប់ថ្នាក់រៀននៅកម្ពុជាដែលមានសិស្សលើសពី ៥០នាក់ គួរចងក្រងនិស្សិតជាក្រុមតូចៗ (៣-៤ នាក់) ឱ្យប្រើប្រាស់សំណុំអថេររួមគ្នាក្នុងមួយក្រុម (Group-based specific variables) ជាជាងម្នាក់ៗ ដើម្បីសន្សំពេលវេលា និងងាយស្រួលគ្រប់គ្រងការដាក់ពិន្ទុ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Active Learning វិធីសាស្ត្របង្រៀនដែលតម្រូវឱ្យនិស្សិតចូលរួមដោយផ្ទាល់ក្នុងការគិត អនុវត្ត ឬពិភាក្សា ជំនួសឱ្យការគ្រាន់តែអង្គុយស្តាប់សាស្ត្រាចារ្យពន្យល់តែម្ខាង។ ដូចជាការរៀនជិះកង់ដោយការធាក់កង់ផ្ទាល់ខ្លួន ជាជាងគ្រាន់តែមើលគេជិះ។
Student Engagement កម្រិតនៃការយកចិត្តទុកដាក់ ការចូលរួមសកម្ម និងចំណាប់អារម្មណ៍របស់និស្សិតនៅក្នុងសកម្មភាពសិក្សាក្នុងថ្នាក់រៀន។ ដូចជាទស្សនិកជនដែលកំពុងហ៊ោកញ្ជ្រៀវនិងតាមដានការប្រកួតកីឡាយ៉ាងជក់ចិត្ត មិនមែនគ្រាន់តែអង្គុយមើលទាំងងងុយដេកនោះទេ។
Problem-based learning វិធីសាស្ត្រសិក្សាដែលផ្តើមចេញពីការលើកយកបញ្ហាជាក់ស្តែងមកឱ្យនិស្សិតដោះស្រាយ ដើម្បីឱ្យពួកគេស្រាវជ្រាវនិងរៀនទ្រឹស្តីតាមរយៈដំណើរការដោះស្រាយបញ្ហានោះ។ ដូចជាការផ្តល់គ្រឿងផ្សំនិងប្រាប់ឱ្យចុងភៅរកវិធីស្លម្ហូបមួយមុខ ដើម្បីឱ្យគាត់ចេះបង្កើតរូបមន្តដោយខ្លួនឯង ជំនួសឱ្យការប្រាប់រូបមន្តត្រង់ៗ។
Cooperative learning ការរៀនសូត្រដោយតម្រូវឱ្យនិស្សិតធ្វើការជាក្រុមតូចៗ ដែលសមាជិកម្នាក់ៗត្រូវជួយគ្នាទៅវិញទៅមកដើម្បីសម្រេចគោលដៅសិក្សា ឬគម្រោងរួមមួយ។ ដូចជាការអុំទូកង ដែលកីឡាករទាំងអស់ត្រូវសហការគ្នាចេញកម្លាំងព្រមគ្នាទើបទូកអាចទៅមុខបានលឿន។
Machine design មុខវិជ្ជាវិស្វកម្មដែលផ្តោតលើការគណនា និងជ្រើសរើសទំហំ សម្ភារៈ ឬគ្រឿងបន្លាស់ម៉ាស៊ីនឱ្យបានត្រឹមត្រូវ ដើម្បីធានាថាវាអាចទ្រទម្ងន់និងដំណើរការបានដោយសុវត្ថិភាព។ ដូចជាការគូសប្លង់សាងសង់ផ្ទះដោយត្រូវគិតគូរថាតើត្រូវប្រើសសរប៉ុនណា និងដែកប៉ុនណាទើបផ្ទះរឹងមាំមិនរលំ។
Dynamic Load rating រង្វាស់ស្តង់ដារនៃបន្ទុកកម្លាំងដែលកាដាង (Bearing) មួយអាចទ្រទម្ងន់បានក្នុងកំឡុងពេលវាកំពុងវិល មុនពេលវាដល់អាយុកាលខូចខាត។ ដូចជាការកំណត់ទម្ងន់អតិបរមាដែលរថយន្តមួយអាចផ្ទុកបាននៅពេលកំពុងបើកបរក្នុងល្បឿនលឿនដោយមិនធ្វើឱ្យបែកកង់។
Radial load កម្លាំងសង្កត់ដែលធ្វើសកម្មភាពកែង (៩០ដឺក្រេ) ទៅនឹងអ័ក្សបង្វិលរបស់ម៉ាស៊ីន (ឧទាហរណ៍ កម្លាំងសង្កត់ពីលើចុះក្រោមលើកង់រថយន្ត)។ ដូចជាទម្ងន់របស់យើងដែលសង្កត់ពីលើទៅលើកង់កង់នៅពេលយើងអង្គុយពីលើវា។
Thrust load កម្លាំងរុញដែលធ្វើសកម្មភាពស្របទៅនឹងអ័ក្សបង្វិលរបស់ម៉ាស៊ីន (ឧទាហរណ៍ កម្លាំងរុញបក់ទៅមុខរបស់កង្ហារអូប័រ)។ ដូចជាកម្លាំងខ្យល់ដែលរុញឆត្រឱ្យប៉ើងទៅក្រោយនៅពេលមានខ្យល់បក់ខ្លាំងចំពីមុខ។
