១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការស្រាវជ្រាវនេះដោះស្រាយបញ្ហានៃការចំណាយខ្ពស់ក្នុងការសាងសង់ឧបករណ៍ពិសោធន៍ផ្ទាល់ ដោយស្នើឡើងនូវការប្រើប្រាស់កម្មវិធីកូដបើកចំហ (OpenFOAM) ដើម្បីក្លែងធ្វើ និងវិភាគរចនាសម្ព័ន្ធអណ្តាតភ្លើងប្រភេទ diffusion jet សម្រាប់ការរចនាក្បាលដុត។

វិធីសាស្ត្រ (The Methodology)៖ ការស្រាវជ្រាវនេះបានអនុវត្តកម្មវិធីកុំព្យូទ័រឌីណាមិកនៃសន្ទនីយ៍ (CFD) ដើម្បីក្លែងធ្វើម៉ូដែលអណ្តាតភ្លើងតាមបែបគណិតវិទ្យា ដោយប្រៀបធៀបជាមួយលទ្ធផលពិសោធន៍ជាក់ស្តែង។

  • ការក្លែងធ្វើកួចខ្យល់ខ្នាតធំដោយប្រើកម្មវិធីកូដបើកចំហ OpenFOAM (Large Eddy Simulation - LES)
  • វិធីសាស្ត្រប្រភាគល្បាយ និងសម្មតិកម្មគីមីលឿនបំផុត (Mixture fraction approach and infinitely-fast chemistry assumption)
  • វិធីសាស្ត្រមាឌកំណត់សម្រាប់ដោះស្រាយសមីការអណ្តាតភ្លើង (Finite volume method - FVM)
  • ការវាស់វែងប្រវែងអណ្តាតភ្លើងតាម៣វិធី៖ កម្រិតសីតុណ្ហភាពអតិបរមា អុកស៊ីហ្សែនសេសសល់ និងអត្រាបញ្ចេញកម្តៅ (Heat release rate)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ការប្រើប្រាស់អត្រាបញ្ចេញកម្តៅ (Heat release rate) គឺជាវិធីសាស្ត្រដ៏ល្អបំផុតក្នុងការកំណត់ប្រវែងអណ្តាតភ្លើងពីលទ្ធផល CFD ។
  • ម៉ូដែល CFD ដែលបានអភិវឌ្ឍដោយភាសា C++ នេះមានកំហុសជាមធ្យមចន្លោះពី ៥,៨៤% ទៅ ៩,៥១% ប៉ុណ្ណោះបើធៀបជាមួយនឹងទិន្នន័យពិសោធន៍។
  • ប្រវែងអណ្តាតភ្លើងកើនឡើងយ៉ាងច្បាស់លាស់អាស្រ័យលើអត្រាលំហូរនៃឧស្ម័នមេតាន ខណៈដែលសម្ពាធបរិស្ថានស្ទើរតែមិនមានឥទ្ធិពលទៅលើប្រវែងរបស់វានោះទេ។

Heat release rate method

1% oxygen remaining method

  • Expertise: ត្រូវការជំនាញកម្រិតខ្ពស់ផ្នែកឌីណាមិកនៃសន្ទនីយ៍ (CFD), ការក្លែងធ្វើកួចខ្យល់ខ្នាតធំ (Large Eddy Simulation) និងការសរសេរកម្មវិធី C++។

សរុបមក ការប្រើប្រាស់កម្មវិធីកូដបើកចំហ OpenFOAM ផ្តល់នូវច្រកចេញដ៏មានប្រសិទ្ធភាពសម្រាប់ប្រទេសកម្ពុជាក្នុងការជំរុញការស្រាវជ្រាវ និងអភិវឌ្ឍបច្ចេកវិទ្យាចំហេះប្រកបដោយនិរន្តរភាព ដោយចំណាយដើមទុនតិចបំផុត។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះទ្រឹស្តី CFD: ផ្តើមដោយការស្វែងយល់ពីទ្រឹស្តីមូលដ្ឋាននៃគណិតវិទ្យា Computational Fluid Dynamics (CFD) និងម៉ូដែល Large Eddy Simulation (LES) តាមរយៈសៀវភៅណែនាំ ឬវគ្គសិក្សាតាមអ៊ីនធឺណិត។
  2. ដំឡើង និងស្វែងយល់កម្មវិធី OpenFOAM: ធ្វើការដំឡើងកម្មវិធី OpenFOAM នៅលើប្រព័ន្ធប្រតិបត្តិការ Linux និងអនុវត្តតាម Tutorials ជាមូលដ្ឋានដើម្បីរៀនពីរបៀបរៀបចំក្រឡា (Mesh generation) និងការកំណត់លក្ខខណ្ឌព្រំដែន (Boundary Conditions)។
  3. អនុវត្តការសរសេរកូដភាសា C++: ពង្រឹងជំនាញសរសេរកូដ C++ ដើម្បីអាចយល់ដឹង និងកែប្រែគំរូគណិតវិទ្យានៅក្នុងបរិស្ថាន OpenFOAM ជាពិសេសការបន្ថែមម៉ូដែលចំហេះ និងការផ្ទេរកម្តៅ។
  4. អភិវឌ្ឍម៉ូដែលអណ្តាតភ្លើង និងដំណើរការក្លែងធ្វើ: បង្កើតម៉ូដែល 3D ស៊ីឡាំងជាមួយនឹងក្បាលដុតសាមញ្ញ បន្ទាប់មកគណនាដោយប្រើក្បួនដោះស្រាយ PIMPLE algorithm ដោយកំណត់សម្ពាធ និងអត្រាលំហូរឧស្ម័នតាមការចង់បាន។
  5. វិភាគលទ្ធផលតាមរយៈអត្រាបញ្ចេញកម្តៅ: ទាញយកទិន្នន័យអត្រាបញ្ចេញកម្តៅ (Heat Release Rate) ពីលទ្ធផល CFD ជំនួសឱ្យការប្រើតែសីតុណ្ហភាពអតិបរមា ដើម្បីកំណត់ប្រវែងអណ្តាតភ្លើង ហើយយកវាទៅប្រៀបធៀបវាយតម្លៃជាមួយទិន្នន័យពិសោធន៍ជាក់ស្តែង។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Computational Fluid Dynamics (CFD) (ឌីណាមិកនៃសន្ទនីយ៍តាមរយៈការគណនាកុំព្យូទ័រ) ជាសាខាមួយនៃយន្តវិទ្យាសន្ទនីយ៍ដែលប្រើប្រាស់ការវិភាគលេខកុំព្យូទ័រ និងក្បួនដោះស្រាយ (Algorithms) ដើម្បីដោះស្រាយ និងវិភាគបញ្ហាដែលពាក់ព័ន្ធនឹងលំហូរនៃអង្គធាតុរាវ ឬឧស្ម័ន ព្រមទាំងការផ្ទេរកម្តៅនិងប្រតិកម្មគីមី (ដូចជាចំហេះ)។ ដូចជាការប្រើប្រាស់កុំព្យូទ័រដើម្បីបង្កើតកន្លែងពិសោធន៍និម្មិតមួយសម្រាប់មើលខ្យល់បក់ ឬទឹកហូរ និងការឆេះ ដោយមិនបាច់ប្រើវត្ថុធាតុពិតប្រាកដ។
Diffusion Jet Flame (អណ្តាតភ្លើងប្រភេទចំហេះសាយភាយតាមក្បាលបាញ់) ជាប្រភេទអណ្តាតភ្លើងដែលឥន្ធនៈ និងអុកស៊ីហ្សែន (ខ្យល់) មិនត្រូវបានលាយបញ្ចូលគ្នាជាមុនទេ តែពួកវាត្រូវបានបាញ់ចេញមកក្រៅដាច់ដោយឡែកពីគ្នា ទើបលាយបញ្ចូលគ្នានិងឆេះនៅពេលតែមួយតាមរយៈដំណើរការសាយភាយចូលគ្នានៅក្នុងបរិយាកាស។ ដូចជាអណ្តាតភ្លើងដែលចេញពីដែកកេះ ឬចង្ក្រានហ្គាស ដែលហ្គាសបាញ់ចេញមកក្រៅទើបប៉ះខ្យល់ហើយឆេះ។
Large Eddy Simulation (LES) (ការក្លែងធ្វើកួចខ្យល់ខ្នាតធំ) ជាបច្ចេកទេសគណិតវិទ្យាក្នុង CFD សម្រាប់យកគំរូលំហូរដែលមានភាពច្របូកច្របល់ (Turbulence) ដោយវាធ្វើការគណនាដោយផ្ទាល់តែលើចលនាកួចខ្យល់ធំៗ និងប្រើរូបមន្តប៉ាន់ស្មានសម្រាប់កួចខ្យល់តូចៗ ដើម្បីកាត់បន្ថយពេលវេលានៃការគណនារបស់កុំព្យូទ័រ។ ដូចជាការគូររូបទឹកហូរដែលយើងគូសរលកធំៗឲ្យច្បាស់លម្អិត តែចំពោះរលកតូចៗល្អិតៗយើងគ្រាន់តែផាត់ពណ៌ព្រាលៗដើម្បីកុំឲ្យខាតពេល។
OpenFOAM (កម្មវិធីកូដបើកចំហ OpenFOAM) ជាកម្មវិធីកុំព្យូទ័រកូដបើកចំហ (Open-source) ដែលផ្តល់សិទ្ធិឱ្យអ្នកប្រើប្រាស់យកទៅកែច្នៃ និងប្រើដោយឥតគិតថ្លៃ សម្រាប់ដោះស្រាយបញ្ហាគណិតវិទ្យាស្មុគស្មាញ ជាពិសេសគឺការក្លែងធ្វើលំហូរសន្ទនីយ៍ (CFD) ដោយប្រើប្រាស់ភាសា C++ ។ ដូចជាប្រអប់ឧបករណ៍ជាង (Toolbox) ឥតគិតថ្លៃដែលគេចែកឲ្យអ្នកវិទ្យាសាស្ត្រយកទៅដំឡើង និងបន្ថែមឧបករណ៍ថ្មីៗដើម្បីដោះស្រាយលំហាត់រូបវិទ្យា។
Heat Release Rate (អត្រាបញ្ចេញកម្តៅ) ជារង្វាស់នៃបរិមាណថាមពលកម្តៅដែលត្រូវបានបញ្ចេញក្នុងមួយឯកតាពេលវេលាក្នុងកំឡុងពេលមានប្រតិកម្មចំហេះ។ នៅក្នុងការស្រាវជ្រាវនេះ វាត្រូវបានគេចាត់ទុកថាជាសូចនាករដ៏ល្អបំផុតសម្រាប់កំណត់ប្រវែង និងរូបរាងពិតប្រាកដរបស់អណ្តាតភ្លើងនៅក្នុងម៉ូដែលកុំព្យូទ័រ។ ដូចជារង្វាស់ល្បឿនដែលអុសមួយដុំឆេះបញ្ចេញកម្តៅមកក្រៅ ដែលធ្វើឲ្យយើងអាចកំណត់តំបន់ដែលកំពុងឆេះសន្ធោសន្ធៅបានច្បាស់លាស់។
Finite Volume Method (FVM) (វិធីសាស្ត្រមាឌកំណត់) ជាបច្ចេកទេសគណនាទម្រង់លេខ (Numerical method) ដែលបំបែកលំហទាំងមូលនៃទម្រង់គណនា (CFD domain) ទៅជាក្រឡា ឬប្រអប់តូចៗ (មាឌ) រួចគណនាលំហូរថាមពល និងរូបធាតុដែលចេញចូលប្រអប់នីមួយៗ ដើម្បីរកចម្លើយរួមនៃប្រព័ន្ធ។ ដូចជាការកាត់នំខេកធំមួយជាដុំតូចៗ ហើយគណនាចំនួនស្ករក្នុងដុំនីមួយៗដើម្បីប៉ាន់ស្មានពីភាពផ្អែមរបស់នំទាំងមូល។
Mixture Fraction (ប្រភាគល្បាយ) ជារង្វាស់គណិតវិទ្យាដែលតំណាងឱ្យសមាមាត្រនៃម៉ាសឥន្ធនៈនៅក្នុងល្បាយឧស្ម័ន ដែលជួយសម្រួលដល់ការគណនាប្រតិកម្មគីមីដ៏ស្មុគស្មាញនៅក្នុងការក្លែងធ្វើអណ្តាតភ្លើង ដោយវាធ្វើការសន្មតថាឥន្ធនៈនិងអុកស៊ីហ្សែនឆេះភ្លាមៗពេលលាយចូលគ្នា។ ដូចជាការវាស់ភាគរយទឹកស៊ីរ៉ូនៅក្នុងកែវទឹកកកឈូស ដើម្បីដឹងថាកន្លែងណាផ្អែមខ្លាំង (ឥន្ធនៈច្រើន) កន្លែងណាសាប (ខ្យល់ច្រើន)។
