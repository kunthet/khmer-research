Pearson Correlation Analysis
ការវិភាគទំនាក់ទំនង Pearson		 មានភាពសាមញ្ញក្នុងការកំណត់កម្រិត និងទិសដៅនៃទំនាក់ទំនងរវាងអថេរឯករាជ្យនីមួយៗ និងអថេរអាស្រ័យ។ វាបង្ហាញយ៉ាងច្បាស់ពីកត្តាណាដែលមានទំនាក់ទំនងវិជ្ជមាន។ មិនអាចបង្ហាញពីឥទ្ធិពលរួមបញ្ចូលគ្នានៃអថេរជាច្រើន ឬកំណត់ពីអំណាចក្នុងការទស្សន៍ទាយ (Predictive power) នោះទេ។ រកឃើញថាការបង្ហាញអារម្មណ៍ (r=.521) ការគ្រប់គ្រងហិរញ្ញវត្ថុ (r=.411) និងលំហូរទំនាក់ទំនង (r=.378) មានទំនាក់ទំនងវិជ្ជមានយ៉ាងសំខាន់។
Multiple Regression Analysis

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាអំពីឧបករណ៍វាស់ស្ទង់ (Analyze Measurement Instruments): ស្វែងរក និងសិក្សាអំពីកម្រងសំណួរ Marital Adjustment and Personality Types Inventory (MAPTI) ឬ Dyadic Adjustment Scale (DAS) ដើម្បីរៀបចំសម្រួល និងបកប្រែជាភាសាខ្មែរឱ្យស្របតាមវប្បធម៌ក្នុងស្រុក។
  2. រៀបចំការប្រមូលទិន្នន័យ (Digital Data Collection Setup): ប្រើប្រាស់ឧបករណ៍ដូចជា KoboToolbox ឬ Qualtrics ដើម្បីបង្កើតកម្រងសំណួរស្ទង់មតិឌីជីថល ដែលជួយសម្រួលដល់ការប្រមូលទិន្នន័យពីគូស្វាមីភរិយានៅតាមខេត្តក្រុងផ្សេងៗក្នុងប្រទេសកម្ពុជាប្រកបដោយសុវត្ថិភាព។
  3. អនុវត្តការវិភាគស្ថិតិកម្រិតខ្ពស់ (Conduct Statistical Analysis): ប្រើប្រាស់កម្មវិធី IBM SPSS ឬ R Studio ដើម្បីអនុវត្តការវិភាគ Reliability Check (Cronbach's Alpha) អមដោយ Pearson Correlation និង Multiple Regression ដើម្បីប្រៀបធៀបលទ្ធផលជាមួយបរិបទប្រទេសនីហ្សេរីយ៉ា។
  4. រៀបចំកម្មវិធីអន្តរាគមន៍ (Design Intervention Programs): ផ្អែកលើលទ្ធផលស្រាវជ្រាវ សូមរៀបចំសិក្ខាសាលា ឬកម្មវិធីប្រឹក្សាគ្រួសារ (Family Enrichment Program) ដោយប្រើប្រាស់គោលការណ៍ Cognitive Behavioral Therapy (CBT) ដែលផ្តោតសំខាន់លើជំនាញទំនាក់ទំនង និងការគ្រប់គ្រងហិរញ្ញវត្ថុរួមគ្នា។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Marital adjustment (ការសម្របខ្លួនក្នុងអាពាហ៍ពិពាហ៍) ដំណើរការផ្លូវចិត្តនិងអាកប្បកិរិយាដែលប្ដីប្រពន្ធកែប្រែទម្លាប់ តម្រូវការ និងការរំពឹងទុករបស់ខ្លួន ដើម្បីរស់នៅចុះសម្រុងគ្នា ព្រមទាំងចេះរួមគ្នាដោះស្រាយបញ្ហានិងភាពខុសគ្នានៅក្នុងជីវិតគ្រួសារ។ ដូចជាការលេងភ្លេងជាក្រុម ដែលអ្នកលេងម្នាក់ៗត្រូវស្ដាប់ និងកែសម្រួលចង្វាក់ឧបករណ៍របស់ខ្លួនដើម្បីឱ្យបទភ្លេងលេចចេញមកពិរោះរណ្ដំចូលគ្នា។
expo-facto design (រចនាបទស្រាវជ្រាវក្រោយព្រឹត្តិការណ៍) វិធីសាស្ត្រស្រាវជ្រាវដែលអ្នកស្រាវជ្រាវសិក្សាពីឥទ្ធិពលនៃកត្តាអ្វីមួយដែលបានកើតឡើងរួចមកហើយ តាមរយៈការអង្កេតទិន្នន័យដែលមានស្រាប់ ដោយមិនមានការបញ្ជា ឬផ្លាស់ប្តូរអថេរ (variables) ដោយផ្ទាល់នៅក្នុងបន្ទប់ពិសោធន៍នោះទេ។ ដូចជាប៉ូលីសស៊ើបអង្កេតកន្លែងកើតហេតុគ្រោះថ្នាក់ចរាចរណ៍ ដើម្បីស្វែងរកមូលហេតុ (ដូចជាល្បឿន ឬការស្រវឹង) បន្ទាប់ពីហេតុការណ៍បានកើតឡើងរួចបាត់ទៅហើយ។
purposive sampling technique (បច្ចេកទេសជ្រើសរើសគំរូតាមគោលដៅ) ការជ្រើសរើសអ្នកចូលរួមក្នុងការសិក្សាដោយផ្អែកលើការវិនិច្ឆ័យរបស់អ្នកស្រាវជ្រាវផ្ទាល់ ដោយរើសយកតែក្រុមមនុស្សណាដែលមានលក្ខណៈសម្បត្តិស្របតាមគោលបំណងនៃការសិក្សា (ក្នុងទីនេះគឺអ្នកដែលបានរៀបការរួច) ជាជាងការចាប់ឆ្នោតជ្រើសរើសដោយចៃដន្យទូទៅ។ ដូចជាគ្រូបង្វឹកបាល់ទាត់ដើររើសតែសិស្សណាដែលមានកម្ពស់ខ្ពស់ និងរត់លឿន ដើម្បីបង្កើតក្រុមជម្រើសជាតិ មិនមែនចាប់ឆ្នោតរើសសិស្សណាក៏បានក្នុងសាលានោះទេ។
Cronbach alpha (មេគុណអាល់ហ្វា Cronbach) រង្វាស់ស្ថិតិមួយប្រើសម្រាប់វាស់ស្ទង់កម្រិតនៃភាពជឿជាក់ (Reliability) ឬភាពស៊ីចង្វាក់គ្នានៃសំណួរខាងក្នុងកម្រងសំណួរ (Internal consistency) ថាតើសំណួរទាំងនោះពិតជាកំពុងវាស់ស្ទង់លើចំណុចគំនិតតែមួយពិតប្រាកដមែនឬទេ។ ដូចជាការថ្លឹងទម្ងន់របស់របរមួយចំនួន៣ដងដោយប្រើជញ្ជីងដដែល បើជញ្ជីងនោះបង្ហាញទម្ងន់ដូចគ្នាច្រើនដង មានន័យថាជញ្ជីងនោះមានភាពជឿជាក់ខ្ពស់។
Multiple Regression Analysis (ការវិភាគតំរែតំរង់ពហុគុណ) វិធីសាស្ត្រស្ថិតិដែលប្រើដើម្បីទស្សន៍ទាយតម្លៃនៃអថេរអាស្រ័យមួយ (ឧទាហរណ៍៖ ការសម្របខ្លួនក្នុងអាពាហ៍ពិពាហ៍) ដោយគណនាផ្អែកលើការរួមបញ្ចូលគ្នានៃអថេរឯករាជ្យពីរ ឬច្រើនក្នុងពេលតែមួយ (ឧទាហរណ៍៖ ការគ្រប់គ្រងលុយ កម្រិតនៃការទំនាក់ទំនង។ល។) ដើម្បីដឹងថាកត្តាណាមានឥទ្ធិពលខ្លាំងជាងគេ។ ដូចជាការទស្សន៍ទាយពិន្ទុប្រឡងរបស់សិស្ស ដោយយកកត្តាជាច្រើនមកគិតបញ្ចូលគ្នាក្នុងពេលតែមួយ ដូចជា ម៉ោងរៀនគួរ ម៉ោងគេង និងកម្រិតអាហារូបត្ថម្ភ។
Inter-correlation matrix (ម៉ាទ្រីសទំនាក់ទំនងអន្តរអថេរ) តារាងទិន្នន័យស្ថិតិដែលបង្ហាញពីកម្រិតនិងទិសដៅនៃទំនាក់ទំនងរវាងអថេរនីមួយៗជាមួយអថេរផ្សេងទៀតទាំងអស់នៅក្នុងការសិក្សា ដើម្បីឱ្យគេមើលឃើញខ្វែងគ្នាថាតើកត្តាណាខ្លះដើរស្របគ្នា ឬដើរផ្ទុយគ្នា។ ដូចជាតារាងចម្ងាយផ្លូវពីខេត្តមួយទៅខេត្តមួយទៀតនៅលើផែនទី ដែលយើងអាចមើលខ្វែងជួរឈរនិងជួរដេក ដើម្បីដឹងថាទីក្រុងណាខ្លះនៅជិតគ្នាជាងគេ។
R2 adjusted (R ការ៉េដែលបានកែតម្រូវ) តម្លៃភាគរយដែលបញ្ជាក់ថា តើការផ្លាស់ប្តូរនៃលទ្ធផល (Variance) អាចត្រូវបានពន្យល់ដោយកត្តាដែលយើងកំពុងសិក្សាបានប៉ុន្មានភាគរយ ហើយវាបានដកចេញនូវភាគរយខុសឆ្គងដែលកើតពីការប្រើប្រាស់អថេរច្រើនពេក។ ក្នុងឯកសារនេះទទួលបាន ០.៣៦ ឬ ៣៦%។ ប្រៀបដូចជាការធ្វើនំខេកមួយបានឆ្ងាញ់ យើងដឹងថា ៣៦% គឺដោយសារការលាយម្សៅនិងស្ករបានត្រឹមត្រូវ ចំណែក ៦៤% ទៀតប្រហែលមកពីកត្តាផ្សេងដូចជាសីតុណ្ហភាពចង្ក្រានដែលយើងមិនបានវាស់។
marital enrichment programme (កម្មវិធីពង្រឹងគុណភាពអាពាហ៍ពិពាហ៍) កម្មវិធីអន្តរាគមន៍បែបបង្ការដែលមានគោលដៅបង្រៀនគូស្វាមីភរិយាឱ្យរៀនពីជំនាញទំនាក់ទំនង វិធីសាស្ត្រដោះស្រាយបញ្ហា និងការយល់ចិត្តគ្នា ដើម្បីពង្រឹងចំណងស្នេហា និងជៀសវាងការឈានទៅរកការលែងលះនាពេលអនាគត។ ដូចជាការយកឡានទៅត្រួតពិនិត្យ និងប្តូរប្រេងម៉ាស៊ីនមុនពេលវាខូច ដើម្បីធានាថាឡានអាចជិះបានយូរអង្វែង ដោយមិនបាច់រង់ចាំទាល់តែងាប់ម៉ាស៊ីនទើបអូសយកទៅជាងនោះទេ។
