៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

  1. សិក្សាពីគោលនយោបាយកសិកម្មតាមកិច្ចសន្យា: ស្រាវជ្រាវឯកសារគោលនយោបាយកសិកម្មកម្ពុជា (ដូចជាអនុក្រឹត្យស្តីពីកសិកម្មតាមកិច្ចសន្យា) និងប្រៀបធៀបជាមួយគោលនយោបាយវៀតណាមដោយប្រើប្រាស់ Comparative Policy Analysis ដើម្បីស្វែងរកចំណុចខ្វះខាតក្នុងការអនុវត្ត។
  2. វិភាគខ្សែច្រវាក់តម្លៃនិងប្រព័ន្ធឈ្មួញកណ្តាល: ចុះប្រមូលទិន្នន័យនៅមូលដ្ឋានដើម្បីគូសវាសខ្សែច្រវាក់តម្លៃស្រូវនៅកម្ពុជាដោយប្រើប្រាស់ Value Chain Mapping Tools និង Stakeholder Analysis ដើម្បីយល់ពីឥទ្ធិពលរបស់ឈ្មួញកណ្តាល។
  3. វាយតម្លៃសមត្ថភាពសហគមន៍កសិកម្ម (ACs): អនុវត្តការវាយតម្លៃសមត្ថភាពស្ថាប័នដោយប្រើប្រាស់ SWOT Analysis ដើម្បីកំណត់ភាពខ្លាំង និងចំណុចខ្សោយរបស់សហគមន៍កសិកម្មក្នុងការធ្វើជាតំណាងកសិករសម្រាប់ចុះកិច្ចសន្យាជាមួយរោងម៉ាស៊ីន។
  4. រៀបចំនិងសាកល្បងគំរូកិច្ចសន្យាដឹកនាំដោយសហគ្រាស: សហការជាមួយរោងម៉ាស៊ីនកិនស្រូវដើម្បីបង្កើតគម្រោងសាកល្បង (Pilot project) ដោយប្រើប្រាស់វិធីសាស្ត្រ Participatory Action Research (PAR) ដោយតម្រូវឱ្យរោងម៉ាស៊ីនផ្តល់ធាតុចូល (ពូជ ជី) ហើយសហគមន៍ធានាការផ្គត់ផ្គង់ទិន្នផលត្រលប់មកវិញ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)
