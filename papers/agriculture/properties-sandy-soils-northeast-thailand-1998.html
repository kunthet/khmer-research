បញ្ហា (The Problem)៖ ការសិក្សានេះវិភាគលើលក្ខណៈរូបសាស្ត្រ គីមី និងសមត្ថភាពជីជាតិនៃដីខ្សាច់នៅតំបន់ខ្ពង់រាបភាគឦសាននៃប្រទេសថៃ ដែលជាឧបសគ្គចម្បងដល់ការដាំដុះដំណាំកសិកម្មដោយសារតែកង្វះជីវជាតិ។

វិធីសាស្ត្រ (The Methodology)៖ ការស្រាវជ្រាវនេះត្រូវបានអនុវត្តតាមរយៈការចុះប្រមូលទិន្នន័យផ្ទាល់នៅទីវាល រួមជាមួយនឹងការវិភាគសំណាកដីនៅក្នុងមន្ទីរពិសោធន៍កសិកម្ម។

  • ការវិភាគកម្រិតស្រទាប់ដី និងការសង្កេតបរិស្ថាន (Pedon analysis and soil environment observation)
  • ការវិភាគលក្ខណៈរូបសាស្ត្រ គីមីសាស្ត្រ និងរ៉ែនៃដី (Physical, chemical, and mineralogical analyses)
  • ការកំណត់ចំណាត់ថ្នាក់សមត្ថភាពជីជាតិដីដោយប្រើកម្មវិធីកុំព្យូទ័រ (Soil fertility capability classification - FCC)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ដីទាំងនេះភាគច្រើនជាប្រភេទដីខ្សាច់ (Sandy Entisols, Alfisols, Ultisols) ដែលមានជាតិអាស៊ីតខ្ពស់ (pH ≤ 6.5) សារធាតុសរីរាង្គទាប (<10 g/kg) និងកម្រិតផូស្វ័រ ព្រមទាំងប៉ូតាស្យូមទាប។
  • ដីតំបន់ខ្ពង់រាបមានសមត្ថភាពផ្ទុកទឹកទាប និងអត្រាជ្រាបទឹកលឿន ដែលងាយប្រឈមនឹងការខ្វះខាតសំណើម ខណៈដីតំបន់ទំនាបមានសក្តានុពលបាត់បង់អាសូត (Denitrification) ក្នុងលក្ខខណ្ឌគ្មានអុកស៊ីហ្សែន។
  • ការគ្រប់គ្រងដីប្រកបដោយប្រសិទ្ធភាពតម្រូវឱ្យមានការបែងចែកការដាក់ជី (Split application) ការបង្កើនសារធាតុសរីរាង្គលើផ្ទៃដី ការបន្សាបអាស៊ីតក្នុងកម្រិតទាប និងការតាមដានកម្រិតប៉ូតាស្យូមជាប្រចាំ។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Standard Soil Laboratory Analysis
ការវិភាគដីតាមស្តង់ដារមន្ទីរពិសោធន៍ (រូបសាស្ត្រ គីមីសាស្ត្រ និងរ៉ែ)		 ផ្តល់ទិន្នន័យលម្អិតនិងច្បាស់លាស់អំពីលក្ខណៈរបស់ដីដូចជា កម្រិត pH សារធាតុសរីរាង្គ និងប្រភេទរ៉ែ។ ចំណាយពេលយូរ ត្រូវការឧបករណ៍ពិសោធន៍ទំនើប និងអ្នកជំនាញបច្ចេកទេស។ រកឃើញថាដីមានជាតិអាស៊ីតខ្ពស់ (pH ≤ 6.5) សារធាតុសរីរាង្គទាប (<10 g/kg) និងកម្រិត N, P, K ទាប។
Soil Fertility Capability Classification (FCC)
ការកំណត់ចំណាត់ថ្នាក់សមត្ថភាពជីជាតិដី (FCC)		 ជួយបំប្លែងទិន្នន័យស្មុគស្មាញពីមន្ទីរពិសោធន៍ទៅជាព័ត៌មានងាយយល់សម្រាប់ការគ្រប់គ្រងដីកសិកម្មដោយប្រើកម្មវិធីកុំព្យូទ័រ។ ត្រូវការទិន្នន័យបញ្ចូលដែលត្រឹមត្រូវពីមន្ទីរពិសោធន៍ជាមុនសិនទើបអាចដំណើរការបាន។ ចាត់ថ្នាក់ដីជាក្រុម Sdaekp, Sdhekp, SLdhekp (ដីទួល) និង Lgaekp, Lghekp (ដីទំនាប) ដើម្បីងាយស្រួលគ្រប់គ្រង។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះទាមទារការប្រើប្រាស់ឧបករណ៍មន្ទីរពិសោធន៍កសិកម្មទំនើប និងកម្មវិធីកុំព្យូទ័រសម្រាប់ការវិភាគនិងចាត់ថ្នាក់ទិន្នន័យ។

  • Hardware: ឧបករណ៍មន្ទីរពិសោធន៍ដូចជា Atomic Absorption Spectrophotometer (AA), Spectronic 20, X-ray diffractometer និង Polarizing microscope សម្រាប់ការវិភាគរ៉ែដី។
  • Software: កម្មវិធីកុំព្យូទ័រ (សរសេរជាភាសា Basic language) សម្រាប់ការចាត់ថ្នាក់ Fertility Capability Classification (FCC)។
  • Dataset: សំណាកដី និងទិន្នន័យបរិស្ថានពីទីតាំងចំនួន ៩ កន្លែងនៅខ្ពង់រាបភាគឦសានប្រទេសថៃ (Northeast Plateau)។
  • Expertise: ជំនាញផ្នែកវិទ្យាសាស្ត្រដី (Soil Science) ការវិភាគរ៉ែ និងការប្រើប្រាស់ប្រព័ន្ធវិភាគមន្ទីរពិសោធន៍។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងផ្តោតសំខាន់ទៅលើដីខ្សាច់នៅតំបន់ខ្ពង់រាបភាគឦសាននៃប្រទេសថៃ ដែលមានអាកាសធាតុប្រភេទសាវ៉ាណា (Tropical savanna)។ ទិន្នន័យនេះមានសារៈសំខាន់សម្រាប់ប្រទេសកម្ពុជា ដោយសារតំបន់មួយចំនួននៅកម្ពុជាមានលក្ខណៈភូគព្ភសាស្ត្រ និងអាកាសធាតុប្រហាក់ប្រហែលគ្នា ដែលអាចយកលទ្ធផលនេះមកប្រៀបធៀប និងអនុវត្តបានយ៉ាងមានប្រសិទ្ធភាព។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រនៃការវាយតម្លៃដី និងការណែនាំពីការគ្រប់គ្រងដីខ្សាច់នៅក្នុងឯកសារនេះ គឺមានប្រយោជន៍យ៉ាងខ្លាំងសម្រាប់ការកែលម្អវិស័យកសិកម្មនៅប្រទេសកម្ពុជា។

  • តំបន់ដីខ្សាច់នៅកម្ពុជា (ឧទាហរណ៍៖ ខេត្តសៀមរាប តាកែវ និងតំបន់ខ្ពង់រាប): អាចអនុវត្តបច្ចេកទេសចែករំលែកការដាក់ជី (Split application) និងការរក្សាសារធាតុសរីរាង្គលើផ្ទៃដី ដើម្បីដោះស្រាយបញ្ហាដីខ្សាច់ដែលងាយជ្រាបទឹក និងខ្វះជីវជាតិសម្រាប់ដំណាំដំឡូងមី ឬអំពៅ។
  • ការដាំដុះដំណាំស្រូវនៅតំបន់ទំនាប (Lowland Rice Cultivation): ជួយកសិករឱ្យយល់ពីការបាត់បង់អាសូត (Denitrification) ក្នុងលក្ខខណ្ឌដីលិចទឹក និងណែនាំពីការប្រើប្រាស់ជីប្រកបដោយប្រសិទ្ធភាព។
  • វិទ្យាស្ថានស្រាវជ្រាវកសិកម្មកម្ពុជា (CARDI) និងសាកលវិទ្យាល័យភូមិន្ទកសិកម្ម (RUA): អាចយកប្រព័ន្ធចំណាត់ថ្នាក់ FCC (Fertility Capability Classification) ដើម្បីធ្វើការវាយតម្លៃ និងគូសផែនទីជីជាតិដីកសិកម្មឱ្យកាន់តែមានស្តង់ដារ។

សរុបមក ការអនុវត្តបច្ចេកទេសទាំងនេះនឹងជួយកែលម្អទិន្នផលកសិកម្មនៅលើតំបន់ដីខ្សាច់នៅកម្ពុជា តាមរយៈការគ្រប់គ្រងជី និងការថែរក្សាសំណើមដីបានត្រឹមត្រូវ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ជំហានទី១៖ សិក្សាមូលដ្ឋានគ្រឹះនៃវិទ្យាសាស្ត្រដី និងប្រព័ន្ធ FCC: ស្វែងយល់ពីលក្ខណៈរូបសាស្ត្រ និងគីមីរបស់ដី និងវិធីសាស្ត្រចំណាត់ថ្នាក់ Fertility Capability Classification (FCC) របស់ Sanchez et al. (1982) តាមរយៈការស្រាវជ្រាវឯកសារបន្ថែម។
  2. ជំហានទី២៖ ប្រមូល និងវិភាគសំណាកដី: ចុះប្រមូលសំណាកដីនៅតំបន់គោលដៅ និងប្រើប្រាស់ឧបករណ៍មន្ទីរពិសោធន៍ (ឬបញ្ជូនទៅមន្ទីរពិសោធន៍ជាតិ) ដើម្បីវិភាគរកកម្រិត pH ការផ្លាស់ប្តូរអុីយ៉ុង កម្រិតអាសូត ផូស្វ័រ និងប៉ូតាស្យូម។
  3. ជំហានទី៣៖ បង្កើតទិន្នន័យចំណាត់ថ្នាក់សមត្ថភាពដី (FCC): ប្រើប្រាស់កម្មវិធីកុំព្យូទ័រ (ឧទាហរណ៍ Python ឬ R) ដើម្បីសរសេរកូដបំប្លែងទិន្នន័យមន្ទីរពិសោធន៍ទៅជាក្រុមចំណាត់ថ្នាក់ FCC (ដូចជា Sdaekp សម្រាប់ដីទួល ឬ Lgaekp សម្រាប់ដីទំនាប)។
  4. ជំហានទី៤៖ អភិវឌ្ឍយុទ្ធសាស្ត្រគ្រប់គ្រងដីកសិកម្មជាក់ស្តែង: ផ្អែកលើលទ្ធផល FCC សូមបង្កើតការណែនាំជាលាយលក្ខណ៍អក្សរដល់កសិករ ដូចជាការដាក់ជីជាដំណាក់កាល (Split application) ការគ្របដីដោយសារធាតុសរីរាង្គ ឬការប្រើប្រាស់កំបោរកសិកម្មក្នុងកម្រិតទាប។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Pedon analysis (ការវិភាគកម្រិតស្រទាប់ដី) ការសិក្សានិងវិភាគលើទម្រង់បញ្ឈរនៃដីពីផ្ទៃខាងលើរហូតដល់ស្រទាប់ថ្មខាងក្រោម (Soil Profile) ដើម្បីយល់ពីការកកើត លក្ខណៈរូបសាស្ត្រ និងការបែងចែកស្រទាប់របស់វា។ ដូចជាការកាត់នំខេកមួយចំណិតដើម្បីមើលថាមានស្រទាប់រសជាតិអ្វីខ្លះនៅខាងក្នុង។
Cation exchange capacity / CEC (សមត្ថភាពផ្លាស់ប្តូរអុីយ៉ុងវិជ្ជមាន) រង្វាស់នៃសមត្ថភាពរបស់ដីក្នុងការផ្ទុក និងផ្លាស់ប្តូរអ៊ីយ៉ុងដែលមានបន្ទុកវិជ្ជមាន (ដូចជា កាល់ស្យូម ម៉ាញេស្យូម ប៉ូតាស្យូម) ដែលជួយទប់សារធាតុចិញ្ចឹមមិនឱ្យលេចជ្រាបបាត់ទៅតាមទឹក។ ដូចជាអេប៉ុងដែលអាចស្រូបទាញនិងរក្សាទុកទឹកជីជាតិសម្រាប់ឱ្យរុក្ខជាតិបឺតស្រូបយកពេលវាត្រូវការ។
Fertility Capability Classification / FCC (ចំណាត់ថ្នាក់សមត្ថភាពជីជាតិដី) ប្រព័ន្ធវាយតម្លៃដីដោយផ្តោតលើលក្ខណៈរូបសាស្ត្រ និងគីមីនៃដីស្រទាប់ខាងលើ (ជម្រៅ ៥០សង់ទីម៉ែត្រ) ដើម្បីកំណត់ពីសក្តានុពល និងចង្អុលបង្ហាញពីបញ្ហាប្រឈមសម្រាប់ការដាំដុះដំណាំ។ ដូចជាសៀវភៅកំណត់ហេតុសុខភាពរបស់ដី ដែលប្រាប់កសិករថាតើដីនោះមានជំងឺអ្វី ខ្វះវីតាមីនអ្វីខ្លះ និងត្រូវព្យាបាលបែបណា។
Denitrification (ការបាត់បង់អាសូត) ដំណើរការគីមីជីវៈនៅក្នុងដីលិចទឹក ឬដីខ្វះអុកស៊ីហ្សែន ដែលបាក់តេរីបំប្លែងសារធាតុនីត្រាត (Nitrate) ទៅជាឧស្ម័នអាសូត (Nitrogen gas) ហួតចេញទៅក្នុងបរិយាកាស ដែលធ្វើឱ្យដីបាត់បង់ជីជាតិ។ ដូចជាទឹកអប់ដែលទុកចោលមិនបិទគម្រប ធ្វើឱ្យក្លិន(ជីជាតិអាសូត)ហួតបាត់ទៅក្នុងខ្យល់អាកាសអស់។
Base saturation (តិត្ថិភាពបាស) ភាគរយនៃសមត្ថភាពផ្លាស់ប្តូរអ៊ីយ៉ុង (CEC) ដែលត្រូវបានកាន់កាប់ដោយអ៊ីយ៉ុងបាស (កាល់ស្យូម ម៉ាញេស្យូម ប៉ូតាស្យូម សូដ្យូម) ធៀបនឹងអ៊ីយ៉ុងអាស៊ីត (អ៊ីដ្រូសែន អាលុយមីញ៉ូម) ដែលបង្ហាញពីភាពមានជីជាតិ និងកម្រិតអាស៊ីត-បាសរបស់ដី។ ដូចជាភាគរយនៃកៅអីក្នុងថ្នាក់រៀនដែលមានសិស្សពូកែ(សារធាតុចិញ្ចឹមល្អ)អង្គុយ ធៀបនឹងកៅអីដែលទំនេរឬមានសិស្សកំហូច(សារធាតុអាស៊ីត)អង្គុយ។
Argillic horizons (ស្រទាប់ដីឥដ្ឋប្រមូលផ្តុំ) ស្រទាប់ដីខាងក្រោមផ្ទៃដី (Subsoil) ដែលមានការប្រមូលផ្តុំនូវភាគល្អិតដីឥដ្ឋ (Silicate clay) ដែលបានហូរជ្រាបពីស្រទាប់ផ្ទៃដីខាងលើតាមរយៈទឹកភ្លៀងរាប់ពាន់ឆ្នាំ។ ដូចជាកម្ទេចកាហ្វេដែលធ្លាក់មកកកកុញនៅបាតកែវ បន្ទាប់ពីចាក់ទឹកក្តៅទុករួចមួយសន្ទុះ។
Micromorphology (មីក្រូរូបសាស្ត្រដី) ការសិក្សាពីទម្រង់ និងការរៀបចំភាគល្អិតតូចៗនៃដី រួមទាំងរ៉ែ និងសរីរាង្គផ្សេងៗ នៅកម្រិតមីក្រូទស្សន៍ (Microscope) ដើម្បីយល់ពីប្រវត្តិសាស្រ្តនៃការកកើត និងដំណើរការរូបសាស្ត្ររបស់ដី។ ដូចជាការប្រើកែវពង្រីកដើម្បីមើលសរសៃអំបោះតូចៗនៃសាច់ក្រណាត់ថាតើវាត្រូវបានត្បាញចូលគ្នាយ៉ាងដូចម្តេច។
Infiltration rate (អត្រាជ្រាបទឹក) ល្បឿនដែលទឹកអាចជ្រាបចូលទៅក្នុងផ្ទៃដី។ សម្រាប់ដីខ្សាច់ អត្រានេះលឿនពេក ដែលធ្វើឱ្យទឹកហូរជ្រាបចុះក្រោមបាត់លឿន នាំឱ្យដីមិនអាចរក្សាសំណើមបានយូរសម្រាប់រុក្ខជាតិ។ ដូចជាការចាក់ទឹកលើគំនរដីខ្សាច់នៅមាត់សមុទ្រ ដែលទឹកលិចបាត់ចូលទៅក្នុងដីភ្លាមៗមិនដក់នៅលើមុខដីឡើយ។
