១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការស្រាវជ្រាវនេះមានគោលបំណងសិក្សាស្វែងយល់ពីឥទ្ធិពលនៃរូបរាងផ្លែរ៉ូតារី (Rotary blades) ខុសៗគ្នាទៅលើលក្ខណៈនៃកម្លាំងបង្វិល (Torque) នៅក្នុងដំណើរការភ្ជួររាស់ដីកសិកម្ម។

វិធីសាស្ត្រ (The Methodology)៖ ការពិសោធន៍ត្រូវបានធ្វើឡើងនៅក្នុងមន្ទីរពិសោធន៍ដោយប្រើប្រាស់ធុងដី (Soil bin) ដើម្បីវាស់ស្ទង់កម្លាំងបង្វិលនៃផ្លែរ៉ូតារីចំនួន ៣ ប្រភេទក្នុងល្បឿន និងប្រភេទដីខុសៗគ្នា។

  • ការធ្វើតេស្តក្នុងធុងដី (Soil bin) សម្រាប់ប្រភេទដីល្បាយខ្សាច់ (Sandy loam) និងដីឥដ្ឋ (Clay soils) ជាមួយនឹងល្បឿនទៅមុខ ០,០៣៤ និង ០,០៦៩ ម៉ែត្រ/វិនាទី និងល្បឿនបង្វិល ១៥០, ២១៨, ២៧៨ និង ៣៤៨ ជុំ/នាទី។
  • ការប្រៀបធៀបផ្លែរ៉ូតារី ៣ ប្រភេទ៖ រាងអក្សរ C របស់ជប៉ុន (Japanese C-shaped), រាងអក្សរ L របស់អឺរ៉ុប (European L-shaped) និងរាងអក្សរ C របស់អឺរ៉ុប (European C-shaped)។
  • ការវាស់វែងការប្រែប្រួលនៃកម្លាំងបង្វិល (Torque variation) និងការសង្កេតវិភាគលើលំនាំនៃការជះដី (Soil throwing patterns)។

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • រូបរាងនៃផ្លែរ៉ូតារីគឺជាប៉ារ៉ាម៉ែត្រដ៏សំខាន់ដែលជះឥទ្ធិពលដោយផ្ទាល់ទៅលើលក្ខណៈនៃកម្លាំងបង្វិល (Torque characteristic)។
  • សម្រាប់ផ្លែរាងអក្សរ C របស់ជប៉ុន កម្លាំងបង្វិលបានកើនឡើងជាបន្តបន្ទាប់ ហើយឈានដល់កម្រិតអតិបរមានៅចន្លោះមុំ ១០៨ ទៅ ១២៥ ដឺក្រេ មុននឹងថយចុះវិញ។
  • សម្រាប់ផ្លែរាងអក្សរ L និង C របស់អឺរ៉ុប កម្លាំងបង្វិលកើនឡើងភ្លាមៗនៅពេលវាត្រូវកាត់ចូលម៉ាស់ដី ដោយកម្រិតអតិបរមាស្ថិតនៅចន្លោះ ១១១-១២០° និង ១០២-១២០° រៀងគ្នា បង្កើតបានជាខ្សែកោងស៊ីនុយសូអ៊ីត (Sinusoidal curves)។

Japanese C-shaped blade
ផ្លែរ៉ូតារីរាងអក្សរ C ជប៉ុន		 កម្លាំងបង្វិល (Torque) កើនឡើងជាបន្តបន្ទាប់និងសន្សឹមៗ ដែលជួយកាត់បន្ថយការប៉ះទង្គិចភ្លាមៗទៅលើអ័ក្សម៉ាស៊ីន។ មានភាពស័ក្តិសមខ្ពស់សម្រាប់ការប្រើប្រាស់ជាមួយត្រាក់ទ័រដើរតាម។ ទាមទារការរចនារាងកោងជាក់លាក់ដើម្បីឱ្យចុងផ្លែចូលកាត់ដីមុន ដែលអាចមានភាពស្មុគស្មាញក្នុងការផលិត។ កម្លាំងបង្វិលឈានដល់កម្រិតអតិបរមានៅចន្លោះមុំ ១០៨° ទៅ ១២៥° រួចថយចុះវិញ។
European L-shaped blade
ផ្លែរ៉ូតារីរាងអក្សរ L អឺរ៉ុប		 មានសមត្ថភាពកាត់ចូលម៉ាស់ដីបានលឿន និងផ្ទាល់ជាងមុន ដែលអាចរាស់ដីបានជ្រៅនិងមានប្រសិទ្ធភាពក្នុងស្ថានភាពដីរឹង។ កម្លាំងបង្វិលកើនឡើងភ្លាមៗ (Sudden impact) នៅពេលចាប់ផ្តើមកាត់ដី ដែលបណ្តាលឱ្យមានរំញ័រខ្លាំង និងឆាប់សឹកអ័ក្សម៉ាស៊ីន (ស័ក្តិសមតែជាមួយត្រាក់ទ័រកម្លាំងធំ)។ កម្លាំងបង្វិលឈានដល់កម្រិតអតិបរមាភ្លាមៗនៅចន្លោះមុំ ១១១° ទៅ ១២០°។

ផ្លែរ៉ូតារីរាងអក្សរ C អឺរ៉ុប		 មានរាងកោងជាងអក្សរ L បន្តិច ប៉ុន្តែនៅតែរក្សាបាននូវសមត្ថភាពកាត់ដីបានលឿននិងផ្ទាល់។ មានចរិតលក្ខណៈកម្លាំងបង្វិលស្រដៀងនឹងអក្សរ L ដែរ ពោលគឺបង្កើតនូវរំញ័រនិងកម្លាំងប៉ះទង្គិចខ្លាំង (Cyclicity) ដែលទាមទារម៉ាស៊ីនកម្លាំងខ្លាំង។ កម្លាំងបង្វិលឈានដល់កម្រិតអតិបរមាភ្លាមៗនៅចន្លោះមុំ ១០២° ទៅ ១២០° រួចបង្កើតជាខ្សែកោងស៊ីនុយសូអ៊ីត (Sinusoidal curves)។

ការចំណាយលើធនធាន (Resource Cost)៖ ការពិសោធន៍នេះទាមទារការរៀបចំមន្ទីរពិសោធន៍ផ្នែកយន្តការកសិកម្មកម្រិតខ្ពស់ និងការគ្រប់គ្រងបរិស្ថានតឹងរ៉ឹង ជាពិសេសប្រព័ន្ធធុងដី (Soil bin) និងឧបករណ៍វាស់កម្លាំងអគ្គិសនី។

  • Hardware: ប្រព័ន្ធធុងដី (Soil bin) ទំហំ ៥០ស.ម x ២៥០ស.ម x ៣០ស.ម, ម៉ូទ័រអគ្គិសនី (7 kW និង 0.746 kW), ឧបករណ៍វាស់កម្លាំងអ័ក្ស (Cross-strain gauges KFG-5-350-D16-11), ឧបករណ៍ចាប់ល្បឿន (Magnetic pick up) និងឧបករណ៍កិនពង្រាបដី (Compactor)។
  • Materials/Dataset: គំរូដីពីរប្រភេទ៖ ដីល្បាយខ្សាច់ (Sandy loam) និងដីឥដ្ឋ (Clay soil) ដែលត្រូវបានគ្រប់គ្រងកម្រិតសំណើម (១១.៣% សម្រាប់ដីល្បាយខ្សាច់) និងកម្រិតហាប់ណែនជារៀងរាល់លើកមុនពេលធ្វើតេស្តម្តងៗ។
  • Software: ម៉ាស៊ីនថតសញ្ញាឧបករណ៍ (Instrumentation tape - TEAC CT-90) និងឧបករណ៍វិភាគដើម្បីបំប្លែងសញ្ញាអាណាឡូកទៅជាលេខទិន្នន័យ (Analyzing recorder AR 1200)។

ទោះជាយ៉ាងនេះក្តី ការយល់ដឹងអំពីចរិតលក្ខណៈនៃកម្លាំងបង្វិលផ្លែរ៉ូតារី គឺមានអត្ថប្រយោជន៍យ៉ាងខ្លាំងសម្រាប់ការជ្រើសរើស និងអភិវឌ្ឍគ្រឿងយន្តកសិកម្មនៅកម្ពុជា។

  • តំបន់វាលទំនាប (ខេត្តបាត់ដំបង ពោធិ៍សាត់ និងព្រៃវែង): កសិករដែលប្រើប្រាស់ត្រាក់ទ័រដើរតាម (គោយន្តកន្ត្រៃ) ក្នុងតំបន់ដីឥដ្ឋ ឬដីល្បាយខ្សាច់ គួរតែជ្រើសរើសផ្លែរ៉ូតារីប្រភេទអក្សរ C ជប៉ុន (Japanese C-shaped) ដើម្បីជៀសវាងការខូចខាតអ័ក្សម៉ាស៊ីន និងសន្សំសំចៃប្រេងឥន្ធនៈ។
  • ឧស្សាហកម្មផលិតនិងនាំចូលគ្រឿងយន្តក្នុងស្រុក: អ្នកជំនួញ និងជាងកែច្នៃគ្រឿងយន្តកសិកម្មកម្ពុជា អាចប្រើប្រាស់ទិន្នន័យនៃមុំកម្លាំងអតិបរមា និងការរចនាទម្រង់កោង (Curvature) ដើម្បីផលិតផ្លែរ៉ូតារីដែលស័ក្តិសមនឹងកម្លាំងម៉ាស៊ីនជាក់លាក់ (ឧទាហរណ៍៖ មិនយកផ្លែអឺរ៉ុបមកបំពាក់លើម៉ាស៊ីនតូចៗ ដែលនាំឱ្យញ័រនិងឆាប់ខូច)។

សរុបមក ការជ្រើសរើសរូបរាងផ្លែរ៉ូតារីឱ្យបានត្រឹមត្រូវទៅតាមប្រភេទត្រាក់ទ័រនិងស្ថានភាពដី នឹងជួយពន្យារអាយុកាលគ្រឿងយន្ត និងបង្កើនប្រសិទ្ធភាពការងាររៀបចំដីកសិកម្មនៅកម្ពុជា។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ស្វែងយល់ពីមូលដ្ឋានគ្រឹះនៃយន្តការកាត់ដី (Soil Dynamics): និស្សិតគួរចាប់ផ្តើមពីការសិក្សាទ្រឹស្តីទាក់ទងនឹងអន្តរកម្មរវាងដីនិងគ្រឿងយន្ត (Soil-machine interaction) រួមទាំងការគណនាកម្លាំងកាត់ និងកម្លាំងកកិតដី ដោយប្រើសៀវភៅគោលផ្នែកវិស្វកម្មកសិកម្ម។
  2. រៀបចំប្រព័ន្ធវាស់ស្ទង់ (Measurement Setup): រៀនអំពីការបំពាក់និងប្រើប្រាស់ Strain gauges លើអ័ក្សវិល និងការតភ្ជាប់ទៅកាន់ប្រព័ន្ធប្រមូលទិន្នន័យដូចជា Arduino ឬឧបករណ៍ DAQ (Data Acquisition) របស់ National Instruments ដើម្បីវាស់កម្លាំងបង្វិលជាក់ស្តែង។
  3. រៀបចំការធ្វើតេស្តជាក់ស្តែង (Field Testing): ជំនួសឱ្យការធ្វើតេស្តក្នុងធុងដីមន្ទីរពិសោធន៍ គួរសហការជាមួយសហគមន៍កសិកម្មដើម្បីធ្វើតេស្តផ្លែរ៉ូតារីប្រភេទផ្សេងៗគ្នាភ្ជាប់នឹងគោយន្តកន្ត្រៃ ឬត្រាក់ទ័រ ទៅលើដីស្រែជាក់ស្តែងនៅក្នុងប្រទេសកម្ពុជា។
  4. វិភាគទិន្នន័យដោយប្រើកម្មវិធីកុំព្យូទ័រ (Data Analysis): ប្រមូលទិន្នន័យដែលបានពីឧបករណ៍វាស់ រួចយកមកគូរជាខ្សែកោងកម្លាំងបង្វិល (Torque curves) ដោយប្រើប្រាស់កម្មវិធី MATLAB ឬ Python (Matplotlib/SciPy) ដើម្បីរកមើលចំណុចកម្លាំងអតិបរមានិងលំនាំរំញ័ររបស់វា។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Torque (កម្លាំងបង្វិល) កម្លាំងដែលធ្វើឱ្យវត្ថុណាមួយវិលជុំវិញអ័ក្សរបស់វា។ ក្នុងការសិក្សានេះ វាសំដៅលើកម្លាំងដែលម៉ាស៊ីន (ត្រាក់ទ័រ ឬគោយន្ត) ត្រូវបញ្ចេញតាមរយៈអ័ក្សដើម្បីបង្វិលផ្លែរ៉ូតារីឱ្យកាត់ចូលទៅក្នុងម៉ាស់ដី។ ដូចជាកម្លាំងដែលយើងប្រើប្រាស់កដៃដើម្បីមួលបើកគម្របដបទឹកអញ្ចឹងដែរ បើមួលកាន់តែតឹង កម្លាំងបង្វិលកាន់តែធំ។
Rotary blade (ផ្លែរ៉ូតារី ឬ ផ្លែវាយដី) ជាប្រភេទផ្លែកាំបិតដែករាងកោងដែលត្រូវបានបំពាក់លើអ័ក្សម៉ាស៊ីនកសិកម្ម សម្រាប់វាយបំបែកដី កាត់ស្មៅ និងកប់កាកសំណល់រុក្ខជាតិទៅក្នុងដី។ ក្នុងពាក្យបច្ចេកទេសវាមានច្រើនរាង ដូចជារាងអក្សរ C ឬ អក្សរ L។ ដូចជាស្លាបកង្ហារនៃម៉ាស៊ីនក្រឡុកផ្លែឈើ ដែលវិលយ៉ាងលឿនដើម្បីកាត់ និងកិនដីឱ្យម៉ត់ល្អសម្រាប់ដាំដុះ។
Soil bin (ធុងដីពិសោធន៍) ឧបករណ៍ប្រអប់ទ្រវែងធំមួយនៅក្នុងមន្ទីរពិសោធន៍ ដែលគេដាក់ដីចូល និងអាចគ្រប់គ្រងកម្រិតសំណើម និងភាពហាប់ណែនបានយ៉ាងច្បាស់លាស់ ដើម្បីប្រើប្រាស់សម្រាប់ធ្វើតេស្តគ្រឿងយន្តកសិកម្មដោយមិនបាច់ទៅវាលស្រែផ្ទាល់។ ដូចជាប្រអប់ដីខ្សាច់ក្មេងលេងដ៏ធំមួយ ដែលវិស្វកររៀបចំទុកសម្រាប់បើកឡាន ឬម៉ាស៊ីនខ្នាតតូចធ្វើតេស្តមើលថាតើកង់ម៉ាស៊ីនកកិតជាមួយដីបែបណា។
Down-cut process (ដំណើរការកាត់ដីចុះក្រោម) ទិសដៅនៃការបង្វិលផ្លែរ៉ូតារីស្របគ្នានឹងទិសដៅនៃការបរទៅមុខរបស់ត្រាក់ទ័រ ដែលធ្វើឱ្យផ្លែកាំបិតកាត់ពីលើផ្ទៃដីចុះទៅក្រោមជម្រៅដី ដែលជួយរុញម៉ាស៊ីនទៅមុខ ប៉ុន្តែទាមទារកម្លាំងសង្កត់ធំ។ ដូចជាការប្រើចបកាប់ពីលើផ្ទៃដីចុះទៅក្រោម ខណៈពេលដែលយើងដើរទៅមុខស្របគ្នានឹងមុខចប។
Sinusoidal curve (ខ្សែកោងស៊ីនុយសូអ៊ីត) លក្ខណៈនៃការប្រែប្រួលកម្លាំងបង្វិលដែលឡើងចុះៗជាចង្វាក់ទៀងទាត់ (រលក) ពេលផ្លែរ៉ូតារីកាត់ចូលដី និងផុតពីដី។ សម្រាប់ផ្លែអឺរ៉ុប កម្លាំងនេះកើនឡើងខ្លាំងភ្លាមៗរួចធ្លាក់ចុះមកវិញបង្កើតជារាងរលក។ ដូចជាការជិះរទេះភ្លើងកន្ត្រាក់ (Rollercoaster) ដែលឡើងដល់កំពូលរួចចុះមកក្រោមវិញយ៉ាងលឿន បង្កើតជារលកឡើងចុះៗបន្តបន្ទាប់គ្នា។
Soil wedge (ក្រូចឆ្មារដី ឬ ដីផ្តុំជារាងក្រូចឆ្មារ) បំណែកដីដែលកកកុញនិងស្អិតជាប់នៅពីមុខផ្ទៃកោងនៃផ្លែកាំបិតរ៉ូតារីអំឡុងពេលវាកំពុងកាត់ដី ដែលជះឥទ្ធិពលដល់កម្លាំងកកិត និងទម្រង់នៃការជះដី (Throwing pattern) ចេញពីម៉ាស៊ីន។ ដូចជាពេលយើងយកស្លាបព្រាទៅឈូសការ៉េម ការ៉េមដែលប្រមូលផ្តុំកកកុញនៅពីមុខស្លាបព្រាគឺជា "ក្រូចឆ្មារដី" នោះឯង។
Strain gauge (សេនស័រវាស់កម្លាំងអ័ក្ស / ស្ត្រេនហ្គេច) សេនស័រ (Sensor) អគ្គិសនីតូចមួយដែលគេបិទភ្ជាប់លើអ័ក្សម៉ាស៊ីន ដើម្បីវាស់ស្ទង់ការប្រែប្រួលនៃកម្លាំងបង្វិល (Torque) និងកម្លាំងមួល ដោយផ្អែកលើការប្រែប្រួលរេស៊ីស្តង់អគ្គិសនីនៅពេលអ័ក្សរងសម្ពាធ។ ដូចជាសរសៃប្រសាទនៅលើស្បែករបស់យើង ដែលបញ្ជូនសញ្ញាទៅខួរក្បាលដើម្បីដឹងថាធ្ងន់ឬស្រាល នៅពេលមានអ្វីមួយមកសង្កត់លើសាច់ដុំយើង។
