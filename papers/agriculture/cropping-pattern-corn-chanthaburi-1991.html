  • ការកែលម្អគុណភាពដី (Soil Fertility Management): ការដាំដំណាំអម្បូរសណ្តែក (Legumes) ជាដំណាំទីមួយ អាចជួយចាប់យកអាសូតពីបរិយាកាសបញ្ចូលទៅក្នុងដី ដែលផ្តល់ជីវជាតិល្អសម្រាប់ដំណាំពោតដែលដាំបន្ទាប់។
  • សេដ្ឋកិច្ចកសិកម្ម (Agricultural Economics): ជួយកសិករក្នុងការចៀសវាងហានិភ័យពីការធ្លាក់ចុះតម្លៃទីផ្សារ ដោយការលក់សណ្តែកសៀងដើមរដូវធ្វើជាគ្រាប់ពូជ ដែលអាចទទួលបានតម្លៃខ្ពស់ជាងទីផ្សារធម្មតា។

សរុបមក ការផ្លាស់ប្តូរទម្លាប់ពីការដាំពោតមុន មកដាំសណ្តែកមុន គឺជាយុទ្ធសាស្រ្តសាមញ្ញតែមានប្រសិទ្ធភាពខ្ពស់ក្នុងការបង្កើនប្រាក់ចំណេញ និងនិរន្តរភាពដីកសិកម្មនៅកម្ពុជា។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. វាយតម្លៃស្ថានភាពដី និងអាកាសធាតុ: សិក្សាពីប្រភេទដី និងបរិមាណទឹកភ្លៀងនៅក្នុងតំបន់គោលដៅ (ឧ. បាត់ដំបង) ដោយប្រៀបធៀបជាមួយលក្ខខណ្ឌអាកាសធាតុបច្ចុប្បន្ន។ និស្សិតអាចប្រើប្រាស់ទិន្នន័យពីក្រសួងធនធានទឹក និងឧតុនិយម កម្ពុជា ដើម្បីរៀបចំកាលវិភាគដាំដុះឱ្យបានត្រឹមត្រូវ។
  2. ជ្រើសរើសពូជដំណាំ (Crop Selection): កំណត់ប្រភេទពូជសណ្តែកសៀង និងពោតដែលធន់នឹងអាកាសធាតុ និងមានតម្រូវការទីផ្សារខ្ពស់នៅកម្ពុជា។ សាកសួរព័ត៌មានពីអគ្គនាយកដ្ឋានកសិកម្ម ឬវិទ្យាស្ថានស្រាវជ្រាវ និងអភិវឌ្ឍន៍កសិកម្មកម្ពុជា (CARDI) សម្រាប់ជម្រើសពូជទំនើប។
  3. អនុវត្តការដាំដុះសាកល្បង (Pilot Testing): ចាប់ផ្តើមការសាកល្បងលើផ្ទៃដីតូចមួយដោយអនុវត្តតាមគំរូសណ្តែកសៀង-ពោត។ កត់ត្រាការចំណាយ (ដី, ជី, ពលកម្ម) និងទិន្នផលជាប្រចាំ ដោយប្រើប្រាស់កម្មវិធី Microsoft Excel ដើម្បីធ្វើការវិភាគប្រាក់ចំណេញសុទ្ធ។
  4. តាមដានទីផ្សារ និងយុទ្ធសាស្ត្រលក់ (Market Monitoring): សិក្សាពីការប្រែប្រួលតម្លៃទីផ្សារនៃសណ្តែកសៀងនៅដើមរដូវ និងចុងរដូវ។ រៀបចំយុទ្ធសាស្ត្រចងក្រងសហគមន៍កសិករ ដើម្បីលក់សណ្តែកសៀងជាគ្រាប់ពូជ (Seed market) នៅដើមរដូវ ដែលអាចផ្តល់តម្លៃបន្ថែមខ្ពស់។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Cropping pattern (គំរូដាំដុះ / ប្រព័ន្ធដាំដុះ) របៀបរៀបចំ និងកំណត់លំដាប់លំដោយនៃការដាំដុះដំណាំផ្សេងៗគ្នានៅលើផ្ទៃដីតែមួយក្នុងរយៈពេលមួយឆ្នាំ ដើម្បីទាញយកអត្ថប្រយោជន៍អតិបរមាពីដី និងទទួលបានប្រាក់ចំណេញខ្ពស់បំផុត។ ដូចជាការរៀបចំកាលវិភាគសិក្សាដែរ គឺត្រូវដឹងថាមុខវិជ្ជាណាត្រូវរៀនមុន និងមុខវិជ្ជាណាត្រូវរៀនបន្ទាប់ ដើម្បីឱ្យសិស្សងាយយល់និងទទួលបានលទ្ធផលល្អបំផុត។
Rainfed conditions (លក្ខខណ្ឌពឹងផ្អែកលើទឹកភ្លៀង) ការធ្វើកសិកម្មដែលពឹងផ្អែកទាំងស្រុងទៅលើទឹកភ្លៀងធម្មជាតិតាមរដូវកាល ដោយមិនមានប្រព័ន្ធធារាសាស្ត្រ ឬការស្រោចស្រពពីប្រភពទឹកផ្សេងៗឡើយ ដែលទាមទារឱ្យមានការកំណត់ពេលវេលាដាំដុះច្បាស់លាស់។ ដូចជាការរង់ចាំទឹកពីមេឃដើម្បីងូតទឹក គឺយើងមិនមានទុយោទឹកសម្រាប់បើកប្រើប្រាស់តាមចិត្តនៅពេលណាដែលយើងចង់បាននោះទេ។
Net return (ប្រាក់ចំណេញសុទ្ធ) ចំនួនទឹកប្រាក់ដែលនៅសល់ជាក់ស្តែង បន្ទាប់ពីបានកាត់កងការចំណាយសរុប (ថ្លៃពូជ ជី ពលកម្ម ជាដើម) ចេញពីប្រាក់ចំណូលសរុបដែលទទួលបានពីការលក់ទិន្នផលកសិកម្ម។ ដូចជាប្រាក់ដែលនៅសល់ក្នុងហោប៉ៅរបស់អ្នក បន្ទាប់ពីលក់នំអស់ ហើយយកប្រាក់នោះទៅទូទាត់ថ្លៃម្សៅ និងស្កររួចរាល់។
Variable costs (ការចំណាយអថេរ / ថ្លៃដើមប្រែប្រួល) ប្រភេទនៃការចំណាយលើការផលិតដែលប្រែប្រួលទៅតាមទំហំនៃការងារ ឬទំហំដី ដូចជាថ្លៃទិញគ្រាប់ពូជ ជីថ្នាំ និងថ្លៃជួលកម្មករ ដែលវានឹងកើនឡើងនៅពេលដាំដុះលើផ្ទៃដីកាន់តែធំ។ ដូចជាការចាក់សាំងម៉ូតូ គឺជិះកាន់តែឆ្ងាយ អ្នកត្រូវចំណាយលុយចាក់សាំងកាន់តែច្រើន។
Farm gate price (តម្លៃកសិដ្ឋាន / តម្លៃលក់ចេញពីចម្ការ) តម្លៃនៃកសិផលដែលកសិករអាចលក់បានភ្លាមៗនៅនឹងកន្លែង (នៅចម្ការផ្ទាល់) ដោយមិនទាន់បូកបញ្ចូលថ្លៃដឹកជញ្ជូន ឬថ្លៃសេវាកម្មកណ្តាលផ្សេងៗ ដើម្បីយកទៅកាន់ទីផ្សារឡើយ។ ដូចជាការទៅទិញផ្លែឈើពីម្ចាស់ចម្ការផ្ទាល់ ដែលមានតម្លៃថោកជាងការទិញនៅតាមផ្សារ ព្រោះមិនមានបូកគិតថ្លៃដឹកជញ្ជូន។
First crops / Second crops (ដំណាំទីមួយ / ដំណាំទីពីរ) យុទ្ធសាស្ត្រនៃការបែងចែកវដ្តដាំដុះក្នុងមួយឆ្នាំ ដោយដំណាំទីមួយត្រូវបានដាំនៅដើមរដូវវស្សា (ពេលភ្លៀងចាប់ផ្តើមធ្លាក់) ហើយដំណាំទីពីរត្រូវបានដាំបន្តភ្លាមៗបន្ទាប់ពីប្រមូលផលដំណាំទីមួយរួច ដើម្បីប្រើប្រាស់សំណើមដីដែលនៅសល់។ ដូចជាការញ៉ាំអាហារក្នុងភោជនីយដ្ឋាន ដែលមានម្ហូបគោលជាមុន រួចទើបញ៉ាំបង្អែមតាមក្រោយជាបន្តបន្ទាប់នៅលើតុតែមួយ។
