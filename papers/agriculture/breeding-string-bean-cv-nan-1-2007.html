៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃការបង្កាត់ពូជដំណាំ: និស្សិតត្រូវសិក្សាពីទ្រឹស្តីនៃការបង្កាត់ពូជរុក្ខជាតិ ដោយផ្តោតលើបច្ចេកទេសបង្កាត់ខ្វែង (Hybridization) និងការជ្រើសរើសពូជសុទ្ធ (Pure line selection) តាមរយៈឯកសារស្រាវជ្រាវ ឬសៀវភៅពន្ធុវិទ្យា។
  2. រៀបចំការសាកល្បងដាំដុះនៅស្ថានីយ: អនុវត្តការដាំដុះសាកល្បងដោយប្រើប្រាស់ប្លង់ពិសោធន៍ Randomized Complete Block (RCB) ដោយមានការដាំដុះជាប្លុក និងមានពូជត្រួតពិនិត្យ (Control) ដើម្បីធ្វើការប្រៀបធៀប។
  3. ប្រមូល និងវិភាគទិន្នន័យស្ថិតិ: ប្រើប្រាស់កម្មវិធី SAS Software ឬ R Programming ដើម្បីធ្វើការវិភាគទិន្នន័យកសិកម្ម ដូចជាការធ្វើ ANOVA និង Duncan’s Multiple Range Test (DMRT) ដើម្បីរកមើលភាពខុសគ្នាផ្នែកស្ថិតិ។
  4. វាយតម្លៃគុណភាព និងសមាសភាពគីមី: សហការជាមួយមន្ទីរពិសោធន៍ដើម្បីធ្វើតេស្តស្វែងរកបរិមាណសារធាតុពណ៌ Anthocyanin ដោយប្រើ Spectrophotometer និងវាស់កម្រិតជាតិស្ករដោយប្រើ Refractometer។
  5. វាយតម្លៃរសជាតិ និងសាកល្បងនៅចម្ការកសិករ: រៀបចំកម្មវិធីវាយតម្លៃរសជាតិ (Sensory Evaluation / Panel taste) និងពង្រីកការសាកល្បងទៅកាន់ចម្ការកសិករ (On-farm trial) ដើម្បីធានាថាពូជថ្មីនេះពិតជាមានសក្តានុពលទីផ្សារមុននឹងផ្សព្វផ្សាយ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Hybridization (ការបង្កាត់ខ្វែង) គឺជាដំណើរការនៃការយកលំអងឈ្មោលពីពូជរុក្ខជាតិមួយទៅដាក់លើកេសរញីនៃពូជមួយទៀត ដើម្បីបង្កើតបានកូនកាត់ថ្មីដែលទទួលយកលក្ខណៈល្អៗពីមេបាទាំងពីរ (ដូចជាធន់នឹងជំងឺ និងផ្តល់ទិន្នផលខ្ពស់)។ ដូចជាការយកឆ្កែពូជការពារផ្ទះទៅបង្កាត់ជាមួយឆ្កែពូជរត់លឿន ដើម្បីទទួលបានកូនឆ្កែដែលទាំងចេះការពារផ្ទះ និងអាចរត់បានលឿន។
Pure line selection (ការជ្រើសរើសពូជសុទ្ធ) ជាវិធីសាស្ត្រជ្រើសរើសរុក្ខជាតិដែលមានលក្ខណៈល្អឥតខ្ចោះពីក្រុមរុក្ខជាតិកូនកាត់ ហើយដាំបន្តពូជដោយខ្លួនឯង (បង្កាត់ឯង) ជាច្រើនជំនាន់ រហូតដល់បានពូជមួយដែលមានលក្ខណៈនឹងនរ មិនប្រែប្រួល។ ដូចជាការរែងយកតែគ្រាប់ខ្សាច់ដែលមានទំហំប៉ុនៗគ្នា និងពណ៌ដូចៗគ្នាចេញពីគំនរខ្សាច់ចម្រុះ រហូតដល់ទទួលបានខ្សាច់មួយគំនរដែលមានលក្ខណៈដូចគ្នាទាំងស្រុងមិនប្រែប្រួល។
Anthocyanin (អង់តូស៊ីយ៉ានីន) ជាប្រភេទសារធាតុពណ៌ធម្មជាតិ (ពណ៌ក្រហម ស្វាយ ឬខៀវ) ដែលមាននៅក្នុងរុក្ខជាតិ ពិសេសផ្លែឈើ និងបន្លែ ហើយវាមានតួនាទីជាសារធាតុប្រឆាំងអុកស៊ីតកម្មយ៉ាងមានប្រសិទ្ធភាព ដែលជួយការពារកោសិកាពីការខូចខាត។ ដូចជាថ្នាំលាបពណ៌ការពារច្រែះដែលគេលាបលើដែក ដើម្បីការពារកុំឱ្យដែកឆាប់ខូចដោយសារធាតុអាកាសខាងក្រៅ។
Antioxidant (សារធាតុប្រឆាំងអុកស៊ីតកម្ម) ជាសមាសធាតុដែលអាចការពារ ឬពន្យឺតការខូចខាតកោសិកាដោយសាររ៉ាឌីកាល់សេរី (ម៉ូលេគុលមិនស្ថិតស្ថេរដែលបំផ្លាញកោសិកា) ដែលជួយការពាររាងកាយពីជំងឺផ្សេងៗ ដូចជាជំងឺបេះដូង និងមហារីក។ ដូចជាខែលការពារដែលជួយរារាំងគ្រាប់កាំភ្លើង (រ៉ាឌីកាល់សេរី) មិនឱ្យបាញ់ទម្លុះប៉ះពាល់ដល់រាងកាយ (កោសិកា) របស់យើង។
Randomized Complete Block (RCB) (ប្លង់ពិសោធន៍ប្លុកចៃដន្យពេញលេញ) ជាការរៀបចំប្លង់ពិសោធន៍កសិកម្មដោយបែងចែកដីជាប្លុក (កន្លែង) ផ្សេងៗគ្នា ហើយនៅក្នុងប្លុកនីមួយៗ ពូជដែលត្រូវសាកល្បងត្រូវបានដាំដោយចៃដន្យ ដើម្បីកាត់បន្ថយឥទ្ធិពលនៃគុណភាពដីដែលមិនស្មើគ្នាទៅលើលទ្ធផលនៃការស្រាវជ្រាវ។ ដូចជាការបែងចែកសិស្សជាក្រុមៗដែលមានសមត្ថភាពចម្រុះគ្នាដើម្បីប្រឡងប្រជែង ដើម្បីធានាថាគ្មានក្រុមណាមួយមានប្រៀបជាងគេដោយសារតែសិស្សពូកែៗប្រមូលផ្តុំគ្នានៅមួយកន្លែងនោះទេ។
Duncan’s multiple range test / DMRT (ការធ្វើតេស្តប្រៀបធៀបមធ្យម Duncan) ជាវិធីសាស្ត្រស្ថិតិដែលប្រើសម្រាប់ប្រៀបធៀបតម្លៃមធ្យមនៃទិន្នន័យច្រើនក្រុម (ឧទាហរណ៍ ទិន្នផលពូជសណ្តែក៥ផ្សេងគ្នា) ដើម្បីរកមើលថាតើក្រុមណាដែលមានភាពខុសគ្នាជាដាច់ខាតពីក្រុមផ្សេងទៀត។ ដូចជាការយកកម្ពស់សិស្សក្នុងថ្នាក់មកប្រៀបធៀបគ្នាជាគូៗ ដើម្បីចាត់ថ្នាក់ថាអ្នកណាខ្ពស់ជាងគេពិតប្រាកដ ឬអ្នកណាមានកម្ពស់ប្រហាក់ប្រហែលគ្នាដែលអាចចាត់ចូលក្រុមតែមួយបាន។
On-farm trial (ការសាកល្បងនៅចម្ការកសិករ) ការយកពូជដំណាំដែលទើបស្រាវជ្រាវបានពីស្ថានីយពិសោធន៍ ទៅដាំសាកល្បងផ្ទាល់នៅលើដីចម្ការរបស់កសិករ ក្នុងលក្ខខណ្ឌអាកាសធាតុ និងការថែទាំជាក់ស្តែង មុននឹងសម្រេចបញ្ចេញពូជនោះជាផ្លូវការ។ ដូចជាការយកឡានម៉ូដែលថ្មីដែលទើបផលិតរួច ទៅបើកបរលើផ្លូវលំជាក់ស្តែងនៅតាមខេត្ត ដើម្បីមើលថាតើវាធន់ប៉ុនណា មុននឹងដាក់លក់ជាផ្លូវការលើទីផ្សារ។
