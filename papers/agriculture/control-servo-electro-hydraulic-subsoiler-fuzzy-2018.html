វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះបានរចនាប្រព័ន្ធស៊ែវ៉ូអេឡិចត្រូអ៊ីដ្រូលីក (SEHS) ដោយប្រៀបធៀបប្រសិទ្ធភាពរវាងប្រព័ន្ធបញ្ជាបែបហ្វាស៊ី (Fuzzy logic control) និងប្រព័ន្ធបញ្ជា PID ដើម្បីគ្រប់គ្រងប្រេកង់រំញ័រ។

  • ការរចនាប្រព័ន្ធគ្រប់គ្រងស៊ែវ៉ូអេឡិចត្រូអ៊ីដ្រូលីក (Servo Electro-hydraulic System)
  • ការប្រើប្រាស់សេនស័រ (Proximity Sensor) និងកុងត្រូល័រ Arduino សម្រាប់ចាប់សញ្ញា និងដំណើរការទិន្នន័យត្រឡប់ (Feedback signal)
  • ការធ្វើតេស្តក្នុងល្បឿនត្រាក់ទ័រ ២,០៩ គ.ម/ម៉ និងជម្រៅ ៣០ ស.ម ក្នុងប្រេកង់រំញ័រ ៧, ៩, និង ១១ ហឺត (Hz) លើដីល្បាយខ្សាច់

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ប្រព័ន្ធបញ្ជាទាំងពីរ (Fuzzy និង PID) អាចគ្រប់គ្រងប្រេកង់រំញ័របានយ៉ាងមានប្រសិទ្ធភាព និងថេរក្នុងកំឡុងពេលភ្ជួររាស់។
  • ប្រព័ន្ធបញ្ជាបែបហ្វាស៊ី (Fuzzy-based controller) ផ្តល់ការឆ្លើយតបលឿនជាង និងមានភាពត្រឹមត្រូវខ្ពស់តាំងពីចំណុចចាប់ផ្តើមដោយមិនមានការកើនឡើងហួសកម្រិត (Overshoot) នោះទេ។
  • ប្រព័ន្ធបញ្ជា PID មានការកើនឡើងហួសកម្រិត (Overshoot) ខ្ពស់រហូតដល់ ១១,៧១%, ៦%, និង ៦,៥៥% នៅពេលកំណត់ប្រេកង់ ៧, ៩, និង ១១ ហឺតរៀងគ្នា។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Fuzzy Logic Controller
ឧបករណ៍បញ្ជាបែបហ្វាស៊ី (Fuzzy Logic Controller)		 មានល្បឿនចូលដល់ចំណុចកំណត់ (Setting Time) លឿន ភាពត្រឹមត្រូវខ្ពស់ និងមិនមានការកើនឡើងហួសកម្រិត (Overshoot) នៅពេលចាប់ផ្តើមរំញ័រនោះទេ។ មាន Delay Time និង Rise Time យឺតជាងប្រព័ន្ធ PID បន្តិចនៅពេលចាប់ផ្តើមដំណើរការដំបូងពីចំណុចសូន្យ។ អាចរក្សាប្រេកង់រំញ័រនៅ ៧, ៩ និង ១១ Hz បានយ៉ាងថេរ ដោយគ្មាន Overshoot និងមានលំនឹងប្រសើរជាងប្រព័ន្ធ PID។
PID Controller
ឧបករណ៍បញ្ជា PID (Proportional-Integral-Derivative)		 មានភាពរហ័សក្នុងការចាប់ផ្តើមរំញ័រពីចំណុចឈប់ (Delay Time និង Rise Time លឿនជាងហ្វាស៊ី)។ មានការកើនឡើងហួសកម្រិត (Overshoot) ខ្ពស់រហូតដល់ ១១.៧១%, ៦% និង ៦.៥៥% ដែលធ្វើឱ្យការចូលទៅដល់ចំណុចគោល (Setting Time) មានភាពយឺតយ៉ាវ។ អាចរក្សាប្រេកង់រំញ័របាន ប៉ុន្តែមានកំហុស (Error) ប្រមាណ ៥% ទៅ ៧.៥៧% ធៀបនឹងចំណុចគោលដែលបានកំណត់។

ការចំណាយលើធនធាន (Resource Cost)៖ ការស្រាវជ្រាវនេះទាមទារការប្រើប្រាស់គ្រឿងចក្រកសិកម្ម ឧបករណ៍បញ្ជាអេឡិចត្រូនិក និងប្រព័ន្ធថាមពលអ៊ីដ្រូលីកដែលត្រូវតំឡើងរួមគ្នា។

  • Hardware: ត្រាក់ទ័រ (កម្លាំង 50 HP ដូចជា Kubota M 5000 SU), នង្គ័លរំញ័រជើងពីរ, ម៉ូទ័រ និងបូមអ៊ីដ្រូលីក, សេនស័រវាស់ល្បឿន (Proximity Sensor), សន្ទះត្រួតពិនិត្យលំហូរប្រេង (Proportional valve) និងកុងត្រូល័រ Arduino ។
  • Software: កម្មវិធី Arduino (ជំនាន់ 1.6.9) សម្រាប់សរសេរកូដ និងប្រវត្តិរូបបញ្ជាប្រព័ន្ធ Fuzzy ព្រមទាំងអេក្រង់ LCD សម្រាប់បង្ហាញលទ្ធផល។
  • Expertise: ចំណេះដឹងផ្នែកវិស្វកម្មមេកានិកកសិកម្ម ប្រព័ន្ធបញ្ជាស្វ័យប្រវត្តិ (Control Systems) គ្រឿងអេឡិចត្រូនិច និងប្រព័ន្ធអ៊ីដ្រូលីក។

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃប្រព័ន្ធបញ្ជា និងអេឡិចត្រូនិក: ស្វែងយល់ពីទ្រឹស្តីនៃប្រព័ន្ធ Fuzzy Logic Controller និង PID Controller ព្រមទាំងការសរសេរកូដបញ្ជានៅលើកម្មវិធី Arduino IDE។
  2. យល់ដឹងពីប្រព័ន្ធ Servo Electro-hydraulic: សិក្សាពីដំណើរការនៃសន្ទះ Proportional Valve ម៉ូទ័រ និងបូមអ៊ីដ្រូលីក និងរបៀបដែលវាបំប្លែងសញ្ញាអគ្គិសនីទៅជាថាមពលមេកានិកសម្រាប់បង្កើតរំញ័រ។
  3. អភិវឌ្ឍគំរូសាកល្បងខ្នាតតូច (Prototype Development): ប្រើប្រាស់បន្ទះ Arduino Board រួមជាមួយ Proximity Sensor ដើម្បីសាកល្បងអានល្បឿនរំញ័រ និងសរសេរកូដបញ្ជាអត្រាលំហូរ (Flow rate) ក្នុងលក្ខខណ្ឌមន្ទីរពិសោធន៍។
  4. ការដំឡើង និងធ្វើតេស្តលើគ្រឿងចក្រជាក់ស្តែង: ដំឡើងប្រព័ន្ធបញ្ជានេះទៅលើនង្គ័លរំញ័រពិតប្រាកដ ភ្ជាប់ជាមួយប្រព័ន្ធ PTO របស់ត្រាក់ទ័រ រួចធ្វើតេស្តវាយតម្លៃដើម្បីកែតម្រូវ Membership Function ឱ្យស័ក្តិសមនឹងប្រភេទដីនៅកម្ពុជា។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Servo Electro-hydraulic System (ប្រព័ន្ធស៊ែវ៉ូអេឡិចត្រូអ៊ីដ្រូលីក) ប្រព័ន្ធកូនកាត់ដែលប្រើប្រាស់សញ្ញាអគ្គិសនីដើម្បីបញ្ជាវ៉ាល់ (Valve) ត្រួតពិនិត្យលំហូរនៃប្រេងអ៊ីដ្រូលីក ដែលវាមានតួនាទីបំប្លែងសញ្ញាអេឡិចត្រូនិចទៅជាថាមពលមេកានិក (ចលនា) ប្រកបដោយភាពច្បាស់លាស់ និងកម្លាំងខ្លាំង។ ដូចជាការប្រើតេឡេបញ្ជា (អគ្គិសនី) ដើម្បីបើកឬបិទក្បាលរ៉ូប៊ីណេទឹក (អ៊ីដ្រូលីក) ឱ្យទឹកហូរខ្លាំងឬខ្សោយដើម្បីទៅបង្វិលកង់ទឹក។
Fuzzy logic controller (ឧបករណ៍បញ្ជាបែបហ្វាស៊ី) ប្រព័ន្ធបញ្ជាដែលផ្អែកលើតក្កវិជ្ជាស្រពិចស្រពិល (Fuzzy logic) ដែលអាចធ្វើការសម្រេចចិត្តប្រែប្រួលជាកម្រិតភាគរយ (ឧទាហរណ៍៖ បើកបន្តិច បើកមធ្យម បើកខ្លាំង) ឆ្លើយតបទៅនឹងការប្រែប្រួលជាក់ស្តែង ជំនួសឱ្យការសម្រេចចិត្តដាច់ស្រេចថាមួយឬសូន្យ។ ដូចជាមនុស្សដែលចេះកាច់កុងតាក់កង្ហារលេខ១ លេខ២ លេខ៣ តាមកម្រិតកម្តៅអាកាសធាតុជាក់ស្តែង មិនមែនមានតែប៊ូតុងបើកឱ្យខ្លាំងបំផុត និងបិទនោះទេ។
Proportional-integral-derivative (PID) frequency control (ប្រព័ន្ធបញ្ជាប្រេកង់ PID) រូបមន្តគណិតវិទ្យាក្នុងប្រព័ន្ធបញ្ជាស្វ័យប្រវត្តិ ដែលគណនាកំហុសឆ្គងរវាងតម្លៃជាក់ស្តែង និងតម្លៃគោលដៅ ដោយប្រើប្រាស់សមាមាត្រ (P) អាំងតេក្រាល (I) និងដេរីវេ (D) ដើម្បីចេញបទបញ្ជាកែតម្រូវប្រព័ន្ធឱ្យដំណើរការបានស្ថិរភាព។ ដូចជាអ្នកបើកបរឡានដែលចេះជាន់ហ្គែរបន្ថែមល្បឿនពេលផ្លូវទូលាយ និងជាន់ហ្វ្រាំងបន្ថយល្បឿនបន្តិចម្តងៗពេលជិតដល់ស្តុបដើម្បីកុំឱ្យឡានឈប់ង៉ក់។
Overshoot (ការកើនឡើងហួសកម្រិត) បាតុភូតនៅក្នុងប្រព័ន្ធបញ្ជាដែលតម្លៃជាក់ស្តែងនៃសញ្ញាចេញ (Output) លោតឡើងលើសកម្រិតគោលដៅដែលបានកំណត់ មុននឹងធ្លាក់ចុះមករកលំនឹងវិញ។ នៅក្នុងការសិក្សានេះ គឺការដែលម៉ាស៊ីនញ័រខ្លាំងលើសប្រេកង់ដែលយើងចង់បាននៅពេលចាប់ផ្តើម។ ដូចជាការចាក់ទឹកចូលកែវឱ្យពេញ ប៉ុន្តែចាក់លឿនពេកធ្វើឱ្យទឹកហៀរចេញក្រៅបន្តិចមុនពេលយើងដកដៃចេញ។
Proportional valve (សន្ទះត្រួតពិនិត្យលំហូរសមាមាត្រ) ឧបករណ៍វ៉ាល់សម្រាប់ត្រួតពិនិត្យលំហូរនៃប្រេងអ៊ីដ្រូលីក ដែលអត្រាលំហូររបស់វាអាចប្រែប្រួលបានគ្រប់កម្រិត ឆ្លើយតបសមាមាត្រទៅនឹងទំហំនៃសញ្ញាអគ្គិសនីដែលវាទទួលបានពីកុងត្រូល័រ។ ដូចជាក្បាលរ៉ូប៊ីណេទឹកដែលអាចមួលបើកតិចឬច្រើនតាមតម្រូវការ មិនមែនមានតែជម្រើសបើកឱ្យហូរខ្លាំង និងបិទជិតនោះទេ។
Vibrating Subsoiler (នង្គ័លរាស់បំបែកដីប្រភេទរំញ័រ) គ្រឿងយន្តកសិកម្មដែលមានមុខងារសម្រាប់ភ្ជួររាស់បំបែកស្រទាប់ដីរឹងនៅខាងក្រោមផ្ទៃដី ដោយប្រើប្រាស់ប្រព័ន្ធរំញ័រជាជំនួយដើម្បីកាត់បន្ថយកម្លាំងអូសទាញរបស់ត្រាក់ទ័រ ធ្វើឱ្យការភ្ជួរបានជ្រៅនិងចំណេញថាមពល។ ដូចជាការប្រើម៉ាស៊ីនខួងបេតុងដែលមានមុខងារញ័រ ដែលជួយឱ្យការខួងចូលរបស់រឹងបានងាយស្រួលជាងការប្រើកម្លាំងសង្កត់តែម្យ៉ាង។
Response Time (ពេលវេលាឆ្លើយតប) រយៈពេលសរុបដែលប្រព័ន្ធប្រើប្រាស់ ចាប់តាំងពីពេលទទួលបានសញ្ញាបញ្ជា (Input Setpoint) រហូតដល់តម្លៃនៃការអនុវត្តជាក់ស្តែង (Output) ផ្លាស់ប្តូរចូលទៅដល់ និងរក្សាបានលំនឹងនៅតម្លៃគោលដៅដែលបានកំណត់។ ដូចជារយៈពេលដែលម៉ាស៊ីនត្រជាក់ត្រូវការ ដើម្បីធ្វើឱ្យបន្ទប់ទាំងមូលត្រជាក់ចុះមកដល់សីតុណ្ហភាព ២៤ អង្សាសេ បន្ទាប់ពីយើងចុចតេឡេកែតម្រូវ។
