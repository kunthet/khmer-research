វិធីសាស្ត្រនៃការតាក់តែងរាងដើមតាមប្រព័ន្ធបើកកណ្តាលសម្រាប់ការដាំដុះគម្លាតជិត គឺពិតជាមានអត្ថប្រយោជន៍ និងអាចអនុវត្តបានយ៉ាងមានប្រសិទ្ធភាពសម្រាប់វិស័យកសិកម្មនៅកម្ពុជា។

  • កសិដ្ឋានដាំឈើហូបផ្លែនៅខេត្តកំពង់ចាម និងកណ្តាល: តំបន់ទាំងនេះមានសក្តានុពលខ្ពស់ក្នុងការដាំជម្ពូពូជល្អៗ។ ការប្រើប្រព័ន្ធគម្លាតជិតជួយកសិករទាញយកផលប្រយោជន៍អតិបរមាពីផ្ទៃដីមានកំណត់ ខណៈប្រព័ន្ធបើកកណ្តាលជួយបង្កើនការចេញផ្កា និងការជាប់ផ្លែ។
  • សាកលវិទ្យាល័យភូមិន្ទកសិកម្ម (RUA): និស្សិត និងអ្នកស្រាវជ្រាវអាចយកវិធីសាស្ត្រទាំង ៤ នេះទៅធ្វើការពិសោធន៍បន្ថែមលើពូជជម្ពូក្នុងស្រុក ឬដើមឈើហូបផ្លែផ្សេងទៀត ដើម្បីរៀបចំជាសៀវភៅណែនាំបច្ចេកទេសកសិកម្ម។

ការជ្រើសរើសប្រព័ន្ធតាក់តែងរាងដើមបានត្រឹមត្រូវតាំងពីដំណាក់កាលដំបូង មិនត្រឹមតែជួយបង្កើនទិន្នផលផ្លែឈើប៉ុណ្ណោះទេ ថែមទាំងជួយសម្រួលដល់ការគ្រប់គ្រងចម្ការ និងបង្កើនគុណភាពកសិផលប្រកួតប្រជែងលើទីផ្សារ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះ និងរៀបចំគម្រោង: ស្វែងយល់ពីបច្ចេកទេសដាំដុះគម្លាតជិត (High Density Planting) និងប្រព័ន្ធតាក់តែងរាងដើមទាំង ៤ ជាពិសេសប្រព័ន្ធ Open centre ដោយសិក្សាលើប្រភេទដី និងពូជជម្ពូដែលត្រូវនឹងអាកាសធាតុតំបន់។
  2. រៀបចំចម្ការ និងប្រព័ន្ធដាំដុះ: កំណត់ទីតាំង និងរៀបចំដីដាំដើមជម្ពូពូជ Syzygium samarangense ដោយប្រើគម្លាតជួរ និងគម្លាតដើមតាមទំហំស្តង់ដារ ព្រមទាំងបំពាក់ប្រព័ន្ធស្រោចស្រពដោយប្រើ Drip irrigation system។
  3. អនុវត្តការកាត់តាក់តែងរាងដើម: ប្រើប្រាស់ Pruning shears អនុវត្តការកាត់មែកជាប្រចាំដើម្បីបង្កើតរាងដើមតាមប្រព័ន្ធដែលបានជ្រើសរើស ចាប់តាំងពីដើមនៅតូច រហូតដល់ដើមចាប់ផ្តើមផ្តល់ផល។
  4. ប្រមូលទិន្នន័យ និងតាមដានដំណុះ: កត់ត្រាចំនួនកញ្ចុំផ្កា អត្រាជ្រុះផ្កា និងអត្រាជាប់ផ្លែក្នុងមួយដើមៗ ដោយប្រមូលទិន្នន័យបញ្ចូលក្នុងកម្មវិធីដូចជា Microsoft Excel ឬ Data loggers ដើម្បីធ្វើការប្រៀបធៀប។
  5. គ្រប់គ្រងគុណភាពផ្លែមុនប្រមូលផល: អនុវត្តបច្ចេកទេសបេះផ្លែចេញខ្លះ (Fruit thinning) និងការរុំផ្លែដោយប្រើ Plastic bagging នៅចន្លោះពេល១០ ទៅ ២០ថ្ងៃក្រោយផ្ការីក ដើម្បីការពារសត្វល្អិត និងកែលម្អគុណភាពផ្លែ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
High Density Planting (ការដាំដុះកម្រិតគម្លាតជិត) ការដាំដើមឈើក្នុងចន្លោះគម្លាតជិតៗគ្នាខុសពីធម្មតា ដើម្បីទទួលបានចំនួនដើមច្រើនក្នុងមួយហិកតា និងបង្កើនទិន្នផលសរុប។ បច្ចេកទេសនេះទាមទារការកាត់តាក់តែងមែកជាប្រចាំដើម្បីគ្រប់គ្រងទំហំដើម និងកុំឱ្យវាបាំងពន្លឺគ្នា។ ដូចជាការរៀបចំតុសិស្សឱ្យបានច្រើនក្នុងថ្នាក់រៀនតូចមួយ ដោយរៀបចំឱ្យមានរបៀបរៀបរយបំផុតដើម្បីកុំឱ្យចង្អៀតពេក និងអាចរៀនបានប្រសិទ្ធភាព។
Training system (ប្រព័ន្ធតាក់តែងរាងដើម) វិធីសាស្ត្រនៃការកាត់តាក់តែង ទាញ ឬចងមែកឈើដើម្បីបង្កើតជារចនាសម្ព័ន្ធ ឬទម្រង់ដើមជាក់លាក់ណាមួយ ក្នុងគោលបំណងឱ្យវាទទួលពន្លឺព្រះអាទិត្យបានល្អ ងាយស្រួលថែទាំ និងងាយប្រមូលផល។ ដូចជាការចាប់ពត់មែកឈើលម្អបុងសៃ (Bonsai) ឱ្យចេញជារាងតាមដែលយើងចង់បាន។
Open centre (ប្រព័ន្ធតាក់តែងរាងដើមបើកកណ្តាល) ទម្រង់នៃការតាក់តែងដើមឈើដោយកាត់មែកកណ្តាល (មែកមេ) ចេញ ដើម្បីឱ្យពន្លឺព្រះអាទិត្យអាចជះចូលដល់ផ្នែកកណ្តាលនៃស៊ុមស្លឹកខាងក្នុងបានល្អ ដែលជួយជំរុញការចេញផ្កា និងជាប់ផ្លែ។ ដូចជាការលាតឆ័ត្រផ្ងារឡើងលើ ដែលអនុញ្ញាតឱ្យពន្លឺចាំងចូលចំកណ្តាលបានយ៉ាងងាយស្រួល។
Slender spindle (ប្រព័ន្ធតាក់តែងរាងអ័ក្សស្រួច) ទម្រង់ដើមឈើដែលមានមែកមេធំមួយនៅកណ្តាលបញ្ឈរត្រង់ ហើយមានមែកតូចៗលូតចេញផ្ដេកជុំវិញ ដោយកាត់មែកខាងក្រោមឱ្យវែង ហើយខាងលើខ្លីស្រួច ដែលស័ក្តិសមបំផុតសម្រាប់ការដាំដុះកម្រិតគម្លាតជិត។ ដូចជារាងនៃដើមគ្រីស្មាស់ (Christmas tree) ដែលមានគល់ធំរីក ហើយស្រួចទៅលើ។
Palmette (ប្រព័ន្ធតាក់តែងរាងផ្លិត) ការតាក់តែងមែកឈើឱ្យដុះសន្ធឹងទៅតែពីរទិសផ្ទុយគ្នា (រាងសំប៉ែត) ស្របតាមជួរដាំដុះ ដើម្បីសន្សំសំចៃទំហំដី ងាយស្រួលដើរតាមចន្លោះជួរ និងងាយស្រួលបាញ់ថ្នាំការពារសត្វល្អិត។ ដូចជាការឈរលាតសន្ធឹងដៃទាំងពីរទៅម្ខាងម្នាក់ ឱ្យរាបស្មើទាល់ទៅនឹងជញ្ជាំង។
Y-trellis (ប្រព័ន្ធតាក់តែងទម្រអក្សរ Y) ការប្រើប្រាស់ទម្រធ្វើពីឈើឬដែកជារាងអក្សរ Y ដើម្បីទ្រមែកឈើដែលលូតបែកជាពីរមែកធំៗ ជួយឱ្យស្លឹកទទួលពន្លឺបានច្រើន និងការពារការបាក់មែកនៅពេលមានផ្លែច្រើន។ ដូចជាការឈរលើកដៃទាំងពីរឡើងលើជារាងអក្សរ Y ដើម្បីជួយទ្រវត្ថុអ្វីមួយពីលើក្បាល។
Fruit set (អត្រាការជាប់ផ្លែ) ដំណើរការដែលផ្កាវិវឌ្ឍទៅជាកូនផ្លែបានសម្រេច បន្ទាប់ពីការបង្កកំណើត (Pollination) រួចរាល់ ដោយមិនជ្រុះទៅវិញ។ វាជារង្វាស់នៃភាពជោគជ័យក្នុងការផ្តល់ទិន្នផល។ ដូចជាសិស្សដែលបានប្រឡងជាប់ចូលរៀនផ្លូវការ មិនមែនត្រឹមតែដាក់ពាក្យប្រឡង (ផ្ការីក) រួចក៏បោះបង់នោះទេ។
Fruit thinning (ការបេះផ្លែចេញខ្លះ) បច្ចេកទេសក្នុងវិស័យកសិកម្ម ដែលគេកាត់ឬបេះកូនផ្លែឈើមួយចំនួនចេញពីកញ្ចុំ ដើម្បីទុកកន្លែងនិងសារធាតុចិញ្ចឹមឱ្យផ្លែដែលនៅសល់អាចលូតលាស់បានធំល្អ និងមានគុណភាពខ្ពស់។ ដូចជាការដកកូនរុក្ខជាតិខ្សោយៗចេញពីថ្នាល ដើម្បីឱ្យកូនរុក្ខជាតិដែលរឹងមាំអាចដុះលូតលាស់បានធំធាត់ល្អដោយមិនដណ្ដើមជីគ្នា។
Inflorescence (កញ្ចុំផ្កា) បណ្តុំនៃផ្កាជាច្រើនដែលដុះចេញពីទងរួមមួយនៅលើមែករុក្ខជាតិ ដូចជាករណីផ្កាជម្ពូដែលតែងតែចេញជាកញ្ចុំ មិនសូវចេញជាផ្កាទោលនោះទេ។ ដូចជាភួងទំពាំងបាយជូរ ដែលមានផ្លែជាច្រើនផ្តុំគ្នានៅលើទងតែមួយ។
