  1. សិក្សាពីសមាសធាតុទិន្នផលដូងប្រេងផ្ទាល់: និស្សិតត្រូវចុះកម្មសិក្សានៅចម្ការដូងប្រេង ដើម្បីស្វែងយល់និងអនុវត្តផ្ទាល់អំពីរបៀបវាស់វែងលក្ខណៈរូបវន្ត ដូចជាទម្ងន់ធ្លាយ (BW) ទម្ងន់ផ្លែ (FW/B) និងសមាមាត្រសាច់ដូង (MTF) ជាដើម។
  2. ប្រមូល និងរៀបចំទិន្នន័យ: រៀបចំសំណាក និងកត់ត្រាទិន្នន័យជាក់ស្តែងពីកសិដ្ឋាន រួចបញ្ចូលទិន្នន័យទៅក្នុង Excel ឬ CSV format ដើម្បីត្រៀមសម្រាប់ការវិភាគ។ ត្រូវប្រាកដថាទិន្នន័យមានភាពត្រឹមត្រូវ និងគ្មានចន្លោះប្រហោង។
  3. រៀនប្រើប្រាស់កម្មវិធីស្ថិតិ R: ដំឡើងនិងសិក្សាពីមូលដ្ឋានគ្រឹះនៃ R Studio ដោយផ្តោតលើការប្រើប្រាស់កញ្ចប់ lavaan ឬ plspm សម្រាប់ការសាងសង់គំរូ Path Analysis។
  4. អនុវត្តការវិភាគ Path Analysis: ដំណើរការកូដនៅក្នុង R ដើម្បីវិភាគរកឥទ្ធិពលផ្ទាល់ និងប្រយោលនៃសមាសធាតុនីមួយៗទៅលើទិន្នផលសរុប រួចគូរដ្យាក្រាម Path Diagram ដើម្បីងាយស្រួលមើលទំនាក់ទំនង។
  5. សរសេររបាយការណ៍ និងទាញសេចក្តីសន្និដ្ឋាន: រៀបចំជារបាយការណ៍ស្រាវជ្រាវដែលរំលេចពីកត្តាចម្បងដែលកំណត់ទិន្នផល (ឧទាហរណ៍ BNO) និងផ្តល់ជាអនុសាសន៍ជាក់ស្តែងដល់កសិករ ឬអ្នកបង្កាត់ពូជក្នុងការជ្រើសរើសពូជដំណាំ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Fresh Fruit Bunch (FFB) (ធ្លាយផ្លែស្រស់) ទិន្នផលសរុបនៃធ្លាយដូងប្រេងដែលប្រមូលផលបានពីដើម ដែលរួមមានទាំងផ្លែ ទង និងកញ្ចុំផ្លែតូចៗ ដែលជាប្រភពចំណូលចម្បងរបស់កសិករ។ ដូចជាផ្លែទំពាំងបាយជូរមួយចង្កោមធំ ដែលទើបតែកាត់ចេញពីដើមភ្លាមៗ។
Path analysis (ការវិភាគផ្លូវ) ជាវិធីសាស្ត្រស្ថិតិមួយប្រភេទដែលត្រូវបានប្រើដើម្បីបំបែកទំនាក់ទំនង (Correlation) រវាងអថេរផ្សេងៗ ទៅជា "ឥទ្ធិពលផ្ទាល់" និង "ឥទ្ធិពលប្រយោល" ដើម្បីរកមើលថាតើកត្តាណាពិតជាធ្វើឱ្យមានការផ្លាស់ប្តូរទិន្នផល។ ដូចជាការស៊ើបអង្កេតរកមើលថាតើអ្នកណាជាអ្នកបង្កបញ្ហាដោយផ្ទាល់ និងអ្នកណាជាអ្នកញុះញង់នៅពីក្រោយខ្នង។
tenera (ពូជដូងប្រេងតេនេរ៉ា) ជាប្រភេទពូជដូងប្រេងកាត់ (Hybrid) ដែលទទួលបានពីការបង្កាត់រវាងពូជ dura (សំបកគ្រាប់ក្រាស់) និង pisifera (គ្មានសំបកគ្រាប់) ដែលផ្តល់នូវសាច់ដូងច្រើន និងទិន្នផលប្រេងខ្ពស់។ ដូចជាកូនកាត់ដែលយកចំណុចល្អៗពីឪពុកម្តាយទាំងសងខាង ដើម្បីបង្កើតជាពូជមួយដែលល្អបំផុតសម្រាប់ផលិតប្រេង។
Mesocarp to fruit (MTF) (សមាមាត្រសាច់ដូងធៀបនឹងផ្លែ) ជារង្វាស់ភាគរយនៃទម្ងន់សាច់ដូង (ផ្នែកពណ៌លឿងដែលផ្ទុកប្រេងច្រើនជាងគេ) ធៀបនឹងទម្ងន់ផ្លែដូងទាំងមូល។ MTF ខ្ពស់មានន័យថាផ្លែនោះអាចផលិតប្រេងបានច្រើន។ ដូចជាការវាស់មើលថាតើផ្លែស្វាយមួយមានសាច់ច្រើនប៉ុនណា បើប្រៀបធៀបជាមួយទំហំគ្រាប់និងសំបករបស់វា។
Rachillae weight per bunch (RCHAE/B) (ទម្ងន់ខ្នែងផ្លែតូចៗក្នុងមួយធ្លាយ) ទម្ងន់នៃខ្នែង ឬមែកតូចៗ (Rachillae) នៅក្នុងធ្លាយដូងប្រេងដែលផ្លែដូងតោងជាប់។ ការយល់ដឹងពីទម្ងន់នេះជួយអ្នកបង្កាត់ពូជវាយតម្លៃថាតើធ្លាយមួយមានទម្ងន់ផ្លែសុទ្ធប៉ុន្មាន។ ដូចជាទម្ងន់នៃទងតូចៗដែលតភ្ជាប់គ្រាប់ទំពាំងបាយជូរនីមួយៗទៅនឹងមែកធំ។
Correlation coefficient (មេគុណទំនាក់ទំនង) ជាតម្លៃលេខស្ថិតិចន្លោះពី -1 ដល់ 1 ដែលបង្ហាញពីកម្រិត និងទិសដៅនៃទំនាក់ទំនងរវាងលក្ខណៈពីររបស់រុក្ខជាតិ។ ទំនាក់ទំនងវិជ្ជមានមានន័យថាកាលណាកត្តាមួយកើន កត្តាមួយទៀតក៏កើនដែរ។ ដូចជាការវាស់កម្រិតភាពស្និទ្ធស្នាលរវាងមនុស្សពីរនាក់ បើម្នាក់សើច ម្នាក់ទៀតក៏សើចតាមដែរ។
Bunch number (BNO) (ចំនួនធ្លាយ) ចំនួនធ្លាយសរុបដែលដើមដូងប្រេងមួយដើមអាចផលិតបានក្នុងរយៈពេលកំណត់មួយ (ជាទូទៅក្នុងមួយឆ្នាំ) ដែលជាកត្តាកំណត់យ៉ាងសំខាន់នៃទិន្នផលសរុប។ ដូចជាការរាប់ចំនួនកូនជ្រូកដែលមេជ្រូកមួយក្បាលកើតបានក្នុងមួយឆ្នាំ។
