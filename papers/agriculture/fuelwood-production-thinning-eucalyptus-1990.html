  • សហគ្រាសផលិតឥដ្ឋ និងឡធ្យូងក្នុងស្រុក: អុសខ្នាតតូចដែលបានពីការកាប់រំលោះនេះ អាចផ្គត់ផ្គង់ដល់ឡឥដ្ឋ និងឡធ្យូងជំនួសឱ្យការកាប់ឈើពីព្រៃធម្មជាតិ ដែលជួយកាត់បន្ថយការកាប់បំផ្លាញព្រៃឈើ។
  • សហគមន៍ព្រៃឈើ និងកសិករខ្នាតតូច: សហគមន៍អាចរៀនសូត្រពីបច្ចេកទេសគ្រប់គ្រងពន្លក (Coppicing) ដើម្បីបង្កើតប្រភពអុសប្រើប្រាស់ប្រចាំថ្ងៃប្រកបដោយនិរន្តរភាព ដោយមិនចាំបាច់ដាំកូនឈើថ្មីជារៀងរាល់ឆ្នាំ។

សរុបមក ការណែនាំបច្ចេកទេសនេះដល់កសិករ និងម្ចាស់ចម្ការឈើនៅកម្ពុជា មិនត្រឹមតែជួយបង្កើនប្រាក់ចំណូលបន្ថែមប៉ុណ្ណោះទេ ថែមទាំងលើកកម្ពស់សន្តិសុខថាមពលជីវម៉ាសប្រកបដោយនិរន្តរភាពផងដែរ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះពីរុក្ខកម្ម និងជីវម៉ាស: ស្វែងយល់ពីបច្ចេកទេសដាំដុះពូជឈើលូតលាស់លឿនដូចជា Eucalyptus camaldulensis និងរៀនអំពីការប្រើប្រាស់ Allometric Equations ក្នុងការគណនាប៉ាន់ស្មានទម្ងន់ជីវម៉ាស។
  2. រៀបចំឡូតិ៍ពិសោធន៍ខ្នាតតូច (Pilot Plots): រៀបចំដីសាកល្បងដាំកូនឈើដោយប្រើគម្លាត 1x1m និង 1x2m នៅក្នុងទីតាំងសាកល្បងរបស់សាកលវិទ្យាល័យ ឬតំបន់សហគមន៍ ដើម្បីតាមដានការលូតលាស់ជាក់ស្តែងក្នុងលក្ខខណ្ឌដីកម្ពុជា។
  3. អនុវត្តការកាប់រំលោះ និងវាស់វែងទិន្នន័យ: នៅពេលចម្ការឈើមានអាយុ ៣ឆ្នាំ ត្រូវអនុវត្តការកាប់រំលោះដើម (Thinning) និងប្រើប្រាស់ Caliper ដើម្បីវាស់អង្កត់ផ្ចិត ព្រមទាំងតាមដានអត្រាលូតលាស់របស់ពន្លកថ្មីរៀងរាល់ ៤ខែម្តង។
  4. វិភាគទិន្នផលសេដ្ឋកិច្ច (Economic Analysis): ប្រមូលទិន្នន័យទម្ងន់អុស និងប្រើប្រាស់កម្មវិធី Microsoft Excel ឬ R Programming ដើម្បីវិភាគប្រាក់ចំណូលប្រៀបធៀបនឹងថ្លៃចំណាយលើកម្លាំងពលកម្ម។
  5. ចងក្រងជាសៀវភៅណែនាំ (Manual) និងផ្សព្វផ្សាយ: សរសេរជារបាយការណ៍ស្រាវជ្រាវ និងសៀវភៅណែនាំបច្ចេកទេសជាភាសាខ្មែរ សម្រាប់ចែករំលែកដល់កសិករ អង្គការក្រៅរដ្ឋាភិបាល (NGOs) និងរដ្ឋបាលព្រៃឈើ ដើម្បីយកទៅអនុវត្តបន្ត។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Thinning (ការកាប់រំលោះដើម / ការកាត់សาง) គឺជាដំណើរការក្នុងវិស័យរុក្ខកម្មដែលគេកាប់ដើមឈើមួយចំនួនចេញពីចម្ការ ដើម្បីបន្ថយភាពកកកុញ និងផ្តល់ចន្លោះ ព្រមទាំងពន្លឺព្រះអាទិត្យ និងសារធាតុចិញ្ចឹមគ្រប់គ្រាន់ដល់ដើមឈើដែលនៅសល់ឱ្យលូតលាស់បានល្អជាងមុន។ ដូចជាការដកកូនរុក្ខជាតិ ឬស្មៅចេញខ្លះពីរងដាំបន្លែដែលដុះញឹកពេក ដើម្បីឲ្យបន្លែដែលនៅសល់មានកន្លែងលូតលាស់បានធំល្អ។
Eucalyptus camaldulensis (ដើមប្រេងខ្យល់ / យូកាលីបទុស) ជាប្រភេទរុក្ខជាតិដែលដុះលូតលាស់លឿន ធន់នឹងភាពរាំងស្ងួត និងជាទូទៅត្រូវបានគេដាំជាលក្ខណៈពាណិជ្ជកម្មសម្រាប់យកឈើ អុស ផលិតក្រដាស ឬប្រេង។ នៅក្នុងការសិក្សានេះ គេសិក្សាពីការដាំវាដើម្បីផលិតអុសខ្នាតតូច។ គឺជាពូជឈើប្រេងខ្យល់ម្យ៉ាងដែលគេចូលចិត្តដាំនៅតាមចម្ការ ព្រោះវាធំលឿននិងងាយស្រួលថែទាំ។
Allometric relation (ទំនាក់ទំនងអាឡូម៉េទ្រីក) ជាវិធីសាស្ត្រគណិតវិទ្យាក្នុងការប៉ាន់ស្មានទំហំ ទម្ងន់ ឬជីវម៉ាសនៃផ្នែកណាមួយរបស់រុក្ខជាតិ (ដូចជាទម្ងន់ឈើ ឬស្លឹក) ដោយផ្អែកលើការវាស់វែងផ្នែកដែលងាយស្រួលវាស់ជាង (ដូចជាអង្កត់ផ្ចិតគល់ និងកម្ពស់ដើម) ដោយប្រើរូបមន្តសមីការ។ ដូចជាការទស្សន៍ទាយទម្ងន់របស់មនុស្សម្នាក់ ដោយគ្រាន់តែដឹងពីកម្ពស់ និងទំហំចង្កេះរបស់គាត់តាមរយៈរូបមន្ត ដោយមិនបាច់ឲ្យគាត់ឡើងជញ្ជីងថ្លឹងផ្ទាល់។
Biomass (ជីវម៉ាស / មวลជីវភាព) ជាបរិមាណសរុបនៃវត្ថុធាតុសរីរាង្គរបស់រុក្ខជាតិ (រួមមានដើម មែក ស្លឹក និងឫស) ដែលត្រូវបានវាស់ជាទម្ងន់ស្ងួត (Dry matter) ក្នុងមួយឯកតាផ្ទៃដី។ វាត្រូវបានប្រើដើម្បីវាយតម្លៃទិន្នផលថាមពល ឬឈើដែលអាចទាញយកបាន។ គឺជាទម្ងន់សរុបរបស់ដើមឈើទាំងមូលនៅពេលដែលគេកាប់វាហើយសម្ងួតជាតិទឹកចេញអស់។
Coppice / Sprout (ពន្លក / ការបែកពន្លកពីគល់) ជាការពន្លកឡើងវិញនៃដើមឈើថ្មីៗចេញពីគល់ចាស់ដែលត្រូវបានគេកាប់រួច ដែលជាយន្តការបន្តពូជតាមបែបលូតលាស់ និងជាប្រភពនៃទិន្នផលឈើ ឬអុសសម្រាប់ជុំបន្ទាប់ដោយមិនចាំបាច់ដាំកូនឈើថ្មី។ ដូចជាការលូតលាស់ត្រួយថ្មីចេញពីគល់ដើមចេក ឬគល់ឫស្សី បន្ទាប់ពីយើងកាប់ដើមចាស់យកទៅប្រើប្រាស់រួច។
Current annual increment (កំណើនប្រចាំឆ្នាំបច្ចុប្បន្ន) ជាអត្រានៃការកើនឡើងនូវទំហំ កម្ពស់ ឬជីវម៉ាសរបស់ដើមឈើ ឬចម្ការឈើ ក្នុងកំឡុងពេលមួយឆ្នាំជាក់លាក់ណាមួយ ដើម្បីតាមដានល្បឿននៃការលូតលាស់របស់វា។ ដូចជាការវាស់កម្ពស់ក្មេងនៅរៀងរាល់ថ្ងៃកំណើត ដើម្បីដឹងថាក្នុងឆ្នាំនេះគាត់លូតកម្ពស់បានប៉ុន្មានសង់ទីម៉ែត្រ។
Turn over period (រយៈពេលបង្វិលជុំ / រយៈពេលជំនួស) ជារយៈពេលដែលដើមឈើ ឬពន្លកថ្មីត្រូវការ ដើម្បីលូតលាស់ និងបង្កើតជីវម៉ាសឡើងវិញ ឲ្យមានបរិមាណស្មើនឹងបរិមាណជីវម៉ាសនៃដើមឈើដែលត្រូវបានគេកាប់ចេញកាលពីពេលមុន។ ដូចជារយៈពេលដែលអ្នកត្រូវរង់ចាំសន្សំប្រាក់ ដើម្បីឲ្យបានចំនួនស្មើនឹងប្រាក់ដែលអ្នកទើបតែបានចំណាយទិញទូរស័ព្ទថ្មីមួយ។
