វិស័យសិក្សា៖ Agronomy

១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការសិក្សានេះដោះស្រាយលើភាពស្មុគស្មាញ និងចំណាយពេលយូរនៃការវាយតម្លៃផ្ទាល់លើស្ករអំពៅពាណិជ្ជកម្ម (Commercial Cane Sugar - C.C.S.) នៅក្នុងដំណាក់កាលដំបូងនៃការជ្រើសរើសពូជអំពៅ។

វិធីសាស្ត្រ (The Methodology)៖ ការស្រាវជ្រាវនេះបានប្រើប្រាស់ការវិភាគតំរែតំរង់ស្ថិតិដើម្បីវាយតម្លៃប្រសិទ្ធភាពនៃសមាសធាតុអំពៅផ្សេងៗគ្នាក្នុងការទស្សន៍ទាយតម្លៃ C.C.S. ដោយធ្វើការប្រៀបធៀបរវាងអំពៅដាំដំបូង និងអំពៅកាត់គល់។

  • ការវិភាគតំរែតំរង់លីនេអ៊ែរទោល និងពហុគុណ (Simple and Multiple Linear Regression)
  • ការប្រមូលទិន្នន័យអថេរទស្សន៍ទាយ៖ Brix, Pol, ជាតិសរសៃ (Fibre) និងភាពបរិសុទ្ធ (Purity)
  • ការវាយតម្លៃលើឥទ្ធិពលនៃពូជមេ (Evaluation of female parent influence)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • សមាសធាតុ Pol និង Brix រួមបញ្ចូលជាមួយ Pol គឺជាអថេរដ៏ស័ក្តិសមបំផុតសម្រាប់ការទស្សន៍ទាយតម្លៃ C.C.S. ទាំងក្នុងអំពៅដាំដំបូង និងអំពៅកាត់គល់។
  • សមីការ Pol តែមួយមានប្រសិទ្ធភាពខ្ពស់ដោយផ្តល់នូវតម្លៃ R² ចន្លោះពី 88.19% ដល់ 91.06% ដែលធ្វើឱ្យវាជាជម្រើសដ៏ល្អ និងងាយស្រួលសម្រាប់ការទស្សន៍ទាយ។
  • ពូជមេមានឥទ្ធិពលយ៉ាងខ្លាំងទៅលើភាពសុក្រឹតនៃការទស្សន៍ទាយ C.C.S. ប៉ុន្តែឥទ្ធិពលនេះមិនត្រូវបានរកឃើញទេនៅពេលដែលវាត្រូវបានទស្សន៍ទាយដោយប្រើសមាសធាតុ Pol។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Simple Linear Regression (Pol only)
តំរែតំរង់លីនេអ៊ែរទោល (ប្រើតែអថេរ Pol)		 ងាយស្រួលអនុវត្ត ចំណាយតិចកម្លាំងពលកម្ម និងមានប្រសិទ្ធភាពខ្ពស់ក្នុងការទស្សន៍ទាយតម្លៃ C.C.S. ដោយមិនសូវរងឥទ្ធិពលពីពូជមេ។ តម្លៃ R² ទាបជាងការប្រើអថេរច្រើនរួមបញ្ចូលគ្នាបន្តិចបន្តួច។ ទទួលបានតម្លៃ R² ចន្លោះពី 88.19% ដល់ 91.06% សម្រាប់អំពៅដាំដំបូងនិងអំពៅកាត់គល់ ដែលចាត់ទុកថាជាកម្រិតមួយដ៏ល្អបំផុតសម្រាប់ការទស្សន៍ទាយ។
Multiple Linear Regression (Brix and Pol)
តំរែតំរង់លីនេអ៊ែរពហុគុណ (ប្រើអថេរ Brix និង Pol)		 ផ្តល់ភាពសុក្រឹតខ្ពស់បំផុត និងមានតម្លៃទស្សន៍ទាយ (R²) ខ្ពស់ជាងការប្រើតែអថេរ Pol តែមួយ។ ទាមទារការវាស់វែងអថេរពីរ ដែលនាំឱ្យចំណាយពេល និងកម្លាំងពលកម្មច្រើនជាងមុនក្នុងបន្ទប់ពិសោធន៍។ ទទួលបានតម្លៃ R² ចន្លោះពី 90.30% ដល់ 97.15%។
Direct C.C.S. Assessment
ការវាយតម្លៃតម្លៃ C.C.S. ដោយផ្ទាល់ពីបន្ទប់ពិសោធន៍ (Methodology Baseline)		 ផ្តល់តម្លៃពិតប្រាកដ និងជាក់លាក់នៃបរិមាណស្ករអំពៅពាណិជ្ជកម្មសម្រាប់ទុកជាទិន្នន័យគោល។ មានភាពស្មុគស្មាញ ចំណាយពេលយូរ ទាមទារកម្លាំងពលកម្ម និងមានការលំបាកក្នុងការអនុវត្តសម្រាប់សំណាកអំពៅចំនួនច្រើនក្នុងដំណាក់កាលដំបូងនៃការបង្កាត់ពូជ។ ត្រូវបានប្រើជាតម្លៃគោល (Observed values) សម្រាប់យកមកប្រៀបធៀបជាមួយម៉ូដែលទស្សន៍ទាយ។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះមិនបានបញ្ជាក់លម្អិតពីតម្លៃធនធានជាទឹកប្រាក់នោះទេ ប៉ុន្តែបានសង្កត់ធ្ងន់លើការកាត់បន្ថយពេលវេលា និងកម្លាំងពលកម្មតាមរយៈការប្រើប្រាស់ម៉ូដែលតំរែតំរង់ស្ថិតិជំនួសឱ្យការធ្វើពិសោធន៍ផ្ទាល់។

  • Software: កម្មវិធីវិភាគស្ថិតិដូចជា SAS (Statistical Analysis System) ឬកម្មវិធីស្រដៀងគ្នាសម្រាប់ដំណើរការទិន្នន័យ និងបង្កើតសមីការតំរែតំរង់។
  • Hardware: ឧបករណ៍វាស់ Brix (Refractometer) និងឧបករណ៍វាស់ Pol (Polarimeter) សម្រាប់ប្រមូលទិន្នន័យពីទឹកអំពៅ។
  • Dataset: ទិន្នន័យកម្រិត Brix, Pol, ជាតិសរសៃ និងភាពបរិសុទ្ធដែលប្រមូលបានពីពូជអំពៅបង្កាត់ចំនួន ៣៧ និងរុក្ខជាតិរាប់រយដើម។
  • Expertise: អ្នកជំនាញកសិកម្ម ឬអ្នកស្រាវជ្រាវដែលមានចំណេះដឹងផ្នែកស្ថិតិ (Regression Analysis) និងការបង្កាត់ពូជដំណាំ (Crop Breeding)។

ការសិក្សានេះត្រូវបានធ្វើឡើងនៅក្នុងប្រទេសថៃ (សាកលវិទ្យាល័យកាសេតសាត កំពែងសែន) ដោយប្រមូលទិន្នន័យពីពូជអំពៅជាក់លាក់នៅក្នុងតំបន់នោះ។ នេះមានសារៈសំខាន់សម្រាប់ប្រទេសកម្ពុជា ដោយសារលក្ខខណ្ឌអាកាសធាតុ ភូមិសាស្ត្រ និងប្រភេទដីមានភាពស្រដៀងគ្នា ដែលធ្វើឱ្យកម្ពុជាអាចយកគំរូម៉ូដែលនេះមកអនុវត្តបានដោយងាយស្រួល តែទាមទារឱ្យមានការកែតម្រូវទៅតាមប្រភេទពូជអំពៅក្នុងស្រុក។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រនៃការទស្សន៍ទាយ C.C.S. តាមរយៈសមាសធាតុ Pol នេះគឺមានប្រយោជន៍ និងស័ក្តិសមយ៉ាងខ្លាំងសម្រាប់វិស័យកសិឧស្សាហកម្មនៅកម្ពុជា។

  • រោងចក្រស្ករសនៅខេត្តកំពង់ស្ពឺ និងកោះកុង: រោងចក្រ និងកសិដ្ឋានខ្នាតធំនៅតំបន់ទាំងនេះអាចប្រើប្រាស់វិធីសាស្ត្រនេះ ដើម្បីវាយតម្លៃនិងជ្រើសរើសពូជអំពៅដែលផ្តល់ទិន្នផលស្ករខ្ពស់តាំងពីដំណាក់កាលដំបូងនៃការដាំដុះដោយចំណាយពេលតិច។
  • វិទ្យាស្ថានស្រាវជ្រាវ និងអភិវឌ្ឍន៍កសិកម្មកម្ពុជា (CARDI): អ្នកស្រាវជ្រាវអាចប្រើប្រាស់អថេរ Pol ជាស្តង់ដារលឿន និងចំណាយតិច ជំនួសឱ្យការវាស់ C.C.S ដោយផ្ទាល់ ដើម្បីពន្លឿនកម្មវិធីបង្កាត់ពូជអំពៅថ្មីៗដែលធន់នឹងអាកាសធាតុ និងផ្តល់ទិន្នផលខ្ពស់។
  • សហគ្រាសខ្នាតតូចនិងមធ្យម (SMEs) ផលិតស្ករអំពៅ: អាចកាត់បន្ថយការចំណាយលើឧបករណ៍ពិសោធន៍ស្មុគស្មាញ ដោយងាកមកប្រើប្រាស់ឧបករណ៍វាស់ Pol ធម្មតា ដើម្បីវាយតម្លៃគុណភាពអំពៅដែលប្រមូលទិញពីកសិករ។

ជារួម ការប្រើប្រាស់សមីការតំរែតំរង់នេះនឹងជួយសន្សំសំចៃពេលវេលា ធនធានរូបវន្ត និងលើកកម្ពស់ប្រសិទ្ធភាពនៃការវាយតម្លៃគុណភាពពូជអំពៅពាណិជ្ជកម្មនៅកម្ពុជាបានយ៉ាងច្រើន។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះ និងរៀបចំឧបករណ៍: និស្សិតត្រូវស្វែងយល់ពីគោលការណ៍នៃការគណនា C.C.S. និងរបៀបប្រើប្រាស់ឧបករណ៍វាស់សាមញ្ញដូចជា Polarimeter (សម្រាប់វាស់ Pol) និង Refractometer (សម្រាប់វាស់ Brix) ព្រមទាំងរៀបចំទម្រង់កត់ត្រាទិន្នន័យឱ្យបានច្បាស់លាស់។
  2. ចុះប្រមូលទិន្នន័យជាក់ស្តែងពីចម្ការអំពៅ: ធ្វើការសហការជាមួយកសិដ្ឋានអំពៅក្នុងស្រុក (ឧទាហរណ៍៖ នៅខេត្តកំពង់ស្ពឺ) ដើម្បីប្រមូលសំណាកអំពៅ និងវាស់តម្លៃ Pol, Brix, ជាតិសរសៃ និងភាពបរិសុទ្ធ បង្កើតជាសំណុំទិន្នន័យមូលដ្ឋាន (Baseline Dataset)។
  3. វិភាគទិន្នន័យ និងបង្កើតម៉ូដែលស្ថិតិ: ប្រើប្រាស់កម្មវិធីកុំព្យូទ័រដូចជា R, Python (Scikit-learn), ឬ SPSS ដើម្បីដំណើរការការវិភាគ Simple and Multiple Linear Regression ស្វែងរកតម្លៃ R² និងបង្កើតសមីការសម្រាប់ពូជអំពៅកម្ពុជា។
  4. វាយតម្លៃ និងផ្ទៀងផ្ទាត់ម៉ូដែល: ធ្វើការប្រៀបធៀបតម្លៃ C.C.S. ដែលបានពីការទស្សន៍ទាយតាមរយៈសមីការ ជាមួយនឹងតម្លៃ C.C.S. ដែលគណនាបានពីបន្ទប់ពិសោធន៍ពិតប្រាកដ (Predicted vs Observed Validation) ដើម្បីកំណត់ភាពសុក្រឹតនៃម៉ូដែលមុននឹងយកទៅអនុវត្តទូលំទូលាយ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
C.C.S. (ស្ករអំពៅពាណិជ្ជកម្ម) ជាប្រព័ន្ធរង្វាស់បរិមាណស្ករស៊ុយក្រូសដែលអាចទាញយកបានពីអំពៅសម្រាប់យកទៅផលិតជាស្ករពាណិជ្ជកម្ម ដែលទាមទារការវាស់វែងកម្រិត Brix, Pol និងសរសៃអំពៅ។ ដូចជាការគិតលុយចំណេញសុទ្ធបន្ទាប់ពីដកថ្លៃដើមចេញពីចំណូលសរុប គឺវាវាស់តែបរិមាណស្ករសុទ្ធដែលអាចចម្រាញ់លក់បានប៉ុណ្ណោះ។
Brix (កម្រិតរឹងរលាយសរុប) ជារង្វាស់ភាគរយនៃសារធាតុរឹងទាំងអស់ដែលរលាយនៅក្នុងទឹកអំពៅ ដែលរួមមានទាំងស្ករ និងសារធាតុមិនមែនស្ករផ្សេងៗទៀត។ ដូចជាការថ្លឹងទម្ងន់របស់របរទាំងអស់ដែលមានក្នុងកាបូបដោយមិនខ្វល់ថាជារបស់មានតម្លៃ ឬជារបស់អត់ប្រយោជន៍។
Pol (កម្រិតស្ករស៊ុយក្រូស) ជារង្វាស់ដែលវាស់បរិមាណស្ករស៊ុយក្រូស (Sucrose) សុទ្ធនៅក្នុងទឹកអំពៅ ដោយប្រើឧបករណ៍បង្វិលពន្លឺ (Polarimeter) ដើម្បីកំណត់កំហាប់ស្ករពិតប្រាកដ។ ដូចជាការរាប់តែចំនួនលុយសុទ្ធនៅក្នុងកាបូប ដោយមិនរាប់បញ្ចូលក្រដាស ឬកាតផ្សេងៗ។
Simple linear regression (តំរែតំរង់លីនេអ៊ែរទោល) ជាវិធីសាស្ត្រស្ថិតិដែលប្រើប្រាស់អថេរឯករាជ្យតែមួយ (ឧទាហរណ៍៖ អថេរ Pol) ដើម្បីទស្សន៍ទាយលទ្ធផលនៃអថេរអាស្រ័យ (ឧទាហរណ៍៖ តម្លៃ C.C.S.) តាមរយៈការគូសបន្ទាត់ត្រង់តំណាង។ ដូចជាការទស្សន៍ទាយពិន្ទុប្រឡងរបស់សិស្សម្នាក់ដោយមើលលើចំនួនម៉ោងដែលគាត់បានរៀនតែមួយមុខគត់។
Multiple linear regression (តំរែតំរង់លីនេអ៊ែរពហុគុណ) ជាវិធីសាស្ត្រស្ថិតិដែលប្រើប្រាស់អថេរឯករាជ្យចាប់ពីពីរឡើងទៅ (ឧទាហរណ៍៖ Brix និង Pol រួមគ្នា) ដើម្បីទស្សន៍ទាយលទ្ធផលអថេរអាស្រ័យឱ្យកាន់តែច្បាស់លាស់។ ដូចជាការទស្សន៍ទាយពិន្ទុប្រឡងដោយមើលទាំងចំនួនម៉ោងរៀន និងចំនួនសៀវភៅដែលសិស្សនោះបានអាន។
Coefficient of determination, R² (មេគុណកំនត់ R²) ជាតម្លៃស្ថិតិ (ពី ០ ដល់ ១ ឬគិតជាភាគរយ) ដែលបង្ហាញពីកម្រិតនៃភាពត្រឹមត្រូវរបស់ម៉ូដែលក្នុងការទស្សន៍ទាយទិន្នន័យជាក់ស្តែង។ តម្លៃកាន់តែខិតជិត ១០០% បង្ហាញថាម៉ូដែលកាន់តែសុក្រឹត។ ដូចជាពិន្ទុភាពត្រឹមត្រូវរបស់អ្នកទាយអាកាសធាតុ បើ R² ស្មើ ៩០% មានន័យថាគាត់ទាយត្រូវ ៩ ដងក្នុងចំណោមការទាយ ១០ ដង។
Ratoon cane (អំពៅកាត់គល់ ឬអំពៅជើងទី២) ជាដំណាំអំពៅដែលដុះចេញពីគល់ចាស់បន្ទាប់ពីការប្រមូលផលលើកមុនរួច ដោយមិនចាំបាច់ដាំកូន ឬដើមថ្មីឡើងវិញ។ ដូចជាការកាត់ស្មៅដែលដុះវែង ហើយទុកឱ្យវាលូតលាស់ចេញពីគល់ដដែលៗនៅរដូវក្រោយដោយមិនបាច់ដាំគ្រាប់ស្មៅថ្មី។
Progenies (ពូជកូនកាត់) ជារុក្ខជាតិជំនាន់ក្រោយដែលកើតចេញពីការបង្កាត់រវាងពូជមេ និងពូជបា (Parental clones) ដើម្បីទទួលបានលក្ខណៈប្រសើរជាងមុនក្នុងការស្រាវជ្រាវកសិកម្ម។ ដូចជាកូនដែលកើតមកមានទម្រង់មុខកាត់រកឪពុកផង និងមានទម្រង់មុខកាត់រកម្តាយផង។
