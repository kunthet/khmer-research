វិស័យសិក្សា៖ Agriculture

១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការសិក្សានេះមានគោលបំណងកំណត់បរិមាណនៃលក្ខណៈដុះពន្លក និងស្វែងរកសីតុណ្ហភាពសំខាន់ៗ ព្រមទាំងកម្រិតសក្តានុពលទឹកសម្រាប់ការដុះពន្លកនៃប្រភេទស្មៅចង្រៃឈ្លានពាន (Euphorbia maculata)។

វិធីសាស្ត្រ (The Methodology)៖ គ្រាប់ពូជត្រូវបានដាក់ឱ្យស្ថិតនៅក្រោមសីតុណ្ហភាពថេរពី 2 ដល់ 45°C និងកម្រិតសក្តានុពលទឹកផ្សេងៗគ្នាពី 0 ដល់ -0.8 MPa ដើម្បីវាយតម្លៃតាមរយៈគំរូគណិតវិទ្យាចំនួនបីផ្សេងគ្នា។

  • ការធ្វើតេស្តសីតុណ្ហភាពដុះពន្លក (Temperature Germination Test) ដោយប្រើគំរូខ្សែបន្ទាត់ប្រសព្វ (Intersected-line model), គំរូទម្រង់ធ្មេញ (Dent-like model) និងសមីការដឺក្រេទី២ (Quadratic polynomials)
  • ការធ្វើតេស្តសក្តានុពលទឹក (Water Potential Test) ដោយប្រើគំរូជលវេលា (Hydro-time model) និងគំរូ Sigmoid បីប៉ារ៉ាម៉ែត្រ

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • គំរូខ្សែបន្ទាត់ប្រសព្វ (Intersected-line model) គឺជាគំរូដ៏ល្អបំផុត ដោយបង្ហាញថាសីតុណ្ហភាពអប្បបរមា ល្អបំផុត និងអតិបរមាសម្រាប់ការដុះពន្លកគឺ 9.8°C, 28.33°C និង 43.16°C រៀងគ្នា។
  • ការដុះពន្លកត្រូវបានបញ្ឈប់ទាំងស្រុងនៅសីតុណ្ហភាព 2°C, 5°C, 10°C និង 45°C ខណៈដែលសីតុណ្ហភាព 30°C ផ្តល់អត្រាដុះពន្លកខ្ពស់បំផុតរហូតដល់ 91%។
  • ថេរវេលាជលសាស្ត្រ (Hydro-time constant) គឺ 291.32 MPa/h និងសក្តានុពលទឹកមូលដ្ឋាន (Base-water potential) គឺ -1.2 MPa ដែលបង្ហាញថាប្រភេទស្មៅនេះមានសក្តានុពលខ្ពស់ក្នុងការសាយភាយទៅតំបន់ដែលមានអាកាសធាតុស្ងួត។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Intersected-lines Model
គំរូខ្សែបន្ទាត់ប្រសព្វ		 ជាគំរូដែលផ្តល់ភាពត្រឹមត្រូវខ្ពស់បំផុត និងមានកម្រិតលម្អៀងទាបក្នុងការប៉ាន់ប្រមាណសីតុណ្ហភាពសំខាន់ៗនៃការដុះពន្លក។ ទាមទារទិន្នន័យច្រើននៅចំណុចប្រសព្វដើម្បីទទួលបានភាពច្បាស់លាស់ពេញលេញ។ សីតុណ្ហភាពអប្បបរមា (9.8°C) ល្អបំផុត (28.33°C) និងអតិបរមា (43.16°C) ដែលមាន R-squared = 0.99 និង RMSE = 0.047។
Dent-like Model
គំរូទម្រង់ធ្មេញ		 មានសមត្ថភាពបង្ហាញពីចន្លោះសីតុណ្ហភាពល្អបំផុតដែលថេរ (Plateau) សម្រាប់ការដុះពន្លក និងមានភាពស័ក្តិសមខ្ពស់ផងដែរ។ មានកម្រិតលម្អៀង (RMSE) ខ្ពស់ជាងគំរូខ្សែបន្ទាត់ប្រសព្វបន្តិច។ សីតុណ្ហភាពអប្បបរមា (10.1°C) ល្អបំផុត (30.05°C) និងអតិបរមា (44.48°C) ដែលមាន R-squared = 0.99 និង RMSE = 0.066។
Quadratic Polynomial Model
សមីការដឺក្រេទី២		 ងាយស្រួលក្នុងការគណនាតាមបែបគណិតវិទ្យា និងការអនុវត្ត។ មានភាពត្រឹមត្រូវទាបបំផុត និងកម្រិតលម្អៀងខ្ពស់ជាងគេបើប្រៀបធៀបទៅនឹងគំរូទាំងពីរខាងលើ។ ទទួលបានតម្លៃ R-squared ទាបបំផុតត្រឹម 0.91 និង RMSE ខ្ពស់រហូតដល់ 0.51។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះទាមទារបរិក្ខារមន្ទីរពិសោធន៍កសិកម្មស្តង់ដារសម្រាប់ការបណ្តុះគ្រាប់ពូជ និងកម្មវិធីកុំព្យូទ័រសម្រាប់វិភាគទិន្នន័យស្ថិតិ។

  • Hardware: ទូកម្តៅ (Germinator ឬ Incubator) សម្រាប់គ្រប់គ្រងសីតុណ្ហភាពថេរពី 2°C ដល់ 45°C និងចាន Petri dishes។
  • Materials: គ្រាប់ពូជស្មៅ, ក្រដាសចម្រោះ, ទឹកចម្រោះ, ទឹកសម្លាប់មេរោគ, និងសារធាតុរាវសម្រាប់បង្កើតកម្រិតសក្តានុពលទឹក (ឧ. កម្រិតពី 0 ដល់ -0.8 MPa)។
  • Software: កម្មវិធីវិភាគទិន្នន័យ និងគូសក្រាហ្វិក SAS version 9.1 និង SigmaPlot 11.0។
  • Expertise: អ្នកជំនាញផ្នែកសរីរវិទ្យារុក្ខជាតិ (Plant Physiology) និងការវិភាគទិន្នន័យស្ថិតិគណិតវិទ្យា។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងនៅក្នុងមន្ទីរពិសោធន៍នៃសាកលវិទ្យាល័យ Islamic Azad ក្នុងប្រទេសអ៊ីរ៉ង់ ដោយប្រើប្រាស់គ្រាប់ពូជស្មៅមកពីខេត្ត Golestan។ ទិន្នន័យនេះឆ្លុះបញ្ចាំងពីលក្ខខណ្ឌអាកាសធាតុស្ងួត និងពូជស្មៅនៅក្នុងប្រទេសអ៊ីរ៉ង់ ដែលអាចមានអាកប្បកិរិយាខុសគ្នាខ្លះពីប្រភេទស្មៅចង្រៃនៅក្នុងបរិយាកាសត្រូពិចសើមរបស់ប្រទេសកម្ពុជា។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រគំរូសីតុណ្ហភាព និងជលវេលា (Hydro-time model) នេះមានអត្ថប្រយោជន៍យ៉ាងខ្លាំងសម្រាប់ការស្រាវជ្រាវកសិកម្មនៅកម្ពុជា ដើម្បីទស្សន៍ទាយពីការដុះរបស់ស្មៅចង្រៃ។

  • ការគ្រប់គ្រងស្មៅចង្រៃក្នុងដំណាំសណ្តែកសៀង និងដំឡូងមី (ខេត្តបាត់ដំបង និងកំពង់ចាម): អាចប្រើវិធីសាស្ត្រនេះដើម្បីកំណត់ពេលវេលាច្បាស់លាស់ដែលស្មៅចង្រៃនឹងដុះពន្លក ជួយកសិករឱ្យដឹងពីពេលវេលាសមស្របបំផុតក្នុងការភ្ជួររាស់ ឬប្រើប្រាស់ថ្នាំសម្លាប់ស្មៅ។
  • ការស្រាវជ្រាវនៅវិទ្យាស្ថាន CARDI (Cambodian Agricultural Research and Development Institute): អ្នកស្រាវជ្រាវអាចប្រើប្រាស់គំរូ Hydro-time model ដើម្បីធ្វើតេស្តសក្តានុពលនៃការដុះពន្លករបស់គ្រាប់ពូជស្រូវកម្ពុជា ក្រោមលក្ខខណ្ឌរាំងស្ងួត និងការប្រែប្រួលអាកាសធាតុ។
  • ការបន្សាំទៅនឹងការប្រែប្រួលអាកាសធាតុ (Climate Change Adaptation): ជួយអ្នកជំនាញកសិកម្មកម្ពុជាយល់ដឹងពីរបៀបដែលស្មៅចង្រៃអាចសាយភាយនៅក្នុងតំបន់ដែលមានគ្រោះរាំងស្ងួតកើនឡើង (ដោយយោងតាមសក្តានុពលទឹកមូលដ្ឋានរបស់វា)។

ការទស្សន៍ទាយពេលវេលាដុះពន្លកតាមរយៈគំរូគណិតវិទ្យា នឹងជួយសម្រួលដល់ការអនុវត្តប្រព័ន្ធគ្រប់គ្រងស្មៅចម្រុះ (Integrated Weed Management) នៅកម្ពុជា ព្រមទាំងកាត់បន្ថយការប្រើប្រាស់សារធាតុគីមីហួសកម្រិត។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ប្រមូល និងរៀបចំគ្រាប់ពូជ (Seed Collection and Preparation): ចុះប្រមូលគ្រាប់ពូជស្មៅចង្រៃឈ្លានពាន (ឧទាហរណ៍ ស្មៅជើងក្រាស) ពីចម្ការគោលដៅ លាងសម្អាតដោយថ្នាំសម្លាប់មេរោគ (Sodium hypochlorite) រួចបំបាត់ភាពសម្ងំរបស់គ្រាប់ពូជ។
  2. រៀបចំការពិសោធន៍សីតុណ្ហភាព និងសក្តានុពលទឹក (Experimental Setup): ប្រើប្រាស់ទូកម្តៅ Germinator ដើម្បីបង្កើតសីតុណ្ហភាពថេរផ្សេងៗគ្នា (ឧ. 10°C ដល់ 45°C) និងប្រើសារធាតុរាវ (ដូចជា PEG) ដើម្បីបង្កើតកម្រិតតានតឹងទឹក ទៅលើគ្រាប់ពូជដែលដាក់ក្នុងចាន Petri dish។
  3. ប្រមូលទិន្នន័យប្រចាំថ្ងៃ (Daily Data Collection): ធ្វើការរាប់ចំនួនគ្រាប់ពូជដែលបានដុះពន្លកជារៀងរាល់ថ្ងៃនៅម៉ោងដដែល រហូតដល់ចំនួនគ្រាប់ដុះឈប់កើនឡើង ដើម្បីយកទិន្នន័យទៅគណនាអត្រា និងល្បឿននៃការដុះពន្លក។
  4. ដំណើរការវិភាគទិន្នន័យតាមគំរូគណិតវិទ្យា (Data Modeling): ប្រើប្រាស់កម្មវិធី R, SAS ឬ SigmaPlot ដើម្បីគូសក្រាហ្វិក និងដំណើរការគំរូ Intersected-lines model និង Hydro-time model រួចទាញយកសីតុណ្ហភាពអប្បបរមា ល្អបំផុត និងអតិបរមា។
  5. បង្កើតប្រតិទិនគ្រប់គ្រងស្មៅ (Develop Weed Management Calendar): យកទិន្នន័យដែលបានពីការវិភាគទៅចងក្រងជាកាលវិភាគណែនាំកសិករ អំពីពេលវេលាដែលស្មៅនឹងដុះលឿនបំផុត ដើម្បីចាត់វិធានការទប់ស្កាត់មុនពេលវាដុះរាលដាលពេញចម្ការ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Cardinal temperatures សីតុណ្ហភាពសំខាន់ៗទាំង៣ (អប្បបរមា ល្អបំផុត និងអតិបរមា) ដែលកំណត់ពីដែនកំណត់នៃការលូតលាស់ ឬការដុះពន្លករបស់រុក្ខជាតិ។ បើសីតុណ្ហភាពទាប ឬខ្ពស់ជាងនេះ គ្រាប់ពូជនឹងមិនដុះទេ។ ដូចជាការកំណត់សីតុណ្ហភាពទឹកម៉ាស៊ីនងូតទឹក គឺមានកម្រិតត្រជាក់បំផុត ក្តៅល្មមស្រួលខ្លួនបំផុត និងក្តៅបំផុតដែលស្បែកយើងអាចទ្រាំបាន។
Hydro-time model គំរូគណិតវិទ្យាដែលប្រើសម្រាប់ទស្សន៍ទាយពេលវេលា និងអត្រានៃការដុះពន្លករបស់គ្រាប់ពូជ ដោយផ្អែកលើកម្រិតសម្ពាធជាតិទឹក (សក្តានុពលទឹក) ដែលមាននៅក្នុងដី។ ដូចជាការគណនាថាតើត្រូវចំណាយពេលយូរប៉ុណ្ណាដើម្បីឱ្យអេប៉ុងមួយស្រូបទឹកបានពេញ ដោយផ្អែកលើបរិមាណទឹកដែលយើងចាក់នៅលើឥដ្ឋ។
Water potential រង្វាស់នៃកម្លាំងដែលទាញទឹកចេញ ឬបញ្ចូលទៅក្នុងគ្រាប់ពូជ។ កាលណាតម្លៃសក្តានុពលទឹកកាន់តែអវិជ្ជមាន វាបញ្ជាក់ថាបរិស្ថានដីកាន់តែស្ងួត ឬប្រៃ ដែលធ្វើឱ្យគ្រាប់ពូជពិបាកទាញយកទឹកដើម្បីដុះពន្លក។ ដូចជាកម្លាំងបឺតទឹកតាមទុយោបឺត វាកាន់តែពិបាកបឺតបើទឹកនោះខាប់ ឬកែវទឹកនោះជិតស្ងួត។
Intersected-line model វិធីសាស្ត្រស្ថិតិដែលគូសខ្សែបន្ទាត់ត្រង់ពីរឱ្យប្រសព្វគ្នា ដើម្បីស្វែងរកចំណុចកំពូលតែមួយគត់ (សីតុណ្ហភាពល្អបំផុត) ដែលរុក្ខជាតិមានអត្រាដុះពន្លកខ្ពស់បំផុត។ ដូចជាការគូសដំបូលផ្ទះ ដែលមានជម្រាលសងខាងជួបគ្នានៅចំណុចកំពូលស្រួចមួយ ដែលតំណាងឱ្យចំណុចលូតលាស់ល្អឥតខ្ចោះ។
Dent-like model គំរូស្ថិតិដែលសន្មតថា ចំណុចល្អបំផុតសម្រាប់ការដុះពន្លកមិនមែនមានតែមួយចំណុចទេ តែវាជាចន្លោះសីតុណ្ហភាពរាបស្មើមួយ (មានទម្រង់ដូចធ្មេញ) ដែលអត្រាដុះពន្លកស្ថិតក្នុងកម្រិតខ្ពស់ និងថេរ។ ដូចជាតុរាបស្មើមួយ ដែលមិនថាយើងដាក់វត្ថុនៅទីតាំងណាមួយលើផ្ទៃតុនោះទេ វានៅតែមានកម្ពស់ស្មើគ្នា (តំណាងឱ្យអត្រាដុះដដែលក្នុងចន្លោះសីតុណ្ហភាពនោះ)។
Sigmoidal regression ទម្រង់ក្រាហ្វិករាងអក្សរ 'S' ដែលបង្ហាញពីអត្រាដុះពន្លកកើនឡើងយឺតៗនៅពេលចាប់ផ្តើម បន្ទាប់មកកើនឡើងយ៉ាងលឿននៅចំណុចកណ្តាល និងចុងក្រោយរក្សាភាពថេរនៅពេលវាឈានដល់កម្រិតអតិបរមា។ ដូចជារបៀបដែលពាក្យចចាមអារ៉ាមសាយភាយ គឺដំបូងមានអ្នកដឹងតិចតួច បន្ទាប់មកល្បីពេញភូមិយ៉ាងលឿន រហូតដល់គ្រប់គ្នាដឹងអស់ទើបវាឈប់សាយភាយ។
Base-water potential កម្រិតជាតិទឹកអប្បបរមាជាមូលដ្ឋាននៅក្នុងដី ដែលចាំបាច់បំផុតដើម្បីឱ្យគ្រាប់ពូជរុក្ខជាតិអាចបំបែកភាពសម្ងំ និងចាប់ផ្តើមដំណើរការដុះពន្លកបាន។ ដូចជាលុយតម្កល់អប្បបរមាក្នុងគណនីធនាគារ បើមានលុយតិចជាងកម្រិតនេះ គណនីនោះនឹងមិនអាចធ្វើប្រតិបត្តិការដកឬផ្ទេរប្រាក់បានឡើយ។
