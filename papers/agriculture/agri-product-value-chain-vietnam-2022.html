១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការសិក្សានេះដោះស្រាយបញ្ហាប្រឈមនៃការអភិវឌ្ឍផលិតផលកសិកម្មនៅប្រទេសវៀតណាម ដែលបច្ចុប្បន្ននៅមានទ្រង់ទ្រាយតូច ខ្វះការតភ្ជាប់ខ្សែច្រវាក់តម្លៃ និងពឹងផ្អែកលើការកែច្នៃបឋមដែលធ្វើឱ្យប្រាក់ចំណូលកសិករនៅមានកម្រិតទាប។

វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះប្រើប្រាស់វិធីសាស្រ្តវិភាគទ្រឹស្តីខ្សែច្រវាក់តម្លៃ (Value Chain Analysis) និងការវិភាគទិន្នន័យបន្ទាប់បន្សំ ដើម្បីវាយតម្លៃស្ថានភាពជាក់ស្តែងនៃវិស័យកសិកម្មនៅវៀតណាម។

  • ការអនុវត្តទ្រឹស្តីខ្សែច្រវាក់តម្លៃរបស់ Porter (Porter's Value Chain Theory) និងវិធីសាស្ត្រ Filière (Filière approach)
  • ការវិភាគវិធីសាស្ត្រខ្សែច្រវាក់តម្លៃសកល (Global Value Chain Approach)
  • ការវាយតម្លៃទិន្នន័យបន្ទាប់បន្សំពីអគ្គនាយកដ្ឋានស្ថិតិ (GSO) និងធនាគារពិភពលោក (World Bank)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ការអភិវឌ្ឍតាមខ្សែច្រវាក់តម្លៃបានរួមចំណែកយ៉ាងសំខាន់ដល់ការកាត់បន្ថយភាពក្រីក្រ និងការធានាសន្តិសុខស្បៀងសម្រាប់ប្រជាជនវៀតណាមជាង ៩៦ លាននាក់។
  • គិតត្រឹមចុងឆ្នាំ ២០២១ វៀតណាមមានផលិតផល OCOP លើសពី ៣ ផ្កាយចំនួន ៥.៤០១ ផលិតផល (កើនឡើង ១,៧ ដងធៀបនឹងឆ្នាំ ២០២០) ដែលបង្ហាញពីការផ្លាស់ប្តូរវិជ្ជមានក្នុងផលិតកម្មទំហំធំ។
  • ដើម្បីជម្នះបញ្ហាប្រឈម រដ្ឋ និងវិស័យឯកជនគួរតែបង្កើនការគាំទ្រផ្នែកបច្ចេកវិទ្យា ហិរញ្ញវត្ថុ និងជំរុញការផ្លាស់ប្តូរផ្នត់គំនិតពី 'ការគិតបែបផលិតកម្មកសិកម្ម' ទៅជា 'ការគិតបែបសេដ្ឋកិច្ចកសិកម្ម'។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Filière Approach
វិធីសាស្ត្រ Filière (វិធីសាស្ត្រតាមខ្សែច្រវាក់)		 ល្អសម្រាប់ការវិភាគប្រព័ន្ធផលិតកម្មក្នុងស្រុកដែលភ្ជាប់ទៅនឹងការកែច្នៃ ពាណិជ្ជកម្ម និងការប្រើប្រាស់ចុងក្រោយ។ ផ្តោតខ្លាំងលើការបែងចែកប្រាក់ចំណូលក្នុងស្រុក ដែលអាចខ្វះការវាយតម្លៃស៊ីជម្រៅលើទិដ្ឋភាពប្រកួតប្រជែងសកល។ ជួយវាយតម្លៃបញ្ហាបង្កើតប្រាក់ចំណូល ការបែងចែក និងការបែងចែកចំណាយរវាងអាជីវកម្មក្នុងស្រុកនិងអន្តរជាតិ។
Porter's Value Chain Framework
ទ្រឹស្តីខ្សែច្រវាក់តម្លៃរបស់ Porter		 ជួយសហគ្រាសវាយតម្លៃសកម្មភាពតភ្ជាប់ជាមួយអ្នកផ្គត់ផ្គង់ អតិថិជន និងគូប្រជែងដើម្បីបង្កើនអត្ថប្រយោជន៍ប្រកួតប្រជែង។ ផ្តោតជាចម្បងលើកម្រិតសហគ្រាស (Firm-centric) ជាជាងកម្រិតម៉ាក្រូនៃវិស័យកសិកម្មទាំងមូល។ ធ្វើឲ្យប្រសើរឡើងនូវប្រសិទ្ធភាព និងសមត្ថភាពប្រកួតប្រជែងរបស់សហគ្រាសនីមួយៗក្នុងខ្សែច្រវាក់។
Global Value Chain (GVC) Approach
វិធីសាស្ត្រខ្សែច្រវាក់តម្លៃសកល		 ផ្តល់នូវទិដ្ឋភាពរួមនៃសកម្មភាពអាជីវកម្មពីវត្ថុធាតុដើមរហូតដល់អ្នកប្រើប្រាស់ចុងក្រោយ ជួយក្នុងការរៀបចំគោលនយោបាយស៊ីជម្រៅ។ ទាមទារការប្រមូលទិន្នន័យស្មុគស្មាញពីតួអង្គច្រើន និងការសម្របសម្រួលខ្ពស់រវាងស្ថាប័នរដ្ឋនិងឯកជន។ បង្កើតលទ្ធភាពទទួលបានគោលនយោបាយរួមបញ្ចូលគ្នា និងសមកាលកម្មពីការផលិតរហូតដល់ការប្រើប្រាស់។

ការចំណាយលើធនធាន (Resource Cost)៖ ការអនុវត្តខ្សែច្រវាក់តម្លៃកសិកម្មទាមទារការវិនិយោគយ៉ាងសំខាន់លើបច្ចេកវិទ្យា ហិរញ្ញវត្ថុ និងការអភិវឌ្ឍធនធានមនុស្ស។

  • Financial Capital: ការគាំទ្រឥណទាន និងកម្ចីធនាគារក្នុងអត្រាការប្រាក់អនុគ្រោះសម្រាប់កសិករ និងសហករណ៍។
  • Hardware: គ្រឿងចក្រកសិកម្ម និងហេដ្ឋារចនាសម្ព័ន្ធកែច្នៃ ក៏ដូចជាការថែរក្សាគុណភាពក្រោយពេលប្រមូលផល។
  • Technology: បច្ចេកវិទ្យាកសិកម្មទំនើបសម្រាប់ការដាំដុះ (Agri-tech) ការវេចខ្ចប់ និងការតាមដានប្រភពដើមផលិតផល។
  • Expertise: ការផ្លាស់ប្តូរផ្នត់គំនិតពី 'ផលិតកម្មកសិកម្ម' ទៅជា 'សេដ្ឋកិច្ចកសិកម្ម' និងជំនាញគ្រប់គ្រងសហករណ៍កសិកម្ម។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងនៅក្នុងបរិបទប្រទេសវៀតណាម ដោយពឹងផ្អែកលើទិន្នន័យពីអគ្គនាយកដ្ឋានស្ថិតិវៀតណាម និងលទ្ធផលនៃកម្មវិធី OCOP ក្នុងឆ្នាំ ២០២១។ ទិន្នន័យនេះមានសារៈសំខាន់ខ្លាំងសម្រាប់ប្រទេសកម្ពុជា ដោយសារប្រទេសទាំងពីរមានលក្ខខណ្ឌកសិកម្មស្រដៀងគ្នា និងប្រឈមមុខនឹងបញ្ហាដូចគ្នាដូចជា ការផលិតក្នុងទ្រង់ទ្រាយតូច ខ្វះបច្ចេកវិទ្យាកែច្នៃ និងការពឹងផ្អែកលើឈ្មួញកណ្តាល។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រ និងអនុសាសន៍នៅក្នុងឯកសារនេះមានប្រយោជន៍យ៉ាងខ្លាំងសម្រាប់ការអភិវឌ្ឍវិស័យកសិកម្មនៅកម្ពុជា ពិសេសក្នុងការផ្លាស់ប្តូរពីកសិកម្មបែបចិញ្ចឹមជីវិតទៅជាកសិកម្មពាណិជ្ជកម្ម។

  • កម្មវិធីភូមិមួយផលិតផលមួយ (OVOP) នៅកម្ពុជា: អាចយកគំរូតាមជោគជ័យនៃកម្មវិធី OCOP របស់វៀតណាម ដើម្បីពង្រឹងគុណភាព ស្តង់ដារ និងការវេចខ្ចប់ផលិតផលក្នុងស្រុក។
  • ខេត្តបាត់ដំបង និងពោធិ៍សាត់ (ជង្រុកស្រូវ): អាចអនុវត្តការវិភាគខ្សែច្រវាក់តម្លៃសម្រាប់ដំណាំស្រូវ ដើម្បីកាត់បន្ថយការពឹងផ្អែកលើការនាំចេញស្រូវសើម ជំរុញការកែច្នៃ និងបង្កើនតម្លៃបន្ថែម។
  • ខេត្តមណ្ឌលគិរី និងរតនគិរី (កសិ-ឧស្សាហកម្ម): អាចអនុវត្តការតភ្ជាប់ខ្សែច្រវាក់តម្លៃសម្រាប់ដំណាំកសិ-ឧស្សាហកម្មដូចជា ស្វាយចន្ទី ម្រេច និងកាហ្វេ តាមរយៈការចងក្រងសហករណ៍កសិកម្មរឹងមាំ។

ការអនុវត្តទ្រឹស្តីខ្សែច្រវាក់តម្លៃទាំងនេះអាចជួយអ្នកបង្កើតគោលនយោបាយ និងសហគ្រាសកម្ពុជាក្នុងការបង្កើនប្រាក់ចំណូលរបស់កសិករ និងពង្រឹងសមត្ថភាពប្រកួតប្រជែងសម្រាប់ការនាំចេញទីផ្សារសកល។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាទ្រឹស្តីខ្សែច្រវាក់តម្លៃ: ស្វែងយល់ពីទ្រឹស្តី Porter's Value Chain និង Global Value Chain (GVC) ដើម្បីយល់ពីរបៀបដែលតម្លៃបន្ថែមត្រូវបានបង្កើតឡើងនៅរាល់ដំណាក់កាលនៃផលិតកម្ម។
  2. វិភាគស្ថានភាពជាក់ស្តែងនៃកសិកម្មកម្ពុជា: ប្រើប្រាស់ឧបករណ៍ Value Chain Mapping ដើម្បីគូសផែនទីតួអង្គពាក់ព័ន្ធ (កសិករ ឈ្មួញកណ្តាល អ្នកកែច្នៃ អ្នកលក់រាយ) នៅក្នុងតំបន់គោលដៅណាមួយ។
  3. កំណត់បញ្ហាប្រឈម និងគម្លាត: វិភាគរកចំណុចខ្សោយនៅក្នុងខ្សែច្រវាក់បច្ចុប្បន្ន (ឧទាហរណ៍៖ ការខ្វះខាតឃ្លាំងត្រជាក់ ឬបច្ចេកវិទ្យាកែច្នៃ) ដោយប្រើប្រាស់ SWOT Analysis។
  4. អភិវឌ្ឍម៉ូដែលតភ្ជាប់រវាងតួអង្គ: បង្កើតគំរូកសិកម្មតាមកិច្ចសន្យា (Contract Farming) រវាងសហករណ៍កសិកម្ម និងសហគ្រាសកែច្នៃ ដើម្បីធានាទីផ្សារ និងតម្លៃស្ថិរភាព។
  5. ផ្លាស់ប្តូរផ្នត់គំនិត និងអនុវត្តបច្ចេកវិទ្យា: ជំរុញកសិករឱ្យប្តូរពី 'ការគិតបែបផលិតកម្ម' ទៅជា 'ការគិតបែបសេដ្ឋកិច្ច' ដោយរួមបញ្ចូលការប្រើប្រាស់បច្ចេកវិទ្យាទំនើប (Agri-tech) ដូចជាប្រព័ន្ធស្រោចស្រពឆ្លាតវៃជាដើម។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Value Chain បណ្តុំនៃសកម្មភាព ឬដំណាក់កាលដែលអាជីវកម្ម ឬឧស្សាហកម្មមួយអនុវត្ត ដើម្បីបន្ថែមតម្លៃទៅលើផលិតផល ចាប់តាំងពីវត្ថុធាតុដើម ការកែច្នៃ រហូតដល់អតិថិជនចុងក្រោយ។ ដូចជាការធ្វើនំប៉័ង ដែលមានអ្នកដាំស្រូវសាលី អ្នកកិនម្សៅ និងអ្នកដុតនំ ដែលម្នាក់ៗជួយបន្ថែមតម្លៃជាបន្តបន្ទាប់រហូតដល់ក្លាយជានំប៉័ងសម្រាប់ហូប។
Filière Approach វិធីសាស្ត្រវិភាគខ្សែច្រវាក់ផលិតកម្មកសិកម្មតាមបែបបារាំង ដែលផ្តោតលើការតាមដានលំហូររូបវន្តនៃផលិតផល (តាំងពីកសិដ្ឋានរហូតដល់តុបាយ) និងរបៀបដែលប្រាក់ចំណូលត្រូវបានបែងចែករវាងតួអង្គពាក់ព័ន្ធក្នុងស្រុក។ ដូចជាការតាមដានផ្លូវទឹកហូរពីប្រភពរហូតដល់សមុទ្រ ដើម្បីមើលថាអ្នកណាខ្លះបានទាញប្រយោជន៍ពីទឹកនោះតាមដងទន្លេ។
Porter's Value Chain ទ្រឹស្តីខ្សែច្រវាក់តម្លៃរបស់លោក Michael Porter ដែលផ្តោតលើការវិភាគសកម្មភាពចម្បង និងសកម្មភាពគាំទ្រនៅកម្រិតសហគ្រាស (Firm-level) ដើម្បីកាត់បន្ថយចំណាយ និងបង្កើតអត្ថប្រយោជន៍ប្រកួតប្រជែង។ ដូចជាកីឡាករម្នាក់ៗនៅក្នុងក្រុមបាល់ទាត់ ដែលមានតួនាទីរៀងៗខ្លួន ដើម្បីជួយឱ្យក្រុមទាំងមូលលេងបានល្អនិងឈ្នះ។
Global Value Chain (GVC) ខ្សែច្រវាក់តម្លៃដែលលាតសន្ធឹងឆ្លងកាត់ព្រំដែនអន្តរជាតិ ដែលសកម្មភាពផលិតកម្ម ការកែច្នៃ និងការចែកចាយត្រូវបានបែងចែកនៅតាមប្រទេសផ្សេងៗគ្នា ដើម្បីទាញយកអត្ថប្រយោជន៍ពីភាពចំណេញរៀងៗខ្លួន។ ដូចជាការផលិតទូរស័ព្ទដៃ ដែលអេក្រង់ធ្វើនៅប្រទេសមួយ ថ្មនៅប្រទេសមួយទៀត និងដំឡើងនៅប្រទេសមួយទៀត។
OCOP (One Commune One Product) កម្មវិធីអភិវឌ្ឍន៍សេដ្ឋកិច្ចជនបទ (ភូមិមួយផលិតផលមួយ) ដែលជម្រុញឱ្យឃុំនីមួយៗបង្កើត និងអភិវឌ្ឍផលិតផលកសិកម្ម ឬសិប្បកម្មប្រពៃណីដែលមានសក្តានុពលប្រចាំតំបន់របស់ខ្លួន ដើម្បីបង្កើនចំណូល។ ដូចជាការជ្រើសរើសសិស្សពូកែបំផុតប្រចាំថ្នាក់នីមួយៗ ដើម្បីទៅប្រកួតប្រជែងយកឈ្មោះបោះសំឡេងឱ្យសាលា។
Contract Farming កសិកម្មតាមកិច្ចសន្យា គឺជាការព្រមព្រៀងរវាងកសិករ និងអ្នកទិញ (ដូចជាក្រុមហ៊ុនកែច្នៃ) ដែលកសិករយល់ព្រមផលិតក្នុងបរិមាណ និងគុណភាពជាក់លាក់ ហើយអ្នកទិញធានាទិញយកក្នុងតម្លៃដែលបានព្រមព្រៀងទុកមុន។ ដូចជាការកក់សំបុត្រកុនទុកមុន ដែលធានាថាអ្នកពិតជាមានកន្លែងអង្គុយ ហើយរោងកុនប្រាកដជាលក់សំបុត្រដាច់។
