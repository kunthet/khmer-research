១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ឯកសារនេះផ្តោតលើការវាយតម្លៃនិងព្យាករណ៍ទិន្នផលកសិកម្ម ដោយវិភាគលើទំនាក់ទំនងរវាងលក្ខណៈកសិដ្ឋាន និងកត្តាអាកាសធាតុ តាមរយៈការប្រើប្រាស់ម៉ូដែលម៉ាស៊ីនរៀនសូត្រ (Machine Learning)។

វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះប្រើប្រាស់វិធីសាស្ត្រវិភាគទិន្នន័យ និងប្រៀបធៀបសមត្ថភាពនៃក្បួនដោះស្រាយម៉ាស៊ីនរៀនសូត្រ ដើម្បីស្វែងរកម៉ូដែលដែលផ្តល់លទ្ធផលត្រឹមត្រូវបំផុត។

  • ការរួមបញ្ចូលទិន្នន័យ (Data Integration): បញ្ចូលទិន្នន័យលក្ខណៈកសិដ្ឋាន និងសន្ទស្សន៍អាកាសធាតុ ១១ ប្រភេទនៅប្រទេសស្វីស ដែលប្រមូលបានពី European Climate Assessment & Dataset (ECA&D)។
  • ក្បួនដោះស្រាយ Random Forest (Random Forest Algorithm): បង្កើតមែកធាងសម្រេចចិត្ត (Decision Trees) ជាច្រើនដើម្បីព្យាករណ៍ទិន្នផលដំណាំ។
  • ក្បួនដោះស្រាយ Extreme Gradient Boosting (XGBoost): ប្រើប្រាស់វិធីសាស្ត្រ Regression Tree ផ្អែកលើ Gradient Descent ដើម្បីទស្សន៍ទាយ និងប្រៀបធៀបលទ្ធផល។
  • ការវាយតម្លៃសមត្ថភាពម៉ូដែល (Model Evaluation Metrics): ប្រើប្រាស់រង្វាស់ R², Mean Squared Error (MSE), និង Root Mean Squared Error (RMSE) ដើម្បីវាស់ស្ទង់ភាពត្រឹមត្រូវនៃការព្យាករណ៍។

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ម៉ូដែល Random Forest ដំណើរការបានល្អជាង XGBoost បន្តិច ដោយទទួលបានពិន្ទុ R² ចំនួន ០.៩៥៨៩ (ធៀបនឹង ០.៩៥៦៨) និងមានកំហុសមធ្យម (MSE) ទាបជាងគឺ ៩០៨.៨០ (ធៀបនឹង ៩៥៦.៤៨)។
  • ប្រភេទដំណាំ (Crop Category) គឺជាកត្តាសំខាន់បំផុតដែលជះឥទ្ធិពលដល់ការព្យាករណ៍ទិន្នផល ដែលរួមចំណែកជាង ៨០% នៅក្នុងម៉ូដែល Random Forest និង ៧០% នៅក្នុងម៉ូដែល XGBoost។
  • អថេរអាកាសធាតុមានឥទ្ធិពលតិចតួចបំផុតក្នុងការទស្សន៍ទាយ ហើយម៉ូដែលទាំងពីរបានបង្ហាញពីសញ្ញានៃការរៀនទន្ទេញ (Overfitting) ដែលតម្រូវឱ្យមានការកែលម្អទិន្នន័យ និងការកំណត់ប៉ារ៉ាម៉ែត្របន្ថែមនៅពេលអនាគត។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Random Forest Algorithm
ក្បួនដោះស្រាយ Random Forest (ការប្រើប្រាស់មែកធាងសម្រេចចិត្តច្រើនរួមបញ្ចូលគ្នា)		 មានភាពត្រឹមត្រូវខ្ពស់ក្នុងការទស្សន៍ទាយ (ពិន្ទុ R² ខ្ពស់ដល់ ០.៩៥៨៩) និងមានកំហុសមធ្យម (MSE/RMSE) ទាបជាងគេក្នុងការសិក្សានេះ។ ងាយនឹងជួបប្រទះបញ្ហា Overfitting (ការរៀនទន្ទេញទិន្នន័យជាជាងការយល់ដឹងទូទៅ) ដែលធ្វើឱ្យការអនុវត្តលើទិន្នន័យថ្មីអាចមានភាពលម្អៀង។ R² = ០.៩៥៨៩, MSE = ៩០៨.៧៩, RMSE = ៣០.១៤៦
Extreme Gradient Boosting (XGBoost)
ក្បួនដោះស្រាយ XGBoost (ការបង្កើនប្រសិទ្ធភាព Gradient លើមែកធាងតំណពូជ)		 មានសមត្ថភាពខ្ពស់ក្នុងការដោះស្រាយទិន្នន័យស្មុគស្មាញ មានមុខងារបញ្ឈប់ការរៀនដោយស្វ័យប្រវត្តិដើម្បីកាត់បន្ថយ Overfitting និងមានភាពរឹងមាំជាមួយទិន្នន័យតារាង (Tabular Data)។ មានអត្រាកំហុសខ្ពស់ជាង Random Forest បន្តិច និងទាមទារការកំណត់ប៉ារ៉ាម៉ែត្រ (Hyperparameter tuning) ច្រើននិងស្មុគស្មាញជាង។ R² = ០.៩៥៦៨, MSE = ៩៥៦.៤៧, RMSE = ៣០.៩២៧

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះមិនបានបញ្ជាក់លម្អិតអំពីតម្រូវការផ្នែករឹង (Hardware) នោះទេ ប៉ុន្តែដោយសារទិន្នន័យមានទំហំមធ្យម វាទាមទារត្រឹមតែកម្មវិធីកុំព្យូទ័រ និងបណ្ណាល័យកូដមូលដ្ឋានប៉ុណ្ណោះ។

  • Software: ប្រើប្រាស់ Microsoft Excel និង PostgreSQL សម្រាប់ការរៀបចំទិន្នន័យ និងប្រើប្រាស់ភាសា Python (ជាពិសេសបណ្ណាល័យ Scikit-learn) សម្រាប់កសាងម៉ូដែល។
  • Dataset: ទិន្នន័យកសិដ្ឋានចំនួន ៣៤១៤ ទីតាំងនៅប្រទេសស្វីស ចន្លោះឆ្នាំ ២០១៤-២០១៦ រួមមានព័ត៌មានលម្អិតកសិដ្ឋាន និងសន្ទស្សន៍អាកាសធាតុ១១ប្រភេទពី ECA&D។
  • Hardware: មិនមានបញ្ជាក់សេចក្តីលម្អិត ប៉ុន្តែដោយសារទំហំទិន្នន័យ (៣៤១៤ ជួរ) ជាទំហំតូចទៅមធ្យម កុំព្យូទ័រយួរដៃធម្មតា (Standard CPU) ក៏អាចដំណើរការម៉ូដែលទាំងនេះបាន។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះពឹងផ្អែកទាំងស្រុងលើទិន្នន័យកសិដ្ឋាន និងអាកាសធាតុនៅប្រទេសស្វីស ដែលជាតំបន់អាកាសធាតុត្រជាក់ (Temperate Climate) ព្រមទាំងផ្តោតលើប្រភេទដំណាំខុសពីស្រុកយើង។ នេះជាចំណុចខ្វះខាតដ៏ធំសម្រាប់ការអនុវត្តនៅកម្ពុជា ព្រោះប្រទេសកម្ពុជាមានអាកាសធាតុត្រូពិច ដំណាំចម្បងគឺស្រូវ ហើយរងឥទ្ធិពលយ៉ាងខ្លាំងពីគ្រោះរាំងស្ងួត និងទឹកជំនន់ ដែលមិនត្រូវបានឆ្លុះបញ្ចាំងពេញលេញនៅក្នុងទិន្នន័យនេះទេ។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

ទោះបីជាបរិបទកសិកម្មនិងអាកាសធាតុខុសគ្នាក៏ដោយ វិធីសាស្ត្រក្នុងការប្រើប្រាស់ម៉ូដែល Machine Learning ទាំងពីរនេះពិតជាមានសក្តានុពលខ្ពស់សម្រាប់ជួយវិស័យកសិកម្មនៅកម្ពុជា។

  • ក្រសួងកសិកម្ម រុក្ខាប្រមាញ់ និងនេសាទ (MAFF): អាចប្រើប្រាស់ម៉ូដែលទាំងនេះដើម្បីព្យាករណ៍ទិន្នផលស្រូវនៅតាមបណ្តាខេត្តសក្តានុពលដូចជា បាត់ដំបង និងព្រៃវែង ដោយផ្អែកលើប្រភេទពូជ ទំហំដី និងទិន្នន័យអាកាសធាតុជាក់ស្តែង។
  • វិស័យធានារ៉ាប់រងកសិកម្ម (Agricultural Insurance): ក្រុមហ៊ុនធានារ៉ាប់រងនៅកម្ពុជា អាចយកវិធីសាស្ត្រនេះទៅគណនាហានិភ័យនៃទិន្នផលដំណាំ ដើម្បីផ្តល់នូវកញ្ចប់ធានារ៉ាប់រងស្រូវ ឬដំឡូងមី ដល់កសិករនៅតំបន់ដែលងាយរងគ្រោះដោយអាកាសធាតុ។
  • វិទ្យាស្ថានស្រាវជ្រាវ និងអភិវឌ្ឍន៍កសិកម្មកម្ពុជា (CARDI): អាចរួមបញ្ចូលទិន្នន័យនៃការសិក្សាពូជស្រូវថ្មីៗ ជាមួយនឹងទិន្នន័យសំណើមដី និងអាកាសធាតុ ដើម្បីស្វែងរកកត្តាដែលជះឥទ្ធិពលបំផុតដល់ទិន្នផល តាមរយៈការវិភាគ Feature Importance។

ជារួម វិធីសាស្ត្រវាយតម្លៃទិន្នផលដោយប្រើអថេរចម្រុះនេះ អាចប្រើជាមូលដ្ឋានដ៏រឹងមាំសម្រាប់ការធានាសន្តិសុខស្បៀងនៅកម្ពុជា ប្រសិនបើត្រូវបានបង្វឹក (Trained) ជាមួយនឹងទិន្នន័យក្នុងស្រុកដែលមានគុណភាព។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ការប្រមូល និងរៀបចំទិន្នន័យ (Data Collection & Preprocessing): ប្រើប្រាស់ Microsoft Excel ដើម្បីសម្អាតទិន្នន័យបឋម និងរក្សាទុកក្នុងទិន្នន័យគំរូដោយប្រើប្រាស់ PostgreSQL ដែលរួមមានទិន្នន័យទិន្នផលស្រូវ និងសន្ទស្សន៍អាកាសធាតុប្រចាំតំបន់ពីក្រសួងពាក់ព័ន្ធ រួចប្រើប្រាស់បច្ចេកទេស Imputation ដើម្បីបំពេញទិន្នន័យដែលបាត់បង់។
  2. ការស្ថាបនាមូលដ្ឋានគ្រឹះកូដ (Environment Setup): ដំឡើងភាសា Python និងប្រើប្រាស់បណ្ណាល័យ Scikit-Learn (sklearn) ព្រមទាំង XGBoost Library ដើម្បីរៀបចំបរិស្ថានសម្រាប់ការអភិវឌ្ឍម៉ូដែល។ បែងចែកទិន្នន័យជា Training Set (៧០-៨០%) និង Testing Set (២០-៣០%)។
  3. ការបង្វឹកម៉ូដែលក្បួនដោះស្រាយ (Model Training): សរសេរកូដដើម្បីបង្កើតម៉ូដែល Random Forest Regressor និង XGBoost Regressor បញ្ចូលគ្នាដើម្បីទស្សន៍ទាយទិន្នផល ដោយកំណត់អថេរគោល (Target Variable) ជាបរិមាណទិន្នផលក្នុងមួយហិកតា។
  4. ការវាយតម្លៃ និងកែលម្អ (Evaluation & Hyperparameter Tuning): វាយតម្លៃភាពត្រឹមត្រូវនៃម៉ូដែលដោយប្រើប្រាស់រង្វាស់ R-Squared (R²), Mean Squared Error (MSE), និង Root Mean Squared Error (RMSE)។ ត្រូវអនុវត្តការកំណត់ប៉ារ៉ាម៉ែត្របន្ថែមដើម្បីកាត់បន្ថយបញ្ហាទីទិយភាព (Overfitting) ដែលបានកើតឡើងក្នុងការសិក្សានេះ។
  5. ការទាញយកការយល់ដឹងពីកត្តាជះឥទ្ធិពល (Feature Importance Analysis): ប្រើប្រាស់មុខងារ Feature Importance នៅក្នុងម៉ូដែលទាំងពីរ ដើម្បីកំណត់ថាតើកត្តាណាខ្លះ (ដូចជា ប្រភេទដំណាំ, កម្រិតទឹកភ្លៀង, ឬសីតុណ្ហភាព) ដែលមានឥទ្ធិពលបំផុតដល់ទិន្នផល រួចធ្វើសេចក្តីរាយការណ៍ជួយដល់ការសម្រេចចិត្ត។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Random Forest Algorithm ជាក្បួនដោះស្រាយម៉ាស៊ីនរៀនសូត្រ (Machine Learning) ដែលបង្កើតមែកធាងសម្រេចចិត្ត (Decision Trees) ជាច្រើនផ្ទាំង ហើយយកលទ្ធផលមធ្យម ឬការបោះឆ្នោតភាគច្រើន ដើម្បីធ្វើការទស្សន៍ទាយប្រកបដោយភាពត្រឹមត្រូវខ្ពស់។ ដូចជាការសួរយោបល់ពីមនុស្សមួយក្រុមធំ (អ្នកជំនាញច្រើននាក់) មុននឹងធ្វើការសម្រេចចិត្តរួមមួយជាជាងការជឿលើមនុស្សតែម្នាក់។
Extreme Gradient Boosting (XGBoost) ជាបច្ចេកទេសរៀនសូត្ររបស់ម៉ាស៊ីនដែលកសាងមែកធាងសម្រេចចិត្តជាបន្តបន្ទាប់ ដោយមែកធាងថ្មីនីមួយៗផ្តោតលើការកែតម្រូវកំហុសដែលបន្សល់ទុកដោយមែកធាងមុនៗ តាមរយៈការប្រើប្រាស់គណិតវិទ្យា Gradient Descent។ ដូចជាសិស្សដែលប្រឡងធ្លាក់ចំណុចណា គឺខិតខំរៀនប៉ះប៉ូវចំណុចខ្សោយនោះជារឿយៗរហូតដល់ប្រឡងជាប់បានពិន្ទុល្អឥតខ្ចោះ។
Overfitting ជាបញ្ហានៅក្នុង Machine Learning នៅពេលដែលម៉ូដែលរៀនទន្ទេញទិន្នន័យចាស់ (Training data) លម្អិតពេក រហូតដល់បាត់បង់សមត្ថភាពក្នុងការទស្សន៍ទាយទិន្នន័យថ្មីដែលវាមិនធ្លាប់ជួបពីមុនមក។ ដូចជាសិស្សដែលទន្ទេញវិញ្ញាសាចាស់ៗចាំមាត់ទឹក តែដល់ពេលប្រឡងចេញលំហាត់ថ្មីបែរជាធ្វើមិនចេញព្រោះមិនយល់គោលការណ៍គ្រឹះ។
Mean Squared Error (MSE) ជារង្វាស់សម្រាប់វាយតម្លៃកំហុសរបស់ម៉ូដែល ដោយគណនាមធ្យមភាគនៃការបូកបញ្ចូលតម្លៃការ៉េនៃភាពខុសគ្នារវាងទិន្នន័យដែលទស្សន៍ទាយបាន និងទិន្នន័យជាក់ស្តែង។ តម្លៃកាន់តែតូច បង្ហាញថាម៉ូដែលកាន់តែសុក្រឹត។ ដូចជាការវាស់ចម្ងាយគោលដៅនិងគ្រាប់ព្រួញដែលបាញ់ខុស រួចយកចម្ងាយនោះមកគុណនឹងខ្លួនឯងដើម្បីដាក់ពិន័យកំហុសធំៗឱ្យកាន់តែធ្ងន់ធ្ងរ។
Root Mean Squared Error (RMSE) ជាការបំពាក់ឫសការ៉េទៅលើតម្លៃ MSE ដើម្បីបំប្លែងឯកតាកំហុសឱ្យត្រលប់មកដូចឯកតាដើមនៃទិន្នន័យវិញ ដែលជួយឱ្យអ្នកស្រាវជ្រាវងាយស្រួលយល់ពីទំហំកំហុសជាមធ្យមនៃការព្យាករណ៍។ ដូចជាការបកប្រែពិន្ទុពិន័យ (MSE) ឱ្យត្រលប់មកជាចម្ងាយជាក់ស្តែងវិញ (ឧទាហរណ៍៖ ខុសជាមធ្យម ៣០ តោន) ដើម្បីងាយស្រួលមើលយល់ការពិត។
R-Squared (R²) ឬហៅថា Coefficient of Determination ជាសូចនាករស្ថិតិដែលវាស់ស្ទង់ថា តើអថេរឯករាជ្យ (ដូចជាអាកាសធាតុ) អាចពន្យល់ពីភាពប្រែប្រួលនៃអថេរចំណុះ (ទិន្នផល) បានប៉ុន្មានភាគរយ។ ពិន្ទុជិត ១ (ឬ ១០០%) មានន័យថាម៉ូដែលល្អឥតខ្ចោះ។ ដូចជាពិន្ទុសញ្ញាបត្រដែលបញ្ជាក់ថាម៉ូដែលរបស់យើងឆ្លាតប៉ុណ្ណា បើបាន ០.៩៥ គឺស្មើនឹងប្រឡងបាន ៩៥ ពិន្ទុលើ ១០០។
Feature Importance ជាបច្ចេកទេសវាស់ស្ទង់ដើម្បីរកមើលថាតើ អថេរ (Variables/Features) នីមួយៗមានឥទ្ធិពល ឬរួមចំណែកប៉ុន្មានភាគរយក្នុងការជួយឱ្យម៉ូដែលម៉ាស៊ីនរៀនសូត្រអាចទស្សន៍ទាយលទ្ធផលគោលដៅបានត្រឹមត្រូវ។ ដូចជាការថ្លឹងទម្ងន់គ្រឿងផ្សំដើម្បីរកមើលថា គ្រឿងផ្សំមួយណាដែលធ្វើឱ្យសម្លមានរសជាតិឆ្ងាញ់ជាងគេ (ឧទាហរណ៍៖ អំបិលសំខាន់ជាងស្ករ)។
Autoregressive Integrated Moving Average (ARIMA) ជាវិធីសាស្ត្រស្ថិតិបុរាណមួយសម្រាប់ធ្វើការព្យាករណ៍ទិន្នន័យដែលប្រែប្រួលតាមពេលវេលា (Time-series) ដោយផ្អែកលើនិន្នាការ ទិន្នន័យអតីតកាល និងកំហុសរំកិលបន្តបន្ទាប់។ ដូចជាការទាយអាកាសធាតុថ្ងៃស្អែក ដោយពឹងផ្អែកទាំងស្រុងលើអាកាសធាតុថ្ងៃនេះ និងម្សិលមិញ ដោយសង្កេតមើលលំនាំដដែលៗនៃអតីតកាល។
