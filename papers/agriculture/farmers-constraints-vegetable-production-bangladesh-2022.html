  • ក្រសួងកសិកម្ម រុក្ខាប្រមាញ់ និងនេសាទ (MAFF): អាចយកគំរូនៃការរកឃើញនេះ ដើម្បីរៀបចំគោលនយោបាយផ្តល់ឥណទានកសិកម្មការប្រាក់ទាប ការបណ្តុះបណ្តាលបច្ចេកទេស និងការសាងសង់ហេដ្ឋារចនាសម្ព័ន្ធឃ្លាំងត្រជាក់ (Cold Storage) ដល់សហគមន៍។
  • អង្គការក្រៅរដ្ឋាភិបាល (NGOs) និងគម្រោងអភិវឌ្ឍន៍កសិកម្ម: អាចផ្អែកលើលទ្ធផលនៃការវិភាគតំរែតំរង់ ដើម្បីរចនាកម្មវិធីពង្រឹងសមត្ថភាព ដោយផ្តោតលើការបង្កើនការផ្សព្វផ្សាយ (Extension media contact) និងការបណ្តុះបណ្តាល ដែលបង្ហាញថាអាចកាត់បន្ថយបញ្ហាប្រឈមបានយ៉ាងមានប្រសិទ្ធភាព។

សរុបមក ការស្វែងយល់ពីកត្តារាំងស្ទះជាប្រព័ន្ធតាមរយៈការវាស់វែងបែបបរិមាណនេះ នឹងជួយដល់តួអង្គពាក់ព័ន្ធនៅកម្ពុជាក្នុងការដាក់ចេញនូវយុទ្ធសាស្ត្រគាំទ្រកសិករឱ្យចំគោលដៅ ដើម្បីបង្កើនផលិតកម្មនិងរក្សាស្ថិរភាពតម្លៃបន្លែ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះពីវិធីសាស្ត្រស្រាវជ្រាវបរិមាណ (Quantitative Research): និស្សិតគប្បីស្វែងយល់ពីការរចនាកម្រងសំណួរ (Questionnaire design) និងបច្ចេកទេសជ្រើសរើសគំរូ (Sampling techniques) សម្រាប់ការស្ទង់មតិសង្គម-សេដ្ឋកិច្ចកសិកម្ម ដោយសិក្សាតាមរយៈ Coursera ឬឯកសារស្រាវជ្រាវកសិកម្មពី CARDI។
  2. រៀនប្រើប្រាស់កម្មវិធីវិភាគទិន្នន័យស្ថិតិ: ដំឡើងនិងអនុវត្តការប្រើប្រាស់កម្មវិធី SPSS ឬ R Studio ដើម្បីធ្វើការវិភាគស្ថិតិពិពណ៌នា (Descriptive statistics) និងការវិភាគតំរែតំរង់ពហុគុណ (Multiple Regression Analysis) លើទិន្នន័យគំរូ។
  3. សាកល្បងអនុវត្តការគណនាសន្ទស្សន៍ CFI: សាកល្បងបង្កើតកម្រងសំណួរខ្លីមួយស្តីពីបញ្ហាកសិកម្មក្នុងសហគមន៍របស់អ្នក ចុះប្រមូលទិន្នន័យពីកសិករប្រហែល ១០-២០ នាក់ ហើយធ្វើការគណនា Constraint Facing Index (CFI) ដើម្បីរកចំណាត់ថ្នាក់អាទិភាពនៃបញ្ហាទាំងនោះ។
  4. ចុះកម្មសិក្សា និងសហការជាមួយស្ថាប័នកសិកម្ម: ស្វែងរកឱកាសចុះកម្មសិក្សាជាមួយមន្ទីរកសិកម្មខេត្ត ឬអង្គការដូចជា CE SAIN ដើម្បីចូលរួមក្នុងការចុះប្រមូលទិន្នន័យផ្ទាល់ និងស្វែងយល់ពីបញ្ហាជាក់ស្តែងដូចជាប្រព័ន្ធឃ្លាំងត្រជាក់ ឬខ្សែច្រវាក់តម្លៃបន្លែនៅកម្ពុជា។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Constraint Facing Index (CFI) (សន្ទស្សន៍នៃការប្រឈមមុខនឹងបញ្ហា) ជារូបមន្តគណិតវិទ្យាដែលប្រើប្រាស់នៅក្នុងការស្រាវជ្រាវនេះ ដើម្បីដាក់ពិន្ទុ និងចាត់ថ្នាក់កម្រិតភាពធ្ងន់ធ្ងរនៃបញ្ហាផ្សេងៗដែលកសិករជួបប្រទះ ដោយផ្អែកលើទម្ងន់នៃការឆ្លើយតបរបស់ពួកគេពីកម្រិត "ខ្លាំង" ដល់ "គ្មានសោះ"។ វាជួយឱ្យគេដឹងថាបញ្ហាមួយណាជាអាទិភាពធំបំផុត។ ដូចជាការបូកសរុបពិន្ទុការបោះឆ្នោតក្នុងថ្នាក់រៀន ដើម្បីរកមើលថាច្បាប់មួយណាដែលសិស្សភាគច្រើនគិតថាតឹងរ៉ឹង និងពិបាកអនុវត្តជាងគេ។
Multiple regression analysis (ការវិភាគតំរែតំរង់ពហុគុណ) ជាវិធីសាស្ត្រគណនាស្ថិតិដែលប្រើដើម្បីស្វែងយល់ពីទំនាក់ទំនងរវាងអថេរអាស្រ័យមួយ (ឧទាហរណ៍៖ កម្រិតនៃបញ្ហាប្រឈម) និងអថេរឯករាជ្យច្រើនយ៉ាងក្នុងពេលតែមួយ (ឧទាហរណ៍៖ អាយុ កម្រិតវប្បធម៌ ទំហំដី និងចំណេះដឹងរបស់កសិករ) ថាតើកត្តាទាំងនោះជះឥទ្ធិពលរួមគ្នាដល់បញ្ហាយ៉ាងដូចម្តេចខ្លះ។ ដូចជាការវាស់ស្ទង់រកមើលថាតើកត្តាផ្សំច្រើនមុខ (អំបិល ស្ករ ម្ទេស ក្រូចឆ្មារ) នីមួយៗជះឥទ្ធិពលកម្រិតណាទៅលើរសជាតិនៃសម្លមួយឆ្នាំង។
Input constraints (បញ្ហាប្រឈមផ្នែកធាតុចូល) គឺជាឧបសគ្គឬការលំបាកនានាដែលទាក់ទងនឹងការស្វែងរក ឬការចំណាយទុនលើធនធានរូបវន្តដែលចាំបាច់សម្រាប់ចាប់ផ្តើមផលិតកម្មកសិកម្ម ដូចជា ថ្លៃជួលដី ថ្លៃពលកម្ម ការទិញគ្រាប់ពូជ ជី និងថ្នាំសម្លាប់សត្វល្អិតជាដើម។ ដូចជាការលំបាកក្នុងការរកលុយទិញឥដ្ឋ ស៊ីម៉ងត៍ និងដែក មុនពេលអាចចាប់ផ្តើមសាងសង់ផ្ទះមួយបាន។
Technical constraints (បញ្ហាប្រឈមផ្នែកបច្ចេកទេស) ជាកង្វះខាតឬបញ្ហាទាក់ទងនឹងហេដ្ឋារចនាសម្ព័ន្ធ ចំណេះដឹង និងបច្ចេកវិទ្យាដែលជួយគាំទ្រដល់ការថែទាំកសិផលឱ្យទទួលបានទិន្នផលល្អ ដូចជា កង្វះឃ្លាំងត្រជាក់សម្រាប់ស្តុកទុក ការខ្វះខាតប្រព័ន្ធស្រោចស្រព ឬមិនមានចំណេះដឹងពីពូជដែលផ្តល់ទិន្នផលខ្ពស់។ ដូចជាជាងឈើដែលដឹងពីរបៀបធ្វើតុ ប៉ុន្តែគាត់ខ្វះម៉ាស៊ីនទំនើបដើម្បីឈូសឈើឱ្យបានលឿននិងស្អាត។
Marketing constraints (បញ្ហាប្រឈមផ្នែកទីផ្សារ) គឺជាឧបសគ្គដែលកសិករជួបប្រទះនៅពេលពួកគេនាំយកកសិផលដែលប្រមូលផលរួចទៅលក់ ដែលរួមមានបញ្ហាដូចជាការប្រែប្រួលតម្លៃមិនទៀងទាត់ កង្វះព័ត៌មានពីតម្រូវការទីផ្សារ និងការកេងចំណេញពីឈ្មួញកណ្តាល។ ដូចជាអ្នកនេសាទដែលរកត្រីបានច្រើន ប៉ុន្តែពិបាករកអ្នកទិញក្នុងតម្លៃសមរម្យ ហើយជួនកាលត្រូវបង្ខំចិត្តលក់ថោកៗដើម្បីកុំឱ្យត្រីស្អុយ។
Price fluctuation (ការប្រែប្រួលតម្លៃ) គឺជាស្ថានភាពសេដ្ឋកិច្ចដែលតម្លៃនៃបន្លែ ឬទំនិញនៅលើទីផ្សារមានការឡើងចុះយ៉ាងលឿន និងមិនអាចទាយទុកជាមុនបាន ដោយសារការផ្គត់ផ្គង់និងតម្រូវការមិនមានតុល្យភាព ដែលធ្វើឱ្យកសិករប្រឈមនឹងហានិភ័យនៃការខាតបង់ប្រាក់ចំណេញ។ ដូចជាតម្លៃមាស ឬតម្លៃសាំង ដែលថ្ងៃនេះអាចថោក ប៉ុន្តែថ្ងៃស្អែកអាចនឹងឡើងថ្លៃខ្លាំងខុសធម្មតា។
