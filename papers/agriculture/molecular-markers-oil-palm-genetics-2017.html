  • Primer ចំនួន ៣ (mEgCIR3428, mEgCIR3519 និង mEgCIR0874) គឺមានប្រសិទ្ធភាពគ្រប់គ្រាន់ក្នុងការកំណត់អត្តសញ្ញាណពូជដូងប្រេង Surat Thani លេខ ១-៨។
  • ទីតាំងបម្រែបម្រួលនីយក្លេអូទីតទោលចំនួន ៥ (5 SNPs) ត្រូវបានរកឃើញសម្រាប់ការកំណត់ប្រភេទសំបកដូងប្រេង (Dura, Pisifera និង Tenera) យ៉ាងរហ័ស និងត្រឹមត្រូវ ដែលជួយកាត់បន្ថយការលាយឡំពូជបានយ៉ាងមានប្រសិទ្ធភាព។

Simple Sequence Repeat (SSR) Markers Analysis
ការវិភាគដោយប្រើប្រាស់សញ្ញាសម្គាល់ SSR		 មានប្រសិទ្ធភាពខ្ពស់ក្នុងការសិក្សាពីភាពចម្រុះនៃពន្ធុវិទ្យា និងអាចបែងចែកភាពខុសគ្នារវាងក្រុមប្រជាជនដូងប្រេងបានយ៉ាងច្បាស់លាស់។ ទាមទារពេលវេលាយូរក្នុងការវិភាគ ដោយសារត្រូវឆ្លងកាត់ការបំបែកដោយម៉ាស៊ីន (Capillary electrophoresis) និងត្រូវការប្រើប្រាស់សញ្ញាសម្គាល់ជាច្រើនរួមគ្នាដើម្បីកំណត់អត្តសញ្ញាណ។ សញ្ញាសម្គាល់ SSR ចំនួន ១៣ អាចបែងចែកក្រុមប្រជាជនដូងប្រេងចំនួន ១០ ក្រុមបានយ៉ាងល្អ ហើយ Primer ចំនួន ៣ ត្រូវបានជ្រើសរើសដើម្បីកំណត់អត្តសញ្ញាណពូជ Surat Thani លេខ ១-៨។
Real-Time PCR with TaqMan Probes for SNP Genotyping
ការប្រើប្រាស់ Real-Time PCR ជាមួយ TaqMan Probes សម្រាប់កំណត់ទីតាំង SNP		 មានភាពរហ័ស ជាក់លាក់ និងអាចត្រួតពិនិត្យសំណាកបានច្រើនក្នុងពេលតែមួយ (High-throughput) សម្រាប់ការកំណត់ប្រភេទសំបកដូងប្រេង (Dura, Pisifera, Tenera) ដោយមិនបាច់អានលំដាប់ DNA ឡើងវិញ។ ត្រូវការចំណាយដើមខ្ពស់ក្នុងការទិញម៉ាស៊ីន Real-Time PCR និងការរចនា Probe ដែលមានភ្ជាប់សារធាតុបញ្ចេញពន្លឺ (Fluorescent dyes) ដែលមានតម្លៃថ្លៃ។ កំណត់អត្តសញ្ញាណប្រភេទសំបកដូងប្រេង (SHELL types) នៃសំណាកចំនួន ១២៩ យ៉ាងត្រឹមត្រូវ ១០០% ដោយប្រើប្រាស់ Primer និង Probe ចំនួន ៤ ឈុត។

ការទាញយកបច្ចេកវិទ្យាត្រួតពិនិត្យហ្សែននេះមកអនុវត្ត នឹងជួយលើកកម្ពស់ទំនុកចិត្តលើគុណភាពកូនពូជដូងប្រេង និងជួយបង្កើនទិន្នផលប្រេងអតិបរមាសម្រាប់សេដ្ឋកិច្ចជាតិ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះពន្ធុវិទ្យា និងការស្រង់ DNA: ស្វែងយល់ពីពិធីការនៃការស្រង់ DNA ពីរុក្ខជាតិ (Plant DNA Extraction) ដោយប្រើប្រាស់វិធីសាស្ត្រ CTAB ព្រមទាំងយល់ដឹងពីគោលការណ៍នៃសញ្ញាសម្គាល់ម៉ូលេគុលដូចជា SSR និង SNP នៅក្នុងហ្សែន MADS-box របស់ដូងប្រេង។
  2. អនុវត្តការប្រើប្រាស់កម្មវិធីជីវព័ត៌មានវិទ្យា: រៀនតម្លើង និងប្រើប្រាស់កម្មវិធីកុំព្យូទ័រដូចជា BioEdit និង Clustal W2 សម្រាប់ការតម្រៀបលំដាប់នីយក្លេអូទីតច្រើនបញ្ចូលគ្នា (Multiple Sequence Alignment) ដើម្បីកំណត់រកទីតាំងបម្រែបម្រួល SNP ជាក់លាក់។
  3. សិក្សាពីការរចនា Primer និង Probe សម្រាប់ Real-Time PCR: ហ្វឹកហាត់ពីរបៀបរចនា TaqMan Probes ដោយយល់ពីរបៀបភ្ជាប់សារធាតុបញ្ចេញពន្លឺ (ឧទាហរណ៍ ពណ៌ FAM សម្រាប់ពូជ Dura និងពណ៌ VIC សម្រាប់ពូជ Pisifera) និងឧបករណ៍ Minor Groove Binder (MGB) ដើម្បីបង្កើនភាពជាក់លាក់។
  4. ការដំណើរការម៉ាស៊ីន Real-Time PCR និងការវិភាគទិន្នន័យ: អនុវត្តការដំឡើងប្រតិកម្ម PCR និងការកំណត់កម្មវិធីកម្តៅ (Thermal cycling) នៅលើម៉ាស៊ីន StepOnePlus Real-Time PCR ព្រមទាំងរៀនអានក្រាហ្វលទ្ធផលពីកម្មវិធី Allelic Discrimination plot ដើម្បីបែងចែកប្រភេទសំបកដូងប្រេង។
  5. អនុវត្តផ្ទាល់ក្នុងមន្ទីរពិសោធន៍កសិកម្ម: ស្នើសុំចុះកម្មសិក្សា ឬសហការជាមួយវិទ្យាស្ថានស្រាវជ្រាវ (ដូចជា CARDI) ឬមន្ទីរពិសោធន៍របស់ក្រុមហ៊ុនឯកជន ដើម្បីអនុវត្តការត្រួតពិនិត្យគុណភាពសំណាកកូនដូងប្រេងពិតប្រាកដមុនពេលបញ្ចេញលក់ ឬដាំដុះ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Simple Sequence Repeat (SSR) (សញ្ញាសម្គាល់ម៉ៃក្រូសាតែលឡៃត៍) ជាបំណែក DNA ខ្លីៗដែលច្រំដដែលៗនៅក្នុងសេណូម (Genome) របស់រុក្ខជាតិ។ វាត្រូវបានប្រើជាសញ្ញាសម្គាល់ម៉ូលេគុលដើម្បីសិក្សាពីភាពខុសគ្នានៃពន្ធុវិទ្យារវាងពូជដូងប្រេងផ្សេងៗគ្នា ព្រោះចំនួននៃការច្រំដដែលៗនេះមានភាពខុសគ្នាតាមពូជ។ ដូចជាលេខកូដបាកូដ (Barcode) នៅលើផលិតផលនីមួយៗ ដែលជួយយើងឱ្យដឹងច្បាស់ថាទំនិញនោះមកពីរោងចក្រណា និងជាម៉ាកអ្វី។
Single Nucleotide Polymorphism (SNP) (បម្រែបម្រួលនីយក្លេអូទីតទោល) ជាការផ្លាស់ប្តូរ ឬបម្រែបម្រួលនៃតួអក្សរ DNA (A, T, C, G) តែមួយខ្ទង់នៅក្នុងខ្សែសង្វាក់ DNA។ នៅក្នុងការសិក្សានេះ គេប្រើវាដើម្បីកំណត់ប្រភេទសំបកដូងប្រេង (Dura, Pisifera, Tenera) បានយ៉ាងរហ័សនិងជាក់លាក់បំផុត។ ដូចជាការសរសេរពាក្យខុសអក្ខរាវិរុទ្ធតែមួយតួអក្សរ (ឧទាហរណ៍ «កាល» ទៅជា «កាយ») ដែលធ្វើឱ្យអត្ថន័យទាំងមូលផ្លាស់ប្តូរ និងអាចកត់សម្គាល់បានយ៉ាងងាយ។
Real-Time PCR (បច្ចេកទេស Real-Time PCR) ជាបច្ចេកទេសមន្ទីរពិសោធន៍សម្រាប់ថតចម្លង និងពង្រីកបំណែក DNA ណាមួយឱ្យមានចំនួនច្រើន ហើយអាចតាមដានបរិមាណ DNA ដែលកំពុងកើនឡើងភ្លាមៗក្នុងពេលកំពុងដំណើរការ ដោយប្រើសារធាតុបញ្ចេញពន្លឺ។ វាត្រូវបានប្រើដើម្បីអានទីតាំង SNP និងកំណត់ពូជដូងប្រេងបានយ៉ាងលឿន។ ដូចជាម៉ាស៊ីនថតចម្លងឯកសារដ៏ឆ្លាតវៃមួយ ដែលអាចប្រាប់អ្នកភ្លាមៗនៅលើអេក្រង់ថាតើឯកសារប៉ុន្មានសន្លឹកត្រូវបានថតចម្លងរួចរាល់ ជំនួសឱ្យការរង់ចាំរហូតដល់ម៉ាស៊ីនដើរចប់ទើបរាប់ដោយដៃ។
MADS-box gene (ហ្សែន MADS-box) ជាក្រុមហ្សែនដែលគ្រប់គ្រងការលូតលាស់ និងការអភិវឌ្ឍរបស់រុក្ខជាតិ ជាពិសេសគឺការបង្កើតផ្កា និងផ្លែ។ ក្នុងករណីដូងប្រេង ហ្សែន SHELL ដែលជាប្រភេទ MADS-box នេះ គឺជាតួអង្គចម្បងក្នុងការកំណត់ថាតើគ្រាប់ដូងប្រេងនោះមានសំបកក្រាស់ ស្តើង ឬគ្មានសំបក។ ដូចជាមេការសំណង់ម្នាក់ដែលជាអ្នកកាន់ប្លង់ផ្ទះ និងបញ្ជាយ៉ាងម៉ឺងម៉ាត់ថាតើជញ្ជាំងផ្ទះត្រូវសាងសង់កម្រាស់ប៉ុន្មាន។
TaqMan Probe (ប្រូប TaqMan) ជាខ្សែ DNA ខ្លីម្យ៉ាងដែលត្រូវបានរចនាឡើងយ៉ាងពិសេស ដោយមានភ្ជាប់សារធាតុបញ្ចេញពន្លឺនៅចុងម្ខាង និងសារធាតុទប់ពន្លឺនៅចុងម្ខាងទៀត។ វាមានតួនាទីទៅចាប់យកទីតាំងបម្រែបម្រួល (SNP) គោលដៅ និងបញ្ចេញពន្លឺពណ៌ផ្សេងៗគ្នា (ដូចជា FAM, VIC) ដើម្បីសម្គាល់ពូជខុសគ្នាពេលធ្វើ PCR។ ដូចជាភ្លើងពិលឆ្លាតវៃ ដែលវានឹងបញ្ចេញពន្លឺពណ៌ក្រហមនៅពេលរកឃើញវត្ថុ A និងពណ៌ខៀវនៅពេលរកឃើញវត្ថុ B នៅក្នុងទីងងឹត។
Allelic Discrimination plot (ក្រាហ្វបែងចែកអាឡែល) ជាតារាងក្រាហ្វិកដែលបង្កើតឡើងដោយម៉ាស៊ីន Real-Time PCR ដែលបង្ហាញពីលទ្ធផលនៃការបែងចែកប្រភេទសេណូទីប (Genotype) របស់សំណាកនីមួយៗ ដោយផ្អែកលើការបញ្ចេញពន្លឺខុសៗគ្នា (ឧទាហរណ៍ ចំណុចនៅលើអ័ក្ស X សម្រាប់ពូជមេ, អ័ក្ស Y សម្រាប់ពូជបា និងចំណុចកណ្តាលសម្រាប់កូនកាត់)។ ដូចជាការបែងចែកសិស្សក្នុងថ្នាក់ជា៣ក្រុមនៅលើក្តារខៀន៖ ក្រុមពាក់អាវខៀវឈរនៅខាងឆ្វេង ក្រុមពាក់អាវក្រហមឈរនៅខាងស្តាំ និងក្រុមពាក់អាវចម្រុះពណ៌ឈរនៅកណ្តាល។
Heterozygous (ភាពខុសគ្នានៃអាឡែលទ្វេ) ជាសូចនាករដែលបញ្ជាក់ថាបុគ្គល ឬរុក្ខជាតិមួយមានទម្រង់ហ្សែន (Alleles) ពីរខុសគ្នាដែលទទួលមរតកពីមេ និងបា។ នៅក្នុងដូងប្រេង ពូជកូនកាត់ Tenera គឺជាកូនកាត់ប្រភេទ Heterozygous (Sh_Sh_) ដែលទទួលបានពីការបង្កាត់រវាងពូជ Dura និង Pisifera។ ដូចជាការកាត់សម្លៀកបំពាក់មួយដែលមានពណ៌ដៃអាវខាងឆ្វេងពណ៌ស (ចម្លងពីម្តាយ) និងដៃអាវខាងស្តាំពណ៌ខ្មៅ (ចម្លងពីឪពុក) បង្កើតបានជាអាវចម្រុះពណ៌ថ្មីមួយ។
Phylogenetic tree (ដ្យាក្រាមដើមឈើពន្ធុវិទ្យា) ជាគំនូសបំព្រួញដែលមានរាងដូចមែកឈើ ប្រើសម្រាប់បង្ហាញពីទំនាក់ទំនង និងភាពជិតស្និទ្ធខាងពន្ធុវិទ្យារវាងក្រុមប្រជាជន ឬពូជផ្សេងៗគ្នា។ មែកដែលនៅជិតគ្នាមានន័យថាវាមានហ្សែនស្រដៀងគ្នាខ្លាំង។ ដូចជាតារាងខ្សែស្រឡាយគ្រួសារ (Family tree) ដែលបង្ហាញថានរណាជាបងប្អូនបង្កើត នរណាជាបងប្អូនជីដូនមួយ ផ្អែកលើជីដូនជីតារួមគ្នាក្នុងអតីតកាល។
