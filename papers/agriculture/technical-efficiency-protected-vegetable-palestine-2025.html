វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Stochastic Frontier Analysis (SFA)
ការវិភាគ Stochastic Frontier Analysis (SFA)		 មានសមត្ថភាពអាចបំបែកកំហុសចៃដន្យ (Random error) ដែលបណ្តាលមកពីអាកាសធាតុ ឬកត្តាខាងក្រៅ ចេញពីភាពគ្មានប្រសិទ្ធភាពរបស់កសិករ (Inefficiency)។ វាស័ក្តិសមបំផុតសម្រាប់ទិន្នន័យវិស័យកសិកម្មដែលមានហានិភ័យខ្ពស់។ ទាមទារការសន្មតទៅលើទម្រង់នៃអនុគមន៍ផលិតកម្មជាមុន (Parametric assumption) ដែលអាចនាំឱ្យមានកំហុសប្រសិនបើទម្រង់នោះមិនស័ក្តិសមនឹងទិន្នន័យ។ រកឃើញប្រសិទ្ធភាពបច្ចេកទេសជាមធ្យម ៦៧% និងបានកំណត់អត្តសញ្ញាណកត្តារារាំងប្រសិទ្ធភាពដូចជាការប្រើប្រាស់ជីគីមីហួសកម្រិត។
Cobb-Douglas Production Function
អនុគមន៍ផលិតកម្ម Cobb-Douglas		 មានភាពសាមញ្ញ និងងាយស្រួលក្នុងការគណនាព្រមទាំងបកស្រាយមេគុណ ជាភាពយឺតនៃផលិតកម្ម (Output elasticities) ចំពោះធាតុចូលនីមួយៗ។ មានដែនកំណត់ដោយសារវាសន្មតថាភាពយឺតនៃការជំនួសរវាងធាតុចូលមានតម្លៃថេរ និងស្មើមួយ (Constant return to scale) ដែលអាចមិនឆ្លុះបញ្ចាំងពីការពិតទាំងស្រុង។ បង្ហាញយ៉ាងច្បាស់ពីឥទ្ធិពលវិជ្ជមាននៃការប្រើប្រាស់ជីសរីរាង្គ (មេគុណ 44.71 សម្រាប់ប៉េងប៉ោះ) ធៀបនឹងឥទ្ធិពលអវិជ្ជមាននៃប្រព័ន្ធស្រោចស្រព និងជីគីមីលើសកម្រិត។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះផ្អែកលើទិន្នន័យបឋម (Primary data) ដែលទាមទារការចុះប្រមូលទិន្នន័យផ្ទាល់ និងការប្រើប្រាស់កម្មវិធីកុំព្យូទ័រឯកទេសសម្រាប់ការវិភាគសេដ្ឋកិច្ចត្រឹមត្រូវកម្រិតខ្ពស់។

  • Software: កម្មវិធី SPSS សម្រាប់ស្ថិតិពណ៌នា និងកម្មវិធី FRONTIER 4.1 (អភិវឌ្ឍដោយ Coelli) សម្រាប់ការវិភាគគំរូ SFA ដោយប្រើប្រាស់វិធីសាស្ត្រ Maximum Likelihood Estimation។

  • Expertise: ទាមទារចំណេះដឹងផ្នែកសេដ្ឋកិច្ចកសិកម្ម (Agricultural Economics) ការបង្កើតគំរូសេដ្ឋកិច្ច (Econometrics) និងការបកស្រាយលទ្ធផលស្ថិតិ។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រវិភាគប្រសិទ្ធភាពបច្ចេកទេស SFA នេះមានអត្ថប្រយោជន៍យ៉ាងខ្លាំង សម្រាប់ការវាយតម្លៃ និងកែលម្អវិស័យកសិកម្មទំនើបនៅប្រទេសកម្ពុជា ជាពិសេសការដាំដុះបន្លែសុវត្ថិភាព។

  • ការដាំដុះបន្លែក្នុងផ្ទះសំណាញ់ (ខេត្តកណ្តាល និងកំពង់ចាម): អាចប្រើវិធីសាស្ត្រនេះដើម្បីវាស់ស្ទង់ថា តើកសិករប្រើប្រាស់ជី ថ្នាំសម្លាប់សត្វល្អិត និងពលកម្ម បានត្រឹមត្រូវកម្រិតណា ដើម្បីកាត់បន្ថយការចំណាយមិនចាំបាច់ និងបង្កើនទិន្នផលបន្លែ។
  • ការរៀបចំគោលនយោបាយកសិកម្ម (ក្រសួងកសិកម្ម រុក្ខាប្រមាញ់ និងនេសាទ): លទ្ធផលនៃគំរូ Inefficiency Model អាចជួយរដ្ឋាភិបាល ឬអង្គការក្រៅរដ្ឋាភិបាល កំណត់គោលដៅផ្តល់ការបណ្តុះបណ្តាលចំចំណុច ដូចជាការជំរុញការប្រើប្រាស់ជីសរីរាង្គដល់កសិករដែលមានវ័យចំណាស់ ឬខ្វះចំណេះដឹង។

សរុបមក ការយកគំរូវិភាគនេះមកអនុវត្ត អាចជួយពន្លឿនការផ្លាស់ប្តូររបស់កម្ពុជា ពីការធ្វើកសិកម្មដែលពឹងផ្អែកលើការប្រើប្រាស់ធាតុចូលច្រើនហួសហេតុ ទៅជាកសិកម្មវៃឆ្លាត និងមានប្រសិទ្ធភាពសេដ្ឋកិច្ចខ្ពស់។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃសេដ្ឋកិច្ចកសិកម្ម: និស្សិតត្រូវស្វែងយល់ពីទ្រឹស្តីអនុគមន៍ផលិតកម្ម (Production Functions) ដូចជា Cobb-Douglas ឬ Translog និងគោលគំនិតនៃការវាស់ស្ទង់ប្រសិទ្ធភាពបច្ចេកទេស (Technical Efficiency)។
  2. ស្វែងយល់ពីកម្មវិធីវិភាគទិន្នន័យ: រៀនប្រើប្រាស់កម្មវិធី STATA ឬកញ្ចប់ frontier នៅក្នុងភាសា R ដែលមានភាពទំនើបជាង FRONTIER 4.1 សម្រាប់ការរៀបចំទិន្នន័យ និងដំណើរការគំរូ SFA ប្រកបដោយប្រសិទ្ធភាព។
  3. រចនាកម្រងសំណួរ និងប្រមូលទិន្នន័យ: រៀបចំកម្រងសំណួរដើម្បីចុះសម្ភាសន៍កសិករដាំបន្លែក្នុងផ្ទះសំណាញ់នៅតំបន់គោលដៅ (ឧ. ខេត្តកណ្តាល) ដោយត្រូវប្រមូលទិន្នន័យធាតុចូល (ទំហំដី ពូជ ជីគីមី ជីសរីរាង្គ ទឹក ពលកម្ម) និងទិន្នផលឱ្យបានច្បាស់លាស់។
  4. ការកសាងគំរូ និងសរសេររបាយការណ៍: ដំណើរការវិភាគទិន្នន័យដើម្បីរកមេគុណនៃធាតុចូល និងកត្តាដែលធ្វើឱ្យបាត់បង់ប្រសិទ្ធភាព (Inefficiency variables) ដូចជាអាយុ ឬកម្រិតការអប់រំ រួចសរសេរជាអនុសាសន៍ជាក់ស្តែងសម្រាប់ជួយកសិករកម្ពុជា។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Stochastic Frontier Analysis (ការវិភាគតាមគំរូ Stochastic Frontier) វិធីសាស្ត្រស្ថិតិសេដ្ឋកិច្ចដែលប្រើសម្រាប់ប៉ាន់ស្មានទិន្នផលអតិបរមាដែលអាចសម្រេចបាន (Frontier) និងវាស់ស្ទង់ភាពគ្មានប្រសិទ្ធភាព ដោយបំបែកកំហុសចៃដន្យ (ដូចជាអាកាសធាតុ ឬសត្វល្អិតស៊ី) ចេញពីកំហុសនៃការគ្រប់គ្រងរបស់កសិករ។ ដូចជាការប្រកួតរត់ប្រណាំង ដែលយើងវាស់ស្ទង់ថាតើអ្នករត់ម្នាក់អាចរត់បានលឿនបំផុតកម្រិតណា ហើយរកមើលថាតើគាត់រត់យឺតដោយសាររបួស (កំហុសរបស់គាត់) ឬដោយសារភ្លៀងធ្លាក់ផ្លូវរអិល (កត្តាខាងក្រៅ)។
Technical Efficiency (ប្រសិទ្ធភាពបច្ចេកទេស) សមត្ថភាពរបស់កសិដ្ឋានក្នុងការផលិតទិន្នផលឱ្យបានច្រើនបំផុត ដោយប្រើប្រាស់កម្រិតធាតុចូល (ដូចជា ជី ទឹក ពលកម្ម) ដែលមានស្រាប់ ឬការប្រើប្រាស់ធាតុចូលតិចបំផុតដើម្បីទទួលបានទិន្នផលថេរប្រកបដោយនិរន្តរភាព។ ដូចជាការចម្អិនម្ហូបឱ្យបានច្រើននិងឆ្ងាញ់បំផុត ដោយប្រើប្រាស់គ្រឿងផ្សំដែលមានកំណត់នៅក្នុងទូទឹកកកឱ្យអស់លទ្ធភាព ដោយមិនខ្ជះខ្ជាយ។
Cobb-Douglas Production Function (អនុគមន៍ផលិតកម្ម Cobb-Douglas) រូបមន្តគណិតវិទ្យាក្នុងសេដ្ឋកិច្ច ដែលបង្ហាញពីទំនាក់ទំនងរវាងបរិមាណធាតុចូលរួមផ្សំ (ដូចជាដី ជី និងពលកម្ម) និងបរិមាណផលសម្រេច ដែលជួយឱ្យអ្នកស្រាវជ្រាវដឹងពីកម្រិតនៃការឆ្លើយតបរបស់ទិន្នផលនៅពេលដែលគេបន្ថែមធាតុចូលណាមួយ។ ដូចជារូបមន្តធ្វើនំ ដែលប្រាប់យើងថាបើបូកម្សៅប៉ុណ្ណេះ និងស្ករប៉ុណ្ណេះ តើនឹងលាយចេញជានំប៉ុន្មានដុំ។
Maximum Likelihood Estimation (ការប៉ាន់ស្មានតាមភាពទំនងអតិបរមា) វិធីសាស្ត្រស្ថិតិដែលប្រើដើម្បីស្វែងរកតម្លៃមេគុណនៅក្នុងគំរូគណិតវិទ្យា (ដូចជា SFA) ដែលធ្វើឱ្យទិន្នន័យដែលយើងប្រមូលបានមានភាគរយនៃការកើតឡើង (Probability) ខ្ពស់បំផុត ឬត្រឹមត្រូវបំផុតទៅនឹងតថភាពជាក់ស្តែង។ ដូចជាការតម្រង់អង់តែនទូរទស្សន៍ ដើម្បីរកមើលទិសដៅណាដែលចាប់ប៉ុស្តិ៍បានច្បាស់បំផុតជាងគេ។
Protected Vegetable Cultivation (ការដាំដុះបន្លែក្នុងប្រព័ន្ធការពារ) ការដាំដុះដំណាំនៅក្នុងរចនាសម្ព័ន្ធបិទជិត ឬពាក់កណ្តាលបិទជិត ដូចជាផ្ទះកញ្ចក់ ឬផ្ទះសំណាញ់ ដើម្បីគ្រប់គ្រងបរិយាកាស (សីតុណ្ហភាព ពន្លឺ សំណើម) និងការពារដំណាំពីសត្វល្អិត និងអាកាសធាតុអាក្រក់ដែលអាចបំផ្លាញទិន្នផល។ ដូចជាការដាក់មុង ឬចងតង់ឱ្យដំណាំ ដើម្បីកុំឱ្យមូសខាំ និងការពារកុំឱ្យត្រូវខ្យល់ឬភ្លៀងខ្លាំងពេក។
Solar Soil Sterilization (ការសម្លាប់មេរោគក្នុងដីដោយពន្លឺព្រះអាទិត្យ) ការអនុវត្តកសិកម្មដោយប្រើប្រាស់កម្តៅពីពន្លឺព្រះអាទិត្យ ដោយគ្របផ្ទាំងប្លាស្ទិកថ្លាលើដីសើម ដើម្បីសម្លាប់មេរោគ ផ្សិត សត្វល្អិត និងគ្រាប់ស្មៅចង្រៃដែលមាននៅក្នុងដីមុនពេលចាប់ផ្តើមដាំដុះ។ ដូចជាការយកភួយទៅហាលថ្ងៃឱ្យក្តៅ ដើម្បីសម្លាប់មេរោគមុននឹងយកមកដណ្តប់។
Likelihood Ratio Test (ការធ្វើតេស្តសម្មតិកម្ម Likelihood Ratio) ការធ្វើតេស្តស្ថិតិដើម្បីប្រៀបធៀបគំរូសេដ្ឋកិច្ចពីរ (គំរូមួយមានលក្ខខណ្ឌតឹងរ៉ឹង និងមួយទៀតមិនសូវមានលក្ខខណ្ឌ) ដើម្បីកំណត់ថាគំរូមួយណាដែលស័ក្តិសមជាមួយទិន្នន័យដែលបានប្រមូលជាក់ស្តែងជាងគេ។ ដូចជាការសាកល្បងពាក់វ៉ែនតាពីរប្រភេទខុសគ្នា ដើម្បីមើលថាតើវ៉ែនតាមួយណាជួយឱ្យមើលឃើញអក្សរបានច្បាស់ជាងគេ។
