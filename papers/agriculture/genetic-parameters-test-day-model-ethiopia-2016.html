បញ្ហា (The Problem)៖ ឯកសារនេះដោះស្រាយបញ្ហានៃការវាយតម្លៃពន្ធុវិទ្យាសត្វនៅក្នុងប្រទេសកំពុងអភិវឌ្ឍន៍ ដែលខ្វះខាតប្រព័ន្ធកត់ត្រាទិន្នន័យ តាមរយៈការប្រើប្រាស់ទិន្នន័យតេស្តទិន្នផលទឹកដោះប្រចាំខែជំនួសឱ្យកំណត់ត្រាពេញ 305 ថ្ងៃ។

វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះប្រើប្រាស់ម៉ូដែលតំរែតំរង់ចៃដន្យដើម្បីវិភាគទិន្នន័យតេស្តទឹកដោះប្រចាំខែរបស់គោចម្រុះពូជ ដោយផ្អែកលើអនុគមន៍គណិតវិទ្យា។

  • ការវិភាគកំណត់ត្រាទឹកដោះចំនួន 50,839 ពីមេគោចំនួន 2,045 ក្បាល (Monthly test-day milk records)
  • ការប្រើប្រាស់អនុគមន៍ហ្គាម៉ាមិនពេញលេញដែលត្រូវបានកែប្រែ (Modified incomplete gamma function)
  • ការអនុវត្តម៉ូដែលតំរែតំរង់ចៃដន្យ (Random regression animal repeatability model)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • កម្រិតនៃការបន្តពូជ (Heritabilities) នៃទិន្នផលទឹកដោះក្នុងថ្ងៃតេស្តកើនឡើងពី 0.17 ដល់ 0.42 នៅពេលរយៈពេលនៃការបំបៅដោះកាន់តែខិតទៅមុខ។
  • អត្រានៃការធ្វើឡើងវិញ (Repeatabilities) សម្រាប់ទិន្នផលទឹកដោះក្នុងថ្ងៃតេស្ត មានការកើនឡើងស្រដៀងគ្នាក្នុងចន្លោះពី 0.84 ដល់ 0.94 ។
  • ម៉ូដែលតំរែតំរង់ចៃដន្យ (Random regression model) គឺមានភាពស័ក្តិសម និងផ្តល់អត្ថប្រយោជន៍ខ្ពស់សម្រាប់ការវាយតម្លៃពន្ធុវិទ្យានៅក្នុងហ្វូងគោចម្រុះពូជនេះ។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះទាមទារទិន្នន័យរយៈពេលវែង និងកម្មវិធីស្ថិតិកម្រិតខ្ពស់សម្រាប់ការវិភាគទិន្នន័យពន្ធុវិទ្យាសត្វក្នុងទំហំធំ។

  • Software: ត្រូវការកម្មវិធី ASREML (នីតិវិធី AI-REML) សម្រាប់ប៉ាន់ប្រមាណវ៉ារ្យង់ និង SAS (PROC IML)។
  • Dataset: ត្រូវការកំណត់ត្រាទឹកដោះប្រចាំខែរយៈពេលវែង (ឧ. ក្នុងការសិក្សានេះប្រើកំណត់ត្រាជាង ៥ម៉ឺន ក្នុងរយៈពេល ៣៣ឆ្នាំ)។
  • Expertise: ទាមទារអ្នកជំនាញផ្នែក Quantitative Genetics និងការធ្វើម៉ូដែលគណិតវិទ្យា/ស្ថិតិ (Statistical Modeling)។

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងនៅប្រទេសអេត្យូពី ដោយប្រើប្រាស់ទិន្នន័យគោពូជកាត់រវាងពូជក្នុងស្រុក (Horro, Boran) ជាមួយពូជនាំចូល (Friesian, Jersey, Simmental) ពីមជ្ឈមណ្ឌលស្រាវជ្រាវចំនួនបី។ ការប្រើប្រាស់ទិន្នន័យគោពូជកាត់ក្នុងតំបន់ត្រូពិចនេះមានសារៈសំខាន់សម្រាប់ប្រទេសកម្ពុជា ព្រោះកម្ពុជាក៏មានអាកាសធាតុក្តៅ និងការចិញ្ចឹមគោពូជកាត់ស្រដៀងគ្នា ដែលទាមទារការវាយតម្លៃពន្ធុវិទ្យាក្នុងបរិស្ថានស្រដៀងគ្នានេះ។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

ម៉ូដែល Random Regression នេះមានប្រយោជន៍ខ្លាំងណាស់សម្រាប់ការអភិវឌ្ឍវិស័យគោយកទឹកដោះនៅប្រទេសកម្ពុជា ជាពិសេសក្នុងបរិបទដែលកសិដ្ឋានភាគច្រើនខ្វះប្រព័ន្ធកត់ត្រាទិន្នន័យពេញលេញប្រចាំថ្ងៃ។

  • កសិដ្ឋានគោយកទឹកដោះពាណិជ្ជកម្មខ្នាតធំ (ឧទាហរណ៍៖ Kirisu Farm): អាចប្រើប្រាស់ម៉ូដែលនេះដើម្បីវាយតម្លៃ និងជ្រើសរើសពូជគោ (Breeding values) ដែលផ្តល់ទិន្នផលខ្ពស់ និងមានភាពធន់ ផ្អែកលើកំណត់ត្រាតេស្តទឹកដោះប្រចាំខែជាក់ស្តែង។
  • វិទ្យាស្ថានស្រាវជ្រាវ និងសាកលវិទ្យាល័យកសិកម្ម (ឧទាហរណ៍៖ RUA ឬ CARDI): អាចយកទៅធ្វើជាមូលដ្ឋានក្នុងការស្រាវជ្រាវពីកម្មវិធីបង្កាត់ពូជគោ (Crossbreeding programs) ឱ្យស្របតាមអាកាសធាតុត្រូពិចនៃប្រទេសកម្ពុជា។
  • សហគមន៍កសិករចិញ្ចឹមគោទឹកដោះខ្នាតតូច (ឧទាហរណ៍៖ សហគមន៍នៅតាកែវ ឬពោធិ៍សាត់): ជួយសម្រួលដល់ការតាមដានទិន្នផលទឹកដោះដោយមិនចាំបាច់កត់ត្រារាល់ថ្ងៃ (សន្សំធនធាន) ប៉ុន្តែអាចផ្អែកលើការចុះវាស់វែងត្រឹម១ដងក្នុងមួយខែ ដើម្បីប៉ាន់ស្មានទិន្នផលសរុបប្រកបដោយភាពត្រឹមត្រូវ។

ជារួម ការអនុវត្តម៉ូដែលនេះនឹងជួយពន្លឿនការកែលម្អពន្ធុវិទ្យាគោទឹកដោះនៅកម្ពុជា ដោយផ្តល់នូវដំណោះស្រាយជាក់ស្តែងចំពោះបញ្ហាខ្វះខាតហេដ្ឋារចនាសម្ព័ន្ធកត់ត្រាទិន្នន័យ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះពន្ធុវិទ្យា និងស្ថិតិ: ស្វែងយល់ពីទ្រឹស្តីនៃការវាយតម្លៃពន្ធុវិទ្យាសត្វ (Quantitative Genetics) និងការប្រើប្រាស់ម៉ូដែល Random Regression Models។
  2. រៀបចំប្រព័ន្ធប្រមូលទិន្នន័យសាកល្បង: ចាប់ផ្តើមប្រមូលទិន្នន័យទិន្នផលទឹកដោះប្រចាំខែពីកសិដ្ឋានគោទឹកដោះក្នុងស្រុក (ឧទាហរណ៍កត់ត្រាថ្ងៃផ្តល់ទឹកដោះ បរិមាណទឹកដោះ និងពូជគោរៀងរាល់ ៣០ថ្ងៃម្តង) ដោយប្រើប្រាស់ Microsoft Excel ឬ KoboToolbox។
  3. អនុវត្តកម្មវិធីវិភាគទិន្នន័យ (Software Tools): រៀនប្រើប្រាស់កញ្ចប់កម្មវិធីស្ថិតិដូចជា ASREML ឬកញ្ចប់ឥតគិតថ្លៃនៅក្នុង R (ឧ. sommer, MCMCglmm ឬ pedigreemm) ដើម្បីរៀបចំគណនាសមាសធាតុវ៉ារ្យង់ (Variance components)។
  4. អភិវឌ្ឍ និងសាកល្បងម៉ូដែលលើទិន្នន័យកម្ពុជា: សាកល្បងបញ្ចូលទិន្នន័យទៅក្នុងអនុគមន៍ Modified Incomplete Gamma (MIG) ឬ Wilmink function ដើម្បីត្រាប់តាមខ្សែកោងនៃការបំបៅដោះ និងស្វែងរកកម្រិតបន្តពូជ (Heritability) នៃហ្វូងគោនៅកម្ពុជា។
  5. បកស្រាយលទ្ធផល និងផ្តល់អនុសាសន៍: ប្រើប្រាស់តម្លៃ Estimated Breeding Values (EBV) ដែលគណនាបាន ដើម្បីណែនាំកសិករថាតើមេគោណាគួរទុកពូជ ឬមេគោណាគួរជម្រុះចេញ ក្នុងគោលដៅបង្កើនទិន្នផលសរុប។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Random Regression Model (ម៉ូដែលតំរែតំរង់ចៃដន្យ) ជាម៉ូដែលស្ថិតិមួយប្រភេទដែលត្រូវបានប្រើដើម្បីទស្សន៍ទាយគុណតម្លៃនៃការពូជពង្ស (Breeding values) សម្រាប់លក្ខណៈដែលប្រែប្រួលតាមពេលវេលា (ដូចជាទិន្នផលទឹកដោះក្នុងអំឡុងពេលបំបៅដោះ) ដោយអនុញ្ញាតឱ្យសត្វនីមួយៗមានខ្សែកោងផ្ទាល់ខ្លួនរបស់វា។ ដូចជាការគូរខ្សែបន្ទាត់លូតលាស់ដោយឡែកៗសម្រាប់សិស្សម្នាក់ៗពេញមួយឆ្នាំសិក្សា ជាជាងយកពិន្ទុមធ្យមរបស់សិស្សទាំងអស់មកបូកបញ្ចូលគ្នា។
Heritability (កម្រិតនៃការបន្តពូជ) ជាភាគរយនៃបម្រែបម្រួលលក្ខណៈរូបរាងឬទិន្នផលនៅក្នុងហ្វូងសត្វ ដែលបណ្តាលមកពីកត្តាហ្សែន។ កម្រិតបន្តពូជខ្ពស់មានន័យថាលក្ខណៈនោះអាចត្រូវបានកែលម្អយ៉ាងមានប្រសិទ្ធភាពតាមរយៈការជ្រើសរើសពូជ។ ដូចជាការវាស់ស្ទង់ថាតើកម្ពស់របស់កូនពឹងផ្អែកលើកម្ពស់របស់ឪពុកម្តាយកម្រិតណា បើធៀបនឹងកត្តាខាងក្រៅដូចជារបបអាហារ។
Repeatability (អត្រានៃការធ្វើឡើងវិញ) ជាកម្រិតនៃទំនាក់ទំនងរវាងការវាស់វែងច្រើនដងនៃលក្ខណៈដដែលនៅលើសត្វតែមួយតាមពេលវេលាខុសៗគ្នា ដើម្បីវាយតម្លៃថាតើសមត្ថភាពកន្លងមករបស់សត្វនោះអាចទស្សន៍ទាយសមត្ថភាពទៅថ្ងៃអនាគតបានកម្រិតណា។ ដូចជាការវាយតម្លៃថាតើសិស្សដែលប្រឡងបានពិន្ទុល្អនៅខែនេះ នឹងនៅតែទទួលបានពិន្ទុល្អនៅខែក្រោយៗទៀតកម្រិតណា។
Modified Incomplete Gamma Function (អនុគមន៍ហ្គាម៉ាមិនពេញលេញដែលត្រូវបានកែប្រែ) ជារូបមន្តគណិតវិទ្យាជាក់លាក់មួយដែលត្រូវបានប្រើដើម្បីគូសបង្ហាញពីទម្រង់នៃខ្សែកោងផលិតកម្មទឹកដោះរបស់សត្វគោតាមពេលវេលា (ចាប់ផ្តើមពីឡើងខ្ពស់ដល់ចំណុចកំពូល រួចធ្លាក់ចុះបន្តិចម្តងៗ)។ ដូចជាពុម្ពគណិតវិទ្យាមួយដែលត្រូវបានប្រើដើម្បីគូសបង្ហាញពីដំណើរនៃកម្លាំងរបស់កីឡាកររត់ប្រណាំង ដែលចាប់ផ្តើមបញ្ចេញកម្លាំងខ្លាំងនៅដើមទី និងថយចុះបន្តិចម្តងៗនៅចុងទី។
Additive Genetic Variance (វ៉ារ្យង់ពន្ធុវិទ្យាបូកបញ្ចូល) ជាផ្នែកមួយនៃបម្រែបម្រួលហ្សែនដែលត្រូវបានបញ្ជូនដោយផ្ទាល់ពីឪពុកម្តាយទៅកូន ដោយមិនពឹងផ្អែកលើអន្តរកម្មហ្សែនស្មុគស្មាញផ្សេងទៀត ដែលនេះជាធាតុផ្សំស្នូលសម្រាប់ទស្សន៍ទាយគុណតម្លៃនៃមេជីវិត។ ដូចជាការបូកបញ្ចូលគ្នានូវលក្ខណៈសម្បត្តិល្អៗពីឪពុកនិងម្តាយ ដែលយើងអាចទាយទុកមុនថានឹងត្រូវបន្តទៅកូនយ៉ាងពិតប្រាកដ។
Permanent Environmental Effect (ឥទ្ធិពលបរិស្ថានអចិន្ត្រៃយ៍) ជាកត្តាមិនមែនហ្សែនដែលជះឥទ្ធិពលជាអចិន្ត្រៃយ៍ដល់សមត្ថភាពរបស់សត្វពេញមួយជីវិត (ឧទាហរណ៍ ជំងឺធ្ងន់ធ្ងរតាំងពីតូចដែលធ្វើឱ្យការលូតលាស់ដោះគោមិនបានពេញលេញ)។ ដូចជាស្លាកស្នាម ឬរបួសអចិន្ត្រៃយ៍ដែលប៉ះពាល់ដល់សមត្ថភាពរត់របស់អត្តពលិកអស់មួយជីវិត ទោះបីជាគាត់មានហ្សែនរត់លឿនពីកំណើតក៏ដោយ។
