Arm's length market model
គំរូទីផ្សារប្រកួតប្រជែងសេរី (មិនមានទំនាក់ទំនងជិតស្និទ្ធរវាងអ្នកទិញនិងអ្នកលក់)		 ងាយស្រួលសម្រាប់កសិករខ្នាតតូចក្នុងការចូលរួម ដោយមិនចាំបាច់មានកិច្ចសន្យា ឬលក្ខខណ្ឌស្មុគស្មាញច្រើន។ អ្នកលក់អាចលក់ផលិតផលទៅឱ្យនរណាក៏បាន។ កសិករប្រឈមហានិភ័យទីផ្សារខ្ពស់ មិនមានទីផ្សារច្បាស់លាស់ និងខ្វះអំណាចក្នុងការតថ្លៃ ដែលធ្វើឱ្យពួកគេត្រូវលក់ក្នុងតម្លៃថោក។ បណ្តាលឱ្យខ្សែចង្វាក់តម្លៃគ្មានប្រសិទ្ធភាព កសិករនៅស៊ីមបាវ៉េភាគច្រើនបាត់បង់អត្ថប្រយោជន៍ និងទិន្នផលធ្លាក់ចុះ។
Captive networks / Out-grower contractual arrangements
បណ្តាញខ្សែចង្វាក់តម្លៃបែបចាប់យក ឬកិច្ចសន្យាដាំដុះ (កសិកម្មតាមកិច្ចសន្យា)		 ផ្តល់ការធានាទីផ្សារនិងតម្លៃច្បាស់លាស់ ជំរុញការចែករំលែកចំណេះដឹង បច្ចេកទេស និងធនធានពីអ្នកទិញទៅកសិករ។ កសិករអាចពឹងផ្អែកខ្លាំងលើក្រុមហ៊ុនតែមួយ ដែលទាមទារឱ្យមានការគ្រប់គ្រងកិច្ចសន្យាដោយតម្លាភាពដើម្បីចៀសវាងការកេងប្រវ័ញ្ច។ ត្រូវបានអ្នកស្រាវជ្រាវស្នើឡើងជាជម្រើសដ៏ល្អបំផុតដើម្បីបង្កើនប្រសិទ្ធភាពបច្ចេកទេស និងដោះស្រាយបញ្ហាទីផ្សារសម្រាប់កសិករខ្នាតតូច។
Hierarchical value chain model (Vertical Integration)
គំរូខ្សែចង្វាក់តម្លៃតាមឋានានុក្រម (សមាហរណកម្មខ្សែឈរ)		 ក្រុមហ៊ុនធំតែមួយគ្រប់គ្រងប្រតិបត្តិការទាំងស្រុងតាំងពីការដាំដុះដល់ការកែច្នៃ ដែលជួយធានាបាននូវគុណភាពកម្រិតខ្ពស់ និងបរិមាណផ្គត់ផ្គង់មានស្ថិរភាព។ កាត់បន្ថយឱកាស និងបំបាត់ការចូលរួមរបស់កសិករខ្នាតតូចឯករាជ្យនៅក្នុងប្រព័ន្ធទីផ្សារ។ មានប្រសិទ្ធភាពខ្ពស់ក្នុងការគ្រប់គ្រងគុណភាព ប៉ុន្តែស័ក្តិសមតែនៅពេលដែលពិបាកស្វែងរកគ្រួសារកសិករដែលមានសមត្ថភាពផលិតតាមស្តង់ដារ។

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងនៅក្នុងប្រទេសស៊ីមបាវ៉េ (ជាពិសេសខេត្ត Manicaland) ដោយផ្តោតលើកសិករខ្នាតតូចចំនួន ៥៣០ គ្រួសារ និងឆ្លុះបញ្ចាំងពីបរិបទសេដ្ឋកិច្ច-សង្គមនៅទ្វីបអាហ្វ្រិក។ ទោះបីជាបរិបទភូមិសាស្ត្រខុសគ្នា ប៉ុន្តែលក្ខណៈនៃបញ្ហាគឺស្រដៀងគ្នាខ្លាំងទៅនឹងប្រទេសកម្ពុជា ដែលកសិករខ្នាតតូចភាគច្រើននៅតែលក់វត្ថុធាតុដើមឆៅ (មិនទាន់កែច្នៃ) ក្នុងទីផ្សារអសកម្ម និងខ្វះបច្ចេកវិទ្យា។

វិធីសាស្ត្រវិភាគខ្សែចង្វាក់តម្លៃ និងគំរូកិច្ចសន្យាដាំដុះ (Out-grower models) នៅក្នុងឯកសារនេះ គឺអាចយកមកអនុវត្តដោយផ្ទាល់សម្រាប់ដោះស្រាយបញ្ហាទីផ្សារកសិកម្មនៅកម្ពុជា។

  • វិស័យគ្រាប់ស្វាយចន្ទីនៅខេត្តកំពង់ធំ និងក្រចេះ (Cashew Nut Sector): អាចអនុវត្តគំរូកិច្ចសន្យាដាំដុះ (Out-grower contracts) ដើម្បីដោះស្រាយបញ្ហាកសិករដែលលក់គ្រាប់ស្វាយចន្ទីឆៅក្នុងតម្លៃថោកឱ្យឈ្មួញកណ្តាល ដោយភ្ជាប់ពួកគេផ្ទាល់ទៅនឹងរោងចក្រកែច្នៃក្នុងស្រុក។
  • ដំណាំម៉ាកាដាមៀនៅខេត្តមណ្ឌលគិរី (Macadamia cultivation in Mondulkiri): ដោយសារម៉ាកាដាមៀជាដំណាំថ្មីមានសក្តានុពលនៅតំបន់ខ្ពង់រាបកម្ពុជា ការប្រើប្រាស់មេរៀនពីស៊ីមបាវ៉េជួយឱ្យស្ថាប័នពាក់ព័ន្ធអាចរៀបចំរចនាសម្ព័ន្ធខ្សែចង្វាក់តម្លៃ (Captive networks) តាំងពីដំណាក់កាលចាប់ផ្តើម កុំឱ្យជួបបញ្ហាអសមត្ថភាពទីផ្សារនាពេលអនាគត។
  • ដំណាំម្រេចនៅខេត្តកំពត និងត្បូងឃ្មុំ (Pepper Sector): ការបង្កើតបណ្តាញខ្សែចង្វាក់តម្លៃច្បាស់លាស់ ដោយមានការចែករំលែកព័ត៌មាន (Information-intensive linkages) នឹងជួយកសិកររៀបចំស្តង់ដារគុណភាពដើម្បីនាំចេញដោយផ្ទាល់ និងទទួលបានតម្លៃបន្ថែមខ្ពស់។

ការរៀបចំរចនាសម្ព័ន្ធខ្សែចង្វាក់តម្លៃឡើងវិញដោយឈរលើការចូលរួមពីគ្រប់ភាគី នឹងជួយកសិករកម្ពុជាផ្លាស់ប្តូរពីការលក់វត្ថុធាតុដើមតម្លៃទាប ទៅជាអ្នកផ្គត់ផ្គង់ផលិតផលប្រកបដោយប្រសិទ្ធភាពនិងមានតម្លៃបន្ថែមខ្ពស់លើទីផ្សារអន្តរជាតិ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះពីខ្សែចង្វាក់តម្លៃកសិកម្ម: និស្សិតត្រូវស្វែងយល់ពីទ្រឹស្តី Value Chain Analysis, Transaction Cost Economics និងគំរូកិច្ចសន្យា ដោយអានឯកសារណែនាំជាក់ស្តែងដូចជា FAO Sustainable Food Value Chains Guiding Principles និងសៀវភៅរបស់ UNIDO។
  2. គូសវាសផែនទីតួអង្គពាក់ព័ន្ធ (Stakeholder Mapping): ជ្រើសរើសដំណាំគោលដៅមួយ (ឧ. ស្វាយចន្ទី) រួចចុះប្រមូលទិន្នន័យដើម្បីកំណត់អត្តសញ្ញាណតួអង្គទាំងអស់តាំងពីកសិករ ឈ្មួញកណ្តាល ដល់អ្នកកែច្នៃ ដោយប្រើប្រាស់ឧបករណ៍គូសវាសដូចជា Kumu.io ឬ Lucidchart ដើម្បីមើលពីលំហូរនៃផលិតផលនិងប្រាក់ចំណេញ។
  3. វិភាគប្រសិទ្ធភាព និងប្រាក់ចំណេញ (Margin Analysis): ប្រើប្រាស់កម្មវិធី Microsoft Excel ឬ Stata ដើម្បីគណនាថ្លៃដើមផលិតកម្ម ប្រាក់ចំណេញ និងប្រសិទ្ធភាពបច្ចេកទេសរបស់តួអង្គនីមួយៗ ដើម្បីស្វែងរកចន្លោះប្រហោង (Bottlenecks) នៅក្នុងខ្សែចង្វាក់តម្លៃ។
  4. រៀបចំសំណើគំរូកិច្ចសន្យាដាំដុះ (Design Out-grower Model): ផ្អែកលើទិន្នន័យដែលបានវិភាគ ត្រូវសរសេររបាយការណ៍ស្នើឡើងនូវរចនាសម្ព័ន្ធកិច្ចសន្យាថ្មី (Captive Networks) ដែលផ្តល់ផលចំណេញទាំងសងខាង (Win-Win) រួចយកទៅពិភាក្សាសាកល្បងជាមួយសហគមន៍កសិកម្ម និងសមាគមនានា (ឧ. សមាគមសហព័ន្ធកសិករកម្ពុជា) ដើម្បីស្វែងរកការគាំទ្រ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Value Chain Analysis (ការវិភាគខ្សែចង្វាក់តម្លៃ) ជាវិធីសាស្ត្រនៃការតាមដាននិងវាយតម្លៃរាល់ជំហានដែលពាក់ព័ន្ធតាំងពីការផ្គត់ផ្គង់វត្ថុធាតុដើម ការដាំដុះ ការកែច្នៃ រហូតដល់ការនាំយកផលិតផលសម្រេចទៅដល់ដៃអតិថិជនចុងក្រោយ ដើម្បីស្វែងរកចំណុចខ្សោយនិងឱកាសក្នុងការបង្កើនប្រាក់ចំណេញ។ ដូចជាការតាមដានរាល់ដំណាក់កាលនៃការធ្វើនំខេក តាំងពីការទិញម្សៅរហូតដល់នំត្រូវលក់ចេញ ដើម្បីដឹងថាដំណាក់កាលណាដែលខ្ជះខ្ជាយលុយ ឬអាចធ្វើឱ្យនំមានរសជាតិឆ្ងាញ់ជាងមុនអាចលក់បានថ្លៃជាងមុន។
Technical Efficiency (ប្រសិទ្ធភាពបច្ចេកទេស) សមត្ថភាពរបស់កសិករឬអ្នកផលិត ក្នុងការបង្កើតទិន្នផលឱ្យបានច្រើនបំផុតដែលអាចធ្វើទៅបាន ដោយប្រើប្រាស់បរិមាណធនធាន (ដី ពូជ ជី កម្លាំងពលកម្ម) ដែលមានកំណត់ ឬការសម្រេចបានទិន្នផលគោលដៅដោយប្រើប្រាស់ធនធានតិចតួចបំផុត។ ដូចជាសមត្ថភាពក្នុងការបើកបរម៉ូតូឱ្យបានចម្ងាយឆ្ងាយបំផុត ដោយប្រើប្រាស់សាំងត្រឹមតែមួយលីត្រប៉ុណ្ណោះ។
Arm's length market model (គំរូទីផ្សារប្រកួតប្រជែងសេរី ឬទីផ្សារធម្មតា) ជាទម្រង់ទីផ្សារដែលអ្នកទិញនិងអ្នកលក់ធ្វើការដោះដូរទំនិញគ្នាដោយផ្ទាល់ តាមរយៈការថ្លឹងថ្លែងតម្លៃជាក់ស្តែងនាពេលនោះ ដោយមិនមានកិច្ចសន្យាចងក្រងយូរអង្វែង ឬទំនាក់ទំនងស្អិតរមួតរវាងគ្នានិងគ្នានោះទេ។ ដូចជាការដើរទិញបន្លែនៅផ្សារ ដែលអ្នកអាចទិញពីអ្នកលក់ណាក៏បានដោយគ្រាន់តែតថ្លៃត្រូវរ៉ូវគ្នា មិនចាំបាច់ស្គាល់គ្នា ឬមានការចុះកិច្ចសន្យាទុកមុនឡើយ។
Captive networks / Out-grower contractual arrangements (បណ្តាញខ្សែចង្វាក់តម្លៃបែបចាប់យក ឬកិច្ចសន្យាដាំដុះ) ជាប្រព័ន្ធទីផ្សារដែលក្រុមហ៊ុនធំៗធ្វើកិច្ចសន្យាជាមួយកសិករខ្នាតតូច ដោយក្រុមហ៊ុនជាអ្នកផ្តល់នូវបច្ចេកទេស ពូជ ឬឥណទាន ជាថ្នូរនឹងការធានាទិញយកផលិតផលនោះត្រលប់មកវិញក្នុងលក្ខខណ្ឌនិងស្តង់ដារដែលបានព្រមព្រៀងគ្នា។ ដូចជាម្ចាស់ភោជនីយដ្ឋានជួលកសិករម្នាក់ឱ្យដាំបន្លែសរីរាង្គសម្រាប់ហាងរបស់ខ្លួន ដោយផ្តល់គ្រាប់ពូជនិងបច្ចេកទេស រួចសន្យាធានាទិញយកបន្លែទាំងអស់នោះមកវិញឱ្យតែបានល្អតាមស្តង់ដារ។
Transaction Costs (ថ្លៃដើមប្រតិបត្តិការ / ថ្លៃដើមនៃការជួញដូរ) ជាការចំណាយបន្ថែមក្រៅពីថ្លៃដើមផលិតផលផ្ទាល់ ដែលកើតឡើងក្នុងដំណើរការទីផ្សារ ដូចជាការចំណាយពេលវេលាស្វែងរកអ្នកទិញ ការធ្វើដំណើរ ថ្លៃរៀបចំកិច្ចសន្យា ថ្លៃទាក់ទងព័ត៌មាន ឬការចំណាយលើការដោះស្រាយវិវាទផ្សេងៗក្នុងការលក់ដូរ។ ដូចជាថ្លៃសេវាផ្ទេរប្រាក់តាមភ្នាក់ងារ ឬថ្លៃសាំងធ្វើដំណើរទៅទិញទំនិញ ដែលធ្វើឱ្យការចំណាយសរុបរបស់អ្នកកើនឡើងលើសពីតម្លៃរបស់ទំនិញផ្ទាល់។
Hierarchical value chain model (គំរូខ្សែចង្វាក់តម្លៃតាមឋានានុក្រម / សមាហរណកម្មបញ្ឈរ) ប្រព័ន្ធគ្រប់គ្រងដែលក្រុមហ៊ុនធំតែមួយធ្វើសមាហរណកម្ម និងក្ដោបក្ដាប់ប្រតិបត្តិការទាំងអស់ដោយខ្លួនឯង តាំងពីការដាំដុះវត្ថុធាតុដើម ការកែច្នៃ រហូតដល់ការវេចខ្ចប់និងចែកចាយ ដោយមិនពឹងផ្អែកលើកសិករខ្នាតតូច ឬក្រុមហ៊ុនផ្សេងឡើយ។ ដូចជាហាងកាហ្វេមួយដែលមានដីចម្ការដាំកាហ្វេខ្លួនឯង មានរោងចក្រលីងកាហ្វេខ្លួនឯង និងលក់កាហ្វេនៅក្នុងហាងរបស់ខ្លួនឯងផ្ទាល់តែម្ដង។
Relational-specific assets / RSA (ទ្រព្យសកម្មជាក់លាក់តាមទំនាក់ទំនង) ការវិនិយោគលើម៉ាស៊ីន បច្ចេកវិទ្យា ឬចំណេះដឹង ដែលបង្កើតឡើងតែសម្រាប់បំពេញតម្រូវការជាក់លាក់នៃដៃគូពាណិជ្ជកម្មណាមួយ ហើយវាសឹងតែគ្មានតម្លៃទាល់តែសោះ ឬខាតបង់តម្លៃយ៉ាងច្រើន ប្រសិនបើយកទៅប្រើប្រាស់ជាមួយអ្នកទិញផ្សេង។ ដូចជាជាងកាត់ដេរម្នាក់ដែលកាត់សម្លៀកបំពាក់តម្រូវតាមរាងកាយនិងចំណូលចិត្តរបស់អតិថិជនជាក់លាក់ណាមួយ ដែលសម្លៀកបំពាក់នោះមិនអាចយកទៅលក់ឱ្យអ្នកផ្សេងស្លៀកបានសមល្អដូចម្ចាស់ដើមនោះទេ។
Knowledge-sharing routines / KSR (ទម្លាប់នៃការចែករំលែកចំណេះដឹង) យន្តការឬប្រព័ន្ធដែលមានការរៀបចំជាប្រចាំនៅក្នុងខ្សែចង្វាក់តម្លៃ ដើម្បីផ្ទេរព័ត៌មាន បច្ចេកទេសថ្មីៗ និងស្តង់ដារគុណភាពពីអ្នកទិញឬក្រុមហ៊ុនកែច្នៃ ទៅកាន់កសិករឬអ្នកផលិតវត្ថុធាតុដើម។ ដូចជាការជួបជុំគ្នារៀងរាល់ខែរបស់ក្រុមចុងភៅដើម្បីចែករំលែករូបមន្តម្ហូបថ្មីៗដល់គ្នាទៅវិញទៅមក ធានាថាអាហារគ្រប់ចានមានរសជាតិឆ្ងាញ់ដូចៗគ្នា។
