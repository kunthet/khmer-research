លទ្ធផលនៃការសិក្សានេះមានប្រយោជន៍យ៉ាងខ្លាំងសម្រាប់វិស័យកសិកម្ម និងភស្តុភារកម្ម (Logistics) នៅក្នុងប្រទេសកម្ពុជា ដើម្បីពង្រឹងគុណភាពកសិផល។

  • ខេត្តពោធិ៍សាត់ និងបាត់ដំបង (តំបន់ដាំក្រូច): កសិករ និងសហគមន៍កសិកម្មអាចអនុវត្តបច្ចេកទេសវេចខ្ចប់ផ្លែក្រូចពោធិ៍សាត់ឱ្យហាប់ណែនល្អ ដើម្បីកាត់បន្ថយការស្រុតចុះ និងការខូចខាតពេលដឹកជញ្ជូនមកកាន់រាជធានីភ្នំពេញ។
  • ក្រុមហ៊ុនដឹកជញ្ជូនកសិផល (ឧ. វីរៈប៊ុនថាំ): ក្រុមហ៊ុនដឹកជញ្ជូនទំនិញ និងភស្តុភារកម្មអាចរៀបចំយុទ្ធសាស្ត្រតម្រៀបកន្ត្រក ដោយចៀសវាងដាក់កសិផលដែលទុំងាយខូចនៅផ្នែកខាងក្រោយនៃរថយន្ត ឬនៅស្រទាប់ក្រោមគេបង្អស់។
  • ទីផ្សារបោះដុំ (ឧ. ផ្សារនាគមាស ផ្សារដើមគ): អាជីវករបោះដុំអាចត្រួតពិនិត្យការវេចខ្ចប់ឡើងវិញ (Packing density) ដើម្បីធានាថាវាហាប់ណែនល្អ មុនពេលចែកចាយបន្តទៅកាន់ខេត្តផ្សេងៗ។

ការអនុវត្តតាមការរកឃើញនេះ នឹងជួយកាត់បន្ថយការខាតបង់ផ្នែកសេដ្ឋកិច្ចរបស់កសិករ និងអាជីវករកម្ពុជា ព្រមទាំងរក្សាបាននូវសោភ័ណភាពនិងគុណភាពកសិផលឱ្យនៅស្រស់ល្អពេលទៅដល់ដៃអតិថិជន។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. វាយតម្លៃកម្រិតនៃការវេចខ្ចប់បច្ចុប្បន្ន: និស្សិតត្រូវចុះទៅទីផ្សារបោះដុំ ដើម្បីវាស់ស្ទង់ការវេចខ្ចប់ដោយប្រើឧបករណ៍ Tape Measure និងគណនា Packing Density របស់កសិផលក្នុងស្រុក ធៀបនឹងទំហំកន្ត្រក។
  2. កំណត់អត្តសញ្ញាណកម្រិតរំញ័ររថយន្ត: ប្រើប្រាស់ឧបករណ៍ Vibration Data Logger ឬកម្មវិធីស្មាតហ្វូនដូចជា Physics Toolbox Sensor Suite ដើម្បីវាស់ស្ទង់កម្រិតរំញ័រនៅផ្នែកផ្សេងៗនៃរថយន្តដឹកជញ្ជូន (មុខ កណ្តាល ក្រោយ) ពេលបើកបរលើផ្លូវកម្ពុជា។
  3. សាកល្បងបច្ចេកទេសតម្រៀបកន្ត្រកថ្មី: រៀបចំការតម្រៀបកន្ត្រកជាការសាកល្បង ដោយដាក់កសិផលងាយរងការខូចខាតនៅស្រទាប់ខាងលើ និងផ្នែកកណ្តាលរថយន្ត រួចប្រើប្រាស់កម្មវិធី Microsoft Excel ឬ SPSS ដើម្បីវិភាគប្រៀបធៀបទិន្នន័យនៃការស្រុតចុះ។
  4. ចងក្រងស្តង់ដារនៃការវេចខ្ចប់ (SOP): បង្កើតឯកសារណែនាំប្រតិបត្តិការស្តង់ដារ (Standard Operating Procedure - SOP) សម្រាប់កសិករ និងក្រុមហ៊ុនដឹកជញ្ជូន ដើម្បីណែនាំពីចំនួនផ្លែឈើដែលត្រូវដាក់ក្នុងកន្ត្រកនីមួយៗឱ្យបានហាប់ណែនល្អបំផុត។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Sagging (ការស្រុតចុះ) ដំណើរការដែលកម្ពស់សរុបនៃផ្លែឈើនៅក្នុងកន្ត្រកមានការថយចុះ ឬស្រកចុះក្រោមធៀបនឹងកម្ពស់ដើម ដោយសារតែការរង្គើ និងទម្ងន់សង្កត់រវាងផ្លែឈើអំឡុងពេលដឹកជញ្ជូន។ ដូចជាពេលយើងចាក់អង្ករចូលកំប៉ុងឱ្យពេញ ហើយរលាក់វា អង្ករនឹងហាប់ចូលគ្នាធ្វើឱ្យស្រកកម្ពស់ចុះពីមាត់កំប៉ុង។
Packing Density (កម្រិតហាប់ណែននៃការវេចខ្ចប់) រង្វាស់ដែលបង្ហាញពីចំនួននៃទំហំទំនេរដែលត្រូវបានបំពេញដោយផ្លែឈើនៅក្នុងកន្ត្រក ដោយគណនាធៀបទំហំមាឌផ្លែឈើសរុបទៅនឹងទំហំមាឌរបស់កន្ត្រកផ្ទុក។ បើកម្រិតនេះទាប មានន័យថាមានចន្លោះប្រហោងច្រើន។ ដូចជាការវាស់ថាតើយើងអាចញាត់ខោអាវចូលវ៉ាលីសបានចង្អៀត និងណែនប៉ុណ្ណា កាលណាខោអាវមានរាងត្រូវគ្នា វាជួយកាត់បន្ថយចន្លោះប្រហោង។
Spheroid (រាងស្វ៊ែរពងក្រពើ) រូបរាងធរណីមាត្រដែលស្រដៀងនឹងស៊្វែរ (បាល់ទូលាយ) ប៉ុន្តែមានលក្ខណៈសំប៉ែតបន្តិចនៅប៉ូលសងខាង។ នៅក្នុងការស្រាវជ្រាវនេះ គេសន្មតរូបរាងនេះដើម្បីប្រើរូបមន្តគណនាមាឌពិតប្រាកដរបស់ផ្លែក្រូចឃ្វិច។ ដូចជារាងរបស់ផែនដី ឬផ្លែល្ពៅដែលសំប៉ែតលើក្រោមបន្តិច មិនមែនមូលក្រឡង់ឥតខ្ចោះដូចបាល់ប៊ីយ៉ានោះទេ។
Random sampling (ការយកសំណាកដោយចៃដន្យ) វិធីសាស្ត្រនៃការជ្រើសរើសវត្ថុ ឬទិន្នន័យ (ដូចជាកន្ត្រកក្រូច) ពីក្រុមធំមួយដោយមិនមានការរៀបចំទុកមុន ដើម្បីធានាថាសំណាកដែលយកមកសិក្សានោះ តំណាងឱ្យស្ថានភាពជាក់ស្តែង និងមិនលម្អៀង។ ដូចជាការចាប់ឆ្នោតយកឈ្មោះសិស្សម្នាក់ក្នុងថ្នាក់ដោយបិទភ្នែក ដែលសិស្សគ្រប់គ្នាមានឱកាសត្រូវបានជ្រើសរើសស្មើៗគ្នា។
Wholesale Packages (ការវេចខ្ចប់បោះដុំ) ប្រព័ន្ធនៃការរៀបចំនិងវេចខ្ចប់ទំនិញក្នុងបរិមាណច្រើនៗនៅក្នុងកន្ត្រកធំៗ ដើម្បីងាយស្រួលក្នុងការផ្ទុក និងដឹកជញ្ជូនពីកសិដ្ឋាន ឬឃ្លាំងស្តុកទៅកាន់ទីផ្សារចែកចាយបន្តក្នុងតម្លៃបោះដុំ។ ដូចជាការទិញទឹកបរិសុទ្ធជាកេសធំៗពីក្រុមហ៊ុន ដើម្បីយកមកលក់រាយបន្តតាមដបនៅផ្ទះ។
Vibration (រំញ័រ / ការញ័ររញ្ជួយ) ចលនាញ័ររញ្ជួយ និងការឃ្លេងឃ្លោងដែលកើតឡើងពីរថយន្តដឹកជញ្ជូននៅពេលធ្វើដំណើរលើដងផ្លូវ ដែលជាកត្តាចម្បងធ្វើឱ្យកសិផលរង្គើ ទង្គិចគ្នា និងបណ្តាលឱ្យមានការស្រុតចុះ។ ដូចជាអារម្មណ៍ដែលយើងអង្គុយលើឡានក្រុងពេលជិះកាត់ផ្លូវរលាក់ ធ្វើឱ្យខ្លួនយើងលោតចុះលោតឡើងមិននឹងនរ។
