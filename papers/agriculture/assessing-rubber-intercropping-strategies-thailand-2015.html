លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

ម៉ូដែល WaNuLCAS និងវិធីសាស្ត្រវាយតម្លៃនេះ មានសារៈសំខាន់ និងអាចយកមកអនុវត្តបានយ៉ាងល្អសម្រាប់វិស័យកសិកម្មនៅកម្ពុជា ជាពិសេសសម្រាប់ការស្រាវជ្រាវកសិរុក្ខកម្ម។

  • ខេត្តត្បូងឃ្មុំ កំពង់ចាម និងរតនគិរី (តំបន់ចំការកៅស៊ូ): តំបន់ទាំងនេះជាតំបន់ដាំកៅស៊ូធំៗ ដែលអាចប្រើប្រាស់ម៉ូដែលនេះដើម្បីវាយតម្លៃយុទ្ធសាស្ត្រដាំដំណាំចន្លោះជួរ (Intercropping strategies) ដើម្បីបង្កើនប្រាក់ចំណូលដល់កសិករខ្នាតតូច ក្នុងអំឡុងពេល ៥-៦ ឆ្នាំមុនពេលកៅស៊ូអាចចាប់ផ្តើមចៀរជ័របាន។
  • ខេត្តបាត់ដំបង និងប៉ៃលិន (តំបន់ដាំពោត និងដំណាំឧស្សាហកម្ម): អាចអនុវត្តការដាំដុះរួមបញ្ចូលគ្នារវាងឈើហូបផ្លែ ឬឈើឧស្សាហកម្ម ជាមួយដំណាំពោត ដោយប្រើជីសរីរាង្គផ្សំជាមួយជីគីមី ផ្អែកតាមអនុសាសន៍នៃការសិក្សានេះ ដើម្បីកាត់បន្ថយការប្រកួតប្រជែងជីវជាតិ និងរក្សាគុណភាពដី។
  • សាកលវិទ្យាល័យភូមិន្ទកសិកម្ម (RUA) និងវិទ្យាស្ថានស្រាវជ្រាវកៅស៊ូកម្ពុជា (CRRI): ស្ថាប័នទាំងនេះអាចយកម៉ូដែល WaNuLCAS មកបង្រៀននិស្សិត ឬធ្វើការស្រាវជ្រាវក្លែងធ្វើ (Simulation) ដោយប្រើប្រាស់ទិន្នន័យដី និងអាកាសធាតុក្នុងស្រុក ដើម្បីបង្កើតសៀវភៅណែនាំអំពីគម្លាតដាំដុះកៅស៊ូដ៏ល្អបំផុតនៅកម្ពុជា។

សរុបមក ការប្រើប្រាស់ម៉ូដែលក្លែងធ្វើនេះផ្តល់នូវអត្ថប្រយោជន៍ជាមុនក្នុងការរៀបចំផែនការដាំដុះ និងគ្រប់គ្រងជី ដែលជួយសន្សំសំចៃពេលវេលា ថវិកា និងកាត់បន្ថយហានិភ័យសម្រាប់កសិករខ្នាតតូច។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីមូលដ្ឋានគ្រឹះនៃម៉ូដែលក្លែងធ្វើ: ទាញយក និងដំឡើងកម្មវិធីកុំព្យូទ័រ WaNuLCAS version 4.0 (អភិវឌ្ឍដោយ ICRAF) រួមជាមួយកម្មវិធី Microsoft Excel និងស្វែងយល់ពីរបៀបដំណើរការរចនាសម្ព័ន្ធដី ៤ ស្រទាប់ និងតំបន់លំហ ៤ របស់ម៉ូដែលនេះ។
  2. ប្រមូលទិន្នន័យក្នុងស្រុក (Local Data Collection): ចុះប្រមូលទិន្នន័យអាកាសធាតុ (ទឹកភ្លៀងប្រចាំថ្ងៃ) ទិន្នន័យដី (កម្រិត pH, កម្រិត N, P, K) និងទិន្នន័យពីប្រភេទពូជកៅស៊ូ (Hevea brasiliensis) ព្រមទាំងដំណាំបន្ទាប់បន្សំ (ឧ. ពោត Zea mays) ពីស្ថានីយឧតុនិយម ឬវិទ្យាស្ថានស្រាវជ្រាវកៅស៊ូកម្ពុជា (CRRI)។
  3. ធ្វើការប៉ារ៉ាម៉ែត្រកម្ម និងការផ្ទៀងផ្ទាត់ម៉ូដែល (Parameterization & Validation): បញ្ចូលទិន្នន័យដែលប្រមូលបានទៅក្នុង Tree library នៃម៉ូដែល រួចធ្វើការកែសម្រួលប៉ារ៉ាម៉ែត្រ (ដូចជាកាំដំបូលស្លឹក និងកម្ពស់ដើម) ឲ្យស្របនឹងលក្ខខណ្ឌជាក់ស្តែង ដើម្បីប្រៀបធៀបជាមួយទិន្នន័យវាស់វែងផ្ទាល់រហូតទទួលបានកម្រិត Goodness of Fit (GOF) ខ្ពស់ ឬ R² ធំជាង ០.៥។
  4. រៀបចំ និងក្លែងធ្វើសេណារីយ៉ូនៃការដាំដុះ (Scenario Simulation): បង្កើតសេណារីយ៉ូផ្សេងៗគ្នាដោយប្តូរគម្លាតដើមកៅស៊ូ (ឧ. 2.5x7m ទល់នឹង 3x8m) និងកម្រិតនៃការប្រើប្រាស់ជី (ការបូកបញ្ចូលជីសរីរាង្គនិងជីគីមី) នៅក្នុងកម្មវិធី Excel spreadsheet របស់ WaNuLCAS ដើម្បីព្យាករណ៍ពីទិន្នផលរយៈពេល ១០ឆ្នាំ។
  5. វិភាគលទ្ធផល និងបង្កើតអនុសាសន៍ជូនកសិករ: វិភាគទិន្នន័យលទ្ធផលនៃការប្រកួតប្រជែងយកទឹក ពន្លឺ និងជីវជាតិ រួចចងក្រងជាសៀវភៅណែនាំ ឬឯកសារផ្សព្វផ្សាយដើម្បីណែនាំកសិករខ្មែរអំពីអត្ថប្រយោជន៍នៃការដាំដំណាំចន្លោះជួររួមជាមួយការប្រើប្រាស់ជីសរីរាង្គ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
WaNuLCAS model (ម៉ូដែលចាប់យកទឹក ជីវជាតិ និងពន្លឺក្នុងប្រព័ន្ធកសិរុក្ខកម្ម) ម៉ូដែលកុំព្យូទ័រសម្រាប់ក្លែងធ្វើអន្តរកម្មរវាងដើមឈើ ដី និងដំណាំក្នុងប្រព័ន្ធកសិរុក្ខកម្ម ដោយវាស់ស្ទង់ការស្រូបយកទឹក ជីវជាតិ និងពន្លឺព្រះអាទិត្យ។ ដូចជាហ្គេមក្លែងធ្វើដាំដំណាំ (Farming Simulator) ដែលអាចប្រាប់យើងមុនថាបើយើងដាំកៅស៊ូជិតពោត តើវានឹងដណ្តើមជី និងទឹកគ្នាយ៉ាងដូចម្តេចនៅប៉ុន្មានឆ្នាំខាងមុខ។
Intercropping (ការដាំដំណាំចន្លោះជួរ) ការដាំដុះដំណាំពីរ ឬច្រើនប្រភេទក្នុងពេលតែមួយ និងនៅលើផ្ទៃដីតែមួយ ដើម្បីទាញយកអត្ថប្រយោជន៍ពីទំហំដីទំនេរ និងកាត់បន្ថយហានិភ័យសេដ្ឋកិច្ច។ ដូចជាការជួលបន្ទប់មួយអោយមនុស្សពីរនាក់នៅរួមគ្នា ដើម្បីសន្សំប្រាក់ឈ្នួល និងទាញយកអត្ថប្រយោជន៍ពីទំហំទំនេរឲ្យអស់លទ្ធភាព។
Monocropping / Monoculture (ការដាំដំណាំទោល) ប្រព័ន្ធកសិកម្មដែលដាំដំណាំតែមួយមុខគត់នៅលើផ្ទៃដីធំទូលាយ ដែលអាចប្រឈមនឹងបញ្ហាជំងឺ និងការថយចុះគុណភាពដីក្នុងរយៈពេលវែង។ ដូចជាការហូបម្ហូបតែមួយមុខរាល់ថ្ងៃរាប់ឆ្នាំ ដែលអាចធ្វើអោយយើងខ្វះជីវជាតិ និងងាយឈឺ។
Leaf Area Index - LAI (សន្ទស្សន៍ផ្ទៃស្លឹក) រង្វាស់នៃទំហំផ្ទៃស្លឹកសរុបរបស់រុក្ខជាតិធៀបនឹងផ្ទៃដីខាងក្រោម ដើម្បីវាយតម្លៃសមត្ថភាពនៃការចាប់យកពន្លឺព្រះអាទិត្យសម្រាប់ការធ្វើរស្មីសំយោគ។ ដូចជាការវាស់ទំហំដំបូលផ្ទះ ដើម្បីដឹងថាវាអាចបាំងកម្តៅថ្ងៃ ឬត្រងទឹកភ្លៀងបានប៉ុន្មានធៀបនឹងទំហំដីផ្ទះផ្ទាល់។
Tree girth (ទំហំរង្វង់គល់ឈើ) ទំហំរង្វង់ជុំវិញគល់ ឬដងខ្លួនរបស់ដើមឈើ ដែលជាសូចនាករសម្រាប់វាស់ស្ទង់ការលូតលាស់ និងបរិមាណឈើដែលអាចទទួលបាននៅពេលប្រមូលផល។ ដូចជាការវាស់ទំហំចង្កេះមនុស្ស ឬសត្វ ដើម្បីដឹងពីការលូតលាស់រាងកាយ។
Pedotransfer function (អនុគមន៍ប៉ាន់ស្មានលក្ខណៈដី) រូបមន្តគណិតវិទ្យាដែលប្រើប្រាស់ទិន្នន័យដីងាយស្រួលរក (ដូចជាវាយនភាពដី ខ្សាច់ ដីឥដ្ឋ) ដើម្បីប៉ាន់ស្មានលក្ខណៈស្មុគស្មាញរបស់ដី (ដូចជាចលនា និងការរក្សាទឹកក្នុងដី)។ ដូចជាការមើលរូបរាង និងម៉ាករបស់រថយន្ត ដើម្បីទស្សន៍ទាយពីល្បឿនអតិបរមារបស់វាដោយមិនបាច់សាកល្បងបើកបរផ្ទាល់ ដោយពឹងផ្អែកលើរូបមន្តដែលធ្លាប់មានស្រាប់។
