  • កសិករខ្នាតតូច និងមធ្យម: កសិករអាចយល់ដឹងពីសារៈសំខាន់នៃការគ្រប់គ្រងសត្វល្អិត ជាជាងការផ្ដោតតែទៅលើការទិញជីគីមីក្នុងបរិមាណច្រើន ដែលអាចនាំឱ្យខាតបង់បើដំណាំត្រូវបំផ្លាញដោយដង្កូវ។
  • វិទ្យាស្ថានស្រាវជ្រាវ និងអភិវឌ្ឍន៍កសិកម្មកម្ពុជា (CARDI): អាចយកគំរូស្រាវជ្រាវនេះទៅសាកល្បងជាមួយពូជអំពៅក្នុងស្រុក និងជំនួស Carbofuran ដោយថ្នាំជីវសាស្ត្រ ឬថ្នាំដែលមិនសូវប៉ះពាល់ដល់បរិស្ថាន។

ទោះបីជាការប្រើប្រាស់ថ្នាំ Carbofuran អាចនឹងហួសសម័យ ឬមានបញ្ហាបរិស្ថាន ប៉ុន្តែទ្រឹស្តីនៃការរួមបញ្ចូលការគ្រប់គ្រងសត្វល្អិតដើម្បីកាត់បន្ថយតម្រូវការជី គឺជាគំរូដ៏មានតម្លៃសម្រាប់ការអភិវឌ្ឍកសិកម្មប្រកបដោយចីរភាពនៅកម្ពុជា។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីវដ្តជីវិតរបស់សត្វល្អិត និងការខូចខាត (Pest Identification): និស្សិតត្រូវស្រាវជ្រាវពីដង្កូវស៊ីបណ្ដូលអំពៅដូចជា Chilo infuscatellus និងស្វែងយល់ពីរោគសញ្ញានៃការបំផ្លាញ ដោយអាចប្រើប្រាស់ FAO Pest Management Guidelines ជាឯកសារយោង។
  2. វាយតម្លៃកម្រិតជីជាតិដីមុនពេលដាំដុះ (Soil Nutrient Profiling): ត្រូវធ្វើការវិភាគដីនៅក្នុងតំបន់ដាំដុះអំពៅជាក់ស្តែង ដើម្បីដឹងពីកម្រិត N-P-K ដែលមានស្រាប់ ដោយប្រើឧបករណ៍ដូចជា Soil Nutrient Testing Kit។
  3. រចនាប្លង់ពិសោធន៍ជាមួយនឹងជម្រើសថ្នាំថ្មីៗ (Alternative Treatments): ដោយសារថ្នាំ Carbofuran មានការពុលខ្លាំង និស្សិតគួររចនាការពិសោធន៍ដោយប្រើថ្នាំជីវសាស្ត្រ ឬថ្នាំដែលមានសុវត្ថិភាពជាងមុន ដូចជា Chlorantraniliprole ឬ ការប្រើប្រាស់សត្រូវធម្មជាតិ Trichogramma wasps។
  4. អនុវត្តការរៀបចំប្លង់ពិសោធន៍ (Experimental Design Setup): ដំឡើងប្លង់ពិសោធន៍ប្រភេទ Randomized Complete Block Design (RCBD) ដើម្បីប្រៀបធៀបប្រសិទ្ធភាពនៃកម្រិតជី និងវិធីសាស្រ្តកម្ចាត់សត្វល្អិត។
  5. វិភាគទិន្នន័យសេដ្ឋកិច្ច និងប្រាក់ចំណេញ (Economic Data Analysis): ប្រើប្រាស់កម្មវិធី Microsoft Excel ឬ R Programming ដើម្បីគណនាទិន្នផល និងធ្វើការវិភាគប្រាក់ចំណេញបន្ថែម (Marginal Return Analysis) ដើម្បីផ្ដល់អនុសាសន៍ជាក់ស្តែងដល់កសិករ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Carbofuran (ថ្នាំសម្លាប់សត្វល្អិតកាបូហ្វូរ៉ាន់) ជាប្រភេទថ្នាំសម្លាប់សត្វល្អិតដែលមានជាតិពុលខ្ពស់ ប្រើសម្រាប់កម្ចាត់សត្វល្អិតចង្រៃដែលស៊ីបំផ្លាញដំណាំកសិកម្ម។ វាសម្លាប់សត្វល្អិតតាមរយៈការប៉ះពាល់ផ្ទាល់ និងតាមរយៈការជ្រាបចូលទៅក្នុងជាលិការបស់រុក្ខជាតិ ដែលធ្វើឱ្យសត្វល្អិតពុលនៅពេលស៊ីរុក្ខជាតិនោះ។ ដូចជាថ្នាំទម្លាក់សត្វល្អិតដែលយើងឱ្យសត្វចិញ្ចឹមស៊ី ដើម្បីសម្លាប់ចៃឬព្រូនដែលមកជញ្ជក់ឈាម ឬទាមទារចំណីពីសត្វនោះ។
Shoot Borers (ដង្កូវស៊ីបណ្ដូល) ជាប្រភេទដង្កូវដែលញាស់ចេញពីស៊ុតមេអំបៅ ហើយវាមានទម្លាប់ខួងចូលទៅក្នុងដើម ឬបណ្ដូលខ្ចីរបស់រុក្ខជាតិ (ដូចជាអំពៅ) ដើម្បីស៊ីជាអាហារ ដែលទង្វើនេះកាត់ផ្តាច់ចរន្តទឹកនិងអាហាររបស់រុក្ខជាតិ ធ្វើឱ្យដើមស្វិត ឬងាប់បាត់បង់ទិន្នផល។ ដូចជាសត្វកណ្តៀរដែលស៊ីទំពារសសរផ្ទះពីខាងក្នុង ធ្វើឱ្យមើលពីក្រៅហាក់ដូចជាធម្មតា តែតាមពិតខាងក្នុងប្រហោងនិងពុកផុយអស់។
Marginal Return (ប្រាក់ចំណេញបន្ថែមពីការវិនិយោគ) ជាការវិភាគសេដ្ឋកិច្ចដើម្បីវាយតម្លៃថាតើការបន្ថែមដើមទុនមួយកម្រិតទៀត (ឧទាហរណ៍ ការទិញជី ឬថ្នាំបន្ថែម) នឹងផ្តល់ត្រលប់មកវិញនូវប្រាក់ចំណេញកម្រិតណាបន្ទាប់ពីទូទាត់ការចំណាយបន្ថែមនោះរួចរាល់ ដើម្បីរកមើលចំណុចដែលចំណេញបំផុត។ ដូចជាការគិតថា បើយើងចំណាយលុយទិញសាំង១លីត្រថែមទៀត តើយើងអាចរត់ម៉ូតូឌុបបានលុយចំណេញលើសពីថ្លៃសាំងនោះប៉ុន្មានពិតប្រាកដ។
Randomized Complete Block Design (ការរៀបចំប្លង់ពិសោធន៍បែបចៃដន្យជាប្លុក) ជាវិធីសាស្រ្តស្ថិតិក្នុងការស្រាវជ្រាវកសិកម្ម ដែលគេបែងចែកដីជាប្លុកៗ (ចំណែកៗ) រួចអនុវត្តវិធីសាស្រ្តពិសោធន៍ផ្សេងៗគ្នាដោយចៃដន្យនៅក្នុងប្លុកនីមួយៗ គោលបំណងគឺដើម្បីកាត់បន្ថយភាពលម្អៀងដែលបណ្តាលមកពីកត្តាខាងក្រៅ ដូចជាភាពខុសគ្នានៃកម្រិតជីជាតិដី។ ដូចជាការបែងចែកសិស្សពូកែ និងខ្សោយឱ្យនៅលាយឡំគ្នាយ៉ាងស្មើភាពក្នុងក្រុមនីមួយៗ ដើម្បីឱ្យការប្រកួតប្រជែងទទួលបានលទ្ធផលយុត្តិធម៌បំផុត។
Fertilizer formular 15-15-15 (ជីរូបមន្ត ១៥-១៥-១៥) ជាប្រភេទជីគីមីចម្រុះដែលផ្តល់សារធាតុចិញ្ចឹមសំខាន់ៗដល់រុក្ខជាតិ ដោយមានសមាមាត្រស្មើគ្នានៃ អាសូត (N 15%), ផូស្វ័រ (P 15%) និងប៉ូតាស្យូម (K 15%) ដើម្បីជំរុញទាំងការលូតលាស់ដើម ឫស និងទិន្នផល។ ដូចជាការញ៉ាំអាហារបំប៉នដែលមានផ្ទុកវីតាមីន៣មុខក្នុងបរិមាណស្មើគ្នា ដើម្បីជួយឱ្យរាងកាយលូតលាស់រឹងមាំគ្រប់ផ្នែកក្នុងពេលតែមួយ។
Chilo infuscatellus (ដង្កូវស៊ីបណ្ដូលអំពៅប្រភេទ Chilo infuscatellus) ជាឈ្មោះវិទ្យាសាស្ត្ររបស់ប្រភេទដង្កូវមេអំបៅម្យ៉ាង ដែលជាសត្រូវចម្បងនិងគ្រោះថ្នាក់បំផុតរបស់ដំណាំអំពៅ វាបំផ្លាញអំពៅដោយខួងចូលស៊ីបណ្តូលតាំងពីកូនអំពៅនៅតូចៗ បណ្តាលឱ្យងាប់ពន្លកដើម។ ដូចជាចោរលួចចូលក្នុងផ្ទះតាមបង្អួច ហើយបំផ្លាញនិងប្រមូលយកទ្រព្យសម្បត្តិដ៏មានតម្លៃបំផុតនៅខាងក្នុងផ្ទះ។
