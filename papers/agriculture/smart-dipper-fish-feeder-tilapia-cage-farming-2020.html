  • ការចិញ្ចឹមត្រីតាមដងទន្លេសាប និងទន្លេមេគង្គ: កសិករនៅខេត្តកណ្តាល កំពង់ចាម និងព្រៃវែង ដែលចិញ្ចឹមត្រីប្រា ឬទីឡាព្យាក្នុងបែរ អាចប្រើឧបករណ៍នេះដើម្បីតាមដានការស៊ីចំណី និងកាត់បន្ថយការខ្ជះខ្ជាយ ដែលជាការចំណាយធំបំផុត (៧០%) ក្នុងការចិញ្ចឹម។
  • គម្រោងគាំទ្រដោយអង្គការក្រៅរដ្ឋាភិបាល (NGOs) និងក្រសួងកសិកម្ម: ស្ថាប័នពាក់ព័ន្ធអាចយកប្រព័ន្ធនេះធ្វើជាគំរូដើម្បីផ្តល់ជូនសហគមន៍នេសាទ និងបង្ហាត់បង្រៀនកសិករឱ្យចេះកត់ត្រាទិន្នន័យ និងគណនាប្រាក់ចំណេញតាមបែបឌីជីថល។

ការជ្រើសរើសប្រើប្រាស់ឧបករណ៍ដួសចំណីឆ្លាតវៃនេះ នឹងជួយផ្លាស់ប្តូរទម្លាប់ចិញ្ចឹមត្រីបែបប្រពៃណីរបស់កសិករខ្មែរ ទៅជាការចិញ្ចឹមតាមបែបវិទ្យាសាស្ត្រ ដែលមានទិន្នន័យច្បាស់លាស់ និងអាចគ្រប់គ្រងហានិភ័យបានល្អជាងមុន។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីមូលដ្ឋានគ្រឹះ IoT និង Microcontroller: ចាប់ផ្តើមរៀនប្រើប្រាស់ Arduino IDE ជាមួយ ESP32 ឬ ESP8266 ដើម្បីស្វែងយល់ពីរបៀបភ្ជាប់ប្រព័ន្ធ Wi-Fi និងការបញ្ជូនទិន្នន័យទៅកាន់អ៊ីនធឺណិត។
  2. សាកល្បងភ្ជាប់ឧបករណ៍ចាប់សញ្ញាទម្ងន់ (Load Cell): រៀនតភ្ជាប់ Load Cell Sensor ជាមួយម៉ូឌុល HX711 ដើម្បីថ្លឹងទម្ងន់វត្ថុ និងសរសេរកូដបង្ហាញលទ្ធផលនៅលើអេក្រង់ OLED 128x64 I2C។
  3. រៀបចំប្រព័ន្ធផ្ទុកទិន្នន័យលើ Cloud: បង្កើតគណនីនិងប្រើប្រាស់សេវាកម្មដូចជា Firebase Realtime Database ឬ ThingSpeak ដើម្បីទទួលនិងរក្សាទុកទិន្នន័យទម្ងន់ចំណីពីប្រព័ន្ធ Microcontroller តាមពេលវេលាជាក់ស្តែង។
  4. អភិវឌ្ឍកម្មវិធីទូរស័ព្ទដៃ (Mobile App): ប្រើប្រាស់ Flutter ឬ MIT App Inventor (សម្រាប់អ្នកចាប់ផ្តើម) ដើម្បីបង្កើតកម្មវិធីសម្រាប់ទាញទិន្នន័យពី Cloud មកបង្ហាញ និងសរសេររូបមន្តគណនា FCR, SGR, ថ្លៃដើម និងប្រាក់ចំណេញ។
  5. រចនា និងបោះពុម្ព 3D តួឧបករណ៍ (Hardware Design): ប្រើប្រាស់កម្មវិធី Fusion 360 ឬ Tinkercad ដើម្បីរចនារូបរាងឧបករណ៍ដួសចំណី (Dipper) ដោយផ្តោតលើការរចនាបែប Ergonomic (ដាក់ដៃកាន់នៅផ្នែកខាងលើ) និងកាត់បន្ថយទំហំដើម្បីកុំឱ្យធ្ងន់ពេលកសិករយកទៅប្រើប្រាស់ផ្ទាល់។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Microcontroller បន្ទះសៀគ្វីអេឡិចត្រូនិកខ្នាតតូចដែលដើរតួជាខួរក្បាលបញ្ជាប្រព័ន្ធ ដោយទទួលទិន្នន័យពីឧបករណ៍ចាប់សញ្ញា (Sensor) ដំណើរការវា និងបញ្ជូនទៅកាន់ប្រព័ន្ធផ្សេងទៀតដូចជាម៉ូឌុល Wi-Fi ជាដើម។ ដូចជាខួរក្បាលរបស់មនុស្សដែលទទួលព័ត៌មានពីភ្នែកឬដៃ រួចគិតវិភាគនិងបញ្ជាឱ្យរាងកាយធ្វើសកម្មភាពបន្ត។
Load Cell Sensor ឧបករណ៍ចាប់សញ្ញាដែលបំប្លែងកម្លាំងសង្កត់ ឬទម្ងន់របស់វត្ថុ ទៅជាសញ្ញាអគ្គិសនី ដើម្បីឱ្យមីក្រូកុងត្រូល័រអាចអាន និងទាញយកតម្លៃជាទម្ងន់ពិតប្រាកដបាន។ ដូចជាជញ្ជីងវៃឆ្លាតដែលអាចប្រាប់ពីទម្ងន់របស់វត្ថុដែលយើងដាក់ពីលើវាត្រង់ៗទៅកាន់កុំព្យូទ័រ។
Feed Conversion Ratio; FCR រង្វាស់សម្រាប់វាយតម្លៃប្រសិទ្ធភាពចំណី ដោយគណនាថាតើត្រូវប្រើចំណីប៉ុន្មានគីឡូក្រាមទើបធ្វើឱ្យសត្វចិញ្ចឹមកើនទម្ងន់បានមួយគីឡូក្រាម។ គុណតម្លៃ FCR កាន់តែទាប មានន័យថាការចិញ្ចឹមកាន់តែមានប្រសិទ្ធភាពនិងចំណេញ។ ដូចជាការវាស់ស្ទង់ថាតើម៉ូតូមួយត្រូវចាក់សាំងប៉ុន្មានលីត្រដើម្បីអាចជិះបានចម្ងាយ ១០០ គីឡូម៉ែត្រអញ្ចឹងដែរ។
Realtime database ប្រព័ន្ធផ្ទុកទិន្នន័យនៅលើក្លោដ (Cloud) ដែលធ្វើបច្ចុប្បន្នភាពនិងផ្ញើទិន្នន័យទៅកាន់កម្មវិធីអ្នកប្រើប្រាស់ភ្លាមៗនៅពេលមានការផ្លាស់ប្តូរ ដោយមិនបាច់រង់ចាំ ឬចុច Refresh ឡើយ។ ដូចជាការផ្សាយផ្ទាល់ (Live) លើហ្វេសប៊ុក ដែលអ្នកមើលអាចឃើញព្រឹត្តិការណ៍ភ្លាមៗក្នុងពេលដែលវាកំពុងកើតឡើង។
Specific Growth rate ; SGR អត្រាកំណើននៃការលូតលាស់របស់សត្វចិញ្ចឹមគិតជាភាគរយក្នុងមួយថ្ងៃ ដែលជួយឱ្យកសិករដឹងថាត្រីលូតលាស់លឿនឬយឺតប៉ុណ្ណាធៀបនឹងទម្ងន់ដើមរបស់វាក្នុងរយៈពេលជាក់លាក់មួយ។ ដូចជាការវាស់ថាតើកូនក្មេងម្នាក់លូតកម្ពស់ប៉ុន្មានសង់ទីម៉ែត្រក្នុងមួយខែៗធៀបនឹងកម្ពស់ដើមរបស់គេកាលពីខែមុន។
OLED ប្រភេទអេក្រង់បង្ហាញទិន្នន័យឌីជីថលខ្នាតតូច ដែលអាចបញ្ចេញពន្លឺដោយខ្លួនឯងមិនត្រូវការអំពូលបំភ្លឺពីក្រោយ ធ្វើឱ្យវាស៊ីភ្លើងតិចនិងបង្ហាញអក្សរបានច្បាស់ល្អ។ ដូចជាអេក្រង់នាឡិកាដៃឆ្លាតវៃ (Smartwatch) ដែលអាចបង្ហាញអក្សរច្បាស់ចាំងទោះនៅទីងងឹត។
Daily Feed Intake បរិមាណចំណីប្រចាំថ្ងៃដែលសត្វចិញ្ចឹមស៊ីគិតជាភាគរយនៃទម្ងន់ខ្លួនរបស់វា ដើម្បីជួយកសិករផ្តល់ចំណីក្នុងបរិមាណត្រឹមត្រូវ ជៀសវាងការខ្វះ ឬផ្តល់លើសដែលបណ្តាលឱ្យសល់ចោលក្នុងទឹក។ ដូចជាការកំណត់ថាតើមនុស្សម្នាក់ត្រូវញ៉ាំបាយប៉ុន្មានចានក្នុងមួយថ្ងៃដើម្បីឱ្យសក្ដិសមនឹងទំហំរាងកាយនិងការប្រើប្រាស់កម្លាំងរបស់គាត់។
