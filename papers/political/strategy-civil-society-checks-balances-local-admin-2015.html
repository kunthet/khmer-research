  • អង្គការសង្គមស៊ីវិល (Civil Society Organizations): អង្គការក្រៅរដ្ឋាភិបាល (ឧទាហរណ៍៖ COMFREL, ADHOC) អាចយកយុទ្ធសាស្ត្រទី១ និងទី៤ ទៅបណ្តុះបណ្តាល និងពង្រឹងសមត្ថភាពអ្នកដឹកនាំសហគមន៍ឱ្យមានភាពក្លាហានក្នុងការទាមទារសិទ្ធិ។
  • អង្គភាពប្រឆាំងអំពើពុករលួយ (Anti-Corruption Unit): អាចយកយុទ្ធសាស្ត្រក្នុងការបង្កើតយន្តការការពារអ្នករាយការណ៍ (Whistleblower Protection) និងលើកទឹកចិត្តឱ្យមានការត្រួតពិនិត្យពីថ្នាក់មូលដ្ឋានមកកែលម្អប្រព័ន្ធរបស់ខ្លួន។

ជារួម យុទ្ធសាស្ត្រទាំង ៥ នេះផ្តល់នូវក្របខ័ណ្ឌដ៏រឹងមាំមួយដែលអាចជួយរដ្ឋាភិបាល និងសង្គមស៊ីវិលកម្ពុជាក្នុងការលើកកម្ពស់តម្លាភាព និងគណនេយ្យភាពនៅថ្នាក់មូលដ្ឋានបានយ៉ាងមានប្រសិទ្ធភាព។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីប្រព័ន្ធរដ្ឋបាលថ្នាក់ក្រោមជាតិ: និស្សិតត្រូវស្វែងយល់ពីច្បាប់ និងរចនាសម្ព័ន្ធរដ្ឋបាលថ្នាក់ក្រោមជាតិនៅកម្ពុជា ជាពិសេសតួនាទី និងការទទួលខុសត្រូវរបស់ក្រុមប្រឹក្សាឃុំ/សង្កាត់ ក្រុង ស្រុក និងខណ្ឌ តាមរយៈឯកសាររបស់គណៈកម្មាធិការជាតិសម្រាប់ការអភិវឌ្ឍតាមបែបប្រជាធិបតេយ្យនៅថ្នាក់ក្រោមជាតិ (NCDD)។
  2. រៀនប្រើប្រាស់កម្មវិធីវិភាគស្ថិតិ: អនុវត្តការប្រើប្រាស់កម្មវិធី SPSS ឬ R សម្រាប់ការវិភាគទិន្នន័យបរិមាណ ជាពិសេសការអនុវត្តវិធីសាស្ត្រ Stepwise Multiple Regression Analysis ដើម្បីស្វែងរកកត្តាជះឥទ្ធិពល។
  3. អនុវត្តឧបករណ៍រៀបចំយុទ្ធសាស្ត្រ: សិក្សាពីរបៀបប្រើប្រាស់ SWOT Analysis និង TOWS Matrix ដើម្បីប្រែក្លាយចំណុចខ្លាំង ចំណុចខ្សោយ ឱកាស និងការគំរាមកំហែង ឱ្យទៅជាយុទ្ធសាស្ត្រជាក់ស្តែង (ឧ. SO, WO, ST, WT Strategies)។
  4. ការរចនាម៉ូដសំណួរស្រាវជ្រាវ (Questionnaire Design): រៀនបង្កើតកម្រងសំណួរស្ទង់មតិ ដោយប្រើប្រាស់ Likert Scale (ឧ. កម្រិត ១ ដល់ ៥) និងការសាកល្បងភាពជឿជាក់នៃកម្រងសំណួរតាមរយៈការគណនាតម្លៃ Cronbach's Alpha និងការវាយតម្លៃពីអ្នកជំនាញ (IOC)។
  5. ការចុះប្រមូលទិន្នន័យជាក់ស្តែង: រៀបចំការចុះសម្ភាសន៍ (In-depth Interview) និងធ្វើការពិភាក្សាជាក្រុម (Focus Group Discussion) ជាមួយប្រជាពលរដ្ឋ សកម្មជនសង្គម និងអាជ្ញាធរមូលដ្ឋាន ដើម្បីប្រមូលទិន្នន័យរស់ដែលឆ្លុះបញ្ចាំងពីបញ្ហាពិតប្រាកដ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Civil society សង្គមស៊ីវិល សំដៅលើបណ្តាញក្រុម អង្គការ សមាគម ឬសហគមន៍ដែលប្រជាពលរដ្ឋបង្កើតឡើងដោយស្ម័គ្រចិត្ត និងឯករាជ្យពីរដ្ឋ ដើម្បីការពារផលប្រយោជន៍សាធារណៈ និងចូលរួមក្នុងកិច្ចការសង្គម ព្រមទាំងដើរតួជាអ្នកតាមដានសកម្មភាពរបស់រដ្ឋាភិបាល។ ដូចជាសមាគមអ្នកភូមិដែលរួបរួមគ្នាដោយខ្លួនឯងដើម្បីការពារភូមិពីចោរ ឬពីការកេងប្រវ័ញ្ចផ្សេងៗពីរដ្ឋាភិបាល។
Checks and balances យន្តការត្រួតពិនិត្យ និងរក្សាតុល្យភាពអំណាច គឺជាប្រព័ន្ធដែលធានាថា គ្មានស្ថាប័នរដ្ឋ ឬបុគ្គលណាមួយមានអំណាចផ្ដាច់មុខ ឬរំលោភអំណាចឡើយ ដោយអនុញ្ញាតឱ្យស្ថាប័ន ឬពលរដ្ឋផ្សេងទៀតអាចតាមដាន កែតម្រូវ ឬទប់ស្កាត់ការសម្រេចចិត្តខុសឆ្គងរបស់អង្គភាពមួយទៀត។ ដូចជាការបើកបរឡានដែលមានទាំងហ្គែរ និងហ្វ្រាំង ដើម្បីជាន់បន្ថែមល្បឿនផង និងអាចជាន់ហ្វ្រាំងទប់អំណាចបញ្ឈប់បានពេលមានគ្រោះថ្នាក់។
Local Administration Organizations អង្គការរដ្ឋបាលមូលដ្ឋាន គឺជាស្ថាប័នរដ្ឋនៅថ្នាក់ក្រោមជាតិ (ដូចជា ក្រុមប្រឹក្សាឃុំ-សង្កាត់ ក្រុង ស្រុក) ដែលទទួលបានអំណាចពីរដ្ឋាភិបាលកណ្តាល ដើម្បីគ្រប់គ្រង ផ្តល់សេវាសាធារណៈ និងអភិវឌ្ឍន៍សហគមន៍របស់ខ្លួនដោយផ្ទាល់។ ដូចជាអ្នកគ្រប់គ្រងផ្ទះ ដែលមានសិទ្ធិចាត់ចែងលុយកាក់ និងរៀបចំផ្ទះដោយខ្លួនឯង ដោយមិនបាច់រង់ចាំការអនុញ្ញាតពីមេភូមិគ្រប់រឿង។
Good governance អភិបាលកិច្ចល្អ ឬធรรมาภิบาล គឺជាគោលការណ៍នៃការគ្រប់គ្រងស្ថាប័នប្រកបដោយតម្លាភាព គណនេយ្យភាព ការចូលរួមពីប្រជាពលរដ្ឋ ការអនុវត្តតាមច្បាប់ និងការឆ្លើយតបទៅនឹងតម្រូវការរបស់សង្គមដោយយុត្តិធម៌ និងមានប្រសិទ្ធភាព។ ដូចជាប្រធានក្រុមមួយដែលធ្វើការងារដោយបើកចំហ ចែករំលែកព័ត៌មានដល់សមាជិកគ្រប់គ្នា និងហ៊ានទទួលខុសត្រូវរាល់ការសម្រេចចិត្តរបស់ខ្លួន។
Stepwise multiple regression តំរែតំរង់ពហុគុណតាមជំហាន គឺជាវិធីសាស្ត្រវិភាគស្ថិតិដែលគេប្រើដើម្បីស្វែងរកថាតើអថេរ (កត្តា) ណាមួយដែលមានឥទ្ធិពលខ្លាំងជាងគេទៅលើលទ្ធផលណាមួយ ដោយវាធ្វើការជ្រើសរើសបញ្ជូល ឬដកកត្តាចេញម្តងមួយៗដោយស្វ័យប្រវត្តិដើម្បីរកម៉ូដែលដែលល្អបំផុត។ ដូចជាការសាកល្បងដាក់គ្រឿងផ្សំម្ដងមួយមុខៗចូលក្នុងសម្ល ដើម្បីរកមើលថាគ្រឿងផ្សំណាមួយដែលធ្វើឱ្យសម្លមានរសជាតិឆ្ងាញ់ជាងគេបំផុត។
TOWS Matrix ម៉ាទ្រីស TOWS គឺជាឧបករណ៍វិភាគយុទ្ធសាស្ត្រដែលអភិវឌ្ឍចេញពីការវិភាគ SWOT ដោយវាជួយផ្គូផ្គងចំណុចខ្លាំង (Strengths) ទៅនឹងឱកាស (Opportunities) និងចំណុចខ្សោយ (Weaknesses) ទៅនឹងការគំរាមកំហែង (Threats) ដើម្បីបង្កើតជាផែនការសកម្មភាព ឬយុទ្ធសាស្ត្រជាក់ស្តែង។ ដូចជាការយកអាវុធដែលយើងមាន (ចំណុចខ្លាំង) ទៅវាយលុកចំណុចខ្សោយរបស់គូប្រជែង (ឱកាស) ដើម្បីបង្កើតជាក្បួនសឹកឈ្នះសង្គ្រាមជាក់ស្តែង។
Empowerment ការផ្តល់អំណាច ឬការពង្រឹងអំណាច គឺជាដំណើរការនៃការបង្កើនសមត្ថភាព ភាពជឿជាក់ និងសិទ្ធិអំណាចដល់ប្រជាពលរដ្ឋ ឬសហគមន៍ ដើម្បីឱ្យពួកគេអាចធ្វើការសម្រេចចិត្ត ដោះស្រាយបញ្ហា និងគ្រប់គ្រងជោគវាសនារបស់ខ្លួនឯងបានប្រកបដោយប្រសិទ្ធភាព។ ដូចជាការបង្រៀនមនុស្សឱ្យចេះស្ទូចត្រី និងផ្តល់សិទ្ធិឱ្យពួកគេស្ទូចខ្លួនឯង ជំនួសឱ្យការយកត្រីទៅឱ្យពួកគេហូបជារៀងរាល់ថ្ងៃ។
Public sphere លំហសាធារណៈ គឺជាទីកន្លែង ឬវេទិកា (ទោះជារូបវន្ត ឬអនឡាញ) ដែលអនុញ្ញាតឱ្យប្រជាពលរដ្ឋទូទៅអាចមកជួបជុំគ្នា ពិភាក្សា ជជែកវែកញែកពីបញ្ហាសង្គម ឬបញ្ហានយោបាយដោយសេរី ដោយមិនមានការជ្រៀតជ្រែកឬការគំរាមកំហែងពីរដ្ឋ។ ដូចជាតៀមកាហ្វេនៅកណ្តាលភូមិ ដែលអ្នកភូមិអាចអង្គុយជជែកគ្នាពីបញ្ហាលំបាកក្នុងភូមិ និងរិះគន់មេឃុំដោយសេរី។
