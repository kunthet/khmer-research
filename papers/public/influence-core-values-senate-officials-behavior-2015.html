លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

ទោះបីជាមានគម្លាតវប្បធម៌ការងារក៏ដោយ វិធីសាស្ត្រ និងក្របខ័ណ្ឌទ្រឹស្តីនៃការសិក្សានេះមានប្រយោជន៍ខ្លាំងណាស់សម្រាប់ការកែទម្រង់រដ្ឋបាលសាធារណៈនៅកម្ពុជា។

  • អគ្គលេខាធិការដ្ឋានព្រឹទ្ធសភា និងរដ្ឋសភាកម្ពុជា: ស្ថាប័ននីតិប្បញ្ញត្តិទាំងពីរអាចយកសូចនាករតម្លៃស្នូល (ភាពក្លាហាន ការបម្រើសេវាសាធារណៈ ការមិនរើសអើង) មកវាយតម្លៃមន្ត្រីរបស់ខ្លួន ដើម្បីរៀបចំវគ្គបណ្តុះបណ្តាល និងពង្រឹងវប្បធម៌អង្គការ។
  • ក្រសួងមុខងារសាធារណៈ (MCS): អាចប្រើប្រាស់ក្របខ័ណ្ឌទ្រឹស្តីនេះដើម្បីបញ្ចូលទៅក្នុងកម្មវិធីអភិវឌ្ឍន៍សមត្ថភាព និងការវាស់ស្ទង់ក្រមសីលធម៌វិជ្ជាជីវៈរបស់មន្ត្រីរាជការស៊ីវិលទូទាំងប្រទេស។
  • សាលាភូមិន្ទរដ្ឋបាល (ERA): អាចយកទ្រឹស្តី Organizational Citizenship Behavior (OCB) មកធ្វើជាមុខវិជ្ជាបង្រៀន ដើម្បីបណ្តុះស្មារតីសិស្សមន្ត្រីឱ្យធ្វើការដោយស្ម័គ្រចិត្តលើសពីភារកិច្ចដែលបានកំណត់។

ជារួម ការរៀបចំឱ្យមាន 'តម្លៃស្នូល' ស្ថាប័នច្បាស់លាស់ គឺជារូបមន្តដ៏មានប្រសិទ្ធភាពក្នុងការជំរុញឱ្យមន្ត្រីរាជការកម្ពុជាធ្វើការលើសពីភារកិច្ចមូលដ្ឋានដោយស្ម័គ្រចិត្ត។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីទ្រឹស្តី និងក្របខ័ណ្ឌគំនិត: ស្វែងយល់ស៊ីជម្រៅពីទ្រឹស្តី Organizational Citizenship Behavior (OCB) របស់ Organ (1988) និងសិក្សាពីឯកសារគោលនយោបាយរបស់ក្រសួងស្ថាប័នគោលដៅ ដើម្បីកំណត់តម្លៃស្នូល (Core Values) ដែលពាក់ព័ន្ធ។
  2. រចនាកម្រងសំណួរស្រាវជ្រាវ (Questionnaire Design): បង្កើតកម្រងសំណួរដោយប្រើប្រាស់ Likert Scale ៥ កម្រិត ដោយកែច្នៃសូចនាករពីការសិក្សានេះឱ្យស្របនឹងបរិបទរដ្ឋបាលនៅកម្ពុជា តាមរយៈការប្រើប្រាស់ Google Forms ឬ KoboToolbox។
  3. កំណត់ទំហំសំណាក និងប្រមូលទិន្នន័យ: ប្រើប្រាស់រូបមន្ត Taro Yamane ដើម្បីកំណត់ចំនួនមន្ត្រីដែលត្រូវសួរ និងអនុវត្តការជ្រើសរើសសំណាកតាមស្រទាប់ (Stratified Random Sampling) បែងចែកតាមអគ្គនាយកដ្ឋាន ឬនាយកដ្ឋានដើម្បីធានាភាពតំណាង។
  4. វិភាគទិន្នន័យតាមកម្មវិធីស្ថិតិបរិមាណ: បញ្ជូលទិន្នន័យនិងសម្អាតទិន្នន័យ រួចប្រើប្រាស់កម្មវិធី SPSS ឬ Jamovi ដើម្បីធ្វើការវិភាគ Multiple Regression Analysis ស្វែងរកកម្រិតឥទ្ធិពលនៃតម្លៃស្នូលនីមួយៗ។
  5. ចងក្រងរបាយការណ៍ និងផ្តល់អនុសាសន៍គោលនយោបាយ: បកស្រាយលទ្ធផល R-square និងកម្រិតសារៈសំខាន់ (p-value) ដើម្បីសរសេរជារបាយការណ៍គោលនយោបាយ (Policy Brief) ជូនថ្នាក់ដឹកនាំស្ថាប័ន ក្នុងការកែលម្អការគ្រប់គ្រងធនធានមនុស្ស។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Organizational Citizenship Behavior (OCB) អាកប្បកិរិយារបស់បុគ្គលិកដែលស្ម័គ្រចិត្តធ្វើការងារលើសពីតួនាទីដែលបានកំណត់ ដើម្បីជួយឱ្យស្ថាប័នទទួលបានជោគជ័យ ដោយមិនរំពឹងទាមទារប្រាក់កម្រៃបន្ថែម ឬការតម្លើងឋានៈឡើយ។ ដូចជាសិស្សដែលជួយបោសសម្អាតថ្នាក់រៀនដោយស្ម័គ្រចិត្ត ទោះបីជាមិនមែនជាវេនប្រចាំថ្ងៃរបស់ខ្លួនក៏ដោយ។
Core Values គោលការណ៍ ឬតម្លៃស្នូលដែលស្ថាប័នមួយប្រកាន់ខ្ជាប់ ដើម្បីតម្រង់ទិសដៅអាកប្បកិរិយា និងការសម្រេចចិត្តរបស់បុគ្គលិកទាំងអស់ឱ្យដើរលើផ្លូវតែមួយ។ ដូចជាត្រីវិស័យដែលចង្អុលបង្ហាញផ្លូវប្រាប់សមាជិកគ្រួសារគ្រប់រូបឱ្យដឹងពីអ្វីដែលត្រូវធ្វើ និងអ្វីដែលមិនគួរធ្វើដើម្បីរក្សាកិត្តិយសគ្រួសារ។
Multiple Regression Analysis វិធីសាស្ត្រវិភាគស្ថិតិដែលប្រើដើម្បីស្វែងយល់ពីទំហំឥទ្ធិពលនៃអថេរឯករាជ្យច្រើន (ឧទាហរណ៍៖ តម្លៃស្នូលទាំង៥) ទៅលើអថេរអាស្រ័យតែមួយ (ឧទាហរណ៍៖ អាកប្បកិរិយា OCB) និងទស្សន៍ទាយលទ្ធផលរួម។ ដូចជាការគណនារកមើលថាតើ ជី ទឹក និងពន្លឺព្រះអាទិត្យ មួយណាមានឥទ្ធិពលខ្លាំងជាងគេក្នុងការធ្វើឱ្យដើមឈើលូតលាស់លឿន។
Stratified Random Sampling បច្ចេកទេសជ្រើសរើសគំរូស្រាវជ្រាវ ដោយបែងចែកប្រជាជនជាក្រុមៗ (ស្រទាប់/នាយកដ្ឋាន) ជាមុនសិន រួចទើបចាប់ឆ្នោតជ្រើសរើសដោយចៃដន្យពីក្រុមនីមួយៗតាមសមាមាត្រ ដើម្បីធានាបានភាពតំណាងគ្រប់ជ្រុងជ្រោយ។ ដូចជាការចង់ភ្លក់ម្ហូបក្នុងកម្មវិធីជប់លៀង ដោយយើងដើរភ្លក់មួយម៉ាត់ពីចានសាច់ មួយម៉ាត់ពីចានបន្លែ និងមួយម៉ាត់ពីចានបង្អែម ដើម្បីដឹងរសជាតិជារួម។
Altruism អាកប្បកិរិយានៃការជួយយកអាសារ ឬណែនាំសមាជិកផ្សេងទៀតក្នុងស្ថាប័នទាក់ទងនឹងបញ្ហាការងារ ដោយមិនគិតពីប្រយោជន៍ផ្ទាល់ខ្លួន។ ដូចជាការឈប់ឡានដើម្បីជួយរុញឡានអ្នកដទៃដែលខូចនៅតាមផ្លូវ ដោយមិនទាមទារប្រាក់ឈ្នួល។
Sportsmanship នៅក្នុងបរិបទនៃការងារ វាសំដៅលើភាពអត់ធ្មត់ មិនរអ៊ូរទាំ ឬត្អូញត្អែរនៅពេលប្រឈមមុខនឹងភាពមិនងាយស្រួល ឬបញ្ហាតូចតាចនៅក្នុងកន្លែងធ្វើការ ដោយរក្សាបាននូវភាពវិជ្ជមានជានិច្ច។ ដូចជាកីឡាករដែលចេះទទួលយកការចាញ់ដោយស្នាមញញឹម និងមិនបន្ទោសអាជ្ញាកណ្តាលនៅពេលការប្រកួតមិនបានដូចចិត្ត។
Civic Virtue ការចូលរួមយ៉ាងសកម្ម និងប្រកបដោយការទទួលខុសត្រូវនៅក្នុងកិច្ចការងាររួមរបស់ស្ថាប័ន ដូចជាការចូលរួមប្រជុំដោយយកចិត្តទុកដាក់ និងការផ្តល់យោបល់ស្ថាបនាដើម្បីកែលម្អ។ ដូចជាអ្នកភូមិដែលតែងតែចូលរួមប្រជុំភូមិដោយស្ម័គ្រចិត្ត ដើម្បីស្វែងរកដំណោះស្រាយបញ្ហាសហគមន៍ជុំគ្នា។
