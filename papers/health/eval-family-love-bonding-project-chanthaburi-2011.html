៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាទ្រឹស្តី CIPP Model: និស្សិតត្រូវស្វែងយល់ពីសមាសធាតុទាំង៤នៃ CIPP (Context, Input, Process, Product) ដើម្បីរៀបចំក្របខ័ណ្ឌវាយតម្លៃគម្រោងអភិវឌ្ឍន៍សហគមន៍ណាមួយនៅកម្ពុជា។
  2. រៀបចំកម្រងសំណួរ (Questionnaire Design): បង្កើតកម្រងសំណួរដោយប្រើមាត្រដ្ឋានវាស់ស្ទង់ Likert Scale (ឧ. ពី១ ដល់ ៥) ដើម្បីវាស់ស្ទង់កម្រិតនៃការពេញចិត្ត និងភាពសមស្របពីក្រុមគោលដៅ។
  3. កំណត់ទំហំសំណាក (Sampling Method): ប្រើប្រាស់រូបមន្ត Taro Yamane ដើម្បីគណនាទំហំសំណាកឱ្យបានត្រឹមត្រូវ និងជ្រើសរើសអ្នកចូលរួមពីក្រុមប្រឹក្សាឃុំ ឬអ្នកស្ម័គ្រចិត្តភូមិ។
  4. វិភាគទិន្នន័យស្ថិតិ (Data Analysis): ប្រើប្រាស់កម្មវិធី SPSS ឬ MS Excel ដើម្បីបញ្ចូលទិន្នន័យ និងវិភាគរកប្រេកង់ (Frequency) មធ្យមភាគ (Mean) និងគម្លាតស្តង់ដារ (Standard Deviation)។
  5. សរសេររបាយការណ៍ និងផ្តល់អនុសាសន៍: ផ្អែកលើលទ្ធផលដែលវិភាគរួច ត្រូវសរសេររបាយការណ៍ដែលផ្តោតលើចំណុចខ្សោយ (ឧ. ខ្វះការផ្សព្វផ្សាយ) និងផ្តល់យុទ្ធសាស្ត្រជាក់ស្តែងសម្រាប់ស្ថាប័នពាក់ព័ន្ធ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
CIPP Model គឺជាទម្រង់នៃការវាយតម្លៃគម្រោងដែលបង្កើតឡើងដោយ Stufflebeam ដោយផ្តោតលើទិដ្ឋភាពសំខាន់៤ គឺ បរិបទ (Context) ធនធានឬធាតុចូល (Input) ដំណើរការ (Process) និងលទ្ធផល (Product) ដើម្បីធានាថាគម្រោងដើរត្រូវផ្លូវនិងមានប្រសិទ្ធភាព។ ដូចជាការវាយតម្លៃហាងនំប៉័ងមួយ ដោយមើលតាំងពីទីតាំងហាង (បរិបទ) គ្រឿងផ្សំ (ធនធាន) របៀបដុតនំ (ដំណើរការ) និងរសជាតិនំដែលដុតរួច (លទ្ធផល) ថាតើឆ្ងាញ់ឬអត់។
Context Evaluation ការវាយតម្លៃបរិបទ ឬស្ថានភាពទូទៅមុនពេល ឬអំឡុងពេលចាប់ផ្តើមគម្រោង ដើម្បីផ្ទៀងផ្ទាត់ថាតើគោលបំណងគម្រោងពិតជាឆ្លើយតបទៅនឹងបញ្ហា និងតម្រូវការជាក់ស្តែងរបស់សហគមន៍គោលដៅដែរឬទេ។ ដូចជាការពិនិត្យមើលអាកាសធាតុ និងប្រភេទដីមុនពេលសម្រេចចិត្តដាំដំណាំ ថាតើវាស័ក្តិសមសម្រាប់ដំណាំនោះដែរឬទេ។
Input Evaluation ការវាយតម្លៃលើធនធានដែលត្រូវប្រើប្រាស់ក្នុងគម្រោង ដូចជា ថវិកា បុគ្គលិក សម្ភារៈ បច្ចេកវិទ្យា និងពេលវេលា ថាតើមានគ្រប់គ្រាន់ សមស្រប និងត្រៀមរួចរាល់សម្រាប់ការអនុវត្តគម្រោងឬទេ។ ដូចជាការរាប់លុយក្នុងហោប៉ៅ និងពិនិត្យមើលប្រេងសាំងក្នុងឡាន មុនពេលសម្រេចចិត្តធ្វើដំណើរផ្លូវឆ្ងាយ។
Process Evaluation ការតាមដាននិងវាយតម្លៃសកម្មភាពដែលកំពុងអនុវត្តជាក់ស្តែង ថាតើវាដើរស្របតាមផែនការដែលបានកំណត់ឬទេ និងដើម្បីស្វែងរកបញ្ហាប្រឈមនានាដែលត្រូវកែតម្រូវទាន់ពេលវេលា។ ដូចជាការភ្លក់រសជាតិសម្លពេលកំពុងចម្អិនលើចង្ក្រាន ដើម្បីថែមថយគ្រឿងឱ្យត្រូវមាត់មុនពេលដួសដាក់ចាន។
Product Evaluation ការវាយតម្លៃលទ្ធផលចុងក្រោយនៃគម្រោង ថាតើវាសម្រេចបានតាមគោលដៅរំពឹងទុកឬទេ ហើយបានផ្តល់ប្រយោជន៍ ឬឥទ្ធិពលវិជ្ជមានអ្វីខ្លះដល់សង្គម និងអ្នកទទួលផល។ ដូចជាការពិនិត្យមើលពិន្ទុប្រឡងចុងឆ្នាំរបស់សិស្ស ដើម្បីដឹងថាការខិតខំរៀនពេញមួយឆ្នាំនោះទទួលបានលទ្ធផលកម្រិតណា។
Standard Deviation ជារង្វាស់ស្ថិតិដែលបង្ហាញពីកម្រិតនៃការសាយភាយ ឬការប្រែប្រួលនៃទិន្នន័យ ធៀបនឹងតម្លៃមធ្យម (Mean)។ បើគម្លាតស្តង់ដារតូច មានន័យថាចម្លើយរបស់អ្នកចូលរួមមានលក្ខណៈស្រដៀងៗគ្នា និងប្រមូលផ្តុំជិតមធ្យមភាគ។ ដូចជាការវាស់កម្ពស់សិស្សក្នុងថ្នាក់ បើសិស្សមានកម្ពស់ប្រហាក់ប្រហែលគ្នាទាំងអស់ នោះគម្លាតស្តង់ដារគឺតូច (គ្មានអ្នកខ្ពស់ពេក ឬទាបពេក)។
Antenatal Care ការថែទាំសុខភាពស្ត្រីអំឡុងពេលមានផ្ទៃពោះ ដោយតម្រូវឱ្យទៅពិនិត្យសុខភាពនៅមណ្ឌលសុខភាពជាប្រចាំ (ជាពិសេសការទៅពិនិត្យលើកដំបូងមុនអាយុគភ៌១២សប្តាហ៍) ដើម្បីធានាសុវត្ថិភាព ការលូតលាស់របស់ទារក និងការពារហានិភ័យផ្សេងៗ។ ដូចជាការយកឡានទៅត្រួតពិនិត្យម៉ាស៊ីនតាមកាលកំណត់ ដើម្បីកុំឱ្យខូចតាមផ្លូវ និងធានាសុវត្ថិភាពអ្នកជិះ។
Public Administration ជាមុខជំនាញវិទ្យាសាស្ត្រសង្គមដែលសិក្សាអំពីការគ្រប់គ្រងស្ថាប័នរដ្ឋ ការរៀបចំគោលនយោបាយសាធារណៈ ការគ្រប់គ្រងធនធានមនុស្សក្នុងរដ្ឋបាលសាធារណៈ និងការផ្តល់សេវាសាធារណៈជូនប្រជាពលរដ្ឋប្រកបដោយតម្លាភាព និងប្រសិទ្ធភាព។ ដូចជាការធ្វើជាមេគ្រួសារដែលត្រូវរៀបចំចាត់ចែងលុយកាក់ បែងចែកការងារក្នុងផ្ទះ និងដោះស្រាយបញ្ហាផ្សេងៗ ដើម្បីឱ្យសមាជិកគ្រួសាររស់នៅបានសុខស្រួល។
