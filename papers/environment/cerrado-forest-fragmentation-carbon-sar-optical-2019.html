៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងនៅក្នុងតំបន់អន្តរកាល Cerrado-Amazon នៃប្រទេសប្រេស៊ីល ដែលផ្តោតលើប្រភេទរុក្ខជាតិជាក់លាក់ (Cerradão) ក្នុងអាកាសធាតុទីនោះ។ ទោះបីជាវិធីសាស្ត្រនេះអាចយកមកអនុវត្តបានជាសកលក៏ដោយ ប៉ុន្តែម៉ូដែលគណនាជីវម៉ាស (Allometric Models) គឺមិនអាចយកមកប្រើត្រង់ៗនៅកម្ពុជាបានទេ ដោយសារពូជឈើ និងដង់ស៊ីតេព្រៃនៅកម្ពុជាមានភាពខុសគ្នា ដែលតម្រូវឱ្យមានការវាស់វែង និងកែសម្រួលម៉ូដែលជាថ្មីសិន។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រតាមដានព្រៃឈើពីចម្ងាយដោយប្រើផ្កាយរណបចម្រុះនេះ គឺមានសារៈសំខាន់ និងអាចយកមកអនុវត្តបានយ៉ាងល្អនៅក្នុងបរិបទប្រទេសកម្ពុជា។

  • គម្រោងឥណទានកាបូននៅជួរភ្នំក្រវាញ (Cardamom Mountains REDD+): អាចប្រើប្រាស់វិធីសាស្ត្រគណនាបរិមាណជីវម៉ាស និងតាមដានឥទ្ធិពលនៃការបែកចែកព្រៃឈើ (Edge Effects) ដើម្បីវាយតម្លៃបរិមាណស្តុកកាបូនឱ្យបានសុក្រឹត និងរក្សាបាននូវតម្លាភាពក្នុងការលក់ឥណទានកាបូន។
  • ការតាមដានបទល្មើសនៅតំបន់ព្រៃឡង់ (Prey Lang Wildlife Sanctuary): អាចប្រើទិន្នន័យ Optical និង SAR បញ្ចូលគ្នាដើម្បីត្រួតពិនិត្យការកាប់ឈើខុសច្បាប់ និងការបាត់បង់គម្របព្រៃ ដោយទិន្នន័យរ៉ាដានឹងជួយបង្ហាញពីសកម្មភាពកាប់ឈើទោះបីជានៅរដូវវស្សាដែលពោរពេញដោយពពកក៏ដោយ។
  • ការតាមដានព្រៃលិចទឹកតំបន់ទន្លេសាប (Tonle Sap Flooded Forest): ទិន្នន័យ SAR (ឧ. Sentinel-1) មានសមត្ថភាពខ្ពស់ក្នុងការផ្តិតយករូបភាពរចនាសម្ព័ន្ធព្រៃឈើក្នុងតំបន់ដែលមានទឹកលិច ដែលអាចជួយតាមដានការទន្ទ្រានដីព្រៃលិចទឹកយកមកធ្វើជាកសិកម្ម។

ការអនុវត្តបច្ចេកទេសតេឡេស្កុបពីចម្ងាយ (Remote Sensing) ទាំងនេះ នឹងផ្តល់លទ្ធភាពកាន់តែខ្លាំងដល់ក្រសួងបរិស្ថានក្នុងការតាមដានបទល្មើសព្រៃឈើប្រកបដោយតម្លាភាព និងគាំទ្រដល់របាយការណ៍បម្រែបម្រួលអាកាសធាតុជាតិ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សា និងស្វែងយល់ពីកម្មវិធីកែច្នៃទិន្នន័យ: និស្សិតត្រូវហ្វឹកហាត់ប្រើប្រាស់កម្មវិធី ESA SNAP សម្រាប់ការកែច្នៃទិន្នន័យរ៉ាដា និងរៀនភាសាកូដ R ឬ Python ដើម្បីដំណើរការក្បួនដោះស្រាយ Random Forest។
  2. ប្រមូលទិន្នន័យផ្កាយរណបឥតគិតថ្លៃ: ចូលទៅកាន់ Copernicus Open Access Hub ដើម្បីទាញយករូបភាពអុបទិក Sentinel-2 និងរូបភាពរ៉ាដា Sentinel-1 ប្រចាំតំបន់សិក្សា (ឧទាហរណ៍៖ ព្រៃឡង់) រួចធ្វើការកែសម្រួលពន្លឺ និងស្រមោល (Atmospheric & Terrain Correction)។
  3. ចុះប្រមូលទិន្នន័យផ្ទាល់នៅទីវាល (Ground Truthing): រៀបចំប្លង់វាស់វែងនៅក្នុងព្រៃដោយវាស់អង្កត់ផ្ចិតដើមឈើ (DBH) និងកម្ពស់ ដើម្បីបង្កើត Allometric Models សម្រាប់គណនាជីវម៉ាស (AGB) ដែលសក្តិសមនឹងប្រភេទព្រៃនៅកម្ពុជា។
  4. ធ្វើសមាហរណកម្មទិន្នន័យ និងចំណាត់ថ្នាក់ព្រៃឈើ: ប្រើប្រាស់បច្ចេកទេស Principal Component Analysis (PCA) ដើម្បីបង្រួមទិន្នន័យពហុប្រភព (Optical Indices ដូចជា NDVI និងគុណភាពរូបភាព SAR Textures) រួចបញ្ជាឱ្យម៉ាស៊ីនរៀន (Machine Learning) បង្កើតផែនទីគម្របព្រៃឈើកម្ពុជាឱ្យបានច្បាស់លាស់។
  5. វិភាគស៊េរីពេលវេលាសម្រាប់ការបែកចែកព្រៃ (Edge Effects): ប្រើប្រាស់ទិន្នន័យផ្កាយរណប Landsat Time-Series ប្រចាំឆ្នាំ ដើម្បីទាញយកតម្លៃ NDVI និងតាមដានពីការបាត់បង់ជីវម៉ាសនៅតាមគែមព្រៃរយៈពេលវែង និងរាយការណ៍ពីនិន្នាការនៃការបាត់បង់ព្រៃឈើ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Synthetic Aperture Radar (SAR) ជាប្រព័ន្ធរ៉ាដាដែលបញ្ចេញរលកសញ្ញាទៅកាន់ផែនដី ហើយវាស់ស្ទង់រលកដែលចំណាំងផ្លាតត្រឡប់មកវិញ ដើម្បីបង្កើតជារូបភាពរចនាសម្ព័ន្ធផ្ទៃដី ដោយមានសមត្ថភាពពិសេសអាចទម្លុះពពក និងអាចចាប់យករូបភាពបានទោះជានៅពេលយប់ ឬរដូវវស្សា។ ដូចជាសត្វប្រចៀវប្រើប្រាស់សំឡេងអេកូដើម្បីវាស់ស្ទង់ទីតាំងវត្ថុនៅទីងងឹត ដោយមិនចាំបាច់ត្រូវការការបំភ្លឺពីពន្លឺព្រះអាទិត្យ។
Normalized Difference Vegetation Index (NDVI) ជាសូចនាករគណិតវិទ្យាប្រើក្នុងរូបភាពផ្កាយរណប ដើម្បីវាស់ស្ទង់កម្រិតភាពបៃតង និងដង់ស៊ីតេរុក្ខជាតិ ដោយប្រៀបធៀបការស្រូបពន្លឺពណ៌ក្រហមធម្មតា និងចំណាំងផ្លាតនៃពន្លឺក្រហមអាំងប្រា (Near-Infrared) ពីកោសិការបស់ស្លឹករុក្ខជាតិ។ ដូចជាការប្រើប្រាស់ទែម៉ូម៉ែត្រដើម្បីវាស់កម្តៅអ្នកជំងឺ តែនេះគឺឧបករណ៍សម្រាប់វាស់ភាពបៃតងដើម្បីដឹងថារុក្ខជាតិមានសុខភាពល្អឬក៏អត់។
Allometric Models ជាសមីការគណិតវិទ្យាដែលប្រើសម្រាប់ប៉ាន់ស្មានទម្ងន់ ឬជីវម៉ាសសរុបរបស់ដើមឈើ ដោយផ្អែកលើការវាស់វែងទំហំជាក់លាក់មួយចំនួន ដូចជាអង្កត់ផ្ចិតដើមឈើ (DBH) កម្ពស់ និងដង់ស៊ីតេសាច់ឈើ ដោយមិនចាំបាច់កាប់ដើមឈើនោះផ្ទាល់ដើម្បីយកមកថ្លឹងឡើយ។ ដូចជាការទស្សន៍ទាយទម្ងន់របស់មនុស្សម្នាក់ដោយគ្រាន់តែវាស់កម្ពស់ និងទំហំចង្កេះរបស់គាត់។
Edge Effect ជាឥទ្ធិពលនៃការប្រែប្រួលប្រព័ន្ធអេកូឡូស៊ីនិងបរិស្ថាន (ដូចជាការកើនកម្តៅ និងខ្យល់ស្ងួត) នៅតំបន់ព្រំប្រទល់ចន្លោះព្រៃឈើ និងដីលំហរ ដែលជារឿយៗបណ្តាលឱ្យមានការស្លាប់របស់ដើមឈើធំៗ និងការធ្លាក់ចុះនៃការស្តុកទុកកាបូននៅតាមគែមព្រៃ។ ដូចជាការអង្គុយនៅក្បែរមាត់ទ្វារផ្ទះបើកចំហរក្នុងរដូវរងា អ្នកនឹងមានអារម្មណ៍ត្រជាក់ខុសពីអ្នកដែលអង្គុយនៅតំបន់កណ្តាលផ្ទះដែលកក់ក្តៅជាង។
Random Forest classification ជាក្បួនដោះស្រាយផ្នែកបញ្ញាសិប្បនិម្មិត (Machine Learning) ដែលបង្កើត "ដើមឈើសម្រេចចិត្ត" ជាច្រើន ហើយយកលទ្ធផលភាគច្រើនដើម្បីធ្វើចំណាត់ថ្នាក់ប្រភេទផ្ទៃដី ដូចជាការបែងចែកថាតើកន្លែងណាជាព្រៃឈើ ឬជាតំបន់កសិកម្មដោយស្វ័យប្រវត្តិ។ ដូចជាការសាកសួរមតិពីក្រុមវេជ្ជបណ្ឌិត១០០នាក់ ដើម្បីធ្វើរោគវិនិច្ឆ័យជំងឺមួយដោយយកមតិភាគច្រើន ជាជាងជឿលើគ្រូពេទ្យតែម្នាក់។
Aboveground Biomass (AGB) ជារង្វាស់ទម្ងន់សរុបនៃផ្នែកទាំងអស់របស់រុក្ខជាតិដែលដុះនៅលើផ្ទៃដី (ដូចជា ដើម មែក និងស្លឹក) បន្ទាប់ពីគិតដកជាតិទឹកចេញអស់ ដែលវាមានសារៈសំខាន់ខ្លាំងក្នុងការគណនាបរិមាណកាបូនដែលព្រៃឈើអាចស្តុកទុកបាន។ ដូចជាការថ្លឹងទម្ងន់សាច់និងឆ្អឹងសុទ្ធរបស់រាងកាយ ដោយមិនបូកបញ្ចូលជាតិទឹក ដើម្បដឹងពីម៉ាសពិតប្រាកដ។
Principal Component Analysis (PCA) ជាបច្ចេកទេសស្ថិតិដែលប្រើដើម្បីបង្រួញទំហំទិន្នន័យធំៗនិងស្មុគស្មាញ (ដូចជារូបភាពផ្កាយរណបច្រើនស្រទាប់) ឱ្យមកនៅទំហំតូចងាយស្រួលវិភាគ ដោយនៅតែរក្សាទុកព័ត៌មានសំខាន់ៗដែលបង្ហាញពីភាពខុសគ្នារបស់ទិន្នន័យដើម។ ដូចជាការសង្ខេបសៀវភៅរឿងមួយក្បាលដ៏ក្រាស់ ឱ្យមកនៅត្រឹមមួយទំព័រដែលរៀបរាប់តែចំណុចសំខាន់ៗនៃសាច់រឿង។
Polarimetric decomposition ជាវិធីសាស្ត្រក្នុងការវិភាគរលកសញ្ញារ៉ាដា (SAR) ដើម្បីញែកប្រភេទនៃចំណាំងផ្លាតចេញពីរចនាសម្ព័ន្ធផ្សេងៗគ្នានៅលើផ្ទៃដី ដូចជាចំណាំងផ្លាតចេញពីស្លឹកឈើ (Volume) ពីគល់ឈើនិងដី (Double bounce) ឬពីផ្ទៃដីរាបស្មើ (Surface)។ ដូចជាការយកពន្លឺព្រះអាទិត្យទៅឆ្លុះកាត់កញ្ចក់ព្រីស (Prism) ដើម្បីបំបែកពន្លឺសនោះទៅជាពណ៌ឥន្ទធនូផ្សេងៗគ្នា ដែលជួយឱ្យយើងងាយស្រួលដឹងពីប្រភពរបស់វា។
