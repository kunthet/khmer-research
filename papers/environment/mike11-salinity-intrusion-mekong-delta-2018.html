  • MOWRAM (ក្រសួងធនធានទឹក និងឧតុនិយម): អាចអនុវត្តគំរូនេះនៅទីស្នាក់ការកណ្តាល រួចចែកចាយលទ្ធផលទៅមន្ទីរខេត្តដោយមិនចាំបាច់ចំណាយថវិកាទិញអាជ្ញាប័ណ្ណកម្មវិធី MIKE ថ្លៃៗសម្រាប់គ្រប់ខេត្តឡើយ។

ការអភិវឌ្ឍប្រព័ន្ធស្រង់ទិន្នន័យកណ្តាលបែបនេះ គឺជាដំណោះស្រាយប្រកបដោយប្រសិទ្ធភាពចំណាយ (Cost-effective) សម្រាប់ពង្រឹងប្រព័ន្ធប្រកាសអាសន្នជាមុន (Early Warning System) នៅកម្ពុជា។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃគំរូជលសាស្ត្រ: ស្វែងយល់ពីរបៀបដំណើរការរបស់ MIKE 11 AD (Advection-Dispersion) សម្រាប់ការសិក្សាអំពីលំហូរទឹក និងការសាយភាយជាតិប្រៃនៅក្នុងបណ្តាញទន្លេ។
  2. អភិវឌ្ឍជំនាញសរសេរកូដសម្រាប់ការទាញយកទិន្នន័យ: រៀនប្រើប្រាស់ភាសា Python និង C# (.NET) ដើម្បីរៀបចំកូដទាញយកទិន្នន័យតាមរយៈ MIKE SDK និងឧបករណ៍ Res1d Extraction Tools។
  3. ធ្វើសមាហរណកម្មជាមួយប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ: អនុវត្តការប្រើប្រាស់កម្មវិធីដូចជា QGIS ឬ ArcGIS ដើម្បីតភ្ជាប់ទិន្នន័យកូអរដោនេជាមួយលទ្ធផលជាតិប្រៃ ដើម្បីបង្កើតផែនទីបង្ហាញពីហានិភ័យតាមតំបន់។
  4. សាកល្បងជាមួយទិន្នន័យក្នុងស្រុករបស់កម្ពុជា: ប្រមូលទិន្នន័យកាត់ទទឹងទន្លេ និងកម្រិតទឹកនៅតំបន់គោលដៅក្នុងប្រទេសកម្ពុជា (ឧទាហរណ៍៖ ទន្លេបាសាក់) ដើម្បីរត់គំរូសាកល្បង និងផ្ទៀងផ្ទាត់ភាពត្រឹមត្រូវនៃកម្រិតជាតិប្រៃ។
  5. បង្កើតផ្ទាំងព័ត៌មាន និងប្រព័ន្ធចែកចាយកណ្តាល: រៀបចំប្រព័ន្ធ Web Dashboard មួយដែលអនុញ្ញាតឱ្យអ្នកប្រើប្រាស់នៅតាមខេត្តអាចចូលមើល ទាញយកទិន្នន័យ និងទទួលការព្រមានអំពីជាតិប្រៃជាទម្រង់ក្រាហ្វ និងតារាងបានយ៉ាងងាយស្រួល។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
MIKE 11 AD គឺជាកម្មវិធីគំរូកុំព្យូទ័រមួយប្រភេទដែលប្រើសម្រាប់ក្លែងធ្វើលំហូរទឹក និងការសាយភាយនៃសារធាតុនានា (ដូចជាជាតិប្រៃ) នៅក្នុងបណ្តាញទន្លេនិងព្រែក។ ដូចជាការលេងហ្គេមក្លែងធ្វើ(Simulator)ដែលបង្ហាញពីរបៀបដែលទឹកប្រៃហូរចូលតាមមាត់ទន្លេហើយលាយឡំជាមួយទឹកសាប។
MIKE SDK គឺជាបណ្ដុំឧបករណ៍អភិវឌ្ឍន៍កម្មវិធី (Software Development Kit) ដែលអនុញ្ញាតឱ្យអ្នកសរសេរកូដអាចបង្កើតកម្មវិធីផ្សេងៗដើម្បីភ្ជាប់ អាន និងកែប្រែទិន្នន័យចេញពីប្រព័ន្ធគំរូ MIKE ដោយផ្ទាល់។ ដូចជាប្រអប់ឧបករណ៍ជាង (កូនសោ ទួណឺវីស) ដែលជួយយើងដោះ និងដំឡើងម៉ាស៊ីន (ទិន្នន័យគំរូ) តាមតម្រូវការរបស់យើងដោយមិនបាច់ប្រើកម្មវិធីដើមទាំងមូល។
DFS (Data File System) គឺជាទម្រង់ឯកសារប្រព័ន្ធទិន្នន័យគោលរបស់កម្មវិធី MIKE ដែលផ្ទុកទិន្នន័យពាក់ព័ន្ធនឹងលំហ (ទីតាំងភូមិសាស្ត្រ) និងពេលវេលា (ការផ្លាស់ប្តូរតាមម៉ោងឬថ្ងៃ)។ ដូចជាទូដែកផ្ទុកឯកសារពិសេសមួយ ដែលរក្សាទុកទាំងទីតាំងផែនទី និងកំណត់ត្រាពេលវេលានៃកម្រិតជាតិប្រៃយ៉ាងមានសណ្តាប់ធ្នាប់។
Res1d extraction tools គឺជាឧបករណ៍បច្ចេកទេសសម្រាប់ទាញយកទិន្នន័យលទ្ធផលនៃការគណនាពីឯកសារកន្ទុយ .res1d របស់គំរូ MIKE 11 ដើម្បីបំប្លែងទៅជាទម្រង់អត្ថបទ ឬតារាងដែលងាយស្រួលអាននិងយកទៅប្រើប្រាស់បន្ត។ ដូចជាអ្នកបកប្រែដែលបំប្លែងភាសាកូដកុំព្យូទ័រដ៏ស្មុគស្មាញ ទៅជារបាយការណ៍អក្សរធម្មតាដែលយើងអាចអានយល់បាន។
Gridpoint គឺជាចំណុចកាត់ទទឹង (Cross-section) នៅលើប្រព័ន្ធបណ្តាញទន្លេដែលត្រូវបានកំណត់ក្នុងគំរូកុំព្យូទ័រ ដើម្បីគណនានិងរក្សាទុកទិន្នន័យកម្រិតជាតិប្រៃ និងលំហូរទឹកនៅទីតាំងជាក់លាក់នោះ។ ដូចជាប៉ុស្តិ៍ត្រួតពិនិត្យតាមដងផ្លូវ ដែលគេដាក់ដើម្បីកត់ត្រាចំនួនរថយន្តនិងកម្រិតចរាចរណ៍នៅត្រង់ចំណុចនោះ។
Salinity Intrusion គឺជាបាតុភូតដែលទឹកសមុទ្រ (ទឹកប្រៃ) ហូរជ្រៀតចូលទៅក្នុងប្រព័ន្ធទឹកសាបតាមរយៈតំបន់មាត់ទន្លេ ដែលជារឿយៗកើតឡើងនៅរដូវប្រាំងនៅពេលដែលលំហូរទឹកសាបពីទន្លេធ្លាក់ចុះខ្សោយ។ ដូចជាសត្រូវ (ទឹកប្រៃ) ដែលវាយលុកចូលក្នុងបន្ទាយ (ទន្លេ) នៅពេលដែលកងទ័ពការពារ (ទឹកសាប) មានកម្លាំងខ្សោយ។
GIS (Geographic Information System) គឺជាប្រព័ន្ធកុំព្យូទ័រដែលប្រើសម្រាប់ចាប់យក រក្សាទុក វិភាគ និងបង្ហាញទិន្នន័យដែលមានទំនាក់ទំនងជាមួយទីតាំងភូមិសាស្ត្រនៅលើផែនដី ដូចជាការបង្កើតផែនទីបង្ហាញពីហានិភ័យនៃតំបន់រងគ្រោះដោយទឹកប្រៃ។ ដូចជាផែនទីឆ្លាតវៃដែលអាចប្រាប់យើងមិនត្រឹមតែពីទីតាំងផ្លូវប៉ុណ្ណោះទេ ថែមទាំងប្រាប់ពីកម្រិតជាតិប្រៃនៅតាមតំបន់នីមួយៗបានយ៉ាងច្បាស់លាស់។
