SWAT Model (Surface Runoff / Flow Simulation)
ម៉ូដែល SWAT (ការក្លែងធ្វើរំហូរទឹកលើផ្ទៃ)		 មានសមត្ថភាពខ្ពស់ក្នុងការចាប់យកការប្រែប្រួលតាមរដូវកាល និងបរិមាណទឹកហូរជាមធ្យមប្រចាំខែបានយ៉ាងល្អប្រសើរ។ វាឆ្លើយតបយ៉ាងច្បាស់លាស់ទៅនឹងព្រឹត្តិការណ៍ភ្លៀងធ្លាក់ខ្លាំង។ អាចប៉ាន់ស្មានទាបជាងការពិត (Underestimate) នូវលំហូរទឹកកំពូលក្នុងឆ្នាំខ្លះ ដោយសារការចែកចាយស្ថានីយវាស់ទឹកភ្លៀងមិនស្មើគ្នា និងភាពខ្វះចន្លោះនៃទិន្នន័យ។ សម្រេចបានប្រសិទ្ធភាព ENS ស្មើនឹង ០.៧២ សម្រាប់ការក្រិត និង ០.៧៧ សម្រាប់សុពលភាព។
SWAT Model (Sediment Yield Simulation using MUSLE)
ម៉ូដែល SWAT (ការក្លែងធ្វើទិន្នផលកំណកល្បាប់ដោយសមីការ MUSLE)		 ផ្តល់នូវការប៉ាន់ស្មានបរិមាណកំណកល្បាប់ប្រចាំខែប្រកបដោយភាពជឿជាក់ខ្ពស់ ដែលមានប្រយោជន៍សម្រាប់ការគ្រប់គ្រងទីជម្រាលរងទឹកភ្លៀង និងទប់ស្កាត់សំណឹកដី។ អាចមានភាពល្អៀងខ្លះនៅរដូវវស្សា ដោយសារកង្វះការបញ្ចូលទិន្នន័យនៃការប្រើប្រាស់ទឹកពីអាងស្តុកទឹកដោយផ្ទាល់ (ដូចជាកសិកម្ម និងការផ្គត់ផ្គង់ទឹក)។ សម្រេចបានប្រសិទ្ធភាព ENS ស្មើនឹង ០.៨០ សម្រាប់ការក្រិត និង ០.៧៨ សម្រាប់សុពលភាព។

ការចំណាយលើធនធាន (Resource Cost)៖ ការប្រើប្រាស់ម៉ូដែល SWAT ទាមទារការប្រមូលទិន្នន័យភូមិសាស្ត្រ អាកាសធាតុប្រវត្តិសាស្ត្រ និងកម្មវិធីកុំព្យូទ័រដែលមានសមត្ថភាពដំណើរការការវិភាគលំហរទិន្នន័យធំៗ។

  • Software: ទាមទារកម្មវិធី ArcSWAT (ដែលដើរនៅលើ ArcGIS) សម្រាប់ការដំណើរការម៉ូដែល និង SWAT-CUP សម្រាប់ការក្រិតតាមខ្នាត។

  • Expertise: ត្រូវការអ្នកជំនាញផ្នែកជលសាស្ត្រ (Hydrology) និងការប្រើប្រាស់ប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ (GIS) ដើម្បីរៀបចំ និងវិភាគលទ្ធផល។

  • Cardamom Mountains (ជួរភ្នំក្រវាញ): មានសារៈសំខាន់សម្រាប់សិក្សាពីផលប៉ះពាល់នៃការផ្លាស់ប្តូរគម្របដី (ការរិចរិលព្រៃឈើ) ទៅលើសំណឹកដី និងរំហូរទឹកជំនន់ភ្លាមៗ (flash floods)។

ម៉ូដែល SWAT គឺជាឧបករណ៍ដ៏មានសក្តានុពលសម្រាប់អ្នកធ្វើគោលនយោបាយនៅកម្ពុជា ក្នុងការរៀបចំផែនការអភិវឌ្ឍន៍អាងទន្លេ និងកាត់បន្ថយហានិភ័យនៃសំណឹកដីប្រកបដោយប្រសិទ្ធភាព និងចីរភាព។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះ GIS និង Hydrology: ចាប់ផ្តើមដោយការសិក្សាពីវដ្តទឹក និងការអនុវត្តកម្មវិធី QGIS ឬ ArcGIS ដើម្បីស្វែងយល់ពីរបៀបរៀបចំ និងវិភាគទិន្នន័យលំហរ (Spatial Data) ឱ្យបានស្ទាត់ជំនាញ។
  2. ប្រមូលទិន្នន័យសម្រាប់ម៉ូដែល: ទាញយកទិន្នន័យកម្ពស់ដីកម្រិតច្បាស់ពី ASTER GDEM ឬ SRTM ព្រមទាំងស្នើសុំទិន្នន័យឧតុនិយម និងធនធានដីពីក្រសួងធនធានទឹក និងឧតុនិយម។
  3. ការដំឡើង និងដំណើរការ ArcSWAT: ដំឡើងកម្មវិធី ArcSWAT ចូលទៅក្នុង ArcGIS រួចប្រើប្រាស់វាដើម្បីកំណត់ព្រំដែនទីជម្រាល (Watershed Delineation) និងបង្កើតឯកតាឆ្លើយតបជលសាស្ត្រ (HRUs)។
  4. ការក្រិតតាមខ្នាត និងធ្វើសុពលភាព: ប្រើប្រាស់កម្មវិធី SWAT-CUP សម្រាប់ការធ្វើ Auto-calibration និង Validation ដោយប្រៀបធៀបទិន្នន័យទឹកហូរ និងកំណកល្បាប់ដែលក្លែងធ្វើជាមួយទិន្នន័យវាស់វែងជាក់ស្តែង។
  5. ការវិភាគសេណារីយ៉ូ (Scenario Analysis): ធ្វើការផ្លាស់ប្តូរទិន្នន័យគម្របដីនៅក្នុងម៉ូដែល ដើម្បីតាមដាន និងវាយតម្លៃថា តើការកាប់ព្រៃឈើ ឬការផ្លាស់ប្តូរប្រភេទដំណាំ នឹងប៉ះពាល់ដល់សំណឹកដី និងរំហូរទឹកយ៉ាងដូចម្តេចខ្លះ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
SWAT Model (ម៉ូដែល SWAT / ឧបករណ៍វាយតម្លៃដី និងទឹក) វាជាកម្មវិធីកុំព្យូទ័រដែលប្រើសម្រាប់ក្លែងធ្វើ និងព្យាករណ៍ពីចលនាទឹក ការហូរច្រោះដី និងការបាត់បង់សារធាតុចិញ្ចឹមនៅក្នុងតំបន់ទីជម្រាលរងទឹកភ្លៀងណាមួយ ក្រោមលក្ខខណ្ឌអាកាសធាតុ និងការប្រើប្រាស់ដីផ្សេងៗគ្នា។ វាដូចជាហ្គេមក្លែងធ្វើកសិដ្ឋាន ឬទីក្រុងអញ្ចឹង ដែលអ្នកអាចផ្លាស់ប្តូរប្រភេទដី ឬអាកាសធាតុ ដើម្បីមើលថាតើទឹកជំនន់ ឬសំណឹកដីនឹងកើតឡើងយ៉ាងដូចម្តេចនៅពេលអនាគត។
Sediment yield (ទិន្នផលកំណកល្បាប់) វាគឺជាបរិមាណសរុបនៃភាគល្អិតដីខ្សាច់ ឬភក់ ដែលត្រូវបានហូរនាំដោយទឹកភ្លៀង ឬចរន្តទឹកចេញពីផ្ទៃដី ទៅកកកុញនៅក្នុងទន្លេ ស្ទឹង ឬអាងស្តុកទឹកក្នុងរយៈពេលជាក់លាក់ណាមួយ។ វាដូចជាបរិមាណកម្ទេចកម្ទី និងដីភក់ដែលត្រូវទឹកលាងចេញពីទីធ្លាមុខផ្ទះរបស់អ្នក ហូរចូលទៅកកស្ទះក្នុងលូ បន្ទាប់ពីមេឃភ្លៀងធ្លាក់ខ្លាំងរួច។
Nash-Sutcliffe efficiency (ប្រសិទ្ធភាព Nash-Sutcliffe / ENS) វាជារូបមន្តស្ថិតិដែលគេប្រើសម្រាប់វាយតម្លៃថាតើលទ្ធផលដែលគណនាបានពីម៉ូដែលកុំព្យូទ័រ មានភាពត្រឹមត្រូវ និងស៊ីគ្នាជាមួយទិន្នន័យជាក់ស្តែងដែលវាស់វែងបានក្នុងធម្មជាតិកម្រិតណា (តម្លៃកាន់តែខិតជិត ១ គឺម៉ូដែលកាន់តែល្អ)។ វាប្រៀបដូចជាពិន្ទុនៃការបាញ់ស៊ីបអញ្ចឹង បើអ្នកបាញ់កាន់តែចំកណ្តាលស៊ីប (តម្លៃខិតជិត ១) នោះមានន័យថាការទស្សន៍ទាយរបស់អ្នកកាន់តែត្រឹមត្រូវ។
Hydrological Response Units (ឯកតាឆ្លើយតបជលសាស្ត្រ / HRUs) វាគឺជាការបំបែកផ្ទៃដីធំមួយទៅជាចំណែកតូចៗដែលមានលក្ខណៈដូចគ្នា (មានប្រភេទដី ជម្រាល និងគម្របដីដូចគ្នា) ដើម្បីងាយស្រួលដល់ម៉ូដែលកុំព្យូទ័រក្នុងការគណនាចលនាទឹក និងសំណឹកដីឱ្យកាន់តែលម្អិតនិងជាក់លាក់។ វាស្រដៀងនឹងការបែងចែកសិស្សក្នុងសាលាជាថ្នាក់តូចៗតាមកម្រិតចំណេះដឹង ដើម្បីងាយស្រួលដល់គ្រូក្នុងការបង្រៀនឱ្យចំគោលដៅអញ្ចឹងដែរ។
Digital elevation model (គំរូកម្ពស់ឌីជីថល / DEM) វាគឺជាទិន្នន័យផែនទី 3D ដែលបង្ហាញពីភាពខ្ពស់ទាបនៃផ្ទៃដី ដែលជួយឱ្យកម្មវិធីកុំព្យូទ័រអាចដឹងពីកម្រិតជម្រាលភ្នំ និងកំណត់ទិសដៅដែលទឹកនឹងត្រូវហូរចុះពីទីខ្ពស់មកទាប។ វាប្រៀបដូចជាការយកសន្លឹកកៅស៊ូមកគ្របពីលើដុំថ្មតូចធំ ដើម្បីមើលថាតើផ្ទៃខាងលើមានរាងគ្រលុក និងខ្ពស់ទាបបែបណា។
Curve number (លេខកោង / CN) វាគឺជាប៉ារ៉ាម៉ែត្រជលសាស្ត្រសម្រាប់វាស់ស្ទង់ថាតើទឹកភ្លៀងនឹងជ្រាបចូលទៅក្នុងដី ឬហូរ tràn លើផ្ទៃដី។ ដីដែលមានតម្លៃ CN ខ្ពស់ (ឧ. ទីក្រុងចាក់បេតុង) មានន័យថាទឹកហូរលើផ្ទៃច្រើនជាងជ្រាបចូលក្នុងដី។ វាដូចជាការចាក់ទឹកលើអេប៉ុង (CN ទាប ព្រោះទឹកជ្រាបច្រើន) ធៀបនឹងការចាក់ទឹកលើកញ្ចក់ (CN ខ្ពស់ ព្រោះទឹកហូរចេញទាំងអស់មិនមានជ្រាប)។
Modified Universal Soil Loss Equation (សមីការបាត់បង់ដីសកលកែច្នៃ / MUSLE) ជារូបមន្តគណិតវិទ្យាដែលប្រើប្រាស់កម្លាំងបរិមាណនិងល្បឿនទឹកហូរ ដើម្បីគណនាប៉ាន់ស្មានបរិមាណដីដែលត្រូវបានហូរច្រោះចេញពីទីតាំងណាមួយ ជំនួសឱ្យការប្រើប្រាស់ត្រឹមតែកម្លាំងទឹកភ្លៀងធ្លាក់។ វាដូចជារូបមន្តសម្រាប់ទស្សន៍ទាយថាតើទឹកបាញ់ពីទុយោខ្លាំងប៉ុនណា ទើបអាចរុញច្រានដុំថ្ម ឬដីខ្សាច់ចេញពីទីធ្លារបស់អ្នកបាន។
Model calibration (ការក្រិតតាមខ្នាតម៉ូដែល) វាគឺជាដំណើរការនៃការកែតម្រូវទិន្នន័យ និងប៉ារ៉ាម៉ែត្រនៅក្នុងកម្មវិធីកុំព្យូទ័ររហូតទាល់តែលទ្ធផលដែលវាទស្សន៍ទាយបាន មានភាពជិតស្និទ្ធបំផុតទៅនឹងទិន្នន័យជាក់ស្តែងដែលបានវាស់វែងពីធម្មជាតិពីមុនមក។ វាដូចជាការចាក់សារេខ្សែហ្គីតាឱ្យត្រូវសម្លេងជាមុនសិន មុនពេលចាប់ផ្តើមប្រគុំតន្ត្រី ដើម្បីឱ្យបទចម្រៀងស្តាប់ទៅពីរោះ និងមិនឆ្គង។
