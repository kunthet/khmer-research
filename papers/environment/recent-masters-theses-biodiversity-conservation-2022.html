លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រ និងលទ្ធផលនៃការស្រាវជ្រាវទាំងនេះ មានសារៈប្រយោជន៍ និងអនុវត្តបានយ៉ាងពេញលេញសម្រាប់ការគ្រប់គ្រងធនធានធម្មជាតិនៅក្នុងប្រទេសកម្ពុជា។

  • ការគ្រប់គ្រងជលផលនៅតំបន់ទន្លេសាប និងមេគង្គ (Tonle Sap and Mekong Fisheries): ទិន្នន័យនៃការធ្លាក់ចុះត្រីប្រា (Pangasianodon hypopthalmus) និងត្រីរៀល (Henicorhynchus) ជួយរដ្ឋបាលជលផលក្នុងការកែសម្រួលគោលនយោបាយនេសាទ ការថែរក្សាលំហូរទឹក និងការគ្រប់គ្រងជម្រកត្រីពង។
  • វិស័យកសិកម្មប្រកបដោយចីរភាព (Sustainable Agriculture): លទ្ធផលពីការសិក្សាសត្វប្រចៀវ Scotophilus kuhlii អាចអប់រំកសិករឱ្យកាត់បន្ថយការប្រើប្រាស់ថ្នាំសម្លាប់សត្វល្អិត និងងាកមកលើកទឹកចិត្តឱ្យមានការរក្សាទីជម្រកប្រចៀវដើម្បីកម្ចាត់សត្វល្អិតចង្រៃតាមបែបធម្មជាតិ។
  • ការគ្រប់គ្រងតំបន់ការពារធម្មជាតិក្បាលឆាយ (Kbal Chhay Multiple Use Area): ការប្រើប្រាស់សត្វឥតឆ្អឹងកងជាសូចនាករជីវសាស្ត្រ ជួយក្រសួងបរិស្ថានក្នុងការតាមដានកម្រិតបំពុលទឹក និងត្រៀមរៀបចំផែនការផ្គត់ផ្គង់ទឹកស្អាតដល់ក្រុងព្រះសីហនុ។
  • ការដោះស្រាយជម្លោះមនុស្សនិងសត្វព្រៃ (Human-Wildlife Conflict Resolution): ការស្ទង់មតិនៅឃុំអូបាក់រទេះ ខេត្តព្រះសីហនុ ផ្តល់ជាគំរូសម្រាប់អង្គការក្រៅរដ្ឋាភិបាលក្នុងការរៀបចំយុទ្ធសាស្ត្រផ្សះផ្សាជម្លោះរវាងមនុស្សនិងដំរី ដោយផ្តោតលើការអប់រំ និងការបង្កើតមុខរបរសហគមន៍។

ជារួម ការស្រាវជ្រាវទាំងនេះផ្តល់នូវភស្តុតាងវិទ្យាសាស្ត្រដ៏រឹងមាំសម្រាប់ជួយអ្នកធ្វើគោលនយោបាយកម្ពុជា ថ្លឹងថ្លែងរវាងការអភិវឌ្ឍសេដ្ឋកិច្ច និងការគាំពារប្រព័ន្ធអេកូឡូស៊ីប្រកបដោយចីរភាព។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីវិធីសាស្ត្រប្រមូលសំណាកជីវសាស្ត្រនៅទីវាល: និស្សិតត្រូវអនុវត្តការចុះវាលដោយប្រើប្រាស់ Hand nets និងឧបករណ៍ពាក់ព័ន្ធ ដើម្បីប្រមូលសំណាកសត្វឥតឆ្អឹងកងទឹកសាប និងរៀនវាស់ប៉ារ៉ាម៉ែត្រទឹក (គុណភាពទឹក, សីតុណ្ហភាព)។
  2. ហ្វឹកហាត់ជំនាញកំណត់អត្តសញ្ញាណកម្ម (Taxonomy): ត្រូវចំណាយពេលក្នុងមន្ទីរពិសោធន៍ រៀនប្រើ Microscope និងសៀវភៅមគ្គុទ្ទេសក៍អត្តសញ្ញាណកម្ម ដើម្បីអាចបែងចែកចំណាត់ថ្នាក់ថ្នាក់គ្រួសារ (Family) ឬ ប្រភេទ (Species) នៃសត្វល្អិត និងសំណាកផ្សេងៗទៀត។
  3. ស្ទាត់ជំនាញកម្មវិធីវិភាគទិន្នន័យស្ថិតិ: ត្រូវរៀនសរសេរកូដ និងប្រើប្រាស់កម្មវិធី R Software ឬ Python ដើម្បីធ្វើការវិភាគស្មុគស្មាញដូចជា Cluster analyses និង Multiple linear regression models លើទិន្នន័យអេកូឡូស៊ីនិងជលផល។
  4. រៀបចំវិធីសាស្ត្រស្រាវជ្រាវសង្គមសាស្ត្រ: រៀនបង្កើតកម្រងសំណួរ (Questionnaires) និងអនុវត្តបច្ចេកទេសសម្ភាសន៍ដោយផ្ទាល់ជាមួយប្រជាសហគមន៍ ដើម្បីប្រមូលទិន្នន័យពីការយល់ឃើញ និងកត្តាសេដ្ឋកិច្ចសង្គមពាក់ព័ន្ធនឹងការអភិរក្ស។
  5. ការផ្សារភ្ជាប់លទ្ធផលវិទ្យាសាស្ត្រទៅនឹងគោលនយោបាយ: បកប្រែទិន្នន័យដែលរកឃើញ ទៅជាសារអប់រំ ឬរបាយការណ៍ផ្តល់យោបល់ (Policy briefs) ជូនដល់ស្ថាប័នរដ្ឋពាក់ព័ន្ធ ដូចជារដ្ឋបាលជលផល ឬក្រសួងបរិស្ថាន ដើម្បីជួយគាំទ្រក្នុងការធ្វើសេចក្តីសម្រេចចិត្ត។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Macroinvertebrates សត្វគ្មានឆ្អឹងកងដែលអាចមើលឃើញដោយភ្នែកទទេ (ដូចជាសត្វល្អិតទឹក ខ្យង និងក្ដាម) ដែលអ្នកវិទ្យាសាស្ត្រប្រើប្រាស់ជាសូចនាករដើម្បីវាស់ស្ទង់ភាពស្អាត ឬកម្រិតនៃការបំពុលនៅក្នុងប្រព័ន្ធទឹកសាប។ ដូចជាកញ្ចក់ឆ្លុះបញ្ចាំងពីសុខភាពរបស់ទន្លេ បើមានសត្វទាំងនេះច្រើននិងចម្រុះ មានន័យថាទឹកនោះស្អាតល្អ។
Provisioning services ជាផ្នែកមួយនៃសេវាកម្មប្រព័ន្ធអេកូឡូស៊ី ដែលសំដៅលើផលប្រយោជន៍ ឬធនធានផ្ទាល់ដែលធម្មជាតិផ្តល់ឱ្យមនុស្ស ដូចជាការផ្គត់ផ្គង់ទឹកស្អាត អាហារ ឈើ និងឱសថបុរាណ។ ដូចជាផ្សារទំនើបធម្មជាតិ ដែលផ្គត់ផ្គង់របស់របរប្រើប្រាស់ចាំបាច់ប្រចាំថ្ងៃសម្រាប់ការរស់នៅរបស់យើងដោយឥតគិតថ្លៃ។
Insectivorous លក្ខណៈជីវសាស្ត្ររបស់សត្វ (ឧទាហរណ៍៖ ប្រចៀវ Scotophilus kuhlii) ដែលពឹងផ្អែកលើការស៊ីសត្វល្អិតជាអាហារចម្បង ដែលសកម្មភាពនេះជួយកសិករយ៉ាងច្រើនក្នុងការកម្ចាត់សត្វចង្រៃបំផ្លាញដំណាំ។ ដូចជាកងទ័ពធម្មជាតិការពារដំណាំ ដែលជួយស៊ីកម្ចាត់សត្វល្អិតចង្រៃជំនួសឱ្យការបាញ់ថ្នាំពុលគីមី។
Flagship species ប្រភេទសត្វដ៏លេចធ្លោ និងមានការចាប់អារម្មណ៍ខ្លាំងពីសាធារណជន (ឧទាហរណ៍៖ ត្រីប្រា Pangasianodon hypopthalmus) ដែលត្រូវបានជ្រើសរើសជានិមិត្តសញ្ញាដើម្បីទាក់ទាញការគាំទ្រ និងការរៃអង្គាសថវិកាសម្រាប់ការអភិរក្សបរិស្ថានជារួម។ ដូចជាតារាតំណាង (Brand Ambassador) របស់ទន្លេ ដែលជួយទាក់ទាញចំណាប់អារម្មណ៍មនុស្សឱ្យងាកមកការពារទីជម្រកធម្មជាតិទាំងមូល។
Keystone species ប្រភេទសត្វដែលមានតួនាទីយ៉ាងសំខាន់បំផុតនៅក្នុងប្រព័ន្ធអេកូឡូស៊ី (ឧទាហរណ៍៖ ត្រីរៀល Henicorhynchus) ដែលបើគ្មានពួកវាទេ ប្រព័ន្ធអេកូឡូស៊ីនោះនឹងដួលរលំ ឬប្រែប្រួលយ៉ាងធ្ងន់ធ្ងរ ព្រោះពួកវាជាប្រភពអាហារគោលរបស់សត្វដទៃទៀត។ ដូចជាសសរទ្រូងនៃផ្ទះមួយ បើដកសសរនេះចេញ ផ្ទះទាំងមូលនឹងរលំមិនខាន។
Linear regression វិធីសាស្ត្រស្ថិតិដែលគេប្រើដើម្បីវិភាគ និងរកទំនាក់ទំនងរវាងអថេរពីរ (ឧទាហរណ៍៖ ទំនាក់ទំនងរវាងឆ្នាំ និងបរិមាណទិន្នផលត្រីដែលចាប់បាន) ដើម្បីវាយតម្លៃពីទំនោរនៃការកើនឡើង ឬធ្លាក់ចុះ។ ដូចជាការគូសបន្ទាត់ត្រង់មួយកាត់តាមចំណុចទិន្នន័យជាច្រើន ដើម្បីមើលថាតើលទ្ធផលកំពុងដើរទៅមុខ ឬថយក្រោយ។
Conservation enterprises ការបង្កើតមុខរបរ ឬអាជីវកម្មខ្នាតតូចដល់សហគមន៍មូលដ្ឋាន ដែលអាចផ្តល់ប្រាក់ចំណូលស្របពេលដែលជួយលើកកម្ពស់ការការពារធនធានធម្មជាតិ និងកាត់បន្ថយការពឹងផ្អែកលើការទាញយកផលព្រៃឈើដោយខុសច្បាប់។ ដូចជាការផ្តល់ 'នុយនិងសន្ទូច' ដល់សហគមន៍ឱ្យចេះរកប្រាក់ចំណូលតាមរយៈអេកូទេសចរណ៍ ជាជាងឱ្យពួកគេចូលព្រៃកាប់ឈើ ឬបរបាញ់សត្វ។
