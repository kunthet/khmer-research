  • ខេត្តព្រះសីហនុ (Rapid Urbanization Impact): វាយតម្លៃផលប៉ះពាល់នៃការសាងសង់យ៉ាងឆាប់រហ័ស ទៅលើការបាត់បង់ផ្ទៃដីដែលអាចស្រូបទឹក និងហេតុផលដែលនាំឱ្យមានទឹកជំនន់ក្នុងក្រុង។

ទោះបីជាទិន្នន័យកម្រិត 1-km មិនសូវមានប្រសិទ្ធភាពសម្រាប់ទីក្រុងតូចៗ ការប្រើប្រាស់គម្រូនេះជាមួយនឹងទិន្នន័យផ្កាយរណបជំនាន់ថ្មី (ដូចជា Sentinel ឬ Landsat 8/9) នឹងជួយដល់រដ្ឋាភិបាលក្នុងរៀបចំទីក្រុងវៃឆ្លាតនិងធន់នឹងអាកាសធាតុ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះស្តីពី Remote Sensing: ស្វែងយល់ពីរបៀបនៃការទាញយកទិន្នន័យផ្កាយរណបដោយឥតគិតថ្លៃ ដូចជា MODIS និថ ASTER ពីគេហទំព័រ NASA Earthdata ឬ USGS Earth Explorer។
  2. អនុវត្តការធ្វើចំណាត់ថ្នាក់គម្របដី (Land Cover Classification): រៀនប្រើប្រាស់កម្មវិធី QGIS ឬសរសេរកូដនៅលើ Google Earth Engine (GEE) ដើម្បីបែងចែកប្រភេទដីក្នុងទីក្រុង ដោយប្រើក្បួនដោះស្រាយ Machine Learning ដូចជា Random Forest។
  3. គណនារង្វាស់ទេសភាពទីក្រុង (Calculate Landscape Metrics): ប្រើប្រាស់កម្មវិធី FRAGSTATS ឬ LecoS plugin (ក្នុង QGIS) ដើម្បីគណនារង្វាស់ដូចជា Mean Patch Size, Edge Density, និង IJI ដើម្បីស្វែងយល់ពីភាពស្មុគស្មាញនៃការរៀបចំទីក្រុង។
  4. ទាញយកនិងវិភាគប៉ារ៉ាម៉ែត្រជីវរូបវិទ្យា (Extract Biogeophysical Parameters): ប្រើប្រាស់រូបភាពផ្កាយរណបដើម្បីទាញយកសូចនាកររុក្ខជាតិ NDVI និងសីតុណ្ហភាពផ្ទៃដី Land Surface Temperature (LST)។
  5. វិភាគទំនាក់ទំនងលំហ (Spatial Statistical Analysis): ប្រើប្រាស់ Python (Geopandas, Rasterio, Scipy) ឬ R (Raster package) ដើម្បីស្វែងរកទំនាក់ទំនង (Correlation) រវាងរចនាសម្ព័ន្ធទីក្រុង និងកម្រិតកម្តៅ ដើម្បីផ្តល់ជាអនុសាសន៍ដល់ការរៀបចំក្រុង។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
ASTER ឧបករណ៍ចាប់សញ្ញា (Sensor) លើផ្កាយរណប Terra របស់អង្គការ NASA ដែលអាចផ្តិតយករូបភាពផ្ទៃផែនដីក្នុងកម្រិតភាពច្បាស់ខ្ពស់ (១៥ ទៅ ៩០ ម៉ែត្រ) សម្រាប់សិក្សាពីការប្រើប្រាស់ដី សីតុណ្ហភាព និងរចនាសម្ព័ន្ធទីក្រុងលម្អិត។ ដូចជាកាមេរ៉ាពង្រីក (Zoom lens) ដែលអាចថតមើលលម្អិតពីប្រភេទដី តំបន់បៃតង និងដំបូលផ្ទះក្នុងទីក្រុងពីទីអវកាស។
MODIS ឧបករណ៍ចាប់សញ្ញាលើផ្កាយរណបដែលមានកម្រិតភាពច្បាស់មធ្យមទៅទាប (២៥០ ទៅ ១០០០ ម៉ែត្រ) ប៉ុន្តែអាចថតយករូបភាពផែនដីទាំងមូលបានលឿននិងញឹកញាប់ (១ ទៅ ២ ថ្ងៃម្តង) ស័ក្តិសមសម្រាប់ការតាមដានការប្រែប្រួលអាកាសធាតុជាប្រចាំ។ ដូចជាកាមេរ៉ាថតប្លង់ទូលាយ (Wide-angle camera) ដែលថតបានផ្ទៃធំតែមិនសូវឃើញលម្អិត ដើម្បីមើលទិដ្ឋភាពជារួមរៀងរាល់ថ្ងៃ។
Landscape metrics រង្វាស់គណិតវិទ្យាដែលប្រើសម្រាប់វាស់ស្ទង់ និងពិពណ៌នាពីរចនាសម្ព័ន្ធ លំនាំ និងភាពស្មុគស្មាញនៃការរៀបចំតំបន់ផ្សេងៗគ្នានៅលើផ្ទៃដី ដូចជាទំហំបំណែកដី ដង់ស៊ីតេព្រំប្រទល់ និងការប្រមូលផ្តុំ។ ដូចជាការវាស់វែងទំហំ រូបរាង និងរបៀបដែលបំណែករូបផ្គុំ (Jigsaw puzzle) តម្រៀបចូលគ្នាដើម្បីបង្កើតជាផ្ទាំងគំនូរមួយដ៏ធំ។
Biogeophysical parameters សូចនាករដែលវាស់ស្ទង់លក្ខណៈរូបវន្ត និងជីវសាស្ត្រនៃផ្ទៃផែនដី (ដូចជា សីតុណ្ហភាពផ្ទៃ កម្រិតចំណាំងផ្លាតពន្លឺ និងកម្រិតដង់ស៊ីតេរុក្ខជាតិ) ដែលទាញយកពីទិន្នន័យផ្កាយរណប ដើម្បីសិក្សាពីបរិស្ថាន។ ដូចជាការវាស់ស្ទង់សញ្ញាជីវិតរបស់មនុស្ស (កម្តៅ ចង្វាក់បេះដូង) ប៉ុន្តែនេះគឺសម្រាប់វាស់ "សុខភាព និងស្ថានភាព" របស់តំបន់ភូមិសាស្ត្រណាមួយ។
Expert system classification វិធីសាស្ត្របែងចែកប្រភេទគម្របដីដោយរួមបញ្ចូលទិន្នន័យរូបភាពផ្កាយរណបជាមួយទិន្នន័យបន្ទាប់បន្សំផ្សេងទៀត និងការបង្កើតជាច្បាប់លក្ខខណ្ឌ (Decision rules) ដើម្បីឱ្យកុំព្យូទ័រអាចបែងចែកប្រភេទដីដែលមានលក្ខណៈស្រដៀងគ្នាបានត្រឹមត្រូវជាងមុន។ ដូចជាការបង្រៀនក្មេងឱ្យស្គាល់សត្វដោយមិនត្រឹមតែមើលរូបរាងប៉ុណ្ណោះទេ តែប្រាប់បន្ថែមពីទីជម្រក និងទម្លាប់របស់វា ដើម្បីកុំឱ្យក្មេងច្រឡំគ្នា។
Albedo រង្វាស់នៃសមត្ថភាពរបស់ផ្ទៃវត្ថុ ឬតំបន់ណាមួយក្នុងការចាំងផ្លាតពន្លឺព្រះអាទិត្យត្រលប់ទៅទីអវកាសវិញ។ តំបន់ដែលមាន Albedo ខ្ពស់ ស្រូបកម្តៅតិច និងធ្វើឱ្យតំបន់នោះមិនសូវក្តៅ។ ដូចជាការពាក់អាវពណ៌សនៅរដូវក្តៅ ដែលជួយចំណាំងផ្លាតពន្លឺថ្ងៃ និងធ្វើឱ្យរាងកាយត្រជាក់ជាងការពាក់អាវពណ៌ខ្មៅ។
NDVI (Normalized Difference Vegetation Index) សូចនាកររុក្ខជាតិដែលគណនាពីភាពខុសគ្នានៃចំណាំងផ្លាតពន្លឺក្រហម និងពន្លឺអ៊ីនហ្វ្រារ៉េដ ដើម្បីវាយតម្លៃពីភាពបៃតង ដង់ស៊ីតេ និងសុខភាពរបស់រុក្ខជាតិនៅក្នុងតំបន់ណាមួយ។ ដូចជាការធ្វើតេស្តឈាមដើម្បីដឹងថាមនុស្សម្នាក់មានសុខភាពល្អឬអត់ ចំណែក NDVI គឺប្រាប់ពីភាពស្រស់បំព្រង និងសុខភាពរបស់រុក្ខជាតិលើដី។
Interspersion/Juxtaposition Index (IJI) រង្វាស់ដែលបង្ហាញពីកម្រិតនៃការលាយឡំគ្នា រវាងប្រភេទគម្របដីផ្សេងៗគ្នានៅក្នុងតំបន់មួយ។ តម្លៃ IJI កាន់តែខ្ពស់ មានន័យថាប្រភេទដីផ្សេងៗ (ដូចជា ផ្ទះ ដើមឈើ ផ្លូវ) នៅឆ្លាស់គ្នាច្រើននិងស្មុគស្មាញ។ ដូចជាការលាយគ្រាប់សណ្តែកពណ៌ផ្សេងៗគ្នាចូលក្នុងកែវតែមួយ បើវាលាយចូលគ្នាស្មើល្អ គ្មានពណ៌ណាមួយផ្តុំគ្នាតែឯង នោះ IJI មានកម្រិតខ្ពស់។
