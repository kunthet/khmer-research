  • ដំណាំមានសញ្ញាសម្គាល់ភូមិសាស្ត្រ (GI) (ឧទាហរណ៍៖ ម្រេចកំពត): ជួយពង្រឹងការតាមដានផលិតផលដែលមានការការពារតាមផ្លូវច្បាប់ ធានាថាអ្នកទិញនៅលើទីផ្សារទទួលបានម្រេចកំពតពិតប្រាកដដែលដាំដុះតាមស្តង់ដារត្រឹមត្រូវ មិនមែនជាទំនិញក្លែងបន្លំ។
  • ខ្សែចង្វាក់ផ្គត់ផ្គង់បន្លែសុវត្ថិភាពនៅភ្នំពេញ: អនុញ្ញាតឱ្យផ្សារទំនើប និងអ្នកបរិភោគនៅក្នុងទីក្រុង អាចស្កេនកូដ QR ដើម្បីដឹងច្បាស់ពីប្រភពកសិដ្ឋាន កាលបរិច្ឆេទប្រមូលផល និងការប្រើប្រាស់ជីរ ឬថ្នាំសម្លាប់សត្វល្អិត ដើម្បីធានាសុវត្ថិភាពចំណីអាហារ។

ការចាប់ផ្តើមអនុវត្តជាគម្រោងសាកល្បង (Pilot project) ក្នុងទ្រង់ទ្រាយតូច លើផលិតផលមានតម្លៃខ្ពស់សម្រាប់ការនាំចេញ គឺជាជំហានដ៏ឈ្លាសវៃបំផុតក្នុងការទាញយកអត្ថប្រយោជន៍ពីប្លុកឆេននៅក្នុងប្រទេសកម្ពុជា។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ជំហានទី១៖ សិក្សាមូលដ្ឋានគ្រឹះនៃ Blockchain និង Smart Contracts: និស្សិតគួរចាប់ផ្តើមសិក្សាពីទ្រឹស្តីវិមជ្ឈការ (Decentralization) និងរៀនសរសេរកិច្ចសន្យាឆ្លាតវៃដោយប្រើប្រាស់ភាសា Solidity នៅលើថ្នាលសាកល្បងដូចជា Ethereum Testnet (Sepolia/Goerli) ឬស្ថាបត្យកម្ម Hyperledger Fabric។
  2. ជំហានទី២៖ ស្វែងយល់ពីប្រព័ន្ធ IoT សម្រាប់ការប្រមូលទិន្នន័យកសិកម្ម: សិក្សាពីរបៀបតភ្ជាប់ឧបករណ៍ចាប់សញ្ញា (Sensors) ដូចជាឧបករណ៍វាស់សីតុណ្ហភាព និងសំណើមដី ទៅកាន់ប្រព័ន្ធ Cloud ដោយប្រើប្រាស់ Arduino ឬ Raspberry Pi ដើម្បីទាញយកទិន្នន័យដោយស្វ័យប្រវត្តិពីកសិដ្ឋាន។
  3. ជំហានទី៣៖ អភិវឌ្ឍន៍កម្មវិធី DApp (Decentralized Application) ខ្នាតតូច: បង្កើតកម្មវិធីសាកល្បង (Prototype) មួយដោយប្រើប្រាស់ Truffle Suite, Ganache (សម្រាប់បង្កើត local blockchain), និង Web3.js/Ethers.js ដើម្បីក្លែងធ្វើការកត់ត្រាការប្រមូលផល ការវេចខ្ចប់ និងការដឹកជញ្ជូន។
  4. ជំហានទី៤៖ ការវិភាគទិន្នន័យ និងការកសាងកុងសង់ស៊ីស (Consensus): សរសេរកូដសាកល្បងក្បួនដោះស្រាយកុងសង់ស៊ីស (ដូចដែលបង្ហាញក្នុងឯកសារ) ដោយប្រើប្រាស់ភាសា Python ដើម្បីយល់ពីការបង្កើត Block និងការប្រើប្រាស់ក្បួននីយកម្ម (Hashing algorithms ដូចជា SHA-256)។
  5. ជំហានទី៥៖ ការសហការ និងអនុវត្តជាក់ស្តែងជាមួយសហគមន៍: សហការជាមួយសហករណ៍កសិកម្មក្នុងស្រុក ឬមជ្ឈមណ្ឌលនវានុវត្តន៍ជាតិ (ឧទាហរណ៍៖ Techo Startup Center ឬស្ថាប័នស្រាវជ្រាវរបស់សាកលវិទ្យាល័យ) ដើម្បីដាក់ឲ្យដំណើរការប្រព័ន្ធសាកល្បងនេះជាមួយកសិករពិតប្រាកដ និងប្រមូលមតិកែលម្អ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Blockchain ប្រព័ន្ធកត់ត្រាទិន្នន័យវិមជ្ឈការដែលរក្សាទុកព័ត៌មានជាប្លុក (Blocks) តភ្ជាប់គ្នាជាខ្សែ ហើយមានប្រព័ន្ធសុវត្ថិភាពខ្ពស់ ដែលមិនអនុញ្ញាតឱ្យនរណាម្នាក់អាចកែប្រែ ឬលុបចោលទិន្នន័យបានឡើយ បន្ទាប់ពីវាត្រូវបានកត់ត្រាបញ្ជាក់រួចរាល់។ ដូចជាសៀវភៅកត់ត្រារួមមួយ ដែលសមាជិកគ្រប់គ្នាក្នុងក្រុមមានច្បាប់ចម្លងដូចៗគ្នា ហើយគ្មាននរណាម្នាក់អាចលួចកែតួលេខបានទេ បើគ្មានការដឹងឮនិងយល់ព្រមពីអ្នកទាំងអស់គ្នា។
Consensus algorithm យន្តការ ឬក្បួនដោះស្រាយដែលអនុញ្ញាតឱ្យកុំព្យូទ័រជាច្រើន (nodes) នៅក្នុងបណ្តាញប្លុកឆេន ឈានដល់ការឯកភាពគ្នាមួយក្នុងការបញ្ជាក់ថាប្រតិបត្តិការណាមួយគឺពិតជាត្រឹមត្រូវ មុននឹងអនុញ្ញាតឱ្យកត់ត្រាវាចូលទៅក្នុងប្រព័ន្ធជាអចិន្ត្រៃយ៍។ ដូចជាការបោះឆ្នោតក្នុងក្រុមការងារ ដើម្បីសម្រេចចិត្តថាឯកសារមួយត្រឹមត្រូវ ឬអត់ មុននឹងបោះត្រាអនុម័តផ្លូវការចូលក្នុងប្រវត្តិរូបក្រុមហ៊ុន។
Smart Contract កម្មវិធីកុំព្យូទ័រដែលតម្កល់នៅលើប្លុកឆេន ហើយវាធ្វើប្រតិបត្តិការផ្ទេរប្រាក់ ឬបញ្ជាក់ទិន្នន័យដោយស្វ័យប្រវត្តិ នៅពេលដែលលក្ខខណ្ឌដែលបានកំណត់ទុកជាមុនរវាងភាគីពាក់ព័ន្ធត្រូវបានបំពេញ ដោយមិនចាំបាច់មានអន្តរាគមន៍ពីមនុស្ស ឬតតិយជន (ដូចជាធនាគារ) ឡើយ។ ដូចជាម៉ាស៊ីនលក់ភេសជ្ជៈស្វ័យប្រវត្តិ (Vending Machine) ដែលទម្លាក់ទឹកក្រូចមកភ្លាមៗនៅពេលអ្នកដាក់លុយគ្រប់ចំនួន ដោយមិនបាច់មានអ្នកលក់នៅឈរចាំនោះទេ។
Smart Agriculture ការធ្វើកសិកម្មបែបទំនើប (Precision Agriculture) ដែលប្រើប្រាស់បច្ចេកវិទ្យាដូចជា ឧបករណ៍ចាប់សញ្ញា (Sensors) ដ្រូន និងបញ្ញាសិប្បនិម្មិត (AI) ដើម្បីតាមដានសីតុណ្ហភាព សំណើម និងការលូតលាស់របស់ដំណាំ ដើម្បីទទួលបានទិន្នផលខ្ពស់ និងកាត់បន្ថយការខ្ជះខ្ជាយ។ ដូចជាការបំពាក់នាឡិកាឆ្លាតវៃ (Smartwatch) ឱ្យកសិដ្ឋាន ដើម្បីប្រាប់កសិករពីពេលណាត្រូវស្រោចទឹក ឬដាក់ជីឱ្យបានច្បាស់លាស់ ជំនួសឱ្យការទាយស្មានតាមទម្លាប់ចាស់។
Traceability សមត្ថភាពក្នុងការតាមដាន និងផ្ទៀងផ្ទាត់ប្រវត្តិ ទីតាំង និងដំណើរការនៃផលិតផលកសិកម្មណាមួយ តាំងពីប្រភពដើម (កសិដ្ឋាន) ឆ្លងកាត់ការវេចខ្ចប់ និងដឹកជញ្ជូន រហូតដល់ដៃអ្នកបរិភោគចុងក្រោយ។ ដូចជាការតាមដានលេខកូដកញ្ចប់ឥវ៉ាន់ (Tracking code) តាមក្រុមហ៊ុនដឹកជញ្ជូន ដែលអ្នកអាចដឹងថាឥវ៉ាន់ចេញពីណា ឥឡូវដល់ណាខ្លះ រហូតមកដល់មុខផ្ទះរបស់អ្នក។
Distributed ledger មូលដ្ឋានទិន្នន័យដែលត្រូវបានចែកចាយ និងរក្សាទុកច្បាប់ចម្លងដូចៗគ្នានៅលើកុំព្យូទ័រជាច្រើនកន្លែងផ្សេងៗគ្នានៅទូទាំងពិភពលោក ដោយមិនពឹងផ្អែកលើម៉ាស៊ីនមេកណ្តាល (Centralized Server) តែមួយឡើយ ដែលជួយការពារការវាយប្រហារពី Hacker និងការបាត់បង់ទិន្នន័យ។ ដូចជាការចែកចាយឯកសារ Google Doc ឱ្យសិស្សក្នុងថ្នាក់ទាំងអស់គ្នាអាចមើលឃើញ និងរក្សាទុកច្បាប់ចម្លងរៀងៗខ្លួន ជាជាងទុកសៀវភៅក្រដាសតែមួយក្បាលនៅបណ្ណាល័យដែលងាយនឹងបាត់បង់។
Proof-of-Work (PoW) ប្រភេទនៃកុងសង់ស៊ីសមួយដែលទាមទារឱ្យកុំព្យូទ័រ (Miners) នៅក្នុងបណ្តាញ ត្រូវប្រកួតប្រជែងគ្នាប្រើប្រាស់ថាមពលគណនាដ៏ស្មុគស្មាញដើម្បីដោះស្រាយលំហាត់គណិតវិទ្យា (រកតម្លៃ Nonce) ដើម្បីទទួលបានសិទ្ធិក្នុងការបញ្ជាក់ប្រតិបត្តិការ និងបង្កើតប្លុកថ្មី។ ដូចជាការប្រកួតប្រជែងគ្នាដោះស្រាយល្បែងផ្គុំរូប (Puzzle) ដ៏ពិបាកមួយ អ្នកណាដោះស្រាយបានមុនគេ អ្នកនោះមានសិទ្ធិកត់ត្រាពិន្ទុ និងទទួលបានរង្វាន់។
Query processing system ប្រព័ន្ធកូដកុំព្យូទ័រដែលអនុញ្ញាតឱ្យអ្នកប្រើប្រាស់ (ដូចជាកសិករ ឬអ្នកទិញ) អាចទាញយក ស្វែងរក និងស្រង់ទិន្នន័យជាក់លាក់ពីក្នុងបណ្តាញប្លុកឆេន តាមរយៈលក្ខខណ្ឌដែលគេបានកំណត់ (ឧទាហរណ៍៖ ស្វែងរកតែទំនិញដែលចេញពីកសិដ្ឋាន A ប៉ុណ្ណោះ)។ ដូចជាប្រអប់ស្វែងរក (Search bar) ក្នុងបណ្ណាល័យ ដែលជួយអ្នកទាញយកតែសៀវភៅដែលអ្នកចង់បានយ៉ាងឆាប់រហ័ស ក្នុងចំណោមសៀវភៅរាប់ពាន់ក្បាល។
