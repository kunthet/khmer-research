ចំណងជើងដើម៖ Deep Learning for Computer Vision: A comparison between Convolutional Neural Networks and Hierarchical Temporal Memories on object recognition tasks

អ្នកនិពន្ធ៖ Vincenzo Lomonaco (University of Bologna), Davide Maltoni (Supervisor)

១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការស្រាវជ្រាវនេះដោះស្រាយបញ្ហាការខ្វះខាតទិន្នន័យក្នុងកិច្ចការស្គាល់វត្ថុ (Object Recognition) ដោយស្វែងយល់ថាតើក្បួនដោះស្រាយដែលយកលំនាំតាមជីវសាស្ត្រ (HTM) អាចមានដំណើរការល្អជាងវិធីសាស្ត្រស្ថិតិដោយកម្លាំងបាយ (CNN) ដែរឬទេ។

វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះប្រើប្រាស់ការប្រៀបធៀបដោយផ្ទាល់រវាងម៉ូដែលសិក្សាស៊ីជម្រៅ (Deep Learning Models) ចំនួនពីរ ទៅលើសំណុំទិន្នន័យស្តង់ដារ និងសំណុំទិន្នន័យថ្មីដែលត្រូវបានបង្កើតឡើងជាពិសេស។

  • ការបង្កើតសំណុំទិន្នន័យគោលថ្មីសម្រាប់ស៊េរីរូបភាព (NORB-Sequences Benchmark)
  • ការអនុវត្តបណ្តាញសរសៃប្រសាទ (Convolutional Neural Network - CNN) តាមរយៈ Theano Framework
  • ការអនុវត្តក្បួនដោះស្រាយអង្គចងចាំតាមលំដាប់ពេលវេលា (Hierarchical Temporal Memory - HTM)
  • ការធ្វើតេស្តប្រៀបធៀបភាពត្រឹមត្រូវលើសំណុំទិន្នន័យ NORB (Cross-validation accuracy comparison)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ជាមួយនឹងទិន្នន័យបណ្តុះបណ្តាលតិចតួច (ក្រោម ២០០ គំរូក្នុងមួយថ្នាក់) វិធីសាស្ត្រ HTM ដំណើរការបានល្អជាង CNN ក្នុងការសម្គាល់វត្ថុ។
  • នៅពេលទំហំទិន្នន័យកើនឡើងលើសពី ២០០ គំរូ ក្បួនដោះស្រាយទាំងពីរផ្តល់កម្រិតភាពត្រឹមត្រូវ (Accuracy) ប្រហាក់ប្រហែលគ្នា ដោយប្រើប្រាស់ពេលវេលាបណ្តុះបណ្តាលស្រដៀងគ្នា។
  • នៅក្នុងបរិបទនៃការស្គាល់រូបភាពជាស៊េរីបន្តបន្ទាប់គ្នា ក្បួន HTM បង្ហាញពីសក្តានុពលខ្ពស់ជាងមុន ដោយសារវាអាចប្រើប្រាស់ពេលវេលាជាកត្តាណែនាំក្នុងការរៀនសូត្រដោយមិនមានការត្រួតពិនិត្យ (Unsupervised Learning)។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Convolutional Neural Networks (CNN - LeNet7)
បណ្តាញសរសៃប្រសាទ Convolutional (ម៉ូដែល LeNet7)		 មានប្រសិទ្ធភាពខ្ពស់ក្នុងការសម្គាល់វត្ថុនៅពេលមានទិន្នន័យច្រើន និងមានការគាំទ្រល្អសម្រាប់ការដំណើរការលឿនលើ GPU។ ត្រូវការទិន្នន័យបណ្តុះបណ្តាលក្នុងបរិមាណច្រើនក្រាស់ក្រែល និងប្រើប្រាស់ថាមពលគណនា (Computing Power) ខ្ពស់។ សម្រេចបានភាពត្រឹមត្រូវ ៨៦% (សម្រាប់រូបភាព Monocular) និង ៩៤.៤០% (សម្រាប់រូបភាព Binocular) នៅពេលប្រើទិន្នន័យពេញលេញ។
Hierarchical Temporal Memory (HTM)
អង្គចងចាំតាមលំដាប់លំដោយពេលវេលា (ក្បួនដោះស្រាយតាមលំនាំខួរក្បាល)		 មានសមត្ថភាពខ្ពស់ក្នុងការរៀនសម្គាល់វត្ថុទោះបីជាមានទិន្នន័យបណ្តុះបណ្តាលតិចតួច និងពូកែក្នុងការទាញយកលក្ខណៈពិសេសតាមពេលវេលា (Temporal sequences)។ នៅខ្វះខាតការអភិវឌ្ឍកូដឱ្យមានប្រសិទ្ធភាពខ្ពស់លើ GPU ដែលធ្វើឱ្យការបណ្តុះបណ្តាលអាចមានភាពយឺតយ៉ាវសម្រាប់ទិន្នន័យធំៗ។ មានប្រសិទ្ធភាពខ្ពស់ជាង CNN នៅពេលទិន្នន័យតូចជាង ២០០ គំរូក្នុងមួយថ្នាក់ និងទទួលបានភាពត្រឹមត្រូវប្រហាក់ប្រហែលគ្នានៅពេលទិន្នន័យធំ។
K-Nearest Neighbors (KNN Baseline)
ចំណាត់ថ្នាក់តាមក្បួនជិតខាងក្បែរបំផុត (KNN Baseline)		 ងាយស្រួលក្នុងការអនុវត្តដោយមិនតម្រូវឱ្យមានការបណ្តុះបណ្តាលស្មុគស្មាញ (Complex training) នោះទេ។ ភាពត្រឹមត្រូវពឹងផ្អែកខ្លាំងលើប្រវែងនៃស៊េរីរូបភាព និងមិនអាចរៀនពីលក្ខណៈស៊ីជម្រៅនៃទិន្នន័យ (Deep features) បានទេ។ សម្រេចបានភាពត្រឹមត្រូវចន្លោះពី ៧៨% ទៅ ៩០% លើសំណុំទិន្នន័យគោល NORB-Sequences បែបសាមញ្ញ។

ការចំណាយលើធនធាន (Resource Cost)៖ ការស្រាវជ្រាវនេះទាមទារធនធានកុំព្យូទ័រធុនមធ្យមទៅខ្ពស់ ជាពិសេសសម្រាប់ការបណ្តុះបណ្តាលម៉ូដែល CNN ដែលត្រូវការ GPU ដើម្បីដំណើរការរហ័ស។

  • Hardware: កុំព្យូទ័រដែលមាន CPU ច្រើនគ្រាប់ (Intel Xeon E5-2650 សម្រាប់ CNN ទីតាំង និង Xeon W3550 សម្រាប់ HTM) និងកាតក្រាហ្វិក GPU កម្រិតខ្ពស់ (NVIDIA Tesla C2075) សម្រាប់ដំណើរការរហ័ស។
  • Software: បណ្ណាល័យ Theano (Python) សម្រាប់ CNN, កម្មវិធីភាសា C# សម្រាប់ HTM, និងភាសា Java សម្រាប់បង្កើតកម្មវិធីរៀបចំសំណុំទិន្នន័យ។
  • Dataset: សំណុំទិន្នន័យរូបភាព NORB (មានរូបភាពក្មេងលេង ៥ប្រភេទ) និងទិន្នន័យគោលថ្មី NORB-Sequences ដែលបង្កើតឡើងសម្រាប់ការស្រាវជ្រាវនេះ។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះត្រូវបានធ្វើឡើងដោយប្រើប្រាស់សំណុំទិន្នន័យ NORB ដែលជារូបភាពប្រដាប់ក្មេងលេងពណ៌បៃតងថតកម្រិតពណ៌សខ្មៅ (Grayscale) ក្នុងបរិស្ថានដែលបានគ្រប់គ្រងពន្លឺយ៉ាងច្បាស់លាស់។ វាមិនតំណាងឱ្យរូបភាពពិតប្រាកដ និងស្មុគស្មាញនៅក្នុងពិភពជាក់ស្តែង (Real-world images) នោះឡើយ ដែលទាមទារឱ្យមានការប្រមូលទិន្នន័យសាកល្បងបន្ថែមនៅក្នុងប្រទេសកម្ពុជា ដើម្បីធានាប្រសិទ្ធភាពក្នុងការអនុវត្តជាក់ស្តែង។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

លទ្ធផលនៃការសិក្សានេះផ្តល់អត្ថប្រយោជន៍យ៉ាងខ្លាំងសម្រាប់ប្រទេសកម្ពុជា ជាពិសេសរបកគំហើញដែលថាបច្ចេកវិទ្យា HTM ដំណើរការបានយ៉ាងល្អនៅពេលទិន្នន័យបណ្តុះបណ្តាលនៅមានកម្រិត។

  • វិស័យកសិកម្ម (Agriculture): អាចប្រើប្រាស់បច្ចេកវិទ្យា HTM ដើម្បីសម្គាល់ប្រភេទសត្វល្អិតចង្រៃ ឬជំងឺរុក្ខជាតិដោយប្រើរូបភាពជាវីដេអូបន្តបន្ទាប់គ្នា (Sequences) ដែលស័ក្តិសមសម្រាប់កម្ពុជាព្រោះទិន្នន័យរូបភាពកសិកម្មមានចំនួនតិចតួច។
  • ការត្រួតពិនិត្យចរាចរណ៍ (Traffic Monitoring): អាចចាប់យករូបភាពពីកាមេរ៉ាសុវត្ថិភាពតាមដងផ្លូវក្នុងរាជធានីភ្នំពេញដើម្បីសម្គាល់ និងរាប់ប្រភេទយានយន្តដោយប្រើប្រាស់លក្ខណៈពិសេសនៃចលនាជាស៊េរីតាមពេលវេលា។
  • វិស័យផលិតកម្មនិងឧស្សាហកម្ម (Manufacturing): អាចអនុវត្តម៉ូដែល AI ក្នុងការត្រួតពិនិត្យគុណភាពផលិតផលរោងចក្រ (Defect detection) ទោះបីជាគ្មានទិន្នន័យបញ្ហារាប់ម៉ឺនសន្លឹកដើម្បីបង្រៀនម៉ូដែលក៏ដោយ។

ជារួម ការប្រើប្រាស់បច្ចេកទេសបណ្តុះបណ្តាលដែលមិនពឹងផ្អែកលើ Big Data ដូចជា HTM បើកឱកាសដល់អ្នកស្រាវជ្រាវកម្ពុជាក្នុងការបង្កើតប្រព័ន្ធ AI ទោះបីជាប្រឈមនឹងការខ្វះខាតទិន្នន័យក្នុងស្រុកក៏ដោយ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. យល់ដឹងពីមូលដ្ឋានគ្រឹះនៃ Computer Vision: អ្នកសិក្សាត្រូវចាប់ផ្តើមពីការស្វែងយល់ទ្រឹស្តីមូលដ្ឋាននៃដំណើរការរូបភាព (Image Processing) និងចំណាត់ថ្នាក់របស់ Machine Learning មុននឹងឈានចូលដល់ Deep Learning។
  2. អនុវត្តការកសាងម៉ូដែល CNN សម័យទំនើប: ទោះបីជាឯកសារស្រាវជ្រាវនេះប្រើប្រាស់ Theano ក៏ដោយ អ្នកស្រាវជ្រាវកម្ពុជាគួរងាកមកសិក្សានិងអនុវត្តកសាងម៉ូដែល CNN ដោយប្រើប្រាស់ PyTorch ឬ TensorFlow ព្រោះវាមានភាពងាយស្រួលនិងទាន់សម័យជាង។
  3. សិក្សាស្វែងយល់ពីក្បួន HTM: សិក្សាពីដំណើរការនិងទ្រឹស្តីនៃ HTM តាមរយៈឯកសារនិងកូដកូដបើកចំហរបស់ស្ថាប័ន Numenta ដើម្បីយល់ពីរបៀបដែលម៉ូដែលរៀនពីបម្រែបម្រួលរូបភាពតាមពេលវេលា (Temporal sequences)។
  4. បង្កើតសំណុំទិន្នន័យខ្នាតតូចក្នុងស្រុក (Local Dataset): សាកល្បងថតរូបភាពវីដេអូខ្លីៗអំពីវត្ថុដែលចង់សម្គាល់ (ឧទាហរណ៍៖ ផ្លាកលេខម៉ូតូ ឬផ្លែស្វាយ) ក្នុងបរិមាណតិចតួច (ក្រោម ២០០ គំរូ) ដោយប្រើឧបករណ៍ប្រើប្រាស់ប្រចាំថ្ងៃ។
  5. ប្រៀបធៀប និងវាយតម្លៃលើទិន្នន័យជាក់ស្តែង: សាកល្បងដំណើរការម៉ូដែល CNN និង HTM ដែលបានរៀន ទៅលើសំណុំទិន្នន័យដែលទើបតែប្រមូលបាន ដើម្បីបញ្ជាក់និងវាយតម្លៃថាតើក្បួនមួយណាមានប្រសិទ្ធភាពជាងសម្រាប់បរិបទការងាររបស់អ្នក។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Convolutional Neural Network ជាប្រភេទបណ្តាញសរសៃប្រសាទសិប្បនិម្មិតដែលពូកែខាងវិភាគរូបភាព ដោយប្រើប្រាស់រង្វាស់ (Filters) ឬម៉ាទ្រីសដើម្បីទាញយកលក្ខណៈពិសេសៗ (Features) ពីរូបភាព ដូចជាគែម ពណ៌ ឬទ្រង់ទ្រាយនៃវត្ថុ។ ដូចជាមនុស្សដែលកាន់កែវពង្រីកដើរពិនិត្យមើលរូបភាពម្តងមួយកន្លែងៗ ដើម្បីប្រមូលផ្តុំព័ត៌មានចំណាំថាវាជារូបអ្វី។
Hierarchical Temporal Memory ជាក្បួនដោះស្រាយកុំព្យូទ័រដែលយកលំនាំតាមរចនាសម្ព័ន្ធខួរក្បាលមនុស្ស (Neocortex) ដោយវាមានសមត្ថភាពរៀនចងចាំពីលំដាប់លំដោយនៃពេលវេលា (Time sequences) និងបម្រែបម្រួលនៃទិន្នន័យ។ ដូចជាការដែលយើងអាចស្គាល់បទចម្រៀងមួយបទបាន តាមរយៈការស្តាប់សាច់ភ្លេងដែលលេងបន្តបន្ទាប់គ្នាជាលំដាប់លំដោយ មិនមែនស្តាប់តែមួយណោតនោះទេ។
Back-propagation ជាដំណើរការគណនាកែតម្រូវកំហុសនៅក្នុងម៉ូដែល Deep Learning ដោយវាធ្វើការវាស់ស្ទង់កម្រិតកំហុសពីលទ្ធផលបញ្ចេញចុងក្រោយ រួចបញ្ជូនព័ត៌មានកំហុសនេះត្រឡប់ថយក្រោយវិញដើម្បីកែប្រែទម្ងន់ (Weights) នៃបណ្តាញសរសៃប្រសាទឱ្យកាន់តែសុក្រឹត។ ដូចជាសិស្សដែលធ្វើលំហាត់ខុស ហើយគ្រូប្រាប់ពីចម្លើយពិត ធ្វើឱ្យសិស្សនោះគិតត្រឡប់ថយក្រោយវិញថាតើខ្លួនឯងគិតខុសត្រង់ជំហានណា ដើម្បីកែតម្រូវកុំឱ្យខុសនៅពេលក្រោយ។
Unsupervised learning ជាវិធីសាស្ត្របង្រៀនកុំព្យូទ័រឱ្យចេះស្វែងរកទម្រង់ (Patterns) ឬការចាត់ក្រុមទិន្នន័យដោយខ្លួនឯង ដោយមិនតម្រូវឱ្យមានមនុស្សផ្តល់ចម្លើយ ឬប្រាប់មុនថាទិន្នន័យនោះជាអ្វីឡើយ (គ្មាន Label)។ ដូចជាការឱ្យក្មេងម្នាក់រៀបចំគំនរប្រដាប់ក្មេងលេង ដោយក្មេងនោះរៀបចំផ្តុំរបស់មានពណ៌ ឬរូបរាងស្រដៀងគ្នាចូលគ្នាតាមការគិតរបស់គេផ្ទាល់ ដោយគ្មាននរណាប្រាប់វិធីរៀបចំ។
Subsampling ជានីតិវិធីនៅក្នុងបណ្តាញ CNN សម្រាប់បង្រួមទំហំនៃរូបភាពឬទិន្នន័យ ដើម្បីកាត់បន្ថយចំនួនប៉ារ៉ាម៉ែត្រដែលត្រូវគណនា និងជួយឱ្យម៉ូដែលនៅតែអាចចំណាំវត្ថុបានទោះបីជាវត្ថុនោះផ្លាស់ទីទីតាំងបន្តិចបន្តួចក៏ដោយ។ ដូចជាការបង្រួមរូបថតផ្ទាំងធំមួយឱ្យតូចជាងមុន ប៉ុន្តែយើងនៅតែអាចមើលដឹងយ៉ាងច្បាស់ថាវត្ថុនៅក្នុងរូបនោះគឺជាអ្វីដដែល។
K-Nearest Neighbor ជាក្បួនដោះស្រាយចំណាត់ថ្នាក់ទិន្នន័យ ដោយវាកំណត់ប្រភេទនៃទិន្នន័យថ្មីមួយ ផ្អែកទៅលើទិន្នន័យចាស់ៗចំនួន K ដែលមានលក្ខណៈស្រដៀងវា (នៅជិតវា) បំផុតនៅក្នុងលំហទិន្នន័យ។ ដូចជាពាក្យចាស់ពោលថា "សេពគប់ពាលគឺពាល សេពគប់ប្រាជ្ញគឺប្រាជ្ញ" ពោលគឺវាវិនិច្ឆ័យរបស់ថ្មីមួយតាមរយៈលក្ខណៈរបស់ដែលនៅក្បែរវាបំផុត។
Receptive field ជាផ្នែកតូចមួយនៃទំហំរូបភាពទាំងមូល ដែលណឺរ៉ូន (Neuron) នីមួយៗនៅក្នុងបណ្តាញសរសៃប្រសាទទទួលយកមកផ្តោតអារម្មណ៍ដើម្បីធ្វើការវិភាគរកលក្ខណៈពិសេសរបស់រូបភាព។ ដូចជាការមើលទេសភាពតាមប្រហោងគន្លឹះទ្វារ ដែលភ្នែកយើងអាចមើលឃើញតែមួយផ្នែកតូចនៃទេសភាពទាំងមូលប៉ុណ្ណោះក្នុងពេលតែមួយ។
