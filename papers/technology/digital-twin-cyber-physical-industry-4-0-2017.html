ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃ IoT និងសេនស័រ: ចាប់ផ្តើមរៀនប្រើប្រាស់បន្ទះ Arduino ឬ Raspberry Pi ភ្ជាប់ជាមួយសេនស័រសាមញ្ញ (ឧទាហរណ៍៖ សេនស័រពន្លឺ ឬសេនស័រវាស់ចម្ងាយ) ដើម្បីប្រមូលទិន្នន័យពីវត្ថុពិតប្រាកដ។
  2. ស្វែងយល់ពីកម្មវិធីក្លែងធ្វើ (Simulation Software): សិក្សាពីរបៀបប្រើប្រាស់កម្មវិធី Arena Simulation ឬ AnyLogic ដើម្បីបង្កើតម៉ូដែលបរិស្ថាននិម្មិតដែលឆ្លុះបញ្ចាំងពីប្រព័ន្ធរូបវន្តណាមួយ។
  3. បង្កើតស្ពានភ្ជាប់ទិន្នន័យ (Data Bridging): រៀនសរសេរកូដដោយប្រើ Excel VBA ឬ Python ដើម្បីទាញយកទិន្នន័យពីសេនស័រ ហើយបញ្ចូលវាទៅក្នុងកម្មវិធីក្លែងធ្វើក្នុងពេលវេលាជាក់ស្តែង (Real-time)។
  4. អនុវត្តគម្រោងសាកល្បងខ្នាតតូចជាក្រុម: បង្កើតគម្រោងខ្នាតតូចមួយនៅសាកលវិទ្យាល័យ (ដូចជាប្រព័ន្ធខ្សែក្រវាត់បញ្ជូនទំនិញខ្នាតតូច) ដើម្បីសាកល្បងដំណើរការ Digital Twin ពីដើមដល់ចប់ មុននឹងឈានទៅអនុវត្តក្នុងរោងចក្រពិត។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Digital Twin បច្ចេកវិទ្យាដែលបង្កើតច្បាប់ចម្លងនិម្មិត (Virtual replica) នៃវត្ថុ ឬប្រព័ន្ធរូបវន្តពិតប្រាកដ ដោយមានការតភ្ជាប់ទិន្នន័យទៅមកក្នុងពេលវេលាជាក់ស្តែង ដើម្បីតាមដាន និងវិភាគដំណើរការ។ ដូចជាការមានស្រមោលឌីជីថលមួយនៅលើកុំព្យូទ័រ ដែលធ្វើត្រាប់តាមគ្រប់សកម្មភាពទាំងអស់របស់ម៉ាស៊ីនពិតប្រាកដភ្លាមៗ។
Cyber-physical systems (CPS) ប្រព័ន្ធជំនាន់ថ្មីដែលរួមបញ្ចូលគ្នារវាងផ្នែកកុំព្យូទ័រ (Software/Cyber) និងផ្នែករូបវន្ត (Hardware/Physical) ដែលអាចប្រាស្រ័យទាក់ទងគ្នាទៅវិញទៅមក និងជាមួយមនុស្សតាមពេលវេលាជាក់ស្តែង។ ដូចជារាងកាយមនុស្សដែលមានខួរក្បាល (Cyber) សម្រាប់បញ្ជា និងដៃជើង (Physical) សម្រាប់ធ្វើសកម្មភាព ដោយធ្វើការជាមួយគ្នាយ៉ាងស្អិតរមួត។
Industry 4.0 បដិវត្តន៍ឧស្សាហកម្មលើកទី៤ ដែលផ្តោតលើស្វ័យប្រវត្តិកម្ម ការផ្លាស់ប្តូរទិន្នន័យ និងការផលិតប្រកបដោយភាពឆ្លាតវៃតាមរយៈបច្ចេកវិទ្យាដូចជា IoT និង Cloud Computing។ គឺជារោងចក្រឆ្លាតវៃដែលម៉ាស៊ីនអាចនិយាយគ្នាឯង និងធ្វើការសម្រេចចិត្តដោយស្វ័យប្រវត្តិដោយមិនបាច់មានមនុស្សចាំបញ្ជាគ្រប់ពេល។
Internet of things (IoT) បណ្តាញនៃឧបករណ៍ប្រើប្រាស់ប្រចាំថ្ងៃ ឬម៉ាស៊ីនឧស្សាហកម្មដែលមានបំពាក់សេនស័រ និងកម្មវិធី ដើម្បីភ្ជាប់ និងផ្លាស់ប្តូរទិន្នន័យជាមួយប្រព័ន្ធផ្សេងទៀតតាមរយៈអ៊ីនធឺណិត។ ដូចជាការបំពាក់ប្រព័ន្ធទូរស័ព្ទឱ្យរបស់របរប្រើប្រាស់ ឧទាហរណ៍ ទូរទឹកកកដែលអាចផ្ញើសារប្រាប់អ្នកថាកំពុងអស់ម្ហូប។
Real-time data ទិន្នន័យដែលត្រូវបានប្រមូល បញ្ជូន និងដំណើរការភ្លាមៗនៅពេលដែលព្រឹត្តិការណ៍ណាមួយកើតឡើងក្នុងពិភពពិត ដោយគ្មានការពន្យារពេល។ ដូចជាការផ្សាយបន្តផ្ទាល់ (Live stream) នៃទិន្នន័យ ដែលលោកអ្នកអាចដឹងពីអ្វីដែលកំពុងកើតឡើងនៅវិនាទីនេះភ្លាមៗ។
Simulation ការបង្កើតម៉ូដែលសាកល្បងដោយប្រើកម្មវិធីកុំព្យូទ័រ ដើម្បីត្រាប់តាមដំណើរការនៃប្រព័ន្ធពិតប្រាកដណាមួយ ក្នុងគោលបំណងវិភាគ ទស្សន៍ទាយ និងស្វែងរកដំណោះស្រាយដោយចំណាយតិចដោយមិនប៉ះពាល់ប្រព័ន្ធពិត។ ដូចជាការលេងហ្គេមសាងសង់ទីក្រុង ដែលអ្នកអាចសាកល្បងសង់ផ្លូវ និងមើលការកកស្ទះចរាចរណ៍មុននឹងសង់ផ្លូវពិតប្រាកដ។
Sensor ឧបករណ៍អេឡិចត្រូនិចដែលប្រើសម្រាប់ចាប់យកការផ្លាស់ប្តូរនៃបរិស្ថានជុំវិញ (ដូចជា ពន្លឺ សីតុណ្ហភាព ឬចលនា) រួចបំប្លែងវាទៅជាសញ្ញាឌីជីថលបញ្ជូនទៅកាន់ប្រព័ន្ធកុំព្យូទ័រ។ ប្រៀបបាននឹងសរីរាង្គវិញ្ញាណរបស់ម៉ាស៊ីន (ដូចជាភ្នែក ឬស្បែក) ដែលជួយឱ្យវាអាចដឹងពីអ្វីដែលនៅជុំវិញខ្លួន។
Data twinning ដំណើរការនៃការចាប់យក និងធ្វើសមកាលកម្ម (Synchronize) ទិន្នន័យរវាងប្រព័ន្ធរូបវន្ត និងប្រព័ន្ធនិម្មិត ដើម្បីធានាថាម៉ូដែលនិម្មិតឆ្លុះបញ្ចាំងពីស្ថានភាពជាក់ស្តែងជានិច្ច។ ដូចជាការថតចម្លងឯកសារមួយច្បាប់ទុកក្នុងកុំព្យូទ័រ ដែលវានឹងកែប្រែដោយស្វ័យប្រវត្តិរាល់ពេលដែលអ្នកកែប្រែឯកសារក្រដាសពិត។
