សរុបមក ការរួមបញ្ចូលបច្ចេកវិទ្យាប្រព័ន្ធព័ត៌មានភូមិសាស្ត្រ (GIS) ជាមួយអត្ថបទប្រវត្តិសាស្ត្រ និងសំឡេងអត្ថាធិប្បាយ នឹងជួយលើកស្ទួយវិស័យទេសចរណ៍វប្បធម៌កម្ពុជាឱ្យកាន់តែមានភាពទំនើប ទាក់ទាញ និងផ្តល់បទពិសោធន៍ដ៏ល្អដល់ភ្ញៀវទេសចរ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ប្រមូល និងរៀបចំទិន្នន័យប្រវត្តិសាស្ត្រ: កំណត់ទីតាំងប្រវត្តិសាស្ត្រសំខាន់ៗ ប្រមូលកូអរដោនេ (GPS) រូបភាព និងរៀបចំអត្ថបទ ឬសំឡេងអត្ថាធិប្បាយដោយប្រើប្រាស់ Audio Recording Tools។
  2. រចនាប្រព័ន្ធ និងមុខងារកម្មវិធី: ប្រើប្រាស់ UML (Use Case Diagram, Activity Diagram) ដើម្បីគូសវាសលំហូរនៃការប្រើប្រាស់កម្មវិធី និងរចនាចំណុចប្រទាក់អ្នកប្រើប្រាស់ (UI/UX)។
  3. អភិវឌ្ឍកម្មវិធីទូរស័ព្ទ: ប្រើប្រាស់ Ionic Framework ជាមួយ HTML, CSS, JavaScript នៅក្នុងកម្មវិធី Visual Studio Code ដើម្បីបង្កើតកម្មវិធីដែលអាចដំណើរការបានទាំងលើ iOS និង Android។
  4. ភ្ជាប់ប្រព័ន្ធផែនទី និងបណ្តាញសង្គម: តភ្ជាប់កម្មវិធីជាមួយ Google Maps API ដើម្បីបង្ហាញទីតាំង និងមុខងារនាំផ្លូវ ព្រមទាំងបញ្ចូលមុខងារចែករំលែកទៅកាន់ Facebook, Twitter, ឬ Email។
  5. សាកល្បង និងវាយតម្លៃ: ធ្វើតេស្តកម្មវិធីជាមួយក្រុមគោលដៅ (ឧ. ភ្ញៀវទេសចរ មគ្គុទ្ទេសក៍) ដោយប្រើកម្រងសំណួរវាយតម្លៃកម្រិតការពេញចិត្ត (Likert Scale) ដើម្បីកែលម្អគុណភាព។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Ionic Framework ជាបណ្ដុំកូដបច្ចេកវិទ្យាបើកចំហ (Open-source Framework) សម្រាប់អភិវឌ្ឍកម្មវិធីទូរស័ព្ទ ដែលអនុញ្ញាតឱ្យអ្នកសរសេរកូដប្រើប្រាស់បច្ចេកវិទ្យាវិប (HTML, CSS, JavaScript) តែមួយដង តែអាចបង្កើតកម្មវិធីដែលដំណើរការបានទាំងនៅលើប្រព័ន្ធប្រតិបត្តិការ iOS និង Android។ ដូចជាការរៀនធ្វើម្ហូបមួយមុខ តែអាចយកទៅបម្រើជូនភ្ញៀវដែលចូលចិត្តញ៉ាំទាំងអាហារអឺរ៉ុប និងអាហារអាស៊ីបានដោយមិនបាច់ធ្វើម្ហូបពីរដង។
Unified Modeling Language (UML) ជាភាសានិមិត្តសញ្ញាស្តង់ដារដែលប្រើសម្រាប់គូសវាស និងរចនាទម្រង់ប្រព័ន្ធកុំព្យូទ័រ ដើម្បីបង្ហាញពីទំនាក់ទំនង និងលំហូរការងាររវាងអ្នកប្រើប្រាស់ និងប្រព័ន្ធ (ឧទាហរណ៍ Use Case Diagram) មុននឹងចាប់ផ្តើមសរសេរកូដពិតប្រាកដ។ ដូចជាប្លង់ស្ថាបត្យកម្មដែលគេគូសមុនពេលសាងសង់ផ្ទះ ដើម្បីឱ្យជាងសំណង់ដឹងពីកន្លែងត្រូវធ្វើទ្វារ បង្អួច និងបន្ទប់។
Index of Item Objective Congruence (IOC) ជារូបមន្តស្ថិតិដែលប្រើដើម្បីវាយតម្លៃ និងវាស់ស្ទង់ភាពត្រឹមត្រូវនៃកម្រងសំណួរ ដោយពឹងផ្អែកលើការដាក់ពិន្ទុពីអ្នកជំនាញ ដើម្បីបញ្ជាក់ថាសំណួរទាំងនោះពិតជាសួរចំគោលដៅនៃការស្រាវជ្រាវមែនឬអត់។ ដូចជាការយកវិញ្ញាសាប្រឡងទៅឱ្យគ្រូធំៗ៣នាក់ពិនិត្យមើលសិន មុននឹងយកទៅឱ្យសិស្សប្រឡង ដើម្បីធានាថាសំណួរមិនខុសពីមេរៀន។
Likert Scale ជាមាត្រដ្ឋានវាស់ស្ទង់កម្រិតនៃការយល់ព្រម ឬការពេញចិត្តរបស់អ្នកចូលរួមចំពោះសេចក្តីថ្លែងការណ៍ណាមួយ ដែលជាទូទៅចែកចេញជា ៥កម្រិត (ឧ. ពីមិនពេញចិត្តសោះ ដល់ពេញចិត្តខ្លាំងបំផុត) សម្រាប់ការវិភាគទិន្នន័យបរិមាណ។ ដូចជាការចុចប៊ូតុងមុខញញឹម មុខធម្មតា ឬមុខក្រៀមក្រំ នៅពេលយើងវាយតម្លៃសេវាកម្មបន្ទាប់ពីដើរចេញពីធនាគារ។
Augmented Reality (AR) ជាបច្ចេកវិទ្យាដែលរួមបញ្ចូលរូបភាពនិម្មិត (3D, អក្សរ, ឬវីដេអូ) ទៅក្នុងពិភពពិតតាមរយៈកាមេរ៉ាទូរស័ព្ទ ដើម្បីផ្តល់ព័ត៌មានបន្ថែម ឬបទពិសោធន៍ថ្មីៗដល់អ្នកប្រើប្រាស់ ដែលក្នុងឯកសារនេះស្នើឱ្យប្រើសម្រាប់បន្ថែមភាពទាក់ទាញដល់ទេសចរណ៍ប្រវត្តិសាស្ត្រនាពេលអនាគត។ ដូចជាពេលយើងលេងហ្គេម Pokemon Go ដែលយើងឃើញសត្វចម្លែកលោតចេញមកលើទីតាំងពិតប្រាកដតាមរយៈកាមេរ៉ាទូរស័ព្ទរបស់យើងអញ្ចឹង។
