១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការកើនឡើងនៃការប្រើប្រាស់យន្តហោះគ្មានមនុស្សបើក (UAVs ឬ Drones) បង្កជាការគំរាមកំហែងដល់សន្តិសុខ ដោយសារពួកវាអាចផ្ទុកនូវអាវុធ ឬគ្រឿងផ្ទុះ ដូច្នេះការកំណត់អត្តសញ្ញាណថាតើដ្រូនមានផ្ទុកបន្ទុកឬអត់ (Loaded vs Unloaded) គឺមានសារៈសំខាន់ណាស់ក្នុងការវាយតម្លៃកម្រិតហានិភ័យ។

វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះវាយតម្លៃលើវិធីសាស្រ្តប្រើប្រាស់ម៉ូដែលរៀនដោយម៉ាស៊ីន (Machine Learning) ដែលផ្អែកលើការទាញយកលក្ខណៈពិសេស (Feature-based approach) ដើម្បីបែងចែកដ្រូនមានផ្ទុកបន្ទុក និងមិនមានផ្ទុកបន្ទុក ដោយប្រើប្រាស់សញ្ញាសំឡេង (Acoustic signals)។

  • ការប្រមូលទិន្នន័យសំឡេង (Audio Data Collection): ប្រមូលសំឡេងដ្រូន DJI Phantom 4 និង EVO 2 Pro ចំនួន 1232 គំរូ (រយៈពេលសរុប 204.5 នាទី) ដែលបែងចែកជាដ្រូនមានបន្ទុកទឹក 500ml និងគ្មានបន្ទុក។
  • ការទាញយកលក្ខណៈពិសេសនៃសំឡេង (Audio Feature Extraction): ប្រើប្រាស់បណ្ណាល័យ Librosa ដើម្បីទាញយកលក្ខណៈពិសេសចំនួន 5 រួមមាន MFCC, chroma, mel, contrast, និង tonnetz។
  • ការបណ្តុះបណ្តាលម៉ូដែលរៀនដោយម៉ាស៊ីន (Machine Learning Training): ប្រើប្រាស់ទិន្នន័យលក្ខណៈពិសេសរួមបញ្ចូលគ្នា និងដាច់ដោយឡែក ដើម្បីបង្ហាត់ម៉ូដែលចំនួន 4 រួមមាន Support Vector Machine (SVM), Gaussian Naive Bayes (GNB), K-Nearest Neighbor (KNN), និង Neural Network (NN)។

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ការរួមបញ្ចូលគ្នានៃលក្ខណៈពិសេស (Combination of features) ផ្តល់នូវលទ្ធផលល្អប្រសើរជាងការប្រើលក្ខណៈពិសេសដាច់ដោយឡែក ដោយទទួលបានភាពត្រឹមត្រូវជាមធ្យមប្រមាណ 99% (99% average accuracy) នៅក្នុងម៉ូដែលរៀនដោយម៉ាស៊ីនទាំង 4។
  • ក្នុងចំណោមលក្ខណៈពិសេសដាច់ដោយឡែក (Individual features) MFCC ដំណើរការបានល្អបំផុតសម្រាប់ម៉ូដែល SVM, GNB, និង NN ខណៈពេលដែល chroma ដំណើរការបានល្អបំផុតនៅក្នុងម៉ូដែល KNN។
  • វិធីសាស្រ្តផ្តោតលើវិស្វកម្មលក្ខណៈពិសេសនេះ ទាមទារធនធានកុំព្យូទ័រតិច (Fewer computational resources) និងមានការពន្យល់ច្បាស់លាស់ (Higher explainability) ជាងបើប្រៀបធៀបទៅនឹងការសិក្សាដែលប្រើវិធីសាស្រ្តរ៉ាដា (Micro-Doppler radar)។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Support Vector Machine (SVM)
ម៉ាស៊ីនវ៉ិចទ័រគាំទ្រ (Support Vector Machine)		 មានសមត្ថភាពខ្ពស់ក្នុងការបែងចែកទិន្នន័យនៅពេលប្រើប្រាស់លក្ខណៈពិសេសរួមបញ្ចូលគ្នា (Combined features) និងមានភាពងាយស្រួលក្នុងការកំណត់រចនាសម្ព័ន្ធ (Parameter C=10, linear kernel)។ ទិន្នផលនៃភាពត្រឹមត្រូវមានការធ្លាក់ចុះយ៉ាងខ្លាំងនៅពេលប្រើប្រាស់លក្ខណៈពិសេសដាច់ដោយឡែកមួយចំនួនដូចជា Contrast និង Tonnetz។ ទទួលបានភាពត្រឹមត្រូវ 99.2% (Accuracy) សម្រាប់លក្ខណៈពិសេសរួមបញ្ចូលគ្នា និង 98.6% សម្រាប់ MFCC។
Gaussian Naive Bayes (GNB)
ហ្គោសៀនណាយបាយអេស (Gaussian Naive Bayes)		 ទទួលបានលទ្ធផលល្អឥតខ្ចោះស្មើនឹងម៉ូដែល Neural Network ជាមួយនឹងលក្ខណៈពិសេសរួមបញ្ចូលគ្នា និង MFCC ដោយគ្រាន់តែប្រើប្រាស់ការកំណត់រចនាសម្ព័ន្ធដើម (Default parameters)។ មានដំណើរការខ្សោយបំផុតក្នុងការប្រើប្រាស់លក្ខណៈពិសេស Contrast ដោយទទួលបានភាពត្រឹមត្រូវទាបបំផុតធៀបនឹងម៉ូដែលផ្សេងៗ។ ទទួលបានភាពត្រឹមត្រូវខ្ពស់រហូតដល់ 99.7% ទាំងសម្រាប់លក្ខណៈពិសេសរួមបញ្ចូលគ្នា និង MFCC ចំណែកឯ Contrast ទទួលបានត្រឹម 54.6%។
K-Nearest Neighbor (KNN)
អ្នកជិតខាងជិតបំផុត K (K-Nearest Neighbor)		 ជាម៉ូដែលតែមួយគត់ដែលលក្ខណៈពិសេស Chroma ដាច់ដោយឡែក (99.5%) ដំណើរការបានល្អជាងលក្ខណៈពិសេសរួមបញ្ចូលគ្នា (98.9%)។ ភាពត្រឹមត្រូវនៃលក្ខណៈពិសេសរួមបញ្ចូលគ្នាមានកម្រិតទាបជាងបន្តិចបើប្រៀបធៀបទៅនឹងម៉ូដែល ៣ ផ្សេងទៀត។ ទទួលបានភាពត្រឹមត្រូវ 99.5% សម្រាប់ Chroma ខណៈដែលលក្ខណៈពិសេសរួមបញ្ចូលគ្នាទទួលបាន 98.9%។
Neural Network (NN)
បណ្តាញសរសៃប្រសាទសិប្បនិម្មិត (Neural Network)		 មានសមត្ថភាពខ្ពស់ក្នុងការរៀនលំនាំស្មុគស្មាញ (Complex patterns) ជាមួយនឹងរចនាសម្ព័ន្ធ 3 dense layers, 2 activation layers និង 2 dropout layers។ ទាមទារការរៀបចំរចនាសម្ព័ន្ធម៉ូដែលស្មុគស្មាញជាងម៉ូដែលលីនេអ៊ែរ (Linear models) ផ្សេងទៀត ប៉ុន្តែលទ្ធផលគឺប្រហាក់ប្រហែលនឹង GNB ដែរ។ ទទួលបានភាពត្រឹមត្រូវ 99.7% សម្រាប់ទាំងលក្ខណៈពិសេសរួមបញ្ចូលគ្នា និង MFCC និងមាន F-1 score 0.997។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

ប្រព័ន្ធនេះពិតជាមានសក្តានុពល និងអត្ថប្រយោជន៍ខ្ពស់សម្រាប់ប្រទេសកម្ពុជា ដោយសារវាជាដំណោះស្រាយដែលមានតម្លៃថោកនិងងាយស្រួលអនុវត្តជាងប្រព័ន្ធរ៉ាដាធំៗ។

  • ព្រលានយន្តហោះអន្តរជាតិ (e.g., Phnom Penh International Airport): អាចប្រើប្រាស់ឧបករណ៍ចាប់សញ្ញាសំឡេងនៅជុំវិញរបងព្រលានយន្តហោះ ដើម្បីតាមដានរកមើលដ្រូនដែលហោះហើរខុសច្បាប់ និងអាចបង្កគ្រោះថ្នាក់ដល់សន្តិសុខអាកាសចរណ៍។
  • តំបន់ការពារបេតិកភណ្ឌ (e.g., Angkor Archaeological Park): អាចដាក់ពង្រាយដើម្បីត្រួតពិនិត្យ និងរារាំងដ្រូនដែលលួចហោះហើរថតរូបដោយគ្មានការអនុញ្ញាត ឬអាចផ្ទុកឧបករណ៍ដែលអាចធ្វើឱ្យខូចខាតដល់ប្រាសាទ។
  • ការការពារសន្តិសុខថ្នាក់ជាតិ និងតំបន់ព្រំដែន (National Security): ជួយដល់កងកម្លាំងប្រដាប់អាវុធក្នុងការកំណត់អត្តសញ្ញាណដ្រូនស៊ើបការណ៍ ឬដ្រូនដែលផ្ទុកគ្រឿងផ្ទុះ/អាវុធខុសច្បាប់ឆ្លងកាត់ព្រំដែនបានទាន់ពេលវេលា។

ជារួម ការប្រើប្រាស់បច្ចេកវិទ្យាវិភាគសំឡេងនេះគឺជាជម្រើសដ៏ឆ្លាតវៃសម្រាប់កម្ពុជា ប៉ុន្តែតម្រូវឱ្យមានការកសាងមូលដ្ឋានទិន្នន័យសំឡេង (Audio Dataset) ដែលមានលក្ខណៈចម្រុះនៅក្នុងបរិស្ថានជាក់ស្តែងនៃប្រទេសកម្ពុជាជាមុនសិន។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃការវិភាគសំឡេង (Learn Audio Analysis): ចាប់ផ្តើមសិក្សាពីការប្រើប្រាស់បណ្ណាល័យ Librosa នៅក្នុង Python ដើម្បីយល់ដឹងពីរបៀបទាញយកលក្ខណៈពិសេសនៃសំឡេងដូចជា MFCC, Chroma, និង Mel spectrograms។
  2. ការប្រមូលទិន្នន័យក្នុងស្រុក (Local Data Collection): ប្រើប្រាស់ឧបករណ៍ថតសំឡេង និងដ្រូនទូទៅ (ដូចជា DJI ម៉ូដែលផ្សេងៗ) ដើម្បីថតសំឡេងហោះហើរនៅក្នុងបរិយាកាសផ្សេងៗគ្នានៅកម្ពុជា (ឧទាហរណ៍៖ ទីក្រុងភ្នំពេញ តំបន់ជនបទ) និងសាកល្បងជាមួយបន្ទុកទម្ងន់ខុសៗគ្នា។
  3. ការសាងសង់និងបណ្តុះបណ្តាលម៉ូដែល (Build and Train ML Models): ប្រើប្រាស់បណ្ណាល័យ Scikit-Learn ដើម្បីបង្ហាត់ម៉ូដែលមូលដ្ឋានដូចជា SVM និង KNN ដោយប្រើប្រាស់ទិន្នន័យដែលប្រមូលបាន ហើយវាយតម្លៃលទ្ធផល (Accuracy, F1-Score)។
  4. ការអភិវឌ្ឍប្រព័ន្ធតាមដានជាក់ស្តែង (Develop Real-Time Hardware): សាកល្បងដំឡើងម៉ូដែលដែលជោគជ័យទៅលើឧបករណ៍តូចៗដូចជា Raspberry Pi ភ្ជាប់ជាមួយម៉ៃក្រូហ្វូនដែលមានគុណភាពខ្ពស់ ដើម្បីធ្វើការចាប់សញ្ញាសំឡេងនិងផ្តល់ការព្រមានក្នុងពេលជាក់ស្តែង (Real-time detection)។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Feature Extraction គឺជាដំណើរការនៃការទាញយកលក្ខណៈសម្បត្តិ ឬទិន្នន័យសំខាន់ៗពីទិន្នន័យដើម (ដូចជារលកសំឡេង) ដើម្បីបំប្លែងវាទៅជាទម្រង់លេខ (Vectors) ដែលម៉ាស៊ីនកុំព្យូទ័រអាចយល់ និងរៀនចំណាំបានយ៉ាងងាយស្រួល។ ដូចជាការពណ៌នាពីភ្នាក់ងារសម្ងាត់ម្នាក់ដោយប្រាប់តែពីកម្ពស់ ពណ៌សក់ និងស្នាមសម្លាក ជាជាងការពណ៌នារូបរាងទាំងមូល ដើម្បីឱ្យគេងាយស្រួលចំណាំ។
MFCC គឺជាវិធីសាស្ត្រមួយក្នុងការតំណាងឱ្យលក្ខណៈនៃសំឡេងដោយផ្អែកលើរបៀបដែលត្រចៀកមនុស្សស្តាប់ឮ (Mel scale) ដែលវាជួយបំបែកសំឡេងរំខាន និងចាប់យកតែសម្លេងគោលបានយ៉ាងល្អឥតខ្ចោះ។ ដូចជាឧបករណ៍បំពងសំឡេងឆ្លាតវៃ (Equalizer) ដែលចេះតម្លើងសំឡេងអ្នកចម្រៀង និងបន្ថយសំឡេងភ្លេងរំខានដោយស្វ័យប្រវត្តិ ដើម្បីឱ្យយើងស្តាប់បានច្បាស់។
Support Vector Machine (SVM) គឺជាក្បួនដោះស្រាយរៀនដោយម៉ាស៊ីន (Machine Learning) ដែលមានតួនាទីគូសបន្ទាត់ ឬព្រំដែនគណិតវិទ្យាដ៏ប្រសើរបំផុតមួយ ដើម្បីបែងចែកក្រុមទិន្នន័យផ្សេងៗគ្នាឱ្យដាច់ពីគ្នាបានយ៉ាងច្បាស់លាស់។ ដូចជាការដាក់របាំងខណ្ឌចែកផ្លូវ ដើម្បីបំបែកគន្លងម៉ូតូ និងគន្លងឡានឱ្យដាច់ពីគ្នា ដើម្បីកុំឱ្យមានការភាន់ច្រឡំ។
Chroma គឺជាលក្ខណៈពិសេសនៃសំឡេងដែលផ្តោតទៅលើកម្រិតជម្រាលនៃសូរសព្ទ (Pitch) ដោយបំបែកសំឡេងទៅជាថ្នាក់ខុសៗគ្នាស្រដៀងនឹងណោតភ្លេង ដើម្បីចាប់យកចង្វាក់ ឬលំនាំនៃសំឡេង។ ដូចជាការបែងចែកពណ៌នៃឥន្ធនូទៅជា ៧ ពណ៌ដាច់ដោយឡែកពីគ្នា ដើម្បីងាយស្រួលប្រាប់គេថាវត្ថុមួយមានពណ៌អ្វីខ្លះលាយបញ្ចូលគ្នា។
Micro-Doppler radar គឺជាប្រព័ន្ធរ៉ាដាដែលអាចចាប់សញ្ញាចលនាតូចៗបំផុត (ដូចជាការបង្វិលកង្ហាររបស់ដ្រូន) ដោយវាស់ស្ទង់ការផ្លាស់ប្តូរនៃរលកសញ្ញាដែលជះត្រឡប់មកវិញពីវត្ថុគោលដៅ។ ដូចជាសត្វប្រចៀវបញ្ចេញសំឡេងខ្ទាតប៉ះសត្វល្អិតដែលកំពុងហោះហើរ ហើយស្តាប់សូរត្រឡប់មកវិញដើម្បីដឹងពីទីតាំងនិងទំហំរបស់ចំណីវា។
Acoustic Classification គឺជាការប្រើប្រាស់ប្រព័ន្ធកុំព្យូទ័រដើម្បីស្តាប់ និងធ្វើចំណាត់ថ្នាក់ប្រភេទសំឡេងដោយស្វ័យប្រវត្តិ ថាតើសំឡេងនោះជាសំឡេងអ្វី (ឧទាហរណ៍៖ សំឡេងដ្រូនមានផ្ទុកទម្ងន់ ឬគ្មានផ្ទុកទម្ងន់)។ ដូចជាកម្មវិធី Shazam នៅលើទូរស័ព្ទដៃ ដែលគ្រាន់តែស្តាប់សំឡេងភ្លេងបន្តិច ក៏អាចប្រាប់យើងបានថានោះជាបទចម្រៀងអ្វី។
K-Nearest Neighbor (KNN) គឺជាម៉ូដែលចំណាត់ថ្នាក់ដែលទស្សន៍ទាយប្រភេទនៃទិន្នន័យថ្មីមួយ ដោយមើលទៅលើទិន្នន័យចាស់ៗដែលនៅក្បែរវាបំផុត បើទិន្នន័យនៅក្បែរនោះភាគច្រើនជាអ្វី វានឹងចាត់ទុកទិន្នន័យថ្មីនោះជាប្រភេទនោះដែរ។ ដូចជាការសន្និដ្ឋានថាអ្នកជាមនុស្សចូលចិត្តលេងកីឡា ប្រសិនបើមិត្តភក្តិជិតស្និទ្ធរបស់អ្នកទាំង ៥ នាក់សុទ្ធតែជាអ្នកកីឡា។

៦. ប្រធានបទពាក់ព័ន្ធ (Further Reading)

ប្រធានបទ និងសំណួរស្រាវជ្រាវដែលទាក់ទងនឹងឯកសារនេះ ដែលអ្នកអាចស្វែងរកបន្ថែម៖

  • acoustic signature identification for drone detection
  • micro-Doppler radar feature extraction for UAV classification
  • machine learning models for audio classification
  • real-time drone detection using polyphonic sound data
  • feature engineering techniques for acoustic anomaly detection
