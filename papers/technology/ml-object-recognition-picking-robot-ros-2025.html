  • ការរៀបចំប្រព័ន្ធប្រតិបត្តិការមនុស្សយន្ត (ROS Setup) សម្រាប់ការទំនាក់ទំនងរវាងម៉ូដែល ML និងកម្មវិធីបញ្ជាមនុស្សយន្ត
  • ការគណនាចលនា (Kinematics and Dynamics Library - KDL) សម្រាប់ការធ្វើផែនការគន្លងចលនារបស់ដៃមនុស្សយន្ត
  • ការប្រើប្រាស់បន្ទះគ្រប់គ្រង Raspberry Pi 4 និងម៉ូទ័រ (Servo & Motor Control Shields) សម្រាប់ប្រតិបត្តិការកុំព្យូទ័រ និងចលនា

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ម៉ូដែលនេះបង្ហាញពីដំណើរការដ៏ល្អប្រសើរក្នុងការកំណត់អត្តសញ្ញាណវត្ថុពិតប្រាកដ (High TPR) និងកាត់បន្ថយការកំណត់ខុស (Low FPR) ដោយផ្អែកលើការវាយតម្លៃខ្សែកោង ROC។
  • ប្រព័ន្ធមនុស្សយន្តនេះអាចកំណត់ទីតាំងវត្ថុ ធ្វើផែនការចលនា និងបញ្ជាឱ្យចុងដៃមនុស្សយន្ត (End-effector) ចាប់យកវត្ថុបានយ៉ាងជោគជ័យក្នុងពេលជាក់ស្តែង (Real-time)។
  • ការបង្កើតប្រព័ន្ធនេះផ្តល់នូវសក្តានុពលយ៉ាងធំធេងសម្រាប់ស្វ័យប្រវត្តិកម្មកម្រិតខ្ពស់នៅក្នុងវិស័យឃ្លាំងទំនិញ ផលិតកម្មរោងចក្រ និងកម្មវិធីថែទាំសុខភាព។

YOLO V5 with ROS Integration (Proposed)
ការប្រើប្រាស់ YOLO V5 រួមបញ្ចូលជាមួយប្រព័ន្ធ ROS		 មានសមត្ថភាពខ្ពស់ក្នុងការសម្គាល់វត្ថុក្នុងពេលជាក់ស្តែង (Real-time) និងអាចបែងចែកវត្ថុពិតនិងមិនពិតបានយ៉ាងល្អ។ មានភាពបត់បែនខ្ពស់ក្នុងការគ្រប់គ្រងចលនាមនុស្សយន្តតាមរយៈ ROS។ ទាមទារការពង្រឹងទិន្នន័យ (Data Augmentation) និងការកំណត់រចនាសម្ព័ន្ធទំនាក់ទំនងស្មុគស្មាញរវាង Machine Learning និងប្រព័ន្ធបញ្ជាមនុស្សយន្ត។ ទទួលបានអត្រា True Positive Rate (TPR) ខ្ពស់ និង False Positive Rate (FPR) ទាប ដែលបង្ហាញលើខ្សែកោង ROC ថាវាដំណើរការបានយ៉ាងប្រសើរ។
Random Classifier (Baseline)
ចំណាត់ថ្នាក់ចៃដន្យ (ចំណុចគោល)		 មិនត្រូវការការហ្វឹកហាត់ ឬធនធានកុំព្យូទ័រស្មុគស្មាញសម្រាប់ការគណនាឡើយ។ គ្មានភាពត្រឹមត្រូវក្នុងការសម្គាល់វត្ថុឡើយ ដោយពឹងផ្អែកលើការទាយចៃដន្យទាំងស្រុង។ ដំណើរការស្ថិតនៅលើបន្ទាត់អង្កត់ទ្រូងនៃខ្សែកោង ROC ដែលមានន័យថាវាគ្មានសមត្ថភាពក្នុងការបែងចែកវត្ថុពិតប្រាកដ និងសញ្ញាខុសនោះទេ។
Color-based Object Detection
ការសម្គាល់វត្ថុផ្អែកលើពណ៌ (លើកឡើងក្នុងឯកសារយោង)		 ងាយស្រួលក្នុងការរៀបចំ និងដំណើរការលឿនសម្រាប់បរិស្ថានដែលមានពណ៌ច្បាស់លាស់ និងមិនមានការប្រែប្រួល។ ងាយរងឥទ្ធិពលពីពន្លឺបរិស្ថាន និងមិនអាចសម្គាល់វត្ថុដែលមានពណ៌ដូចគ្នា ឬមានភាពស្មុគស្មាញបាន។ ប្រើប្រាស់បានសម្រាប់តែករណីសិក្សាជាក់លាក់នៅកន្លែងដែលវត្ថុមានពណ៌លេចធ្លោដាច់ពីគេ។

ការចំណាយលើធនធាន (Resource Cost)៖ ការបង្កើតប្រព័ន្ធនេះទាមទារផ្នែករឹង (Hardware) ដែលមានតម្លៃសមរម្យដូចជា Raspberry Pi 4 ព្រមទាំងកម្មវិធីកូដបើកចំហ (Open-source) សម្រាប់ការអភិវឌ្ឍ។

  • Hardware: កុំព្យូទ័រខ្នាតតូច Raspberry Pi 4 (RAM 2GB ដល់ 8GB), កាមេរ៉ា 2D (Webcam), បន្ទះបញ្ជាម៉ូទ័រ (Servo & Motor Control Shields) និងដៃមនុស្សយន្ត (Manipulator Arm)។
  • Software: ប្រព័ន្ធប្រតិបត្តិការមនុស្សយន្ត (ROS), កម្មវិធី PyTorch សម្រាប់ហ្វឹកហាត់ម៉ូដែល, និងកម្មវិធី Gazebo សម្រាប់ការក្លែងធ្វើបរិស្ថាន 3D។
  • Dataset: ទិន្នន័យរូបភាពវត្ថុចម្រុះដែលត្រូវការការកែច្នៃ និងពង្រីក (Data Augmentation ដូចជាការកាត់ ឬធ្វើឱ្យព្រិល) ដើម្បីបង្កើនចំនួនទិន្នន័យ។
  • Expertise: ចំណេះដឹងផ្នែកបណ្ដាញសរសៃប្រសាទ (CNNs/YOLO), ការប្រើប្រាស់ ROS, និងការគណនាចលនាមនុស្សយន្ត (Kinematics and Dynamics)។

  • វិស័យផលិតកម្ម និងរោងចក្រ (តំបន់សេដ្ឋកិច្ចពិសេស): អាចប្រើប្រាស់មនុស្សយន្តប្រភេទនេះដើម្បីរៀបចំ បែងចែកទំនិញ ឬគ្រឿងបន្លាស់នៅលើខ្សែសង្វាក់ផលិតកម្មនៅតំបន់សេដ្ឋកិច្ចពិសេសភ្នំពេញ ឬក្រុងព្រះសីហនុបានយ៉ាងរហ័ស។
  • វិស័យភស្តុភារ និងឃ្លាំងទំនិញ (Logistics & Warehousing): ជួយក្នុងការស្វែងរក ចាប់យក និងរៀបចំកញ្ចប់ទំនិញតាមប្រភេទនៅក្នុងឃ្លាំងស្តុកធំៗ ធ្វើឱ្យប្រតិបត្តិការមានប្រសិទ្ធភាព និងកាត់បន្ថយកំហុសរបស់មនុស្ស។
  • វិស័យកសិកម្ម (ការវេចខ្ចប់កសិផល): អាចអភិវឌ្ឍបន្ថែមដើម្បីសម្គាល់ និងរើសផ្លែឈើ ឬបន្លែដែលមានគុណភាពល្អសម្រាប់ការវេចខ្ចប់នាំចេញទៅកាន់ទីផ្សារអន្តរជាតិ។

ការប្រើប្រាស់ផ្នែករឹងតម្លៃថោកដូចជា Raspberry Pi ធ្វើឱ្យបច្ចេកវិទ្យានេះងាយស្រួលក្នុងការស្រាវជ្រាវ និងអាចដាក់ឱ្យដំណើរការសម្រាប់សហគ្រាសធុនតូច និងមធ្យមនៅកម្ពុជាបាន។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃ ROS និឹង Gazebo: ចាប់ផ្តើមរៀនពី Robot Operating System (ROS) និងសាកល្បងបង្កើតបរិស្ថានក្លែងធ្វើ (Simulation) របស់ដៃមនុស្សយន្តនៅក្នុងកម្មវិធី Gazebo។
  2. ហ្វឹកហាត់ម៉ូដែលសម្គាល់វត្ថុ (Object Detection): អនុវត្តការសរសេរកូដហ្វឹកហាត់ម៉ូដែលដោយប្រើប្រាស់ស្ថាបត្យកម្ម YOLO V5 នៅក្នុងបរិស្ថាន PyTorch ជាមួយនឹងសំណុំទិន្នន័យរូបភាពដែលអ្នកប្រមូលបាន។
  3. រៀបចំផ្នែករឹង និងប្រព័ន្ធទំនាក់ទំនង (Hardware Setup): តំឡើង Raspberry Pi 4 ភ្ជាប់ជាមួយ Webcam និងបន្ទះបញ្ជា Servo & Motor Control Shields ដើម្បីត្រៀមបញ្ជាម៉ូទ័ររបស់ដៃមនុស្សយន្ត។
  4. ធ្វើសមាហរណកម្មប្រព័ន្ធ (System Integration): ភ្ជាប់ម៉ូដែល YOLO V5 ទៅកាន់ ROS nodes ដើម្បីឱ្យកាមេរ៉ាអាចសម្គាល់វត្ថុ និងគណនាទីតាំងវត្ថុនោះ (Object Localization) ក្នុងពេលជាក់ស្តែង។
  5. អនុវត្តការធ្វើផែនការចលនា (Motion Planning): ប្រើប្រាស់កញ្ចប់ MoveIt និងបណ្ណាល័យ Kinematics and Dynamics Library (KDL) នៅក្នុង ROS ដើម្បីគណនាគន្លងចលនា និងបញ្ជាឱ្យដៃមនុស្សយន្តទៅចាប់វត្ថុដោយសុវត្ថិភាព។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Robot Operating System (ROS) ជាប្រព័ន្ធកូដបើកចំហ (Open-source framework) ដែលផ្តល់នូវបណ្ណាល័យ ឧបករណ៍ និងក្បួនសម្រាប់ជួយអ្នកអភិវឌ្ឍន៍ក្នុងការបង្កើតកម្មវិធីបញ្ជាមនុស្សយន្ត ដោយភ្ជាប់គ្រឿងបន្លាស់ (Sensor និងម៉ូទ័រ) និងកម្មវិធីផ្សេងៗបញ្ចូលគ្នាយ៉ាងងាយស្រួល។ ដូចជាប្រព័ន្ធប្រតិបត្តិការ Windows ឬ Android ដែរ ប៉ុន្តែវាត្រូវបានបង្កើតឡើងជាពិសេសសម្រាប់បញ្ជា និងសម្របសម្រួលដំណើរការរបស់មនុស្សយន្ត។
Convolutional Neural Networks (CNNs) ជាប្រភេទនៃបណ្តាញសរសៃប្រសាទសិប្បនិម្មិត (AI algorithm) ដែលមានជំនាញខ្ពស់ក្នុងការវិភាគទិន្នន័យរូបភាព ដើម្បីទាញយកលក្ខណៈពិសេសៗដូចជារាង ទំហំ និងពណ៌សម្រាប់សម្គាល់វត្ថុ។ ដូចជាប្រព័ន្ធភ្នែក និងខួរក្បាលរបស់មនុស្សដែលចេះមើល និងចំណាំមុខមាត់ ឬរូបរាងរបស់វត្ថុផ្សេងៗដោយស្វ័យប្រវត្តិ។
YOLO V5 មកពីពាក្យ You Only Look Once គឺជាស្ថាបត្យកម្ម AI ដ៏មានប្រសិទ្ធភាពមួយសម្រាប់សម្គាល់វត្ថុក្នុងពេលជាក់ស្តែង (Real-time) ដោយវាវិភាគរូបភាពទាំងមូលតែម្តងគត់ដើម្បីរកមើលថាតើមានវត្ថុអ្វីខ្លះ និងនៅទីតាំងណា។ ដូចជាមនុស្សដែលក្រឡេកមើលរូបថតមួយភ្លែត ក៏អាចប្រាប់បានភ្លាមៗថាមានរបស់អ្វីខ្លះ និងនៅត្រង់ណាខ្លះក្នុងរូបនោះ ដោយមិនបាច់ស្វែងរកម្តងមួយជ្រុងៗឡើយ។
Kinematics and Dynamics Library (KDL) ជាបណ្ណាល័យគណិតវិទ្យានៅក្នុងបរិស្ថាន ROS ដែលប្រើសម្រាប់គណនាចលនារបស់សន្លាក់មនុស្សយន្ត (Kinematics) និងកម្លាំងដែលពាក់ព័ន្ធ (Dynamics) ដើម្បីឲ្យវាអាចធ្វើចលនាឈោងចាប់វត្ថុបានចំគោលដៅនិងរលូន។ ដូចជាការគណនារបស់ខួរក្បាលយើង ដែលប្រាប់សាច់ដុំដៃថាតើត្រូវបត់កែងដៃកម្រិតណា ដើម្បីអាចឈោងចាប់កែវទឹកនៅលើតុបានត្រឹមត្រូវ។
Inverse Kinematics ជាការគណនាក្បួនគណិតវិទ្យាត្រឡប់ថយក្រោយ ដោយផ្តើមចេញពីទីតាំងគោលដៅដែលចុងដៃមនុស្សយន្ត (End-effector) ត្រូវទៅដល់ ដើម្បីទាញរកមុំសន្លាក់នីមួយៗរបស់មនុស្សយន្តដែលត្រូវបង្វិល។ ដូចជាការដឹងជាមុនថាអ្នកចង់ចង្អុលម្រាមដៃទៅកាន់ចំណុចមួយ រួចទើបរាងកាយគិតដោយស្វ័យប្រវត្តិថាត្រូវលើកស្មា និងបត់កែងដៃក្នុងមុំប៉ុន្មានទើបអាចចង្អុលចំ។
ROC Curve មកពីពាក្យ Receiver Operating Characteristic គឺជាខ្សែកោងក្រាហ្វិកដែលប្រើសម្រាប់វាស់ស្ទង់សមត្ថភាពរបស់ម៉ូដែល AI ក្នុងការបែងចែករវាងវត្ថុពិតប្រាកដ (True Positive) និងការចំណាំខុស (False Positive) នៅគ្រប់កម្រិតនៃកម្រិតកំណត់ (Thresholds)។ ដូចជាតារាងពិន្ទុវាយតម្លៃសិស្សម្នាក់ ថាតើគេពូកែឆ្លើយត្រូវ (ឆ្លាតពិតប្រាកដ) និងកម្រឆ្លើយខុស (មិនទាយព្រាវ) កម្រិតណា។
Data Augmentation ជាបច្ចេកទេសក្នុងការបង្កើតទិន្នន័យហ្វឹកហាត់ថ្មីៗបន្ថែមពីទិន្នន័យដើមដែលមានស្រាប់ តាមរយៈការកាត់រូបភាព (Cropping) ការបង្វិល ឬការធ្វើឱ្យព្រិល (Blurring) ដើម្បីឱ្យម៉ូដែល AI រៀនស្គាល់វត្ថុក្នុងស្ថានភាពចម្រុះជាច្រើន។ ដូចជាការថតរូបសៀវភៅមួយក្បាលពីជ្រុងផ្សេងៗគ្នា ក្រោមពន្លឺខុសៗគ្នា ដើម្បីឲ្យក្មេងម្នាក់អាចចំណាំសៀវភៅនោះបាន ទោះវានៅក្នុងស្ថានភាពណាក៏ដោយ។
Pulse Width Modulation (PWM) ជាបច្ចេកទេសគ្រប់គ្រងល្បឿនរបស់ម៉ូទ័រ (DC motors) ដោយការបិទបើកចរន្តអគ្គិសនីយ៉ាងលឿន (បង្កើតជារលកសញ្ញា) ដែលធ្វើឱ្យកម្រិតវ៉ុលមធ្យមប្រែប្រួលតាមតម្រូវការជាក់លាក់។ ដូចជាការបើកនិងបិទកុងតាក់ចង្កៀងលឿនៗជាបន្តបន្ទាប់ ដើម្បីធ្វើឲ្យពន្លឺរបស់វាមើលទៅស្រទន់ ឬភ្លឺខ្លាំងតាមចិត្តចង់។
