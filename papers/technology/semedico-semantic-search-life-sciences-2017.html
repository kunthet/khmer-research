លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

ប្រព័ន្ធស្វែងរកកម្រិតខ្ពស់នេះមានអត្ថប្រយោជន៍យ៉ាងខ្លាំង សម្រាប់ការស្រាវជ្រាវក្នុងវិស័យសុខាភិបាល និងវិទ្យាសាស្ត្រជីវិតនៅកម្ពុជា។

  • សាកលវិទ្យាល័យវិទ្យាសាស្ត្រសុខាភិបាល (UHS): និស្សិតពេទ្យ និងសាស្ត្រាចារ្យអាចប្រើប្រាស់គំរូនៃប្រព័ន្ធនេះ ដើម្បីរុករកឯកសារស្រាវជ្រាវអំពីអន្តរកម្មថ្នាំ និងរោគវិទ្យាបានលឿន ដោយមិនបាច់ចំណាយពេលអានឯកសារដែលមិនទាក់ទង។
  • វិទ្យាស្ថានជាតិសុខភាពសាធារណៈ (NIPH): គាំទ្រដល់អ្នកស្រាវជ្រាវកម្ពុជាក្នុងការតាមដាន និងទាញយកទិន្នន័យជាក់លាក់ទាក់ទងនឹងជំងឺឆ្លង ឬរោគរាតត្បាត តាមរយៈការវិភាគសេចក្តីថ្លែងការណ៍ដែលមានភាពប្រាកដប្រជា (Factuality)។
  • ក្រសួងកសិកម្ម រុក្ខាប្រមាញ់ និងនេសាទ: ស្ថាបត្យកម្មប្រព័ន្ធនេះអាចត្រូវបានយកទៅកែច្នៃ ដើម្បីបង្កើតម៉ាស៊ីនស្វែងរកឯកសារស្រាវជ្រាវផ្នែកកសិកម្ម ទាក់ទងនឹងហ្សែនពូជស្រូវ ឬរោគសញ្ញាជំងឺសត្វ។

សរុបមក ការអនុវត្តបច្ចេកវិទ្យា Semantic Search តាមទម្រង់ SEMEDICO នឹងជួយសម្រួលដល់អ្នកស្រាវជ្រាវកម្ពុជា ក្នុងការទទួលបានព័ត៌មានវិទ្យាសាស្ត្រច្បាស់លាស់ និងមានប្រសិទ្ធភាពខ្ពស់។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីមូលដ្ឋានគ្រឹះនៃការទាញយកព័ត៌មាន និងម៉ាស៊ីនស្វែងរក: ចាប់ផ្តើមរៀនពីគោលការណ៍ Information Retrieval ដូចជាការដាក់ពិន្ទុឯកសារដោយប្រើ TF-IDF និងការអនុវត្តប្រព័ន្ធ Elasticsearch សម្រាប់បង្កើតលិបិក្រម (Indexing) និងការស្វែងរកអត្ថបទ។
  2. ស្វែងយល់ពីបច្ចេកវិទ្យាដំណើរការភាសាធម្មជាតិ (NLP) ក្នុងកម្រិតអត្ថន័យ: សិក្សាពីបច្ចេកទេសទាញយកព័ត៌មានពីអត្ថបទ (Text Mining) រួមមានការសម្គាល់ឈ្មោះអង្គភាព (NER) និងការទាញយកទំនាក់ទំនង (Relation Extraction) ដោយសាកល្បងប្រើ Apache UIMA និង JCoRe។
  3. កសាង និងគ្រប់គ្រងប្រព័ន្ធចំណេះដឹង (Ontology): រៀនរៀបចំរចនាសម្ព័ន្ធទិន្នន័យ និងចំណេះដឹងតាមបែបឋានានុក្រម ដោយប្រើប្រាស់មូលដ្ឋានទិន្នន័យក្រាហ្វិក ដូចជាការដំឡើងនិងប្រើប្រាស់ Neo4j។
  4. បង្កើតចំណុចប្រទាក់អ្នកប្រើប្រាស់ (Front-end Web Development): អនុវត្តការសរសេរកូដបង្កើតផ្ទាំងស្វែងរក (Search UI) ដែលមានមុខងារផ្តល់យោបល់ និងរំលេចពាក្យ (Highlighting) ដោយប្រើប្រាស់ Web frameworks ដូចជា Apache Tapestry ឬបច្ចេកវិទ្យាទំនើបដូចជា React រួមជាមួយ JQuery Token Plugin សម្រាប់បំបែកពាក្យគន្លឹះ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Semantic search engine ប្រព័ន្ធស្វែងរកដែលមិនត្រឹមតែពឹងផ្អែកលើការផ្គូផ្គងពាក្យគន្លឹះប៉ុណ្ណោះទេ ប៉ុន្តែវិភាគយល់ពីអត្ថន័យ និងទំនាក់ទំនងរវាងពាក្យដើម្បីទាញយកលទ្ធផលដែលពាក់ព័ន្ធ និងត្រឹមត្រូវបំផុតតាមបរិបទ។ ដូចជាបណ្ណារក្សដែលដឹងថាអ្នកចង់រកសៀវភៅអំពី "សត្វឆ្កែ" ទោះបីជាអ្នកវាយពាក្យថា "សត្វចិញ្ចឹមដែលចេះព្រុស" ក៏ដោយ។
Factuality rating ការវាយតម្លៃកម្រិតនៃភាពប្រាកដប្រជា ឬការពិតនៃសេចក្តីថ្លែងការណ៍នៅក្នុងអត្ថបទ ដោយផ្អែកលើពាក្យសម្គាល់ (ឧ. "អាចនឹង", "បញ្ជាក់ថា", "មិនមែន") ដើម្បីផ្តល់អាទិភាពដល់ព័ត៌មានដែលច្បាស់លាស់ជាងគេក្នុងបញ្ជីលទ្ធផល។ ដូចជាការដាក់ពិន្ទុលើពាក្យចចាមអារ៉ាម ដោយផ្តល់ពិន្ទុខ្ពស់ដល់អ្នកដែលឃើញផ្ទាល់ភ្នែក និងពិន្ទុទាបដល់អ្នកដែលគ្រាន់តែលឺគេនិយាយតៗគ្នា។
Ontologies ការរៀបចំនិងចាត់ថ្នាក់ពាក្យ ឬគំនិតក្នុងវិស័យណាមួយ (ដូចជាវិទ្យាសាស្ត្រជីវិត) ជាប្រព័ន្ធឋានានុក្រម និងបណ្តាញទំនាក់ទំនង ដែលជួយឱ្យកុំព្យូទ័រយល់ពីរបៀបដែលគំនិតទាំងនោះទាក់ទងគ្នាតាមបែបឡូជីខល។ ដូចជាមែកធាងគ្រួសារនៃពាក្យ ដែលបង្ហាញថា "ផ្លែប៉ោម" គឺជាកូនរបស់ "ផ្លែឈើ" ហើយជាចៅរបស់ "រុក្ខជាតិ"។
Named entity recognition បច្ចេកទេសក្នុងដំណើរការភាសាធម្មជាតិ (NLP) ដែលស្វែងរក និងចាត់ថ្នាក់ពាក្យជាក់លាក់នៅក្នុងអត្ថបទទៅជាប្រភេទផ្សេងៗ ដូចជា ឈ្មោះហ្សែន ប្រូតេអ៊ីន ជំងឺ ថ្នាំ ឬឈ្មោះប្រភេទសត្វ។ ដូចជាការប្រើហ្វឺតពណ៌ (Highlighter) គូសពីលើពាក្យក្នុងសៀវភៅ ដោយកំណត់ពណ៌ក្រហមសម្រាប់ឈ្មោះមនុស្ស និងពណ៌ខៀវសម្រាប់ឈ្មោះទីកន្លែង។
Epistemic modalities ការប្រើប្រាស់ពាក្យ ឬកន្សោមពាក្យដែលបង្ហាញពីកម្រិតនៃជំនឿ ការប៉ាន់ស្មាន ឬប្រូបាប៊ីលីតេរបស់អ្នកនិពន្ធទៅលើអ្វីមួយនៅក្នុងអត្ថបទ (ឧទាហរណ៍៖ "ប្រហែលជា", "យើងជឿជាក់ថា", "អាចជា")។ ដូចជារបៀបដែលគ្រូពេទ្យនិយាយថា "អ្នកប្រហែលជាផ្ដាសាយ" (មិនសូវច្បាស់) ធៀបនឹង "អ្នកពិតជាមានជំងឺផ្ដាសាយប្រាកដមែន" (ច្បាស់លាស់១០០%)។
TF-IDF ក្បួនដោះស្រាយសម្រាប់វាស់ស្ទង់សារៈសំខាន់នៃពាក្យមួយនៅក្នុងឯកសារ ដោយប្រៀបធៀបភាពញឹកញាប់នៃការលេចឡើងរបស់វានៅក្នុងឯកសារនោះ ធៀបនឹងចំនួនឯកសារសរុបទាំងអស់ដែលមានពាក្យនេះ។ ដូចជាការវាយតម្លៃភាពកម្រនៃកាក់អញ្ចឹង កាក់ដែលមានច្រើនទូទៅមិនសូវមានតម្លៃទេ តែបើកាក់នោះមានច្រើនតែក្នុងប្រអប់របស់អ្នកហើយកម្រមាននៅកន្លែងផ្សេង នោះវាពិតជាសំខាន់ និងមានតម្លៃសម្រាប់អ្នក។
