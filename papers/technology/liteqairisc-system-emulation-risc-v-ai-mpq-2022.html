  • ការស្រាវជ្រាវ និងការរចនាបន្ទះឈីប (IC Design) ក្នុងសាកលវិទ្យាល័យ: វិទ្យាស្ថានបច្ចេកវិទ្យានៅកម្ពុជា (ITC ឬ NIPTICT) អាចប្រើប្រាស់ក្របខ័ណ្ឌ LiteX នេះ ដើម្បីបង្កើតកម្មវិធីសិក្សា និងឱ្យនិស្សិតរៀនរចនាស្ថាបត្យកម្ម RISC-V ដោយមិនចាំបាច់ចំណាយលុយរាប់លានដុល្លារផលិតបន្ទះឈីបពិតប្រាកដ (ASIC tape-out) ឡើយ ដោយគ្រាន់តែប្រើប្រាស់ FPGA តម្លៃថោក។
  • ប្រព័ន្ធអ៊ីនធឺណិតនៃសព្វវត្ថុ (IoT Devices) សន្សំសំចៃថាមពល: ក្រុមហ៊ុន Startups នៅកម្ពុជាអាចយកគំរូនៃប្រព័ន្ធបរិមាណកម្មកម្រិតច្បាស់ (Mixed-Precision Quantization) នេះ ដើម្បីផលិតឧបករណ៍តាមដានគុណភាពខ្យល់ ឬចរាចរណ៍ក្នុងទីក្រុងឆ្លាតវៃ (Smart City) ដែលប្រើប្រាស់ថាមពលថ្មបានយូរ។

ជារួម ការរួមបញ្ចូលបច្ចេកវិទ្យា AI ទៅក្នុងបំពង់ដំណើរការនៃបន្ទះឈីប RISC-V ផ្តល់នូវដំណោះស្រាយបច្ចេកវិទ្យាដែលឯករាជ្យ សន្សំសំចៃថាមពល និងមានតម្លៃទាប ដែលស័ក្តិសមបំផុតសម្រាប់ការច្នៃប្រឌិតបច្ចេកវិទ្យាក្នុងប្រទេសកំពុងអភិវឌ្ឍ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. យល់ដឹងពីមូលដ្ឋានគ្រឹះនៃស្ថាបត្យកម្ម RISC-V: ចាប់ផ្តើមសិក្សាពីរបៀបដំណើរការរបស់អង្គគណនា (Processor Pipeline) ការរចនាបណ្តុំបញ្ជា (ISA) និងស្វែងយល់ពីប្រព័ន្ធអេកូឡូស៊ីបើកទូលាយតាមរយៈឯកសារផ្លូវការរបស់ RISC-V International។
  2. អនុវត្តការសរសេរកូដផ្នែករឹង (Hardware Description Language): រៀនសរសេរកូដផ្នែករឹងដោយប្រើប្រាស់ Verilog, SystemVerilog ឬ SpinalHDL និងប្រើប្រាស់កម្មវិធីក្លែងធ្វើ Verilator ដើម្បីពិនិត្យមើលដំណើរការនៃសៀគ្វីឌីជីថលដែលអ្នកបានរចនា។
  3. អនុវត្តការប្រើប្រាស់ឧបករណ៍ LiteX SoC Builder: ដំឡើងនិងប្រើប្រាស់ LiteX Framework ដើម្បីសាកល្បងបង្កើតប្រព័ន្ធលើបន្ទះឈីប (SoC) សាមញ្ញមួយ ដោយប្រើប្រាស់អង្គគណនាដែលមានស្រាប់ដូចជា VexRiscv ជាការអនុវត្តមុននឹងឈានដល់ការបង្កើតស្នូលកុំព្យូទ័រផ្ទាល់ខ្លួន។
  4. សិក្សាពីការបង្រួមទំហំម៉ូដែល AI (Model Quantization): ប្រើប្រាស់កម្មវិធីបកប្រែកូដ AI បើកទូលាយដូចជា Apache TVM ឬ microTVM ដើម្បីសិក្សាពីរបៀបបំប្លែងម៉ូដែល AI ធំៗ (FP32) ទៅជាកម្រិតទាប (INT8 ឬ INT4) សម្រាប់ដំណើរការលើឧបករណ៍តូចៗ (Edge Devices)។
  5. សាកល្បងគម្រោងលើបន្ទះ FPGA តម្លៃសមរម្យ: ចាប់ផ្តើមអនុវត្តគម្រោងរបស់អ្នកនៅលើបន្ទះ FPGA កម្រិតសិក្សា ដូចជា PYNQ-Z1 ឬ Arty-A7 ជំនួសឱ្យការប្រើប្រាស់បន្ទះ Xilinx VC707 ដ៏មានតម្លៃថ្លៃ ដើម្បីតេស្តដំណើរការនៃបច្ចេកវិទ្យា Edge AI ដោយផ្ទាល់ភ្នែក។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Mixed-precision Quantization (MPQ) ដំណើរការកាត់បន្ថយទំហំទិន្នន័យនៃម៉ូដែល AI ដោយប្រើប្រាស់ចំនួនប៊ីត (bit-width) ផ្សេងៗគ្នាសម្រាប់ស្រទាប់នីមួយៗនៃម៉ូដែល (ឧទាហរណ៍ 4-bit ខ្លះ និង 8-bit ខ្លះ) ដើម្បីរក្សាតុល្យភាពរវាងភាពត្រឹមត្រូវនៃលទ្ធផល និងទំហំផ្ទុកផ្នែករឹង។ ប្រៀបដូចជាការខ្ចប់អីវ៉ាន់ដោយប្រើប្រអប់តូចសម្រាប់របស់តូច និងប្រអប់ធំសម្រាប់របស់ធំ ដើម្បីសន្សំទំហំផ្ទុក ជាជាងការប្រើប្រអប់ធំទាំងអស់។
Field Programmable Gate Array (FPGA) បន្ទះសៀគ្វីអេឡិចត្រូនិកដែលអាចត្រូវបានសរសេរកូដ ឬរៀបចំរចនាសម្ព័ន្ធផ្នែករឹងឡើងវិញដោយអ្នកប្រើប្រាស់ បន្ទាប់ពីវាត្រូវបានផលិតរួច ដើម្បីបង្កើតជាប្រព័ន្ធកុំព្យូទ័រ ឬឧបករណ៍បង្កើនល្បឿនផ្សេងៗ។ ប្រៀបដូចជាដុំឡេហ្គោ (Lego) ដែលអ្នកអាចដោះចេញ និងតម្រៀបសារជាថ្មីដើម្បីបង្កើតជារូបរាងម៉ាស៊ីន ឬឧបករណ៍អ្វីក៏បានតាមចិត្តចង់។
System-on-Chip (SoC) ការរួមបញ្ចូលសមាសធាតុទាំងអស់នៃកុំព្យូទ័រ ឬប្រព័ន្ធអេឡិចត្រូនិក ដូចជាអង្គគណនា (CPU) អង្គចងចាំ (Memory) និងរន្ធតភ្ជាប់ (I/O ports) ទៅក្នុងបន្ទះឈីប (Microchip) តែមួយ។ ប្រៀបដូចជាផ្ទះមួយដែលមានបន្ទប់គេង ផ្ទះបាយ និងបន្ទប់ទឹក រៀបចំរួចជាស្រេចនៅក្នុងទីតាំងតែមួយ ដោយមិនបាច់ដើរទៅអគារផ្សេង។
Instruction Set Architecture (ISA) វចនានុក្រម ឬបណ្តុំនៃកូដបញ្ជាដែលតភ្ជាប់រវាងផ្នែកទន់ (Software) និងផ្នែករឹង (Hardware) ដោយប្រាប់ពីរបៀបដែលអង្គគណនា (Processor) ត្រូវយល់ និងអនុវត្តតាមកូដកម្មវិធី។ ប្រៀបដូចជាសៀវភៅណែនាំ ឬភាសាបកប្រែដែលជួយឱ្យអ្នកបញ្ជា (កម្មវិធី) អាចនិយាយស្តី និងប្រាប់ឱ្យអ្នកធ្វើការ (ម៉ាស៊ីន) ធ្វើតាមបានយ៉ាងត្រឹមត្រូវ។
Bit Operation Count (BOPs) រង្វាស់សម្រាប់វាស់ស្ទង់ទំហំនៃប្រតិបត្តិការគណនាកម្រិតប៊ីត (Bit) នៅក្នុងម៉ូដែល AI ដែលត្រូវបានប្រើជាតំណាងដើម្បីវាយតម្លៃការស៊ីភ្លើង និងកម្លាំងម៉ាស៊ីនដែលត្រូវចំណាយ។ ប្រៀបដូចជាការរាប់ចំនួនជំហានដែលអ្នកត្រូវដើរដើម្បីបំពេញកិច្ចការមួយ ដើរចំនួនជំហានកាន់តែតិច ចំណាយកម្លាំង (ថាមពល) កាន់តែតិច។
Cycle-Accurate Simulator កម្មវិធីក្លែងធ្វើកុំព្យូទ័រដែលអាចចម្លងដំណើរការរបស់បន្ទះឈីបបានយ៉ាងលម្អិត និងច្បាស់លាស់បំផុត ដោយគិតគូរពីគ្រប់វដ្តនាឡិកា (Clock cycle) របស់ប្រព័ន្ធផ្នែករឹងពិតប្រាកដ។ ប្រៀបដូចជាការមើលវីដេអូយឺតៗ (Slow-motion) ដែលអ្នកអាចឃើញចលនាលម្អិតនៃវិនាទីនីមួយៗ ដោយមិនរំលងសកម្មភាពណាមួយឡើយ។
Bare metal ការដំណើរការកម្មវិធីកុំព្យូទ័រដោយផ្ទាល់នៅលើផ្នែករឹង (Hardware) ដោយមិនចាំបាច់មានប្រព័ន្ធប្រតិបត្តិការ (Operating System ដូចជា Windows ឬ Linux) ធ្វើជាអន្តរការីនៅកណ្តាលឡើយ។ ប្រៀបដូចជាការបើកបររថយន្តដោយប្រើប្រអប់លេខដៃផ្ទាល់ ដោយមិនពឹងផ្អែកលើប្រព័ន្ធបើកបរស្វ័យប្រវត្តិដើម្បីបញ្ជាជំនួសអ្នកឡើយ។
Vector-Matrix Multiply (VMM) ប្រតិបត្តិការគណិតវិទ្យាដែលគុណវ៉ិចទ័រជាមួយម៉ាទ្រីស ដែលជាប្រតិបត្តិការចម្បង និងប្រើប្រាស់ច្រើនបំផុតសម្រាប់ការវិភាគ និងដំណើរការទិន្នន័យនៅក្នុងបណ្តាញសរសៃប្រសាទសិប្បនិម្មិត (Neural Networks) របស់ AI។ ប្រៀបដូចជាការគណនាតម្លៃទំនិញច្រើនមុខក្នុងពេលតែមួយ ដោយយកបរិមាណទំនិញ (វ៉ិចទ័រ) ទៅគុណនឹងតារាងតម្លៃ (ម៉ាទ្រីស) ដើម្បីចេញលទ្ធផលសរុបលឿន។
