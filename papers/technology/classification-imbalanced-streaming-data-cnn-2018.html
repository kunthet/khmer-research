ចំណងជើងដើម៖ AN ACCURATE CLASSIFICATION OF IMBALANCED STREAMING DATA USING DEEP CONVOLUTIONAL NEURAL NETWORK

អ្នកនិពន្ធ៖ Yerremsetty Tayar (Acharaya Nagarjuna University), R.Siva Ram Prasad (Acharaya Nagarjuna University), S.Satayanarayana (Koneru Lakshmaiah Education Foundation)

វិស័យសិក្សា៖ Machine Learning

១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ឯកសារនេះដោះស្រាយបញ្ហានៃការធ្វើចំណាត់ថ្នាក់ទិន្នន័យស្ទ្រីមដែលគ្មានតុល្យភាព (Imbalanced Streaming Data) និងមានបំរែបំរួលគំនិត (Concept Drift) ដែលធ្វើឱ្យម៉ូដែលម៉ាស៊ីនរៀន (Machine Learning) ប្រពៃណីថយចុះប្រសិទ្ធភាព និងភាពត្រឹមត្រូវ។

វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះស្នើឡើងនូវក្របខ័ណ្ឌចំណាត់ថ្នាក់ថ្មីមួយដោយប្រើប្រាស់បណ្តាញសរសៃប្រសាទខនវ៉ូលូសិនស៊ីជម្រៅ (Deep CNN) រួមជាមួយនឹងបច្ចេកទេសកាត់បន្ថយវិមាត្រ និងការជ្រើសរើសលក្ខណៈ។

  • ការកាត់បន្ថយវិមាត្រ (Principal Component Analysis - PCA)
  • ក្បួនដោះស្រាយហ្សេនេទិកផ្អែកលើក្បួនស្វែងរកសម្រាប់ការជ្រើសរើសលក្ខណៈ (Heuristic-based Genetic Algorithm for Feature Selection)
  • ការធ្វើចំណាត់ថ្នាក់តាមរយៈបណ្តាញសរសៃប្រសាទ (Deep Convolutional Neural Network - CNN) បង្វឹកដោយបច្ចេកទេស SGD
  • ការវាយតម្លៃលើសំណុំទិន្នន័យជាក់ស្តែងនិងសិប្បនិម្មិត (Evaluation on MOA and UCI Datasets)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • ម៉ូដែលដែលបានស្នើឡើងទទួលបានភាពត្រឹមត្រូវ (Accuracy) និងអត្រារង្វាស់ល្អជាងក្បួនដោះស្រាយដែលមានស្រាប់ដូចជា DANNLO, ANN, និង SVM ក្នុងការសិក្សាពីទិន្នន័យគ្មានតុល្យភាពកម្រិតខ្ពស់។
  • ការប្រើប្រាស់ Convolution ជួយបង្កើតលទ្ធផលកាន់តែមានប្រសិទ្ធភាពបន្ទាប់ពីការទាញយកលក្ខណៈពិសេស (Feature Extraction) ដែលជួយសម្រួលដល់ដំណើរការទិន្នន័យស្ទ្រីម។
  • ក្របខ័ណ្ឌនេះអាចដោះស្រាយព្រមគ្នានូវបញ្ហាអតុល្យភាពថ្នាក់ (Class Imbalance) និងបំរែបំរួលគំនិត (Concept Drift) យ៉ាងមានប្រសិទ្ធភាពសម្រាប់កម្មវិធីក្នុងពិភពពិត។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Proposed Model (Deep CNN + PCA + GA)
ម៉ូដែលដែលបានស្នើ (បណ្តាញ CNN ស៊ីជម្រៅ រួមជាមួយ PCA និង GA)		 មានសមត្ថភាពខ្ពស់ក្នុងការដោះស្រាយទិន្នន័យស្ទ្រីមដែលមានវិមាត្រខ្ពស់ និងគ្មានតុល្យភាព ព្រមទាំងអាចសម្របខ្លួនទៅនឹងបំរែបំរួលគំនិត (Concept drift) បានយ៉ាងល្អ។ ទាមទារការចំណាយធនធានកុំព្យូទ័រខ្ពស់សម្រាប់ការបង្វឹកម៉ូដែលឡើងវិញ (Retraining) និងដំណើរការទាញយកលក្ខណៈពិសេស។ ទទួលបានលទ្ធផលខ្ពស់បំផុតលើរង្វាស់ Accuracy, F-measure, G-mean, Precision, និង Recall ទាំងលើទិន្នន័យស្ទ្រីម និង Static។
DANNLO
ក្បួនដោះស្រាយ DANNLO		 បង្ហាញលទ្ធផលល្អប្រសើរជាងវិធីសាស្ត្រមូលដ្ឋាន (Baseline) ដូចជា ANN និង SVM ក្នុងការវាយតម្លៃ។ នៅមានកម្រិតភាពត្រឹមត្រូវទាបជាងម៉ូដែល Proposed Deep CNN ជាពិសេសនៅពេលទិន្នន័យមានបំរែបំរួលលឿន។ ជាប់ចំណាត់ថ្នាក់លេខ២ ក្នុងការប្រៀបធៀបដំណើរការទូទៅ យោងតាមក្រាហ្វវាយតម្លៃលទ្ធផល។
ANN (Artificial Neural Network)
បណ្តាញសរសៃប្រសាទសិប្បនិម្មិត (ANN)		 ជាវិធីសាស្ត្រស្តង់ដារដែលងាយស្រួលក្នុងការយល់ និងអនុវត្តសម្រាប់ទិន្នន័យមិនស្មុគស្មាញខ្លាំង។ ជួបការលំបាកក្នុងការចាប់យកលក្ខណៈពិសេសនៅពេលប្រឈមមុខនឹងទិន្នន័យគ្មានតុល្យភាពខ្លាំង (Highly imbalanced) និងរំខានដោយសម្លេង (Noise)។ ទទួលបានលទ្ធផលមធ្យម តែនៅទាបជាងម៉ូដែល Proposed ក្នុងការរក្សាអត្រា Recall នៃទិន្នន័យភាគតិច។
SVM (Support Vector Machine)
Support Vector Machine		 មានមូលដ្ឋានគ្រឹះគណិតវិទ្យារឹងមាំ និងមានប្រសិទ្ធភាពសម្រាប់ចំណាត់ថ្នាក់ទិន្នន័យប្រភេទ Binary។ មិនស័ក្តិសមសម្រាប់ទិន្នន័យស្ទ្រីមខ្នាតធំ និងទិន្នន័យដែលមានវិមាត្រខ្ពស់ខ្លាំងនោះទេ ដោយសារវាត្រូវការពេលវេលាគណនាយូរ។ ទទួលបានលទ្ធផលទាបជាងគេបំផុត (Lowest Accuracy and F-measure) ធៀបជាមួយវិធីសាស្ត្រ៣ផ្សេងទៀតក្នុងឯកសារនេះ។

ការចំណាយលើធនធាន (Resource Cost)៖ ឯកសារនេះបានបញ្ជាក់ថាដំណើរការបង្វឹកម៉ូដែល (Training process) មានតម្លៃចំណាយធនធាន និងពេលវេលាខ្ពស់ (Relatively high cost) នៅក្នុងបរិបទនៃការរៀបចំទិន្នន័យស្ទ្រីម។

  • Hardware: ទាមទារកម្លាំងម៉ាស៊ីនខ្លាំង (ជាពិសេស GPU) ដើម្បីដំណើរការបណ្តាញសរសៃប្រសាទខនវ៉ូលូសិនស៊ីជម្រៅ (Deep CNN) ជាមួយទិន្នន័យស្ទ្រីមតាមពេលវេលាជាក់ស្តែង។
  • Software: ត្រូវការប្រព័ន្ធសរសេរកូដសម្រាប់ Deep Learning និងឧបករណ៍វិភាគទិន្នន័យស្ទ្រីមដូចជា MOA (Massive Online Analysis)។
  • Dataset: ទាមទារទិន្នន័យស្ទ្រីមពិតៗ និងទិន្នន័យសិប្បនិម្មិតពីប្រភពស្តង់ដារដូចជា MOA និង UCI Repository សម្រាប់ការបង្វឹកនិងធ្វើតេស្ត។
  • Expertise: ទាមទារចំណេះដឹងស៊ីជម្រៅលើ Deep Learning, SGD Method, PCA និង Genetic Algorithms ដើម្បីកំណត់ប៉ារ៉ាម៉ែត្រឱ្យបានត្រឹមត្រូវ។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះប្រើប្រាស់សំណុំទិន្នន័យខ្នាតអន្តរជាតិ (MOA និង UCI) ដូចជាទិន្នន័យអគ្គិសនីអូស្ត្រាលី និងព្រៃឈើសហរដ្ឋអាមេរិក ដែលមិនឆ្លុះបញ្ចាំងពីបរិបទកម្ពុជានោះទេ។ ទោះយ៉ាងណាក៏ដោយ បញ្ហាទិន្នន័យគ្មានតុល្យភាព និងការប្រែប្រួលគំនិត (Concept Drift) គឺជាបញ្ហាសកល។ ការអនុវត្តនៅកម្ពុជាទាមទារការប្រមូលទិន្នន័យក្នុងស្រុកដែលមានទំហំធំដើម្បីធានាភាពសុក្រឹតនៃម៉ូដែល។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រនេះមានសក្តានុពលខ្ពស់សម្រាប់ស្ថាប័ននៅកម្ពុជាដែលត្រូវការវិភាគទិន្នន័យហូរចូលបន្តបន្ទាប់ (Streaming) និងមានលក្ខណៈមិនស្មើគ្នា។

  • វិស័យធនាគារ និងហិរញ្ញវត្ថុ (Financial Fraud Detection): ធនាគារក្នុងស្រុកដូចជា ABA ឫ ACLEDA អាចប្រើប្រាស់ម៉ូដែលនេះដើម្បីចាប់យកប្រតិបត្តិការក្លែងបន្លំ (Fraud) ដែលជាទូទៅគឺជាទិន្នន័យភាគតិច (Minority class) ដែលលាក់ខ្លួនក្នុងចំណោមប្រតិបត្តិការរាប់លាន។
  • វិស័យសុខាភិបាល (Healthcare Diagnostics): មន្ទីរពេទ្យនៅកម្ពុជាអាចប្រើវាដើម្បីវិភាគលើទិន្នន័យអ្នកជំងឺដែលចូលមកជាបន្តបន្ទាប់ ដើម្បីកំណត់រោគវិនិច្ឆ័យជំងឺកម្រ (Rare diseases) ដោយប្រើប្រាស់ទិន្នន័យគ្មានតុល្យភាព។
  • ក្រុមហ៊ុនទូរគមនាគមន៍ (Telecom Churn Prediction): ក្រុមហ៊ុនទូរស័ព្ទចល័តនៅកម្ពុជាអាចយកទៅព្យាករណ៍ និងតាមដានអតិថិជនដែលអាចនឹងផ្លាស់ប្តូរទៅប្រើប្រាស់សេវាកម្មក្រុមហ៊ុនផ្សេង (Churn) នៅក្នុងទិន្នន័យស្ទ្រីមប្រចាំថ្ងៃ។

ជារួម ក្របខ័ណ្ឌ Deep CNN រួមបញ្ចូលគ្នានេះ អាចជួយបង្កើនប្រសិទ្ធភាពក្នុងការធ្វើសេចក្តីសម្រេចចិត្តដោយស្វ័យប្រវត្តិសម្រាប់ប្រព័ន្ធស្ទ្រីមទិន្នន័យធំៗនៅកម្ពុជា ប្រសិនបើមានប្រព័ន្ធ Hardware គាំទ្រគ្រប់គ្រាន់។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះ និងរង្វាស់វាយតម្លៃ: ស្វែងយល់ពីបញ្ហាចំណាត់ថ្នាក់ទិន្នន័យគ្មានតុល្យភាព (Imbalanced Data) និងបោះបង់ការផ្ដោតតែលើ Accuracy។ ត្រូវរៀនពីរបៀបគណនា និងប្រើប្រាស់រង្វាស់ផ្សេងៗដូចជា F-measure, G-mean, Precision, និង Recall។
  2. អនុវត្តការកាត់បន្ថយវិមាត្រ និងការជ្រើសរើសលក្ខណៈ: ប្រើប្រាស់ Python និងបណ្ណាល័យ Scikit-Learn ដើម្បីអនុវត្តបច្ចេកទេស PCA (Principal Component Analysis) និងក្បួនដោះស្រាយ Genetic Algorithm សម្រាប់ទាញយកលក្ខណៈពិសេសដែលសំខាន់បំផុតរបស់ទិន្នន័យ។
  3. កសាងម៉ូដែល Deep CNN សម្រាប់ប្រភេទអត្ថបទ/ទិន្នន័យ: ចាប់ផ្តើមសរសេរកូដបង្កើតបណ្តាញសរសៃប្រសាទ CNN ជាមួយ TensorFlow ឬ PyTorch ដោយកំណត់ប្រើប្រាស់បច្ចេកទេស Stochastic Gradient Descent (SGD) និងរៀបចំទិន្នន័យជា Mini-batches។
  4. សាកល្បងជាមួយទិន្នន័យស្ទ្រីម (Streaming Data): ទាញយកឧបករណ៍វិភាគទិន្នន័យស្ទ្រីមដូចជា MOA (Massive Online Analysis) ឬប្រើ Apache Kafka រួមជាមួយទិន្នន័យពី UCI ដូចជាទិន្នន័យ អគ្គិសនី ឬព្រៃឈើ ដើម្បីរៀនពីរបៀបដោះស្រាយបំរែបំរួលគំនិត (Concept drift)។
  5. អនុវត្តលើទិន្នន័យបរិបទកម្ពុជា: ស្វែងរកសំណុំទិន្នន័យក្នុងស្រុក (ឧទាហរណ៍៖ ទិន្នន័យអាកាសធាតុពីក្រសួងធនធានទឹក ឬទិន្នន័យប្រតិបត្តិការហិរញ្ញវត្ថុអនាមិក) ដើម្បីធ្វើការកែសម្រួលម៉ូដែល (Fine-tuning) ឱ្យឆ្លើយតបនឹងបញ្ហាជាក់ស្តែងនៅក្នុងប្រទេសកម្ពុជា។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Class imbalance ស្ថានភាពដែលទិន្នន័យក្នុងក្រុមមួយមានចំនួនច្រើនលើសលប់ធៀបនឹងក្រុមមួយទៀត ធ្វើឱ្យម៉ូដែលម៉ាស៊ីនរៀនងាយនឹងទស្សន៍ទាយលម្អៀងទៅរកក្រុមដែលមានទិន្នន័យច្រើន។ ដូចជាការរៀនកាត់ក្តីដែលតុលាការស្តាប់សាក្សីខាងចុងចោទ១០០នាក់ តែស្តាប់សាក្សីខាងដើមបណ្តឹងតែ១នាក់ ដែលធ្វើឱ្យការកាត់ក្តីងាយនឹងលម្អៀង។
Concept drift បាតុភូតដែលលក្ខណៈ ឬអត្ថន័យនៃទិន្នន័យផ្លាស់ប្តូរតាមពេលវេលា (ឧទាហរណ៍៖ អាកប្បកិរិយាអតិថិជនប្រែប្រួល) ដែលធ្វើឱ្យម៉ូដែលដែលធ្លាប់តែទស្សន៍ទាយត្រូវ ក្លាយជាលែងសុក្រឹត។ ដូចជាច្បាប់ចរាចរណ៍ដែលតែងតែផ្លាស់ប្តូរពីមួយឆ្នាំទៅមួយឆ្នាំ បើអ្នកបើកបរមិនរៀនច្បាប់ថ្មីទេ នោះនឹងប្រព្រឹត្តកំហុសដោយមិនដឹងខ្លួន។
Deep Convolutional Neural Network បណ្តាញសរសៃប្រសាទសិប្បនិម្មិតដែលមានស្រទាប់ច្រើន ដែលប្រើប្រតិបត្តិការខនវ៉ូលូសិន (Convolution) ដើម្បីទាញយកលក្ខណៈពិសេសសំខាន់ៗពីទិន្នន័យស្មុគស្មាញដោយស្វ័យប្រវត្តិ។ ដូចជាខួរក្បាលមនុស្សដែលប្រើភ្នែកមើលរូបភាព រួចបំបែកវាជាផ្នែកតូចៗ (ពណ៌ រូបរាង គែម) ដើម្បីសម្គាល់ថាតើវាជារបស់អ្វីឱ្យប្រាកដ។
Principal Component Analysis បច្ចេកទេសកាត់បន្ថយវិមាត្រនៃទិន្នន័យដោយបំប្លែងទិន្នន័យដែលមានអថេរ (Variables) ច្រើនទៅជាទិន្នន័យតូចជាងមុន ប៉ុន្តែនៅរក្សាព័ត៌មាននិងលក្ខណៈសំខាន់ៗបានភាគច្រើន។ ដូចជាការសង្ខេបសៀវភៅ១០០ទំព័រមកត្រឹម១ទំព័រ ដោយរក្សាទុកតែអត្ថន័យស្នូលសំខាន់ៗបំផុតមិនឱ្យបាត់បង់។
Genetic algorithm ក្បួនដោះស្រាយស្វែងរកដំណោះស្រាយល្អបំផុត ដោយយកត្រាប់តាមទ្រឹស្តីវិវត្តន៍របស់ធម្មជាតិ (ការជ្រើសរើស ការបង្កាត់ពូជ និងការបំប្លែងសេន) ដើម្បីជ្រើសរើសលក្ខណៈពិសេសនៃទិន្នន័យ។ ដូចជាការបង្កាត់ពូជគោ ដោយរើសយកគោដែលខ្លាំង និងឱ្យទឹកដោះច្រើនមកបង្កាត់គ្នា ដើម្បីបានកូនគោជំនាន់ក្រោយដែលកាន់តែល្អប្រសើរ។
Ensemble algorithms វិធីសាស្ត្ររួមបញ្ចូលម៉ូដែលម៉ាស៊ីនរៀនតូចៗជាច្រើនចូលគ្នា ដើម្បីធ្វើការសម្រេចចិត្តរួមមួយ ដែលផ្តល់លទ្ធផលត្រឹមត្រូវនិងមានស្ថិរភាពជាងការប្រើម៉ូដែលតែមួយឯកឯង។ ដូចជាការពិគ្រោះយោបល់ជាមួយគ្រូពេទ្យជំនាញ៥នាក់ផ្សេងគ្នា ដើម្បីរកវិនិច្ឆ័យជំងឺមួយ ជាជាងជឿលើគ្រូពេទ្យតែម្នាក់។
Stochastic gradient descent ក្បួនដោះស្រាយគណិតវិទ្យាសម្រាប់ស្វែងរកតម្លៃកំហុសទាបបំផុតរបស់ម៉ូដែល ដោយធ្វើការកែតម្រូវទម្ងន់ (Weights) នៃបណ្តាញសរសៃប្រសាទបន្តិចម្តងៗ តាមរយៈការប្រើប្រាស់ទិន្នន័យមួយផ្នែកតូច (Mini-batches) ក្នុងពេលម្តងៗ។ ដូចជាមនុស្សម្នាក់ដែលចុះពីលើភ្នំនៅពេលយប់ងងឹត ដោយប្រើជើងស្ទាបរកផ្លូវដែលទេរចុះក្រោមបន្តិចម្តងៗ រហូតដល់ដល់ផ្ទៃរាបស្មើដែលជាចំណុចទាបបំផុត។
F-measure រង្វាស់វាយតម្លៃសមត្ថភាពម៉ូដែលដែលរួមបញ្ចូលគ្នារវាង Precision (ភាពសុក្រឹត) និង Recall (ការរកឃើញ) ជាតម្លៃតែមួយ ដែលស័ក្តិសមបំផុតសម្រាប់វាស់ស្ទង់ការអនុវត្តលើទិន្នន័យដែលគ្មានតុល្យភាពខ្លាំង។ ដូចជាការវាយតម្លៃសិស្សម្នាក់ដែលមិនត្រឹមតែពូកែឆ្លើយត្រូវគ្រប់សំណួរដែលបានឆ្លើយ តែថែមទាំងមិនសូវរំលងសំណួរចោលទៀតផង។
