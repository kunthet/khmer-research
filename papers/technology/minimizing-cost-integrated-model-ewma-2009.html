១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ឯកសារនេះដោះស្រាយបញ្ហានៃការកាត់បន្ថយចំណាយប្រតិបត្តិការដោយការរួមបញ្ចូលគ្នារវាងការត្រួតពិនិត្យដំណើរការតាមស្ថិតិ (SPC) និងការគ្រប់គ្រងការថែទាំ (MM) នៅក្នុងប្រព័ន្ធផលិតកម្ម។

វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះបានអភិវឌ្ឍគំរូគណិតវិទ្យាដើម្បីវិភាគចំណាយ និងស្វែងរកតម្លៃដ៏ប្រសើរបំផុត (Optimal values) ដោយប្រៀបធៀបគំរូរួមបញ្ចូលគ្នានេះជាមួយគំរូឈរឯកឯងផ្សេងទៀត។

  • ការប្រើប្រាស់តារាងត្រួតពិនិត្យ (EWMA control chart) ដើម្បីតាមដានដំណើរការ
  • ការកំណត់ពេលវេលាថែទាំតាមផែនការ (Planned Maintenance)
  • ការស្វែងរកតម្លៃដ៏ប្រសើរបំផុតតាមរយៈក្បួនដោះស្រាយតាមក្រឡាចត្រង្គ (Grid-search approach)

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • គំរូរួមបញ្ចូលគ្នាដែលប្រើប្រាស់តារាង EWMA បានផ្តល់នូវចំណាយប្រចាំម៉ោងទាបបំផុតគឺ E[H] = 153.02 ជាមួយនឹងតម្លៃអថេរដ៏ប្រសើរបំផុត n*=4, h*=1.15, L*=1.1 និង k*=22។
  • ចំណាយនេះមានកម្រិតទាបជាងគំរូត្រួតពិនិត្យដោយតារាង X-bar រួមបញ្ចូលគ្នា ដែលមានចំណាយប្រចាំម៉ោង 158.32។
  • គំរូរួមបញ្ចូលគ្នានេះបង្ហាញពីប្រសិទ្ធភាពសេដ្ឋកិច្ចខ្ពស់ជាងគំរូឈរឯកឯង (Stand-alone models) ដែលមានចំណាយ 195.23 សម្រាប់ការថែទាំ (PM) និង 162.71 សម្រាប់ SPC។

២. ការវិភាគលើប្រសិទ្ធភាព និងដែនកំណត់ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Integrated model (EWMA control chart)
គំរូរួមបញ្ចូលគ្នាដោយប្រើតារាងត្រួតពិនិត្យ EWMA		 ផ្តល់នូវការសន្សំសំចៃចំណាយខ្ពស់បំផុត និងមានប្រសិទ្ធភាពក្នុងការចាប់យកបំរែបំរួលតូចៗនៃដំណើរការផលិតកម្ម។ រក្សាបាននូវតុល្យភាពល្អបំផុតរវាងគុណភាព និងការថែទាំ។ មានភាពស្មុគស្មាញផ្នែកគណិតវិទ្យាក្នុងការកំណត់តម្លៃប៉ារ៉ាម៉ែត្រដ៏ប្រសើរបំផុត (n, h, L, k) និងត្រូវការកម្លាំងម៉ាស៊ីនកុំព្យូទ័រក្នុងការគណនា។ ទទួលបានចំណាយប្រតិបត្តិការប្រចាំម៉ោងទាបបំផុតត្រឹមតែ ១៥៣.០២ ប៉ុណ្ណោះ។
Integrated model (X-bar control chart)
គំរូរួមបញ្ចូលគ្នាដោយប្រើតារាងត្រួតពិនិត្យ X-bar		 ងាយស្រួលយល់ និងងាយស្រួលអនុវត្តជាងគំរូ EWMA ដោយនៅតែផ្តល់នូវលទ្ធផលសេដ្ឋកិច្ចល្អជាងការធ្វើការដាច់ដោយឡែកពីគ្នា។ មិនសូវរហ័សក្នុងការចាប់កំហុសតូចៗដូច EWMA ឡើយ ដែលនាំឱ្យចំណាយសរុបខ្ពស់ជាងបន្តិច។ ទទួលបានចំណាយប្រតិបត្តិការប្រចាំម៉ោងក្នុងកម្រិត ១៥៨.៣២ ដែលនៅតែល្អជាងគំរូឈរឯកឯង។
Stand-alone models (PM & SPC)
គំរូអនុវត្តដាច់ដោយឡែក (ការថែទាំ និងការត្រួតពិនិត្យ)		 ងាយស្រួលក្នុងការគ្រប់គ្រងដោយនាយកដ្ឋានដាច់ដោយឡែកពីគ្នា (ផ្នែកគុណភាព និងផ្នែកថែទាំ) ដោយមិនបាច់ផ្លាស់ប្តូរប្រព័ន្ធការងារចាស់។ ខ្វះការសម្របសម្រួលគ្នា ដែលនាំឱ្យមានការខ្ជះខ្ជាយពេលវេលា និងចំណាយខ្ពស់លើការជួសជុលបន្ទាន់ ឬការខូចគុណភាពផលិតផល។ ចំណាយប្រចាំម៉ោងកើនដល់ ១៩៥.២៣ សម្រាប់ការថែទាំសុទ្ធ (PM) និង ១៦២.៧១ សម្រាប់ការត្រួតពិនិត្យសុទ្ធ (SPC)។

ការចំណាយលើធនធាន (Resource Cost)៖ ការប្រើប្រាស់គំរូនេះទាមទារនូវកម្មវិធីកុំព្យូទ័រសម្រាប់ធ្វើស្វ័យប្រវត្តិកម្មលើការគណនា និងចំណេះដឹងផ្នែកស្ថិតិដើម្បីស្វែងរកតម្លៃដ៏ប្រសើរបំផុត។

  • Software: ត្រូវការកម្មវិធីដូចជា MATLAB (ដូចដែលបានប្រើប្រាស់ជំនាន់ 7.6.0 R2008a ជាមួយ Optimization Toolbox) ឬ Python សម្រាប់ដំណើរការក្បួនដោះស្រាយ Grid-search។
  • Data: ទាមទារទិន្នន័យជាក់ស្តែងពីរោងចក្រដូចជា តម្លៃនៃការបាត់បង់គុណភាព (Taguchi loss function) ចំណាយលើការថែទាំ និងកម្រិតនៃការខូចខាតម៉ាស៊ីន (Weibull distribution)។
  • Expertise: អ្នកជំនាញផ្នែកវិស្វកម្មឧស្សាហកម្មដែលមានចំណេះដឹងលើការត្រួតពិនិត្យដំណើរការតាមស្ថិតិ (SPC) និងយុទ្ធសាស្ត្រថែទាំម៉ាស៊ីន (Maintenance Management)។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះពឹងផ្អែកលើការពិសោធន៍តាមតួលេខ (Numerical experiment) និងទិន្នន័យសម្មតិកម្មពីករណីឧស្សាហកម្ម ដោយប្រើប្រាស់របាយចែកចាយ Weibull។ វាមិនមានទិន្នន័យជាក់ស្តែងពីបរិបទរោងចក្រក្នុងប្រទេសកម្ពុជាឡើយ។ សម្រាប់រោងចក្រនៅកម្ពុជា ការខ្វះខាតប្រព័ន្ធកត់ត្រាទិន្នន័យច្បាស់លាស់អំពីការខូចខាតម៉ាស៊ីន អាចជាឧបសគ្គដ៏ធំក្នុងការអនុវត្តគំរូនេះឱ្យបានជោគជ័យ។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រនេះមានសក្តានុពលខ្ពស់សម្រាប់ការអនុវត្តនៅក្នុងវិស័យឧស្សាហកម្មធុនស្រាលនៅកម្ពុជា ដើម្បីបង្កើនប្រសិទ្ធភាពផលិតកម្ម និងកាត់បន្ថយការចំណាយថវិកា។

  • កម្មន្តសាលកាត់ដេរ និងស្បែកជើង (Garment and Footwear Manufacturing): រោងចក្រនៅតំបន់សេដ្ឋកិច្ចពិសេស (SEZ) អាចអនុវត្តគំរូនេះដើម្បីធ្វើសមកាលកម្មកាលវិភាគជួសជុលម៉ាស៊ីនដេរ ជាមួយនឹងការតាមដានកំហុសលើសម្លៀកបំពាក់ ដែលជួយកាត់បន្ថយពេលវេលាងាប់របស់ម៉ាស៊ីន (Downtime)។
  • រោងចក្រកែច្នៃម្ហូបអាហារ (Food Processing Plants): ការប្រើប្រាស់គំរូ EWMA អាចជួយតាមដានបំរែបំរួលតូចៗនៃគុណភាពចំណីអាហារ ព្រមទាំងផ្តល់សញ្ញាឱ្យធ្វើការថែទាំម៉ាស៊ីនវេចខ្ចប់មុនពេលវាខូចធ្ងន់ធ្ងរ ដែលអាចការពារកុំឱ្យខូចអាហាររាប់តោន។

សរុបមក ការអនុវត្តគំរូរួមបញ្ចូលគ្នានេះ អាចជួយវិស័យឧស្សាហកម្មកម្ពុជាប្រកួតប្រជែងលើទីផ្សារអន្តរជាតិបានតាមរយៈការកាត់បន្ថយចំណាយ ប៉ុន្តែទាមទារការធ្វើទំនើបកម្មលើប្រព័ន្ធប្រមូលទិន្នន័យជាមុនសិន។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. រៀបចំប្រព័ន្ធប្រមូលទិន្នន័យរោងចក្រ (Data Collection System): ចាប់ផ្តើមកត់ត្រាពេលវេលាពិតប្រាកដដែលម៉ាស៊ីនខូច (Time-to-failure) កម្រិតនៃការខូចខាតផលិតផល និងការចំណាយលើការថែទាំនីមួយៗ ដោយប្រើប្រាស់ប្រព័ន្ធដូចជា ERP Systems ឬសូម្បីតែ Microsoft Excel ប្រកបដោយស្តង់ដារ។
  2. បណ្តុះបណ្តាលផ្នែកស្ថិតិ និងការគ្រប់គ្រង (Capacity Building): បង្រៀនវិស្វកររោងចក្រអំពីការគូសតារាងត្រួតពិនិត្យ (EWMA និង X-bar Control Charts) និងការយល់ដឹងពីមុខងារនៃការបាត់បង់របស់ Taguchi (Taguchi Loss Function)។
  3. កសាងគំរូសាកល្បងដោយប្រើប្រាស់កម្មវិធី (Prototyping): ប្រើប្រាស់កម្មវិធី MATLAB ឬ Python (SciPy/NumPy) ដើម្បីសរសេរកូដសម្រាប់ក្បួនដោះស្រាយ Grid-search ក្នុងគោលបំណងស្វែងរកតម្លៃប៉ារ៉ាម៉ែត្រ n*, h*, L*, k* ដែលកាត់បន្ថយចំណាយប្រចាំម៉ោង E[H] ឱ្យនៅទាបបំផុត។
  4. អនុវត្តផ្ទាល់ក្នុងទំហំតូច (Pilot Implementation): ជ្រើសរើសខ្សែសង្វាក់ផលិតកម្មចំនួនមួយដើម្បីសាកល្បងគំរូរួមបញ្ចូលគ្នានេះ តាមដានលទ្ធផលចំណាយប្រៀបធៀបជាមួយវិធីសាស្ត្រចាស់ រួចធ្វើការកែតម្រូវប៉ារ៉ាម៉ែត្រមុននឹងពង្រីកការប្រើប្រាស់ទូទាំងរោងចក្រ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
EWMA control chart (តារាងត្រួតពិនិត្យ EWMA) ជាប្រភេទតារាងស្ថិតិដែលផ្តល់ទម្ងន់ទៅលើទិន្នន័យថ្មីៗច្រើនជាងទិន្នន័យចាស់ ដើម្បីជួយចាប់យកបំរែបំរួលតូចៗនៅក្នុងដំណើរការផលិតកម្មបានយ៉ាងរហ័ស។ ដូចជាការតាមដានចរាចរណ៍ដែលយើងយកចិត្តទុកដាក់លើស្ថានភាពផ្លូវក្នុងរយៈពេល៥នាទីចុងក្រោយ ច្រើនជាងស្ថានភាពកាលពី១ម៉ោងមុន ដើម្បីដឹងថាមានការកកស្ទះឬអត់។
Statistical process control (ការត្រួតពិនិត្យដំណើរការតាមស្ថិតិ) ជាវិធីសាស្ត្រនៃការគ្រប់គ្រងគុណភាពដែលប្រើប្រាស់រូបមន្តស្ថិតិ និងតារាងទិន្នន័យ ដើម្បីតាមដាន និងរក្សាដំណើរការផលិតកម្មឱ្យមានស្ថិរភាព និងគ្មានកំហុស។ ដូចជាការវាស់កម្ដៅខ្លួនអ្នកជំងឺជារៀងរាល់ម៉ោង ហើយកត់ត្រាទុកលើតារាងដើម្បីមើលថាតើកម្ដៅឡើងខុសធម្មតាឬទេ មុនពេលជំងឺធ្វើទុក្ខខ្លាំង។
Maintenance management (ការគ្រប់គ្រងការថែទាំ) ជាការរៀបចំផែនការ និងការអនុវត្តការជួសជុល ឬថែទាំម៉ាស៊ីនក្នុងរោងចក្រ ដើម្បីធានាថាម៉ាស៊ីនដំណើរការបានល្អ កាត់បន្ថយការខូចខាតភ្លាមៗ និងសន្សំសំចៃចំណាយ។ ដូចជាការប្តូរប្រេងម៉ាស៊ីនឡានរៀងរាល់ ៥០០០ គីឡូម៉ែត្រម្តង ដើម្បីការពារកុំឱ្យម៉ាស៊ីនខូចធ្ងន់ធ្ងរនៅពេលកំពុងបើកបរ។
Taguchi loss function (អនុគមន៍បាត់បង់ Taguchi) ជារូបមន្តគណិតវិទ្យាដែលប្រើសម្រាប់គណនាទំហំនៃការខាតបង់ផ្នែកហិរញ្ញវត្ថុ នៅពេលដែលគុណភាពផលិតផលឃ្លាតឆ្ងាយពីស្តង់ដារគោល ទោះបីជាវានៅក្នុងកម្រិតដែលអាចទទួលយកបានក៏ដោយ។ ដូចជាការបាញ់ព្រួញ ការបាញ់ចំកណ្តាលស៊ីបគឺល្អបំផុត ប៉ុន្តែបើបាញ់រាងឃ្លាតពីកណ្តាលបន្តិច ទោះបីចូលស៊ីបក៏ដោយ ក៏ពិន្ទុត្រូវថយចុះបន្តិចម្តងៗដែរ។
Weibull distribution (របាយចែកចាយ Weibull) ជារបាយប្រូបាប៊ីលីតេដែលគេនិយមប្រើប្រាស់នៅក្នុងវិស្វកម្មដើម្បីវិភាគ និងព្យាករណ៍ពីអាយុកាល ឬពេលវេលាដែលម៉ាស៊ីនមួយអាចនឹងខូចខាត។ ដូចជាការទស្សន៍ទាយថាអំពូលភ្លើងមួយនឹងអាចភ្លឺបានប៉ុន្មានម៉ោងមុនពេលវាដាច់ ដោយផ្អែកលើអាយុកាលនៃការប្រើប្រាស់របស់វាកន្លងមក។
Grid-search approach (ក្បួនដោះស្រាយតាមក្រឡាចត្រង្គ) ជាវិធីសាស្ត្រសាកល្បងបញ្ចូលតម្លៃលេខផ្សេងៗគ្នាជាប្រព័ន្ធទៅក្នុងរូបមន្ត ដើម្បីស្វែងរកបន្សំតម្លៃដែលផ្តល់លទ្ធផលល្អបំផុត (ឧទាហរណ៍ ចំណាយទាបបំផុត)។ ដូចជាការសាកល្បងចាក់សោលេខដោយរំកិលលេខពី ០០០ ដល់ ៩៩៩ ម្តងមួយៗតាមលំដាប់លំដោយ រហូតដល់រកឃើញលេខកូដដែលត្រឹមត្រូវ។
