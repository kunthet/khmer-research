១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការស្រាវជ្រាវនេះដោះស្រាយពីតម្រូវការក្នុងការទាញយកព័ត៌មាន និងពាក្យគន្លឹះសំខាន់ៗចេញពីទិន្នន័យអត្ថបទដែលមានទំហំធំ ដោយប្រើប្រាស់បច្ចេកវិទ្យាបញ្ញាសិប្បនិម្មិត។ វាផ្តោតលើការយកឈ្នះដែនកំណត់នៃការរាប់ប្រេកង់ពាក្យធម្មតា (Term Frequency) ដែលតែងតែផ្តល់តម្លៃខ្ពស់ដល់ពាក្យទូទៅដែលគ្មានអត្ថន័យ។

វិធីសាស្ត្រ (The Methodology)៖ ការសិក្សានេះបានអភិវឌ្ឍកម្មវិធីស្រង់ពាក្យគន្លឹះដោយប្រើវិធីសាស្ត្រផ្អែកលើប្រេកង់នៅក្នុងភាសាការសរសេរកូដ Python ដោយឆ្លងកាត់ការអនុវត្តចំនួន ៨ ជំហានចម្បង។

  • ការរៀបចំអត្ថបទជាមុន (Preprocessing Text): ការបំប្លែងអក្សរតូច ការលុបសញ្ញាវណ្ណយុត្តិ និងការលុបពាក្យដែលមិនចាំបាច់ (Stopwords)។
  • ការបង្កើតកញ្ចប់ពាក្យ និងប្រេកង់ពាក្យ (Bag of Words & Term Frequency): ការបំបែកអត្ថបទជាពាក្យ និងការគណនាភាពញឹកញាប់នៃពាក្យនីមួយៗក្នុងឯកសារ។
  • ការគណនាប្រេកង់ឯកសារច្រាស (Inverse Document Frequency - IDF): ការវាស់ស្ទង់សារៈសំខាន់នៃពាក្យធៀបនឹងសំណុំឯកសារទាំងមូលដោយប្រើរូបមន្តលោការីត (Logarithm)។
  • ការថ្លឹងទម្ងន់ TF-IDF និងការតម្រៀប (TF-IDF Weighting & Sorting): ការគុណតម្លៃ TF និង IDF រួចតម្រៀបពាក្យគន្លឹះតាមលំដាប់ពីធំទៅតូចដើម្បីស្វែងរកពាក្យដែលលេចធ្លោជាងគេ។

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • កម្មវិធីដែលបានអភិវឌ្ឍដោយប្រើភាសា Python អាចដំណើរការជំហានមូលដ្ឋានទាំង ៨ នៃការស្រង់ពាក្យគន្លឹះបានយ៉ាងជោគជ័យដោយមិនចាំបាច់ប្រើប្រាស់បណ្ណាល័យបន្ថែម (Additional Libraries) ក្រៅពីអនុគមន៍ស្តង់ដាររបស់ Python ឡើយ។
  • ការធ្វើតេស្តលើអត្ថបទពិសោធន៍ពី Wikipedia បានបង្ហាញថាប្រព័ន្ធនេះអាចកំណត់អត្តសញ្ញាណពាក្យគន្លឹះដែលពិពណ៌នាពីខ្លឹមសារអត្ថបទបានយ៉ាងត្រឹមត្រូវតាមរយៈការផ្តល់ទម្ងន់ TF-IDF ។
  • វិធីសាស្ត្រ TF-IDF បានបង្ហាញពីប្រសិទ្ធភាពខ្ពស់ក្នុងការទាញយកលក្ខណៈតំណាងនៃអត្ថបទ ដែលជាមូលដ្ឋានគ្រឹះដ៏សំខាន់សម្រាប់កម្មវិធីរៀនម៉ាស៊ីន (Machine Learning) និងការជីកកកាយអត្ថបទ (Text Mining) ។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Term Frequency (TF)
ការគណនាប្រេកង់ពាក្យ		 ងាយស្រួលក្នុងការគណនាដោយផ្អែកលើចំនួនដងដែលពាក្យមួយលេចឡើងក្នុងឯកសារ។ វាជាមូលដ្ឋានគ្រឹះដំបូងសម្រាប់ការវិភាគអត្ថបទ។ មានចំណុចខ្សោយដោយសារពាក្យទូទៅ (ឧទាហរណ៍៖ the, is, are) ទទួលបានតម្លៃខ្ពស់ ទោះបីជាគ្មានអត្ថន័យសំខាន់ក្នុងការពណ៌នាអត្ថបទក៏ដោយ។ បានលើកឡើងក្នុងឯកសារថាជាវិធីសាស្ត្រស្ថិតិដំបូង (បង្កើតនៅឆ្នាំ១៩៥៨ ដោយ Hans Luhn) តែត្រូវបានជំនួសដោយវិធីសាស្ត្រទំនើបជាងមុន។
Term Frequency-Inverse Document Frequency (TF-IDF)
ការគណនាប្រេកង់ពាក្យ និងប្រេកង់ឯកសារច្រាស		 យកឈ្នះដែនកំណត់របស់ TF ដោយវាស់ស្ទង់សារៈសំខាន់នៃពាក្យធៀបនឹងសំណុំឯកសារទាំងមូល ធ្វើឱ្យពាក្យគន្លឹះពិតប្រាកដលេចធ្លោ។ វាមានប្រសិទ្ធភាពខ្ពស់ក្នុងការស្រង់ពាក្យគន្លឹះ។ មិនបានចាប់យកអត្ថន័យស៊ីជម្រៅ (Semantic Meaning) ឬបរិបទនៃពាក្យដូចវិធីសាស្ត្របណ្តាញសរសៃប្រសាទសិប្បនិម្មិត (Neural Networks) ទំនើបនោះទេ។ កម្មវិធីដែលបានអភិវឌ្ឍអាចដំណើរការជំហានមូលដ្ឋានទាំង ៨ និងទាញយកពាក្យគន្លឹះ ព្រមទាំងតម្រៀបតាមតម្លៃទម្ងន់បានយ៉ាងត្រឹមត្រូវពីអត្ថបទ Wikipedia ។

ការចំណាយលើធនធាន (Resource Cost)៖ ការស្រាវជ្រាវនេះប្រើប្រាស់ធនធានតិចតួចបំផុត ដោយសារវាពឹងផ្អែកតែលើអនុគមន៍ស្តង់ដាររបស់ភាសា Python ដោយមិនចាំបាច់ដំឡើងបណ្ណាល័យស្មុគស្មាញឡើយ។

  • Software: ប្រើប្រាស់ភាសា Python ស្តង់ដារ ដោយមិនប្រើប្រាស់បណ្ណាល័យបន្ថែមដូចជា NLTK, Pandas ឬ Scikit-Learn នៅក្នុងកូដផ្ទាល់ឡើយ។
  • Dataset: ប្រើប្រាស់អត្ថបទពិសោធន៍ខ្នាតតូច (Experimental Text) ដែលទាញយកពីគេហទំព័រ Wikipedia ។
  • Hardware: មិនត្រូវការកុំព្យូទ័រដែលមានកម្លាំងខ្លាំង (No GPU required) ដោយសារទំហំទិន្នន័យតូច និងក្បួនដោះស្រាយមានភាពសាមញ្ញ។ អាចដំណើរការលើកុំព្យូទ័រយួរដៃធម្មតា។
  • Expertise: ទាមទារចំណេះដឹងមូលដ្ឋានផ្នែកការសរសេរកូដ Python និងការយល់ដឹងពីគណិតវិទ្យា (Logarithm) សម្រាប់ការគណនាទម្ងន់ពាក្យ។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះបានធ្វើតេស្តទៅលើតែអត្ថបទពិសោធន៍ជាភាសាអង់គ្លេសដែលទាញយកពី Wikipedia ប៉ុណ្ណោះ ដែលមានទម្រង់វេយ្យាករណ៍ច្បាស់លាស់ និងមានការដកឃ្លារវាងពាក្យ។ សម្រាប់ប្រទេសកម្ពុជា ការប្រើប្រាស់វិធីសាស្ត្រនេះដោយផ្ទាល់នឹងជួបឧបសគ្គ ដោយសារភាសាខ្មែរមិនប្រើដកឃ្លាដើម្បីបំបែកពាក្យទេ ដូច្នេះទាមទារឱ្យមានការប្រើប្រាស់ឧបករណ៍បំបែកពាក្យ (Word Segmentation Tool) ជាមុនសិន។

  • បណ្ណាល័យជាតិ និងបណ្ណាល័យសាកលវិទ្យាល័យ (Digital Libraries): អាចប្រើដើម្បីបង្កើតប្រព័ន្ធស្រង់ពាក្យគន្លឹះស្វ័យប្រវត្តិពីសារណា និក្ខេបបទ ឬសៀវភៅឌីជីថល ដើម្បីងាយស្រួលក្នុងការស្វែងរក (Search Indexing) ។
  • ស្ថាប័នព័ត៌មាន និងសារព័ត៌មានអនឡាញ (News Agencies): ជួយក្នុងការរៀបចំចំណាត់ថ្នាក់អត្ថបទព័ត៌មានស្វ័យប្រវត្តិ (Article Categorization) និងជួយណែនាំអត្ថបទពាក់ព័ន្ធទៅកាន់អ្នកអានដោយផ្អែកលើពាក្យគន្លឹះ។
  • ក្រសួង និងស្ថាប័នរដ្ឋាភិបាល (e-Government Sector): គាំទ្រដល់ប្រព័ន្ធរដ្ឋាភិបាលអេឡិចត្រូនិក ក្នុងការចាត់ថ្នាក់ឯកសារផ្លូវការ និងការទាញយកប្រធានបទសំខាន់ៗពីរបាយការណ៍កិច្ចប្រជុំវែងៗដោយស្វ័យប្រវត្តិ។

ជារួម ការអនុវត្តក្បួនដោះស្រាយ TF-IDF គឺជាជំហានចាប់ផ្តើមដ៏ល្អមួយក្នុងការអភិវឌ្ឍប្រព័ន្ធស្រាវជ្រាវទិន្នន័យអត្ថបទនៅកម្ពុជា ប៉ុន្តែទាមទារយ៉ាងចាំបាច់នូវការសហការបញ្ចូលជាមួយឧបករណ៍បំបែកពាក្យភាសាខ្មែរ ដើម្បីអាចដំណើរការបានពេញលេញ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះនៃភាសាការសរសេរកូដ: ចាប់ផ្តើមរៀនសរសេរកូដមូលដ្ឋានជាមួយ Python ដោយផ្តោតលើការគ្រប់គ្រងទិន្នន័យប្រភេទ String និង Data Structures ដូចជា Lists, Sets, និង Dictionaries ដែលជាធាតុផ្សំសំខាន់ក្នុងអត្ថបទនេះ។
  2. អនុវត្តការសម្អាតទិន្នន័យអត្ថបទ (Text Preprocessing): អនុវត្តការលុបសញ្ញាវណ្ណយុត្តិ និងពាក្យមិនចាំបាច់ (Stopwords) ដោយសាកល្បងសរសេរអនុគមន៍ដោយខ្លួនឯង ឬប្រើប្រាស់បណ្ណាល័យ NLTK សម្រាប់អត្ថបទភាសាអង់គ្លេសដើម្បីស្វែងយល់ពីគំរូ។
  3. រៀនគណនាដោយផ្ទាល់នូវក្បួនដោះស្រាយ TF-IDF: សរសេរកូដដើម្បីគណនា Term Frequency និង Inverse Document Frequency តាមរូបមន្តគណិតវិទ្យាដូចមានក្នុងឯកសារ មុននឹងប្តូរទៅប្រើប្រាស់បណ្ណាល័យសម្រួលការងារដូចជា Scikit-Learn (TfidfVectorizer) ។
  4. រួមបញ្ចូលជាមួយប្រព័ន្ធបំបែកពាក្យភាសាខ្មែរ: ដើម្បីអាចប្រើជាមួយអត្ថបទខ្មែរបាន និស្សិតត្រូវសិក្សាពីការប្រើប្រាស់ឧបករណ៍បំបែកពាក្យ (Word Segmenter) ដូចជាបណ្ណាល័យ khmer-nltk ឬ SeamKhao មុននឹងបញ្ចូលពាក្យទាំងនោះទៅក្នុងប្រព័ន្ធ TF-IDF ។
  5. អភិវឌ្ឍគម្រោងតូចមួយ (Mini-Project) ដាក់ឱ្យដំណើរការ: បង្កើតកម្មវិធីស្រង់ពាក្យគន្លឹះពីអត្ថបទព័ត៌មានខ្មែរ និងបង្ហាញលទ្ធផលនៅលើគេហទំព័រ (Web Interface) ដោយប្រើប្រាស់ Streamlit ឬ Flask ដើម្បីបន្ថែមជាស្នាដៃក្នុងប្រវត្តិរូប (Portfolio) របស់អ្នក។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Term Frequency (TF) ជារង្វាស់ដែលគណនាថាពាក្យមួយលេចឡើងប៉ុន្មានដងនៅក្នុងឯកសារតែមួយ ដោយធៀបនឹងចំនួនពាក្យសរុបក្នុងឯកសារនោះ។ វាមានគោលបំណងកំណត់ថាតើពាក្យនោះមានភាពសកម្ម ឬសំខាន់កម្រិតណានៅក្នុងអត្ថបទជាក់លាក់មួយ។ ដូចជាការរាប់ចំនួនដងដែលសិស្សម្នាក់លើកដៃឆ្លើយសំណួរក្នុងម៉ោងសិក្សា ដើម្បីដឹងថាគាត់សកម្មប៉ុណ្ណា។
Inverse Document Frequency (IDF) ជារង្វាស់ដែលវាយតម្លៃភាពកម្ររបស់ពាក្យនៅក្នុងសំណុំឯកសារទាំងមូល (Corpus)។ វាមានតួនាទីកាត់បន្ថយទម្ងន់នៃពាក្យដែលលេចឡើងស្ទើរតែគ្រប់ឯកសារ (ដូចជា "the", "and") និងបង្កើនទម្ងន់ដល់ពាក្យដែលកម្រមាន។ ដូចជារបស់កម្រ (វត្ថុបុរាណ) តែងតែមានតម្លៃខ្ពស់ ចំណែករបស់ដែលមានលក់នៅគ្រប់ទីកន្លែងទូទៅមានតម្លៃថោក។
TF-IDF ជារូបមន្តគណិតវិទ្យាដែលគុណតម្លៃ TF និង IDF បញ្ចូលគ្នា ដើម្បីថ្លឹងទម្ងន់រកពាក្យគន្លឹះដែលលេចធ្លោខ្លាំងក្នុងឯកសារមួយ ប៉ុន្តែកម្រមានក្នុងឯកសារដទៃទៀត ដែលធ្វើឱ្យវាជាពាក្យតំណាងដ៏ល្អបំផុតសម្រាប់ឯកសារនោះ។ ដូចជាការស្វែងរកកីឡាករដែលមិនត្រឹមតែពូកែក្នុងក្រុមរបស់ខ្លួន (TF) ប៉ុន្តែក៏មានជំនាញពិសេសដែលកម្រមានកីឡាករណាក្នុងលីគអាចធ្វើបាន (IDF) ផងដែរ។
Bag of Words (BoW) ជាទម្រង់តំណាងទិន្នន័យអត្ថបទដោយប្រមូលផ្តុំពាក្យទាំងអស់ដែលមានក្នុងអត្ថបទ ដោយមិនខ្វល់ពីលំដាប់លំដោយ វេយ្យាករណ៍ ឬបរិបទរបស់វាឡើយ ពោលគឺរាប់តែវត្តមាន និងចំនួនដងនៃពាក្យនីមួយៗប៉ុណ្ណោះ។ ដូចជាការយកគ្រឿងផ្សំទាំងអស់បោះចូលក្នុងថង់តែមួយ រួចក្រឡុកបញ្ចូលគ្នា ដោយមិនខ្វល់ថាគ្រឿងផ្សំណាដាក់មុន ឬដាក់ក្រោយឡើយ។
Stopwords ជាពាក្យទូទៅដែលប្រើញឹកញាប់ក្នុងភាសា (ឧទាហរណ៍៖ "is", "am", "are", "the") ប៉ុន្តែមិនមានអត្ថន័យសំខាន់ក្នុងការពណ៌នាពីខ្លឹមសារចម្បងនៃអត្ថបទ ដែលជាទូទៅត្រូវលុបចោលមុនពេលឱ្យកុំព្យូទ័រធ្វើការវិភាគទិន្នន័យ។ ដូចជាសំបកស្ករគ្រាប់ដែលយើងត្រូវបកចោលមុននឹងញ៉ាំ ដោយសារវាមិនមានរសជាតិអ្វីនោះទេ។
Tokenization ជាដំណើរការបំបែកកញ្ចប់ទិន្នន័យអត្ថបទ ឬប្រយោគវែងៗ ទៅជាកង់តូចៗ (Tokens) ដែលជាទូទៅអាចជាពាក្យនីមួយៗ ឬកន្សោមពាក្យ ដើម្បីងាយស្រួលឱ្យក្បួនដោះស្រាយកុំព្យូទ័រធ្វើការគណនាបន្ត។ ដូចជាការហាន់សាច់គោមួយដុំធំទៅជាចំណិតតូចៗ ដើម្បីងាយស្រួលយកទៅចម្អិន។
Vector Space Model (VSM) ជាទម្រង់គណិតវិទ្យាដែលបំប្លែងឯកសារអត្ថបទទៅជាវ៉ិចទ័រនៃតួលេខ (ម៉ាទ្រីស) ដើម្បីឱ្យកុំព្យូទ័រអាចគណនា វាស់ស្ទង់ភាពស្រដៀងគ្នា ឬចាត់ថ្នាក់ឯកសារទាំងនោះដោយប្រើរូបមន្តពីជគណិតបាន។ ដូចជាការបំប្លែងលក្ខណៈសម្បត្តិ និងចំណង់ចំណូលចិត្តរបស់មនុស្សម្នាក់ៗទៅជាតារាងពិន្ទុលេខ ដើម្បីងាយស្រួលប្រៀបធៀបរកអ្នកដែលមានចំណូលចិត្តស្រដៀងគ្នា។
