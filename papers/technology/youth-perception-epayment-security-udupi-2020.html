Chi-Square Analysis
ការវិភាគ Chi-Square (ការធ្វើតេស្តសម្មតិកម្ម)		 អាចកំណត់ថាតើមានទំនាក់ទំនងប្រកបដោយអត្ថន័យ (Significant Relationship) រវាងអថេរពីរប្រភេទ (ឧ. កម្រិតវប្បធម៌ និងការយល់ដឹងពីសន្តិសុខ) ដែរឬទេ។ បង្ហាញត្រឹមតែទំនាក់ទំនងប៉ុណ្ណោះ ប៉ុន្តែមិនអាចបញ្ជាក់ពីភាពជាហេតុនិងផល (Causality) បានឡើយ។ រកឃើញថាមិនមានទំនាក់ទំនងគួរឱ្យកត់សម្គាល់រវាងកម្រិតវប្បធម៌និងការយល់ដឹងពីសន្តិសុខទេ (តម្លៃ X2=0.22 ធៀបនឹងតម្លៃតារាង 5.99)។

  • Dataset: ទិន្នន័យបឋម (Primary Data) ដែលប្រមូលបានពីយុវជនចំនួន ២០០នាក់ ក្នុងស្រុក Udupi តាមរយៈកម្រងសំណួររចនាសម្ព័ន្ធ។

  1. កំណត់គោលដៅ និងទំហំនៃការស្រាវជ្រាវ (Define Scope): កំណត់តំបន់គោលដៅ (ឧ. និស្សិតសាកលវិទ្យាល័យក្នុងរាជធានីភ្នំពេញ) និងជ្រើសរើសប្រព័ន្ធទូទាត់ដែលពេញនិយមនៅកម្ពុជាដូចជា ABA Mobile ឬ Bakong ដើម្បីធ្វើជាប្រធានបទស្នូល។
  2. រៀបចំកម្រងសំណួរតាមអនឡាញ (Design Questionnaire): ប្រើប្រាស់កម្មវិធី Google Forms ឬ KoboToolbox ដើម្បីបង្កើតសំណួរទាក់ទងនឹងទម្លាប់នៃការប្រើប្រាស់លេខកូដសម្ងាត់ ការស្គាល់ពី Phishing និងការប្រើប្រាស់ Two-Factor Authentication (2FA)។
  3. ប្រមូលទិន្នន័យជាក់ស្តែង (Data Collection): ចែកចាយកម្រងសំណួរតាមរយៈបណ្តាញសង្គមដូចជា Telegram Groups និង Facebook Messenger ដោយកំណត់គោលដៅអ្នកចូលរួមយ៉ាងតិច ៣០០ ទៅ ៥០០នាក់ ដើម្បីទទួលបានលទ្ធផលប្រហាក់ប្រហែលនឹងចំនួនប្រជាជនជាក់ស្តែង។
  4. វិភាគទិន្នន័យតាមវិធីសាស្ត្រស្ថិតិ (Data Analysis): ប្រើប្រាស់កម្មវិធី SPSS ឬ Microsoft Excel ដើម្បីគណនាភាគរយ (Descriptive Statistics) និងធ្វើតេស្ត Chi-Square ដើម្បីមើលថាតើកម្រិតប្រាក់ចំណូល ឬទីលំនៅ (ទីក្រុង vs ជនបទ) មានឥទ្ធិពលលើការយល់ដឹងពីសន្តិសុខដែរឬទេ។
  5. សរសេររបាយការណ៍ និងផ្តល់អនុសាសន៍ (Report & Recommend): ចងក្រងលទ្ធផលដែលរកឃើញទៅជារបាយការណ៍ស្រាវជ្រាវ និងស្នើឡើងនូវដំណោះស្រាយជាក់ស្តែងជូនដល់ក្រុមហ៊ុន FinTech ក្នុងស្រុក អំពីវិធីកែលម្អ User Interface (UI) ឱ្យកាន់តែមានសុវត្ថិភាពនិងងាយស្រួលប្រើ។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
E-Payment system ប្រព័ន្ធសម្រាប់ធ្វើការទូទាត់ប្រាក់ ឬផ្ទេរប្រាក់តាមរយៈប្រព័ន្ធអ៊ីនធឺណិតដោយមិនប្រើប្រាស់សាច់ប្រាក់ផ្ទាល់ ដើម្បីសម្រួលដល់ការដោះដូរទំនិញនិងសេវាកម្ម។ ដូចជាការប្រើប្រាស់កម្មវិធី ABA Mobile ឬ Bakong ដើម្បីបង់លុយថ្លៃកាហ្វេដោយមិនបាច់ហុចលុយក្រដាស។
E-Commerce ការទិញនិងលក់ទំនិញ ព័ត៌មាន ឬសេវាកម្មផ្សេងៗតាមរយៈប្រព័ន្ធអ៊ីនធឺណិត ដែលអនុញ្ញាតឱ្យក្រុមហ៊ុនអាចលក់ផលិតផលរបស់ខ្លួនទៅកាន់អតិថិជនដោយមិនចាំបាច់មានតូបលក់ផ្ទាល់។ ដូចជាការបញ្ជាទិញខោអាវ ឬម្ហូបអាហារតាមរយៈ Facebook ឬ Nham24 ជំនួសឱ្យការធ្វើដំណើរទៅទិញផ្ទាល់នៅហាង។
Chi-Square Analysis វិធីសាស្ត្រស្ថិតិមួយប្រភេទដែលប្រើសម្រាប់សាកល្បងថាតើមានទំនាក់ទំនងគួរឱ្យកត់សម្គាល់រវាងអថេរពីរប្រភេទ (ឧទាហរណ៍ កម្រិតវប្បធម៌ និងការយល់ដឹងពីសន្តិសុខ) ដែរឬទេ។ ដូចជាការធ្វើតេស្តគណិតវិទ្យាដើម្បីមើលថាតើមនុស្សដែលចូលចិត្តញ៉ាំផ្អែម និងមនុស្សដែលធាត់ គឺពិតជាមានជាប់ពាក់ព័ន្ធគ្នា ឬគ្រាន់តែជាការចៃដន្យ។
Null hypothesis ការសន្មតបឋមក្នុងការវិភាគស្ថិតិដែលបញ្ជាក់ថា គ្មានទំនាក់ទំនង ឬគ្មានឥទ្ធិពលអ្វីឡើយរវាងអថេរដែលកំពុងសិក្សា (ឧទាហរណ៍ កម្រិតវប្បធម៌មិនមានឥទ្ធិពលលើការយល់ដឹងពីសន្តិសុខទេ)។ ដូចជាការសន្មតជាមុនថា "ការរៀនគួរ និងពិន្ទុប្រឡង គឺមិនមានជាប់ពាក់ព័ន្ធគ្នាទេ" មុនពេលអ្នកស្រាវជ្រាវប្រមូលទិន្នន័យដើម្បីមករកការពិត។
Technology Acceptance Model ទ្រឹស្តីប្រព័ន្ធព័ត៌មានដែលត្រូវបានប្រើប្រាស់ដើម្បីពន្យល់ និងទស្សន៍ទាយពីកត្តាដែលធ្វើឱ្យអ្នកប្រើប្រាស់សម្រេចចិត្តទទួលយក និងប្រើប្រាស់បច្ចេកវិទ្យាថ្មីមួយ (ផ្តោតលើភាពងាយស្រួល និងអត្ថប្រយោជន៍នៃការប្រើប្រាស់)។ ដូចជាការសិក្សាស្វែងយល់ថាហេតុអ្វីបានជាមនុស្សចាស់មួយចំនួនពិបាកនឹងប្តូរមកប្រើស្មាតហ្វូន (Smartphone) ជំនួសទូរស័ព្ទចុចប៊ូតុងធម្មតា។
Descriptive research វិធីសាស្ត្រស្រាវជ្រាវដែលផ្តោតលើការប្រមូលទិន្នន័យដើម្បីពណ៌នាពីលក្ខណៈ ឬអាកប្បកិរិយារបស់ក្រុមគោលដៅនៅពេលវេលាណាមួយដោយមិនមានការកែប្រែ ឬគ្រប់គ្រងអថេរណាមួយឡើយ។ ដូចជាការថតរូបសកម្មភាពមនុស្សនៅតាមដងផ្លូវ ដើម្បីពណ៌នាពីស្ថានភាពចរាចរណ៍ជាក់ស្តែង ដោយមិនបានទៅបញ្ជាឱ្យពួកគេបើកបរលឿនឬយឺតឡើយ។
Smart card កាតប្លាស្ទិកដែលមានបង្កប់បន្ទះឈីបអេឡិចត្រូនិកខាងក្នុង សម្រាប់រក្សាទុកទិន្នន័យអត្តសញ្ញាណ ឬធ្វើប្រតិបត្តិការហិរញ្ញវត្ថុដោយសុវត្ថិភាពខ្ពស់។ ដូចជាកាត ATM ជំនាន់ថ្មី ឬកាតគ្រី ដែលមានបន្ទះឈីបពណ៌មាសតូចមួយនៅខាងមុខសម្រាប់ការពារការលួចចម្លងទិន្នន័យ។
