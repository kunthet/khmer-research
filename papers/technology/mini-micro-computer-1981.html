Minicomputers
ម៉ាស៊ីនកុំព្យូទ័រខ្នាតតូច (Minicomputers)		 មានសមត្ថភាពដំណើរការខ្ពស់ ប្រើប្រាស់បច្ចេកវិទ្យា MSI មានកម្មវិធីគាំទ្រច្រើន និងស័ក្តិសមសម្រាប់ក្រុមហ៊ុនធំៗ។ មានតម្លៃថ្លៃខ្លាំង (៣ម៉ឺន ទៅ ១៥ម៉ឺនដុល្លារ) ទំហំធំ និងស្មុគស្មាញក្នុងការថែទាំ។ ជាជម្រើសចម្បងសម្រាប់ស្ថាប័នធំៗដែលត្រូវការសមត្ថភាពផ្ទុកទិន្នន័យនិងដំណើរការល្បឿនលឿនក្នុងទសវត្សរ៍ឆ្នាំ១៩៧០ និងដើមទសវត្សរ៍១៩៨០។
Microcomputers
មីក្រូកុំព្យូទ័រ (Microcomputers)		 មានតម្លៃថោក (ចាប់ពី ១ពាន់ ទៅ ២,៥ពាន់ដុល្លារ) ទំហំតូច (ប្រើបច្ចេកវិទ្យា LSI/Microprocessor) និងងាយស្រួលប្រើប្រាស់ទូទៅ។ នៅដើមដំបូងមានល្បឿនយឺតជាង និងខ្វះខាតកម្មវិធី (Software) គាំទ្របើធៀបនឹង Minicomputer។ បានក្លាយជាកម្លាំងចលករដ៏សំខាន់ក្នុងការធ្វើឱ្យកុំព្យូទ័រអាចប្រើប្រាស់បានយ៉ាងទូលំទូលាយសម្រាប់អាជីវកម្មខ្នាតតូចនិងមធ្យម ព្រមទាំងការប្រើប្រាស់ផ្ទាល់ខ្លួន។

  • ប្រព័ន្ធស្វ័យប្រវត្តិកម្ម និង IoT (Internet of Things): គោលការណ៍នៃការប្រើប្រាស់មីក្រូប្រូសេស័រដើម្បីគ្រប់គ្រងម៉ាស៊ីន ឬភ្លើងចរាចរណ៍ ដែលបានរៀបរាប់ក្នុងឯកសារ គឺជាមូលដ្ឋានគ្រឹះនៃប្រព័ន្ធ IoT ដែលកសិដ្ឋាននិងរោងចក្រឆ្លាតវៃនៅកម្ពុជាកំពុងប្រើប្រាស់សព្វថ្ងៃ។
  • ការធ្វើបរិវត្តកម្មឌីជីថលសម្រាប់សហគ្រាសធុនតូចនិងមធ្យម (SMEs): អត្ថបទបង្ហាញពីការផ្លាស់ប្តូរពីការធ្វើការងារដោយដៃទៅជាការប្រើប្រព័ន្ធកុំព្យូទ័រសម្រាប់គណនេយ្យនិងការគ្រប់គ្រងស្តុក ដែលឆ្លុះបញ្ចាំងពីតម្រូវការបច្ចុប្បន្នរបស់អាជីវកម្មតូចៗនៅកម្ពុជា។

ការយល់ដឹងពីប្រវត្តិ និងការវិវឌ្ឍន៍នៃមីក្រូកុំព្យូទ័រ ផ្តល់នូវទស្សនវិស័យយ៉ាងទូលំទូលាយដល់និស្សិត និងអ្នកបច្ចេកទេសនៅកម្ពុជាក្នុងការអភិវឌ្ឍប្រព័ន្ធស្វ័យប្រវត្តិកម្ម និងដំណោះស្រាយឌីជីថលប្រកបដោយភាពច្នៃប្រឌិតនាពេលបច្ចុប្បន្ន។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះស្ថាបត្យកម្មកុំព្យូទ័រ: ស្វែងយល់ពីរបៀបដែល CPU, RAM, ROM, និងមុខងារ I/O ដំណើរការបញ្ចូលគ្នា ដោយប្រើប្រាស់កម្មវិធីក្លែងធ្វើដូចជា Logisim ឬ Proteus។
  2. អនុវត្តជាក់ស្តែងជាមួយប្រព័ន្ធមីក្រូបញ្ជា (Microcontrollers): ចាប់ផ្តើមរៀនសរសេរកូដបញ្ជាផ្នែករឹងដោយប្រើប្រាស់ Arduino ឬ Raspberry Pi ដែលជាជំនាន់ទំនើបនិងតូចជាងមុននៃមីក្រូប្រូសេស័រដែលបានលើកឡើងក្នុងឯកសារ។
  3. រៀនភាសាសរសេរកូដកម្រិតទាប (Low-Level Programming): សិក្សាពីភាសា C/C++ ឬ Assembly Language ដើម្បីយល់ច្បាស់ពីការគ្រប់គ្រងអង្គចងចាំ និងការបញ្ជា Hardware ដោយផ្ទាល់ប្រកបដោយប្រសិទ្ធភាព។
  4. អភិវឌ្ឍគម្រោងស្វ័យប្រវត្តិកម្មខ្នាតតូច: អនុវត្តចំណេះដឹងដើម្បីបង្កើតប្រព័ន្ធងាយៗ ដូចជាប្រព័ន្ធស្រោចស្រពដំណាំស្វ័យប្រវត្តិ ឬប្រព័ន្ធគ្រប់គ្រងសីតុណ្ហភាព ដោយប្រើប្រាស់សេនស័រ (Sensors) និង Microcontrollers សម្រាប់ដោះស្រាយបញ្ហាក្នុងស្រុក។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Microprocessor (មីក្រូប្រូសេស័រ) ជាបន្ទះសៀគ្វីអេឡិចត្រូនិកដែលប្រមូលផ្តុំមុខងារបញ្ជានិងគណនារបស់កុំព្យូទ័រ (CPU) ទៅក្នុងបន្ទះឈីបតូចតែមួយ ដែលធ្វើឱ្យកុំព្យូទ័រមានទំហំតូច ដំណើរការបានលឿន និងមានតម្លៃថោក។ ប្រៀបដូចជាខួរក្បាលរបស់កុំព្យូទ័រដែលបញ្ជាសកម្មភាពគ្រប់យ៉ាង តែត្រូវបានបង្រួមឱ្យតូចប៉ុនក្រចកដៃ។
LSI - Large Scale Integrated Circuit (សៀគ្វីរួមបញ្ចូលខ្នាតធំ) បច្ចេកវិទ្យាក្នុងការបង្រួមនិងរៀបចំបណ្ដុំត្រង់ស៊ីស្ទ័រ (Transistors) រាប់ពាន់ទៅម៉ឺននៅលើបន្ទះឈីបស៊ីលីកូនតែមួយ ដើម្បីបង្កើនសមត្ថភាពផ្ទុកនិងល្បឿនដំណើរការទិន្នន័យ។ ដូចជាការសាងសង់ទីក្រុងធំមួយដែលមានផ្ទះរាប់ម៉ឺនខ្នងនៅលើផ្ទៃដីដ៏តូចចង្អៀតមួយ។
Minicomputer (ម៉ាស៊ីនកុំព្យូទ័រខ្នាតតូច) ជាប្រភេទកុំព្យូទ័រក្នុងទសវត្សរ៍ឆ្នាំ១៩៧០-១៩៨០ ដែលមានទំហំប៉ុនទូទឹកកក មានសមត្ថភាពខ្ពស់ក្នុងការដំណើរការទិន្នន័យសម្រាប់ស្ថាប័នធំៗ ប៉ុន្តែតូចនិងថោកជាងកុំព្យូទ័រខ្នាតយក្ស (Mainframe)។ ប្រៀបដូចជារថយន្តក្រុងខ្នាតតូច (Minibus) ដែលអាចដឹកជញ្ជូនទិន្នន័យបានច្រើនសម្រាប់ក្រុមហ៊ុន ធៀបនឹងរថយន្តផ្ទាល់ខ្លួនដែលមានទំហំតូច។
Microcomputer (មីក្រូកុំព្យូទ័រ) ជាកុំព្យូទ័រដែលប្រើប្រាស់មីក្រូប្រូសេស័រ (Microprocessor) ជាអង្គគណនាកណ្តាល (CPU) ដែលធ្វើឱ្យវាមានទំហំតូច តម្លៃថោក និងស័ក្តិសមសម្រាប់ការប្រើប្រាស់ផ្ទាល់ខ្លួន ឬអាជីវកម្មខ្នាតតូចនិងមធ្យម។ គឺកុំព្យូទ័រលើតុ (Desktop) ឬកុំព្យូទ័រយួរដៃ (Laptop) ដែលយើងប្រើប្រាស់សម្រាប់ការងារប្រចាំថ្ងៃនេះឯង។
ROM - Read Only Memory (អង្គចងចាំសម្រាប់តែអាន) ជាប្រភេទអង្គចងចាំដែលផ្ទុកទិន្នន័យ ឬកម្មវិធីជាអចិន្ត្រៃយ៍ពីក្រុមហ៊ុនផលិត ដែលទិន្នន័យទាំងនោះមិនបាត់បង់ទេទោះបីជាបិទកុំព្យូទ័រក៏ដោយ ហើយវាប្រើសម្រាប់ប្រាប់កុំព្យូទ័រពីរបៀបចាប់ផ្តើមដំណើរការ។ ដូចជាសៀវភៅបោះពុម្ពដែលអ្នកអាចអានព័ត៌មាននៅក្នុងនោះបាន ប៉ុន្តែមិនអាចលុប ឬសរសេរអ្វីបន្ថែមលើវាបានដោយងាយនោះទេ។
Interface (ចំណុចប្រទាក់ / អន្តរមុខ) ជាផ្នែករឹង (Hardware) ឬផ្នែកទន់ (Software) ដែលដើរតួជាស្ពានចម្លង ឬច្រកតភ្ជាប់ ដើម្បីអនុញ្ញាតឱ្យប្រព័ន្ធពីរផ្សេងគ្នា (ឧទាហរណ៍ កុំព្យូទ័រ និងម៉ាស៊ីនបោះពុម្ព) អាចទំនាក់ទំនងនិងបញ្ជូនទិន្នន័យទៅវិញទៅមកបាន។ ប្រៀបដូចជាអ្នកបកប្រែភាសា ដែលជួយឱ្យមនុស្សពីរនាក់ដែលនិយាយភាសាផ្សេងគ្នាអាចសន្ទនានិងយល់គ្នាបាន។
Stand alone computer (កុំព្យូទ័រឯករាជ្យ) ជាប្រព័ន្ធកុំព្យូទ័រដែលមានសមាសធាតុគ្រប់គ្រាន់ (ដូចជា CPU អេក្រង់ ក្តារចុច និងអង្គចងចាំ) នៅក្នុងតួតែមួយ ដើម្បីដំណើរការដោយខ្លួនឯងបានពេញលេញ ដោយមិនចាំបាច់តភ្ជាប់ទៅកាន់ម៉ាស៊ីនកុំព្យូទ័រមេផ្សេងទៀតឡើយ។ ដូចជាផ្ទះមួយដែលមានបន្ទប់ទឹក ផ្ទះបាយ និងបន្ទប់គេងគ្រប់គ្រាន់ដោយខ្លួនឯង ដោយមិនចាំបាច់ពឹងផ្អែកទៅប្រើប្រាស់របស់ផ្ទះអ្នកជិតខាង។
