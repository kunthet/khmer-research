១. សេចក្តីសង្ខេបប្រតិបត្តិ (Executive Summary)

បញ្ហា (The Problem)៖ ការសិក្សានេះដោះស្រាយបញ្ហានៃការការពារប្រព័ន្ធរូបវន្ត (Cyber-Physical Systems - CPSs) ដែលជួបប្រទះការលំបាកក្នុងការបែងចែករវាងកំហុសបច្ចេកទេសដែលកើតឡើងដោយឯកឯង និងការវាយប្រហារដោយចេតនាពីឧក្រិដ្ឋជន។

វិធីសាស្ត្រ (The Methodology)៖ អ្នកនិពន្ធប្រើប្រាស់វិធីសាស្ត្រផ្អែកលើគំរូរូបវិទ្យា ដោយចាត់ទុក CPS ជាប្រព័ន្ធលីនេអ៊ែរតាមពេលវេលាដាច់ដោយឡែក (Discrete-time linear system) ដើម្បីតាមដាន និងវិភាគភាពមិនប្រក្រតី។

  • ការប្រើប្រាស់ក្របខ័ណ្ឌអ្នកសង្កេតការណ៍ (Luenberger Observer) ដើម្បីគណនាសំណល់ (Residuals) និងញែកកំហុស។
  • ការពិសោធន៍លើប្រព័ន្ធធុងទឹកបី (Three-tank hydraulic benchmark system) ដើម្បីធ្វើជាគំរូនៃការធ្វើតេស្ត។

លទ្ធផលសំខាន់ៗ (The Verdict)៖

  • វិធីសាស្ត្រផ្អែកលើរូបវិទ្យាអាចបែងចែកយ៉ាងច្បាស់រវាងការវាយប្រហារលើឧបករណ៍ចាប់សញ្ញា (Sensor attacks) និងកំហុសបច្ចេកទេសរបស់ឧបករណ៍ចាប់សញ្ញា។
  • ការវាយប្រហារលើឧបករណ៍បញ្ជា (Actuator attacks) មិនអាចបែងចែកដាច់ពីកំហុសបច្ចេកទេសរបស់ឧបករណ៍បញ្ជាបានទេ ដោយសារឥទ្ធិពលរូបវិទ្យាទៅលើប្រព័ន្ធមានលក្ខណៈដូចគ្នាទាំងស្រុង។
  • ការវិភាគលើអត្រាបម្រែបម្រួលទិន្នន័យ (First derivative analysis) អនុញ្ញាតឱ្យរកឃើញទិន្នន័យក្លែងក្លាយដែលបង្កើតឡើងដោយអ្នកវាយប្រហារ ជាពិសេសនៅពេលដែលសំណល់កើនឡើងលើសកម្រិតកំណត់។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Sensor Attack Detection (Physics-based)
ការរកឃើញការវាយប្រហារលើឧបករណ៍ចាប់សញ្ញា (Sensor) ដោយផ្អែកលើរូបវិទ្យា		 អាចបែងចែកយ៉ាងច្បាស់រវាងការវាយប្រហារ (Attack) និងកំហុសបច្ចេកទេស (Fault) ដោយវិភាគលើទំនាក់ទំនងរវាងទិន្នន័យនិងប្រតិកម្មរបស់ប្រព័ន្ធ។ ទាមទារឱ្យមានគំរូ (Model) នៃប្រព័ន្ធដែលមានភាពជាក់លាក់ខ្ពស់ បើមិនដូច្នោះទេអាចមានកំហុសក្នុងការវិភាគ។ ជោគជ័យក្នុងការរកឃើញ និងញែកដាច់ពីគ្នារវាងកំហុសធម្មតានិងការវាយប្រហារ។
Actuator Attack Detection (Physics-based)
ការរកឃើញការវាយប្រហារលើឧបករណ៍បញ្ជា (Actuator/Valve) ដោយផ្អែកលើរូបវិទ្យា		 អាចរកឃើញថាមានភាពមិនប្រក្រតីកើតឡើងនៅក្នុងប្រព័ន្ធ។ មិនអាចបែងចែកដាច់ពីគ្នារវាងការវាយប្រហារ និងកំហុសបច្ចេកទេសបានទេ ព្រោះឥទ្ធិពលរូបវិទ្យាទៅលើប្រព័ន្ធមានលក្ខណៈដូចគ្នា។ អាចរកឃើញភាពមិនប្រក្រតី ប៉ុន្តែបរាជ័យក្នុងការកំណត់ប្រភពថាជាការវាយប្រហារឬកំហុស។

ការចំណាយលើធនធាន (Resource Cost)៖ ការសិក្សានេះគឺជាការពិសោធន៍តាមរយៈការធ្វើត្រាប់តាម (Simulation) ដូចនេះមិនទាមទារធនធានរូបវន្តថ្លៃៗទេ ប៉ុន្តែទាមទារជំនាញគណិតវិទ្យាខ្ពស់។

  • Software: កម្មវិធីសម្រាប់ធ្វើត្រាប់តាមប្រព័ន្ធ (Simulation tools) ដូចជា MATLAB/Simulink ឬ Python (Scipy/NumPy)។
  • Expertise: ចំណេះដឹងស៊ីជម្រៅលើផ្នែកទ្រឹស្តីគ្រប់គ្រង (Control Theory) និងម៉ូដែលលីនេអ៊ែរ (Linear State-Space Models)។
  • Computing Power: កុំព្យូទ័រទូទៅអាចដំណើរការបាន ដោយមិនចាំបាច់មាន GPU ខ្លាំងក្លាទេ ព្រោះម៉ូដែលជាសមីការឌីផេរ៉ង់ស្យែលធម្មតា។

៣. ការពិនិត្យសម្រាប់បរិបទកម្ពុជា/អាស៊ីអាគ្នេយ៍

ភាពលំអៀងនៃទិន្នន័យ (Data Bias)៖

ការសិក្សានេះប្រើប្រាស់ទិន្នន័យដែលបង្កើតឡើងដោយកុំព្យូទ័រ (Simulated Data) លើប្រព័ន្ធធុងទឹកស្តង់ដារ (Three-tank benchmark)។ វាមិនបានឆ្លុះបញ្ចាំងពីសំឡេងរំខាន (Noise) ឬភាពស្មុគស្មាញនៃបណ្តាញទំនាក់ទំនងជាក់ស្តែងនៅក្នុងរោងចក្រឧស្សាហកម្មនៅកម្ពុជាឡើយ។

លទ្ធភាពនៃការអនុវត្ត (Applicability)៖

វិធីសាស្ត្រនេះមានសារៈសំខាន់ខ្លាំងសម្រាប់កម្ពុជា ក្នុងដំណាក់កាលដែលយើងកំពុងអភិវឌ្ឍប្រព័ន្ធគ្រប់គ្រងស្វ័យប្រវត្តិកម្ម។

  • វិស័យផ្គត់ផ្គង់ទឹកស្អាត (Water Supply): អាចអនុវត្តនៅ រដ្ឋាករទឹកស្វយ័តក្រុងភ្នំពេញ (PPWSA) ដើម្បីការពារប្រព័ន្ធ SCADA ពីការបញ្ជូនទិន្នន័យសម្ពាធទឹកក្លែងក្លាយ។
  • វិស័យថាមពល (Energy Sector): មានប្រយោជន៍សម្រាប់ អគ្គិសនីកម្ពុជា (EDC) ក្នុងការតាមដានស្ថានីយអគ្គិសនីដើម្បីធានាថាការដាច់ចរន្តជាកំហុសបច្ចេកទេស មិនមែនការវាយប្រហារ។
  • តំបន់សេដ្ឋកិច្ចពិសេស (SEZs): រោងចក្រដែលមានប្រព័ន្ធស្វ័យប្រវត្តិកម្មនៅតំបន់សេដ្ឋកិច្ចពិសេសភ្នំពេញ អាចប្រើដើម្បីត្រួតពិនិត្យសុវត្ថិភាពម៉ាស៊ីន។

វាជាមូលដ្ឋានគ្រឹះដ៏ល្អសម្រាប់ការការពារសុវត្ថិភាពហេដ្ឋារចនាសម្ព័ន្ធសំខាន់ៗ ប៉ុន្តែត្រូវប្រើរួមគ្នាជាមួយប្រព័ន្ធការពារបណ្តាញ (Network Security) ផ្សេងទៀត។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Cyber-Physical Systems (CPSs) ប្រព័ន្ធដែលរួមបញ្ចូលគ្នារវាងការគណនារបស់កុំព្យូទ័រ (Cyber) និងដំណើរការនៃគ្រឿងយន្តរូបវន្ត (Physical)។ វាប្រើប្រាស់បណ្តាញដើម្បីតាមដាន និងគ្រប់គ្រងវត្ថុរូបវន្តដូចជា រោងចក្រអគ្គិសនី ឬយានយន្តជាដើម។ ប្រៀបដូចជាមនុស្សដែលមានខួរក្បាល (កុំព្យូទ័រ) បញ្ជាទៅសាច់ដុំ (គ្រឿងយន្ត) តាមរយៈប្រព័ន្ធសរសៃប្រសាទ (បណ្តាញ)។
Luenberger observer គឺជាក្បួនដោះស្រាយគណិតវិទ្យាដែលប្រើដើម្បីប៉ាន់ស្មានស្ថានភាពខាងក្នុង (Internal State) នៃប្រព័ន្ធមួយ ដោយផ្អែកលើទិន្នន័យចេញ (Output) និងទិន្នន័យចូល (Input) ដែលគេស្គាល់។ ប្រៀបដូចជាការព្យាករណ៍អាកាសធាតុ ដោយមើលលើសីតុណ្ហភាពបច្ចុប្បន្នដើម្បីទាយដឹងពីស្ថានភាពបរិយាកាសខាងលើដែលយើងមើលមិនឃើញ។
Residuals គឺជាផលសង ឬភាពខុសគ្នារវាងតម្លៃដែលវាស់បានជាក់ស្តែងពីឧបករណ៍ចាប់សញ្ញា (Sensor) និងតម្លៃដែលបានប៉ាន់ស្មានដោយគំរូគណិតវិទ្យា។ នៅក្នុងឯកសារនេះ វាត្រូវបានប្រើដើម្បីកំណត់ថាមានកំហុស ឬការវាយប្រហារឬអត់។ ដូចជាការផ្ទៀងផ្ទាត់លុយអាប់នៅផ្សារ បើលុយដែលទទួលបានខុសពីលុយដែលត្រូវទទួលបាន នោះហៅថា 'Residual' (កំហុស)។
Actuator គឺជាឧបករណ៍មេកានិចដែលបំប្លែងសញ្ញាបញ្ជា (Control Signal) ទៅជាចលនារូបវន្ត ដូចជាការបើក/បិទវ៉ាល់ទឹក ឬការដំណើរការម៉ូទ័រជាដើម។ គឺជាដៃជើងរបស់ម៉ាស៊ីន ដែលធ្វើសកម្មភាពជាក់ស្តែងតាមការបញ្ជារបស់ខួរក្បាល។
Discrete-time linear system គំរូគណិតវិទ្យាដែលពិពណ៌នាអំពីប្រព័ន្ធដែលការផ្លាស់ប្តូររបស់វាកើតឡើងនៅចន្លោះពេលជាក់លាក់ (មិនមែនជាប់រហូតទេ) ហើយទំនាក់ទំនងរវាងធាតុចូល និងធាតុចេញគឺជាសមាមាត្រត្រង់ (Linear)។ ប្រៀបដូចជានាឡិកាដើរទាក់ៗមួយវិនាទីម្តងៗ (Discrete) ជាជាងនាឡិកាដែលដើររលូនជាប់គ្នារហូត។
Mode Identification គឺជាដំណើរការនៃការកំណត់ថាតើប្រព័ន្ធកំពុងដំណើរការក្នុងស្ថានភាព (Mode) មួយណា៖ ស្ថានភាពធម្មតា ស្ថានភាពមានកំហុសបច្ចេកទេស ឬស្ថានភាពកំពុងត្រូវបានវាយប្រហារ។ ដូចជាគ្រូពេទ្យធ្វើរោគវិនិច្ឆ័យដើម្បីដឹងថាអ្នកជំងឺគ្រាន់តែអស់កម្លាំង (ធម្មតា) ឈឺ (កំហុស) ឬត្រូវថ្នាំពុល (ការវាយប្រហារ)។
