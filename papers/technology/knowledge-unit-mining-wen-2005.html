ចំណងជើងដើម៖ 知识元挖掘

អ្នកនិពន្ធ៖ 温有奎 (Wen Youkui), 徐国华 (Xu Guohua), 赖伯年 (Lai Bonian), 温浩 (Wen Hao)

ឆ្នាំបោះពុម្ព៖ 2005, 西安电子科技大学出版社 (Xidian University Press)

វិស័យសិក្សា៖ Information Science & Knowledge Management

១. សេចក្តីសង្ខេប (Overview)

ប្រធានបទ (Topic)៖ ការទាញយកព័ត៌មានតាមបែបប្រពៃណីមានកម្រិតត្រឹមតែការផ្គូផ្គងពាក្យគន្លឹះ និងឯកសារទាំងមូល ដែលបណ្តាលឱ្យមានព័ត៌មានច្រើនលើសលុប (Information Overload) និងធ្វើឱ្យមានការលំបាកយ៉ាងខ្លាំងក្នុងការទាញយកចំណេះដឹងជាក់លាក់ និងស៊ីជម្រៅពីអត្ថបទដែលគ្មានរចនាសម្ព័ន្ធ។

រចនាសម្ព័ន្ធ (Structure)៖ អ្នកនិពន្ធស្នើឡើងនូវក្របខ័ណ្ឌទ្រឹស្តី និងការអនុវត្តជាក់ស្តែងសម្រាប់ការរុករក "ឯកតាចំណេះដឹង" (Knowledge Unit) ដោយប្រើប្រាស់ដំណើរការភាសាធម្មជាតិ និងបច្ចេកវិទ្យាបណ្តាញអត្ថន័យ (Semantic Web)។

  • ការស្រង់ចេញឯកតាចំណេះដឹងពីអត្ថបទ (Text Knowledge Unit Extraction)
  • ការបង្កើតគំរូអនតូឡូស៊ីចំណេះដឹងដោយប្រើប្រាស់ XML និង OWL (XML/OWL Ontology Modeling)
  • ការវិភាគរចនាសម្ព័ន្ធ និងការបែងចែកឋានានុក្រមប្រធានបទ (Document Structure Analysis and Clustering)
  • ការវែកញែកអត្ថន័យ និងការតភ្ជាប់ឯកតាចំណេះដឹង (Semantic Reasoning and Knowledge Linking)

ចំណុចសំខាន់ៗ (Key Takeaways)៖

  • ការបំបែកឯកសារទៅជាឯកតាចំណេះដឹងតូចៗ បង្កើនភាពសុក្រឹតនៃការស្រង់យកទិន្នន័យជាក់លាក់ (សម្រេចបានអត្រាភាពត្រឹមត្រូវ ១០០% សម្រាប់ការស្រង់ទិន្នន័យលេខតួលេខ ជាមួយនឹងការកែសម្រួលដោយមនុស្សត្រឹមតែ ២០%)។
  • ការប្រើប្រាស់បច្ចេកវិទ្យា XML និង OWL អនុញ្ញាតឱ្យប្រព័ន្ធកុំព្យូទ័រយល់ដឹងពីអត្ថន័យនៃអត្ថបទ និងធ្វើការវែកញែកតក្កវិជ្ជាចំណេះដឹងដោយស្វ័យប្រវត្តិ។
  • ការផ្លាស់ប្តូរពីសេវាកម្មស្វែងរកឯកសារទៅជាសេវាកម្មផ្តល់ចំណេះដឹងផ្ទាល់ គឺជាបដិវត្តន៍ដ៏សំខាន់សម្រាប់ការគ្រប់គ្រងចំណេះដឹង (Knowledge Management Revolution) ក្នុងយុគសម័យបណ្តាញ (Grid Era)។

២. គោលបំណងសិក្សា (Learning Objectives)

បន្ទាប់ពីអានឯកសារនេះ អ្នកគួរអាច៖

  1. យល់ដឹងពីគោលគំនិតជាមូលដ្ឋាននៃធាតុចំណេះដឹង (Knowledge Elements) និងការរកឃើញចំណេះដឹងក្នុងមូលដ្ឋានទិន្នន័យ (Knowledge Discovery in Databases - KDD)។","សិក្សាពីក្បួនដោះស្រាយ និងម៉ូដែលសម្រាប់ការធ្វើលិបិក្រមអត្ថបទ និងការទាញយកទិន្នន័យ ដូចជាម៉ូដែលលំហវ៉ិចទ័រ (Vector Space Model - VSM) និងការវាស់ស្ទង់ព័ត៌មាន។","ស្ទាត់ជំនាញលើវិធីសាស្ត្រក្នុងការទាញយកចំណេះដឹងពីអត្ថបទដោយប្រើប្រាស់បច្ចេកវិទ្យាភាសាធម្មជាតិ (NLP) និងឧបករណ៍ផ្អែកលើ XML/Ontology។","ស្វែងយល់ពីតួនាទីនៃការគ្រប់គ្រងចំណេះដឹង (Knowledge Management) និងខ្សែច្រវាក់ចំណេះដឹង (Knowledge Chains) ក្នុងការជំរុញនវានុវត្តន៍ក្នុងស្ថាប័ន។

ឯកសារនេះសិក្សាស៊ីជម្រៅអំពីវដ្តនៃការបង្កើត ការរៀបចំ និងការទាញយកចំណេះដឹងដោយស្វ័យប្រវត្តិពីអត្ថបទ។ វាណែនាំអំពីគំនិតនៃ "ធាតុចំណេះដឹង" (Knowledge Elements) ដែលជាឯកតាតូចបំផុតនៃចំណេះដឹង ព្រមទាំងបង្ហាញពីវិធីសាស្ត្រទាញយកទិន្នន័យអត្ថបទ ការវែកញែកអុនតូឡូស៊ី (Ontology reasoning) និងការប្រើប្រាស់ XML ដើម្បីធ្វើឲ្យប្រសើរឡើងនូវប្រព័ន្ធស្វែងរកព័ត៌មាន និងការគ្រប់គ្រងចំណេះដឹង។

៣. គោលគំនិតសំខាន់ៗ (Key Concepts)

គោលគំនិត (Concept) ការពន្យល់ (Explanation) ឧទាហរណ៍ (Example)
Knowledge Element (KE)
ធាតុចំណេះដឹង (Knowledge Element)		 ជាឯកតាតូចបំផុត ឯករាជ្យ និងមិនអាចបំបែកបាននៃចំណេះដឹងនៅក្នុងអត្ថបទមួយ (ឧទាហរណ៍៖ អង្គហេតុជាក់លាក់ រូបមន្ត ឬសេចក្តីសន្និដ្ឋាន) ដែលត្រូវបានប្រើប្រាស់សម្រាប់ការធ្វើលិបិក្រម និងការស្វែងរកដ៏ជាក់លាក់។ ជំនួសឲ្យការស្វែងរកឯកសារទាំងមូល ប្រព័ន្ធអាចទាញយកតែចំណុចសំខាន់ៗដែលអ្នកប្រើប្រាស់ត្រូវការ។ ការទាញយកទិន្នន័យជាក់លាក់ដូចជា "ប្រសិទ្ធភាពម៉ាស៊ីនគឺ 8 តោន/គីឡូវ៉ាត់" ចេញពីរបាយការណ៍បច្ចេកទេសដ៏វែងមួយ ជាជាងការបង្ហាញរបាយការណ៍ទាំងមូលនៅពេលអ្នកប្រើប្រាស់ស្វែងរកពាក្យ "ម៉ាស៊ីន"។
Knowledge Discovery in Databases (KDD) / Text Mining
ការរកឃើញចំណេះដឹងក្នុងមូលដ្ឋានទិន្នន័យ / ការទាញយកទិន្នន័យអត្ថបទ (KDD / Text Mining)		 ដំណើរការដ៏ស្មុគស្មាញក្នុងការកំណត់អត្តសញ្ញាណគំរូទិន្នន័យដែលត្រឹមត្រូវ ថ្មី មានប្រយោជន៍ និងអាចយល់បានពីក្នុងមូលដ្ឋានទិន្នន័យធំៗ ឬអត្ថបទដែលគ្មានរចនាសម្ព័ន្ធ។ វាប្រើប្រាស់ក្បួនស្ថិតិ និងការរៀនរបស់ម៉ាស៊ីន (Machine Learning) ដើម្បីស្វែងរកទំនាក់ទំនងដែលលាក់កំបាំង។ ការកំណត់អត្តសញ្ញាណដោយស្វ័យប្រវត្តិនូវនិន្នាការស្រាវជ្រាវថ្មីៗ ដោយការវិភាគលើពាក្យគន្លឹះ និងបណ្តាញយោងនៃឯកសារស្រាវជ្រាវវិទ្យាសាស្ត្ររាប់ពាន់ច្បាប់។
Vector Space Model (VSM)
ម៉ូដែលលំហវ៉ិចទ័រ (Vector Space Model)		 ជាម៉ូដែលគណិតវិទ្យាដែលតំណាងឲ្យឯកសារអត្ថបទជាវ៉ិចទ័រនៃពាក្យគន្លឹះ (Index terms) ដែលត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយនៅក្នុងប្រព័ន្ធស្វែងរកព័ត៌មាន ដើម្បីគណនាភាពស្រដៀងគ្នារវាងសំណួររបស់អ្នកប្រើប្រាស់ និងឯកសារ។ ការតំណាងសំណួរស្វែងរក និងឯកសារជាវ៉ិចទ័រដោយផ្អែកលើប្រេកង់នៃពាក្យ (TF-IDF) ដើម្បីស្វែងរកអត្ថបទដែលពាក់ព័ន្ធបំផុតនៅក្នុងម៉ាស៊ីនស្វែងរក (Search Engine)។
Ontology Reasoning
ការវែកញែកអុនតូឡូស៊ី (Ontology Reasoning)		 ការប្រើប្រាស់រចនាសម្ព័ន្ធនៃចំណេះដឹង (អង្គភាព គុណលក្ខណៈ និងទំនាក់ទំនង) ដែលសរសេរជាទម្រង់ XML ឬ OWL ដើម្បីអនុញ្ញាតឲ្យប្រព័ន្ធកុំព្យូទ័រអាចទាញសេចក្តីសន្និដ្ឋានចំណេះដឹងថ្មីៗដោយស្វ័យប្រវត្តិផ្អែកលើតក្កវិជ្ជា។ ប្រសិនបើប្រព័ន្ធដឹងថា "A ជាផ្នែកមួយនៃ B" ហើយ "B ស្ថិតនៅក្នុង C" នោះប្រព័ន្ធអាចទាញសេចក្តីសន្និដ្ឋានដោយស្វ័យប្រវត្តិថា "A ស្ថិតនៅក្នុង C" ដើម្បីឆ្លើយតបទៅនឹងសំណួររបស់អ្នកប្រើប្រាស់។
Rough Set Theory
ទ្រឹស្តីសំណុំគ្រើម (Rough Set Theory)		 វិធីសាស្ត្រគណិតវិទ្យាសម្រាប់ដោះស្រាយភាពមិនច្បាស់លាស់ និងភាពមិនប្រាកដប្រជានៅក្នុងការចាត់ថ្នាក់ទិន្នន័យ ដោយមិនតម្រូវឲ្យមានប្រូបាប៊ីលីតេជាមុន តាមរយៈការប្រើប្រាស់ការប៉ាន់ស្មានផ្នែកខាងក្រោម និងខាងលើ (Lower and Upper Approximations)។ ការចាត់ថ្នាក់ទិន្នន័យរោគវិនិច្ឆ័យវេជ្ជសាស្ត្រដែលមិនពេញលេញ ដើម្បីកំណត់ថាតើសំណុំនៃរោគសញ្ញាជាក់លាក់ណាមួយពិតជាស្ថិតក្នុងប្រភេទជំងឺណាមួយ ឬគ្រាន់តែស្ថិតនៅក្នុងតំបន់ព្រំដែនដែលមិនច្បាស់លាស់។

៤. ភាពពាក់ព័ន្ធសម្រាប់កម្ពុជា (Cambodia Relevance)

ការផ្លាស់ប្តូររបស់ប្រទេសកម្ពុជាទៅកាន់សេដ្ឋកិច្ចឌីជីថល តម្រូវឲ្យមានការបោះជំហានពីការគ្រាន់តែរក្សាទុកទិន្នន័យ ទៅជាការគ្រប់គ្រងចំណេះដឹងប្រកបដោយភាពឆ្លាតវៃ ដើម្បីជំរុញនវានុវត្តន៍ និងប្រសិទ្ធភាពការងារ។

ការអនុវត្ត (Applications)៖

  • វិស័យអប់រំ និងបណ្ណាល័យឌីជីថល (Education & Digital Libraries): ការអនុវត្តការទាញយកធាតុចំណេះដឹង (KE Extraction) ដើម្បីធ្វើឌីជីថលនីយកម្ម និងធ្វើលិបិក្រមឯកសារប្រវត្តិសាស្ត្រ និងការស្រាវជ្រាវរបស់កម្ពុជា ដែលអនុញ្ញាតឲ្យសិស្សនិស្សិតអាចស្វែងរកអង្គហេតុជាក់លាក់ ជំនួសឲ្យការអានឯកសារទាំងមូល។
  • រដ្ឋាភិបាលអេឡិចត្រូនិក និងការវិភាគគោលនយោបាយ (E-Government & Policy Analysis): ការប្រើប្រាស់ Text Mining និង KDD ដើម្បីវិភាគមតិយោបល់របស់សាធារណជន ឯកសារច្បាប់ និងរបាយការណ៍សេដ្ឋកិច្ចសង្គម ដើម្បីជួយរដ្ឋាភិបាលកម្ពុជាក្នុងការតាក់តែងគោលនយោបាយផ្អែកលើភស្តុតាងជាក់ស្តែង។
  • ប្រព័ន្ធព័ត៌មានសុខាភិបាល (Healthcare Information Systems): ការអនុវត្ត Ontology Reasoning ដើម្បីកសាងមូលដ្ឋានទិន្នន័យវេជ្ជសាស្ត្រដែលភ្ជាប់ទំនាក់ទំនងរវាងរោគសញ្ញា ការព្យាបាល និងការផ្ទុះឡើងនៃជំងឺតាមតំបន់នីមួយៗក្នុងប្រទេសកម្ពុជា ដើម្បីជួយដល់ការសម្រេចចិត្តរបស់គ្រូពេទ្យ។

ការយល់ដឹងពីបច្ចេកទេសទាញយកចំណេះដឹងទាំងនេះ នឹងផ្តល់លទ្ធភាពដល់អ្នកជំនាញព័ត៌មានវិទ្យា និងអ្នកស្រាវជ្រាវកម្ពុជា ក្នុងការកសាងប្រព័ន្ធឆ្លាតវៃ ដែលចូលរួមចំណែកដោយផ្ទាល់ដល់ការអភិវឌ្ឍប្រព័ន្ធអេកូឡូស៊ីឌីជីថលរបស់ជាតិ។

៥. មគ្គុទ្ទេសក៍សិក្សា (Study Guide)

លំហាត់ និងសកម្មភាពសិក្សាដើម្បីពង្រឹងការយល់ដឹង៖

  1. ការអនុវត្តម៉ូដែលលំហវ៉ិចទ័រ (Implementing Vector Space Model): ប្រើប្រាស់ភាសា Python និងបណ្ណាល័យដូចជា scikit-learn ដើម្បីបង្កើតម៉ូដែលលំហវ៉ិចទ័រ (VSM) សាមញ្ញមួយ ដែលគណនា TF-IDF សម្រាប់បណ្តុំអត្ថបទព័ត៌មានជាភាសាខ្មែរ ឬអង់គ្លេស ដើម្បីស្វែងរកឯកសារដែលពាក់ព័ន្ធនឹងពាក្យគន្លឹះ។
  2. ការរចនាអុនតូឡូស៊ីសម្រាប់វិស័យជាក់លាក់ (Designing a Domain Ontology): ប្រើប្រាស់កម្មវិធី Protégé ដើម្បីរចនាអុនតូឡូស៊ីសម្រាប់វិស័យជាក់លាក់ណាមួយ (ឧទាហរណ៍៖ ប្រព័ន្ធមុខវិជ្ជាសិក្សានៅសាកលវិទ្យាល័យកម្ពុជា) ដោយកំណត់ថ្នាក់ (Classes) គុណលក្ខណៈ (Properties) និងវត្ថុ (Instances) រួចទាញយកជាទម្រង់ XML/OWL។
  3. លំហាត់ទាញយកធាតុចំណេះដឹង (Knowledge Element Extraction Exercise): ជ្រើសរើសឯកសារស្រាវជ្រាវវិទ្យាសាស្ត្រមួយ រួចធ្វើការកំណត់អត្តសញ្ញាណដោយដៃនូវ "ធាតុចំណេះដឹង" យ៉ាងតិច ៥ ទៅ ១០ ចំណុច (ដូចជា សេចក្តីសន្និដ្ឋាន ទិន្នន័យ ឬវិធីសាស្ត្រ) ហើយចងក្រងវាទៅតាមម៉ូដែល OAV (Object, Property, Value)។
  4. ការចំណាត់ថ្នាក់អត្ថបទដោយប្រើ Decision Trees (Text Classification with Decision Trees): អនុវត្តក្បួនដោះស្រាយ ID3 ដែលបានរៀបរាប់ក្នុងមេរៀន ទៅលើសំណុំទិន្នន័យគំរូ ដោយប្រើប្រាស់ Python (pandas និង DecisionTreeClassifier) ដើម្បីទស្សន៍ទាយប្រភេទនៃឯកសារអត្ថបទដោយផ្អែកលើប្រេកង់នៃពាក្យគន្លឹះ។

៦. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Knowledge Element ជាឯកតាតូចបំផុតនៃចំណេះដឹងដែលមិនអាចបំបែកបាន និងមានអត្ថន័យពេញលេញនៅក្នុងអត្ថបទ (ដូចជារូបមន្ត ទិន្នន័យជាក់លាក់ ឬសេចក្តីសន្និដ្ឋាន) ដែលប្រព័ន្ធកុំព្យូទ័រអាចទាញយកមកប្រើប្រាស់ដោយឯករាជ្យបាន។ ដូចជាដុំឥដ្ឋមួយដុំៗដែលគេយកសង់ផ្ទះ Knowledge Element គឺជាបំណែកព័ត៌មានតូចៗបំផុតដែលផ្គុំចូលគ្នាបង្កើតបានជាចំណេះដឹងពេញលេញមួយ។
Vector Space Model (VSM) ជាម៉ូដែលគណិតវិទ្យាដែលបំប្លែងអត្ថបទ ឬឯកសារទៅជាវ៉ិចទ័រក្នុងលំហ ដើម្បីគណនាភាពស្រដៀងគ្នារវាងសំណួររបស់អ្នកប្រើប្រាស់ និងឯកសារ ដែលជួយសម្រួលដល់ការស្វែងរកព័ត៌មានបានច្បាស់លាស់និងមានប្រសិទ្ធភាព។ ដូចជាការរកទីតាំងហាងកាហ្វេដោយប្រើប្រព័ន្ធ GPS ដែលវាស់ចម្ងាយពីអ្នកទៅហាង VSM វាស់គម្លាតរវាងពាក្យដែលអ្នកស្វែងរកនិងអត្ថបទដែលមាន ដើម្បីរកឯកសារដែលពាក់ព័ន្ធបំផុត។
Knowledge Discovery in Databases (KDD) ជាដំណើរការដ៏ស្មុគស្មាញនៃការស្រង់យកចំណេះដឹង លំនាំ ឬវិធានដែលលាក់កំបាំង មានប្រយោជន៍ និងថ្មីពីក្នុងបណ្តុំទិន្នន័យដ៏ធំមហិមា ដោយរួមបញ្ចូលនូវការសម្អាតទិន្នន័យ និងការទាញយកទិន្នន័យ (Data Mining)។ ដូចជាការរែងរកគ្រាប់មាសពីក្នុងគំនរខ្សាច់ដ៏ធំ KDD គឺជាការរែងរកព័ត៌មានដ៏មានតម្លៃចេញពីទិន្នន័យរាប់លាន។
Rough Set Theory ជាទ្រឹស្តីគណិតវិទ្យាសម្រាប់ដោះស្រាយភាពមិនច្បាស់លាស់ ឬទិន្នន័យដែលមិនពេញលេញ ដោយការប្រើប្រាស់ការប៉ាន់ស្មានផ្នែកខាងក្រោម និងខាងលើ ដើម្បីចាត់ថ្នាក់ទិន្នន័យដោយមិនបាច់ដឹងពីប្រូបាប៊ីលីតេជាមុន។ ដូចជាការចាត់ថ្នាក់ផ្លែឈើដែលខូចបន្តិចបន្តួចទៅក្នុងប្រអប់ 'អាចញ៉ាំបាន' ឬ 'គួរចោល' Rough Set ជួយកុំព្យូទ័រសម្រេចចិត្តលើទិន្នន័យដែលមិនសូវច្បាស់លាស់។
Ontology ជាការរៀបចំរចនាសម្ព័ន្ធចំណេះដឹងដោយកំណត់ថ្នាក់ (classes) គុណលក្ខណៈ (properties) និងទំនាក់ទំនង (relationships) រវាងពាក្យ ឬគំនិតក្នុងវិស័យណាមួយ ដើម្បីឲ្យកុំព្យូទ័រអាចយល់ និងធ្វើការវែកញែកបានដោយស្វ័យប្រវត្តិ។ ដូចជាការគូរតារាងពង្សាវតារគ្រួសារដែលបង្ហាញយ៉ាងច្បាស់ថាអ្នកណាជាកូនអ្នកណា Ontology ប្រាប់កុំព្យូទ័រពីទំនាក់ទំនងរវាងពាក្យនិងគំនិតផ្សេងៗ។
Semantic Web ជាគំនិតផ្តួចផ្តើមសម្រាប់អ៊ីនធឺណិតជំនាន់ថ្មីដែលក្នុងនោះទិន្នន័យត្រូវបានរៀបចំឡើងជាទម្រង់ (ដូចជា XML, RDF, OWL) ដែលម៉ាស៊ីន (កុំព្យូទ័រ) អាចអាន និងយល់ពីអត្ថន័យរបស់វាបានស៊ីជម្រៅ មិនមែនត្រឹមតែបង្ហាញជាអក្សរនោះទេ។ ដូចជាការដាក់ស្លាកឈ្មោះមុខម្ហូបនិងគ្រឿងផ្សំនៅលើម៉ឺនុយដើម្បីឲ្យចុងភៅដឹងពីរបៀបធ្វើ Semantic Web ជួយឲ្យកុំព្យូទ័រយល់ពីអត្ថន័យនៃទំព័រវ៉ិបសាយនីមួយៗបាន។
ID3 Algorithm ជាក្បួនដោះស្រាយដ៏ល្បីល្បាញក្នុងបញ្ញាសិប្បនិម្មិត (AI) សម្រាប់បង្កើតដើមឈើសម្រេចចិត្ត (Decision Tree) តាមរយៈការគណនា Entropy និងការកើនឡើងនៃព័ត៌មាន (Information Gain) ដើម្បីបែងចែកប្រភេទចំណេះដឹង ឬទិន្នន័យ។ ដូចជាការសួរសំណួរ 'បាទ/ទេ' បន្តបន្ទាប់គ្នាដើម្បីទាយឈ្មោះសត្វមួយក្បាល ID3 ជួយកុំព្យូទ័របែងចែកទិន្នន័យដោយជ្រើសរើសសំណួរដែលសំខាន់ជាងគេមកសួរមុនគេ។
