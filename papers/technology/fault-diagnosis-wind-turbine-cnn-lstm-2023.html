  • ការទាញយកលក្ខណៈពិសេសពេលវេលាដោយប្រើបណ្តាញអង្គចងចាំរយៈពេលខ្លី-វែង (Long Short-Term Memory - LSTM)
  • ការប្រើប្រាស់ម៉ូដែលមេតានៃការរៀនបណ្តុំដោយផ្នែក (Partial Ensemble Learning Meta-model) សម្រាប់ចំណាត់ថ្នាក់កំហុសដែលពិបាកបែងចែក

  • ម៉ូដែលនេះកាត់បន្ថយកំហុសការ៉េមធ្យម (MSE) បាន 57.9% បើប្រៀបធៀបទៅនឹងម៉ូដែល LSTM តែមួយ។

LSTM
បណ្តាញអង្គចងចាំរយៈពេលខ្លី-វែង (LSTM តែមួយ)		 មានសមត្ថភាពខ្ពស់ក្នុងការដោះស្រាយបញ្ហាការព្យាករណ៍និងចំណាត់ថ្នាក់ទិន្នន័យស៊េរីពេលវេលា (Time Series) តាមរយៈការចងចាំព័ត៌មានរយៈពេលវែង។ មានកម្រិតក្នុងការទាញយកលក្ខណៈពិសេសពីទិន្នន័យដែលមានវិមាត្រច្រើន (Spatial features) ប្រសិនបើប្រៀបធៀបជាមួយ CNN។ ភាពត្រឹមត្រូវ 98.93%, កំហុស MSE 0.001554
CNN / 1D-CNN
បណ្តាញសរសៃប្រសាទកាឡៃ (CNN និង 1D-CNN)		 មានសមត្ថភាពល្អក្នុងការទាញយកលក្ខណៈពិសេសលំហ (Spatial features) ពីទិន្នន័យ SCADA បានយ៉ាងល្អតាមរយៈ Convolutional layers។ មានដែនកំណត់ក្នុងការទាញយកនិងរក្សាទុកលក្ខណៈពិសេសពីការផ្លាស់ប្តូរទិន្នន័យតាមពេលវេលា។ ភាពត្រឹមត្រូវ 99.19%, កំហុស MSE 0.001125 (ម៉ូដែល CNN)
CNN-LSTM Serial network model
ម៉ូដែលបណ្តាញតភ្ជាប់ជាស៊េរី CNN-LSTM		 រួមបញ្ចូលសមត្ថភាពរបស់ CNN ក្នុងការទាញយកលក្ខណៈពិសេសលំហ និងបន្ទាប់មកប្រើ LSTM សម្រាប់ទាញយកលក្ខណៈពិសេសពេលវេលា។ ការតភ្ជាប់ជាស៊េរីអាចធ្វើឱ្យ CNN បោះបង់ចោលព័ត៌មានមានប្រយោជន៍មួយចំនួន ដែលបណ្តាលឱ្យ LSTM ទទួលបានទិន្នន័យមិនពេញលេញ និងប៉ះពាល់ដល់ការកំណត់អត្តសញ្ញាណកំហុស។ ភាពត្រឹមត្រូវ 99.39%, កំហុស MSE 0.000978
CNN-LSTM Parallel network model
ម៉ូដែលបណ្តាញស្របគ្នា CNN-LSTM (ម៉ូដែលស្នើឡើង)		 ទាញយកលក្ខណៈពិសេសពីវិមាត្រលំហ និងពេលវេលាក្នុងពេលតែមួយដោយមិនបាត់បង់ព័ត៌មាន និងប្រើប្រាស់ម៉ូដែលមេតា (Meta-model) ដើម្បីសម្គាល់កំហុសដែលពិបាកបែងចែក។ មានរចនាសម្ព័ន្ធស្មុគស្មាញ និងទាមទារថាមពលកុំព្យូទ័រខ្ពស់ជាងមុនសម្រាប់ការហ្វឹកហាត់បណ្តាញស្របគ្នា និងម៉ូដែលមេតា។ ភាពត្រឹមត្រូវខ្ពស់បំផុត 99.86%, កំហុស MSE ទាបបំផុតត្រឹម 0.000654

  • វិស័យថាមពលពន្លឺព្រះអាទិត្យ (Solar Power Plants) នៅខេត្តកំពង់ស្ពឺ និងពោធិ៍សាត់: អាចប្រើវិធីសាស្ត្រនេះដើម្បីវិភាគទិន្នន័យស៊េរីពេលវេលាពី Inverter ឬបន្ទះសូឡា (ដូចជាវ៉ុល ចរន្ត និងសីតុណ្ហភាព) ដើម្បីទស្សន៍ទាយនិងរកមើលការចុះខ្សោយនៃប្រព័ន្ធ។
  • រោងចក្រវារីអគ្គិសនី (Hydropower Plants) ដូចជាទំនប់សេសានក្រោម២: បច្ចេកទេស CNN-LSTM នេះអាចយកទៅកែច្នៃប្រើជាមួយទិន្នន័យ SCADA របស់ទួរប៊ីនទឹក ដើម្បីត្រួតពិនិត្យរំញ័រនិងសម្ពាធ ឈានទៅរកការថែទាំទុកជាមុន (Predictive Maintenance)។
  • តំបន់សេដ្ឋកិច្ចពិសេស (SEZ) ក្នុងវិស័យរោងចក្រផលិត និងខ្សែចង្វាក់ស្វ័យប្រវត្តិ: រោងចក្រផលិតអាចដំឡើងឧបករណ៍ចាប់សញ្ញា (IoT Sensors) លើម៉ាស៊ីនរបស់ពួកគេ ហើយប្រើប្រាស់បណ្តាញស្របគ្នានេះដើម្បីតាមដានសុខភាពម៉ាស៊ីន និងការពារការខូចខាតដែលបណ្តាលឱ្យផ្អាកខ្សែចង្វាក់ផលិតកម្ម។

ជារួម វិធីសាស្ត្ររៀនស៊ីជម្រៅដោយប្រើបណ្តាញស្របគ្នា CNN-LSTM រួមបញ្ចូលជាមួយ Meta-model នេះ គឺជាគំរូដ៏រឹងមាំមួយដែលស្ថាប័នស្រាវជ្រាវកម្ពុជាអាចយកទៅបន្សាំជាមួយការវិភាគទិន្នន័យឧបករណ៍ IoT សម្រាប់គម្រោងទីក្រុងឆ្លាតវៃ និងរោងចក្រឆ្លាតវៃ (Smart Factory)។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. ជំហានទី១៖ សិក្សាមូលដ្ឋានគ្រឹះនៃបណ្តាញស្របគ្នាក្នុង Deep Learning: ចាប់ផ្តើមដោយការរៀនបង្កើតបណ្តាញសរសៃប្រសាទដែលមានលក្ខណៈជាសាខាស្របគ្នា (Functional API) ជាជាងការតភ្ជាប់ជាស៊េរី (Sequential) ដោយប្រើប្រាស់ TensorFlow Keras ឬ PyTorch តាមរយៈគម្រោងតូចៗដើម្បីយល់ពីរបៀបច្របាច់បញ្ចូលគ្នា (Concatenate) នូវទិន្នផលចេញពី CNN និង LSTM។
  2. ជំហានទី២៖ ប្រមូលនិងរៀបចំទិន្នន័យ SCADA ឬ IoT: ដោយសារទិន្នន័យទួរប៊ីនខ្យល់នៅកម្ពុជាមានកម្រិត អ្នកអាចស្វែងរកសំណុំទិន្នន័យសាធារណៈពី Kaggle (ឧទាហរណ៍ Wind Turbine SCADA Dataset) ឬប្រមូលទិន្នន័យពីឧបករណ៍ IoT។ អនុវត្តការកែច្នៃទិន្នន័យជាមុន (Data Preprocessing) ដោយប្រើប្រាស់ MinMaxScaler ពី Scikit-Learn ដើម្បីធ្វើឱ្យទិន្នន័យស្ថិតក្នុងចន្លោះ [0, 1]។
  3. ជំហានទី៣៖ កំណត់ប៉ារ៉ាម៉ែត្រនិងដោះស្រាយការធ្វើឱ្យម៉ូដែលរៀនទន្ទេញ (Overfitting): អនុវត្តការសាកល្បងកំណត់ Dropout Rate (ឧទាហរណ៍ 0.2 ដូចក្នុងឯកសារ) ដើម្បីការពារបញ្ហា Overfitting។ ត្រូវប្រាកដថាអ្នកបានសាកល្បងកែប្រែទំហំរបស់ Convolutional kernels (ឧ. ទំហំ 3x1) និងចំនួនបណ្តាញ (Filters) ដើម្បីបង្កើនប្រសិទ្ធភាពចាប់យកទិន្នន័យប្រែប្រួល។
  4. ជំហានទី៤៖ បង្កើតម៉ូដែលមេតាសម្រាប់ការរៀនបណ្តុំដោយផ្នែក (Partial Ensemble Meta-model): បន្ទាប់ពីហ្វឹកហាត់ម៉ូដែលចម្បងរួចរាល់ សូមពិនិត្យមើល Confusion Matrix។ ប្រសិនបើមានប្រភេទកំហុស (Fault classes) មួយចំនួនដែលម៉ូដែលតែងតែទស្សន៍ទាយខុសច្រឡំគ្នា សូមបង្កើតម៉ូដែលតូចមួយទៀត (Meta-model) ដាច់ដោយឡែក ដែលយកទិន្នផលទស្សន៍ទាយរបស់ម៉ូដែលមុនមកហ្វឹកហាត់ ដើម្បីបែងចែកតែកំហុសដែលពិបាកទាំងនោះ។
  5. ជំហានទី៥៖ វាយតម្លៃប្រៀបធៀបជាមួយម៉ូដែលផ្សេងៗ: ប្រើប្រាស់រង្វាស់រង្វាល់ស្តង់ដាររួមមាន MSE, RMSE, MAE, និង R2 Score តាមរយៈបណ្ណាល័យ Scikit-Learn metrics ដើម្បីប្រៀបធៀបសមត្ថភាពនៃម៉ូដែលបណ្តាញស្របគ្នារបស់អ្នក ទល់នឹងម៉ូដែល CNN ឬ LSTM ទោល ដើម្បិបញ្ជាក់ពីភាពត្រឹមត្រូវខ្ពស់ជាង។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Convolutional Neural Networks (CNN) ជាប្រភេទបណ្តាញសរសៃប្រសាទសិប្បនិម្មិតដែលពូកែខាងទាញយកលក្ខណៈពិសេសពីទិន្នន័យដែលមានរចនាសម្ព័ន្ធជាលំហ (Spatial features) ដូចជារូបភាព ឬទិន្នន័យស៊េរី១វិមាត្រ (1D) តាមរយៈប្រតិបត្តិការកាឡៃ (Convolution) និងការចែករំលែកទម្ងន់ (Weight sharing)។ ដូចជាមនុស្សម្នាក់ដែលប្រើកែវពង្រីកដើរឆ្លុះមើលរាល់ចំណុចតូចៗនៃផ្ទាំងគំនូរ ដើម្បីស្វែងរកទម្រង់ ឬលក្ខណៈពិសេសរួមរបស់គំនូរនោះ។
Long Short-Term Memory (LSTM) ជាប្រភេទបណ្តាញសរសៃប្រសាទ Recurrent Neural Network (RNN) ពិសេសមួយដែលត្រូវបានរចនាឡើងដើម្បីចងចាំព័ត៌មានក្នុងរយៈពេលវែង និងដោះស្រាយបញ្ហាការបាត់បង់ជម្រាល (Gradient vanishing) ក្នុងការរៀនម៉ាស៊ីន។ វាប្រើប្រាស់ច្រក (Gates) ដូចជា Input, Output, និង Forget gate ដើម្បីត្រួតពិនិត្យការហូរចូលនិងចេញនៃព័ត៌មានតាមពេលវេលា។ ដូចជាសៀវភៅកំណត់ហេតុឆ្លាតវៃមួយ ដែលចេះរើសទុកតែព័ត៌មានសំខាន់ៗពីអតីតកាល ហើយលុបចោលព័ត៌មានដែលលែងចាំបាច់ ដើម្បីយកមកធ្វើការសម្រេចចិត្តនៅថ្ងៃមុខ។
SCADA data ជាទិន្នន័យដែលប្រមូលបានពីប្រព័ន្ធត្រួតពិនិត្យ និងប្រមូលទិន្នន័យ (Supervisory Control and Data Acquisition) ដែលបំពាក់លើម៉ាស៊ីនឧស្សាហកម្មដូចជាទួរប៊ីនខ្យល់។ វាមានផ្ទុកព័ត៌មានអំពីសីតុណ្ហភាព សម្ពាធ ល្បឿន និងរំញ័រនៅតាមចន្លោះពេលវេលាជាក់លាក់។ ដូចជាកំណត់ត្រាពិនិត្យសុខភាពប្រចាំថ្ងៃរបស់ម៉ាស៊ីន ដែលកត់ត្រាដោយស្វ័យប្រវត្តិពីរាល់ចង្វាក់បេះដូងនិងកម្ដៅរបស់វា។
Partial Ensemble Learning meta-model ជាបច្ចេកទេសរៀនម៉ាស៊ីនដែលប្រើប្រាស់លទ្ធផលទស្សន៍ទាយ (Predictions) ពីម៉ូដែលផ្សេងៗ (ដូចជា CNN និង LSTM) យកមកធ្វើជាទិន្នន័យបញ្ចូលសម្រាប់ហ្វឹកហាត់ម៉ូដែលថ្មីមួយទៀតដែលហៅថា Meta-model។ គោលបំណងគឺដើម្បីកែលម្អភាពត្រឹមត្រូវក្នុងការបែងចែកប្រភេទកំហុសដែលពិបាកមើលដឹង ព្រោះវាមានទិន្នន័យស្រដៀងគ្នាខ្លាំង។ ដូចជាការយកមតិយោបល់របស់វេជ្ជបណ្ឌិតជំនាញពីរនាក់ផ្សេងគ្នា ទៅឱ្យគ្រូពេទ្យកំពូលម្នាក់ទៀតធ្វើការសម្រេចចិត្តចុងក្រោយលើជំងឺដែលពិបាកធ្វើរោគវិនិច្ឆ័យ។
Dropout rate ជាបច្ចេកទេសមួយក្នុងការហ្វឹកហាត់ Deep Learning ដែលបិទដំណើរការ (Drop) ណឺរ៉ូនមួយចំនួនដោយចៃដន្យនៅក្នុងបណ្តាញ ក្នុងអត្រាជាក់លាក់ណាមួយ (ឧទាហរណ៍ 0.2 ឬ 20%)។ វាត្រូវបានប្រើដើម្បីការពារកុំឱ្យម៉ូដែលរៀនទន្ទេញទិន្នន័យហ្វឹកហាត់ខ្លាំងពេក (Overfitting) និងជួយឱ្យម៉ូដែលដំណើរការល្អជាមួយទិន្នន័យថ្មីៗ។ ដូចជាការបង្ខំឱ្យក្រុមការងារម្នាក់ៗចេះធ្វើការងារជំនួសគ្នា ដោយការឱ្យសមាជិកខ្លះឈប់សម្រាកឆ្លាស់គ្នាដោយចៃដន្យ ដើម្បីកុំឱ្យក្រុមទាំងមូលពឹងផ្អែកតែលើមនុស្សតែម្នាក់។
Spatial and temporal dimensions Spatial (លំហ) សំដៅលើទំនាក់ទំនងនៃរចនាសម្ព័ន្ធទិន្នន័យ និងទំហំទិន្នន័យក្នុងពេលតែមួយ ខណៈដែល Temporal (ពេលវេលា) សំដៅលើការផ្លាស់ប្តូរនៃទិន្នន័យនោះពីមួយវិនាទីទៅមួយវិនាទីតាមបណ្តោយស៊េរីពេលវេលា។ ម៉ូដែលស្របគ្នានេះទាញយកលក្ខណៈពិសេសទាំងពីរនេះព្រមគ្នាក្នុងពេលតែមួយ។ ដូចជាការមើលវីដេអូមួយ៖ Spatial គឺជារូបភាពក្នុងប្លង់នីមួយៗ រីឯ Temporal គឺជារបៀបដែលរូបភាពទាំងនោះធ្វើចលនាផ្លាស់ប្តូរពីវិនាទីមួយទៅវិនាទីមួយទៀត។
Min-Max method ជាដំណើរការកែច្នៃទិន្នន័យជាមុន (Data Preprocessing / Normalization) ដោយធ្វើការបំប្លែងតម្លៃទិន្នន័យទាំងអស់ឱ្យស្ថិតនៅក្នុងចន្លោះប្រភាគមួយជាក់លាក់ (ជាទូទៅពី 0 ទៅ 1)។ ការធ្វើបែបនេះជួយឱ្យម៉ូដែល Deep Learning រៀនបានលឿននិងមានស្ថិរភាព ដោយមិនមានការលម្អៀងទៅលើលក្ខណៈពិសេសណាមួយដែលមានតម្លៃលេខធំជាងគេនោះទេ។ ដូចជាការប្តូរពិន្ទុមុខវិជ្ជាផ្សេងៗដែលប្រើខ្នាតខុសៗគ្នា (ឧ. គណិតពិន្ទុពេញ ១០០, គីមីពិន្ទុពេញ ៥០) ឱ្យទៅជាប្រព័ន្ធពិន្ទុភាគរយ (%) តែមួយដើម្បីងាយស្រួលប្រៀបធៀប។
