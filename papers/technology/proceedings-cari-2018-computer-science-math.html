  • ការវិភាគបណ្តាញ និងការបែងចែកធនធានប្រកបដោយថាមវន្ត (Network analysis and dynamic resource allocation)

  • គំរូគណិតវិទ្យា និងក្បួនដោះស្រាយកុំព្យូទ័រដែលបានស្នើឡើង អាចជួយធ្វើឱ្យប្រសើរឡើងនូវការគ្រប់គ្រងធនធានកសិកម្ម ការព្យាករណ៍ទឹកជំនន់ និងប្រព័ន្ធថែទាំសុខភាពយ៉ាងមានប្រសិទ្ធភាព។

Full Multi-seasonal Model (Model M)
គំរូពហុរដូវពេញលេញ		 អាចពណ៌នាអំពីអន្តរកម្មរវាងណេម៉ាតូត និងឫសចេកបានយ៉ាងលម្អិតទាំងដំណាក់កាលវារស់នៅសេរីក្នុងដី និងពេលវាទម្លុះចូលក្នុងឫស។ មានភាពស្មុគស្មាញខ្ពស់ក្នុងការគណនា ពិបាកធ្វើវិភាគតាមបែបគណិតវិទ្យា និងទាមទារប៉ារ៉ាម៉ែត្រច្រើន។ បង្ហាញពីសក្ដានុពលជាក់ស្តែងនៃបំរែបំរួលចំនួនសត្វល្អិត ប៉ុន្តែពិបាកទាញរកចំណុចសូន្យនៃសត្វល្អិត (Pest Free Equilibrium)។
Reduced Model (Model RM) using Singular Perturbation
គំរូកាត់បន្ថយដោយប្រើទ្រឹស្តី Singular Perturbation		 សម្រួលដល់ការគណនាដោយផ្តោតលើសក្ដានុពលសំខាន់ៗ និងអនុញ្ញាតឱ្យរកឃើញនូវកម្រិតដែលសត្វល្អិតត្រូវវិនាសផុតពូជ (Pest Free Solution) និងគណនារយៈពេលសម្រាកដីបានយ៉ាងងាយស្រួល។ អាចមានភាពលម្អៀងបន្តិចបន្តួច បើប្រៀបធៀបនឹងគំរូដើម នៅពេលអត្រានៃការឆ្លងដំបូង (Beta) មានកម្រិតទាបខ្លាំង។ អាចគណនារកតម្លៃកម្រិតចម្លងរាលដាល R0 និងរយៈពេលសម្រាកដីអប្បបរមា (Tau_0 = 8.04 ឬ 11.78) យ៉ាងសុក្រឹតនៅពេលអត្រាឆ្លងខ្ពស់។

  • Software: កម្មវិធីសម្រាប់ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល និងធ្វើគំនូសតាង (ឧទាហរណ៍៖ MATLAB, Python ជាមួយបណ្ណាល័យ SciPy)។

  • Dataset: ទិន្នន័យប៉ារ៉ាម៉ែត្រជាក់ស្តែងអំពីការលូតលាស់របស់ឫសចេក និងសក្ដានុពលណេម៉ាតូត (ទាញចេញពីឯកសារយោងកសិកម្ម ដូចជាទិន្នន័យពីប្រទេស Costa Rica)។

ការប្រើប្រាស់គំរូនេះនៅក្នុងការអនុវត្តជាក់ស្តែង អាចជួយកសិករ និងក្រុមហ៊ុនកសិកម្មនៅកម្ពុជា កាត់បន្ថយការចំណាយលើថ្នាំសម្លាប់សត្វល្អិត ការពារបរិស្ថាន និងបង្កើនទិន្នផលប្រកបដោយនិរន្តរភាព។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាមូលដ្ឋានគ្រឹះគណិតវិទ្យា និងបរិស្ថានវិទ្យា: និស្សិតត្រូវស្វែងយល់អំពីសមីការឌីផេរ៉ង់ស្យែល (ODEs) ទ្រឹស្តី Singular Perturbation Theory និងសក្ដានុពលនៃប្រព័ន្ធអេកូឡូស៊ី។
  2. ប្រមូលទិន្នន័យជាក់ស្តែងនៅកម្ពុជា: សហការជាមួយមន្ទីរកសិកម្មដើម្បីប្រមូលទិន្នន័យប៉ារ៉ាម៉ែត្រអំពីមេរោគ Radopholus similis ភាពធន់នៃឫសចេក និងប្រភេទដី (ដីក្រហម ដីល្បាយ) ក្នុងតំបន់ដាំដុះជាក់ស្តែង។
  3. បង្កើត និងកែសម្រួលកូដគំរូ: ប្រើប្រាស់កម្មវិធី Python (SciPy) ឬ MATLAB ដើម្បីសរសេរកូដបញ្ចូលប៉ារ៉ាម៉ែត្រដែលប្រមូលបាន និងធ្វើតេស្តសាកល្បង (Simulations)។
  4. ធ្វើការសាកល្បង និងវាយតម្លៃផ្ទាល់នៅចម្ការ: យកលទ្ធផលដែលគណនាបាន (ឧ. រយៈពេលសម្រាកដី ២ ឬ ៣ខែ) ទៅអនុវត្តជាក់ស្តែងនៅកសិដ្ឋាន ដើម្បីប្រៀបធៀបអត្រាឆ្លងជំងឺជាមួយចម្ការដែលប្រើប្រាស់ថ្នាំគីមី។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Semi-discrete model ម៉ូដែលគណិតវិទ្យាដែលបន្សំរវាងសមីការបន្តបន្ទាប់ (Continuous time) សម្រាប់គណនាការផ្លាស់ប្តូរចំនួនសត្វល្អិតក្នុងរដូវដាំដុះ និងសមីការដាច់ៗ (Discrete time) សម្រាប់គណនាការប្រែប្រួលចំនួនសត្វល្អិតភ្លាមៗ នៅពេលបញ្ចប់រដូវ (ឧទាហរណ៍ ពេលដកដើមចេកចេញ)។ ដូចជាការតាមដានម៉ែត្រល្បឿនរថយន្តដែលកំពុងរត់ជាប់រហូត បូករួមទាំងការកត់ត្រាភ្លាមៗនៅពេលរថយន្តឈប់នៅចំណត។
Singular perturbation theory ទ្រឹស្តីគណិតវិទ្យាដែលប្រើសម្រាប់បំបែកប្រព័ន្ធអេកូឡូស៊ីស្មុគស្មាញដែលមានសក្ដានុពលល្បឿនខុសគ្នា (ធាតុមួយផ្លាស់ប្តូរលឿន មួយទៀតយឺត) ដើម្បីងាយស្រួលដោះស្រាយសមីការ ដោយចាត់ទុកធាតុដែលប្រែប្រួលលឿនពេកថាបានឈានដល់ចំណុចលំនឹងភ្លាមៗ។ ដូចជាការគិតលុយចំណេញប្រចាំខែ (ដើរយឺត) ដោយយើងសន្មត់ថាមិនបាច់ខ្វល់ពីការប្រែប្រួលតម្លៃកាក់សេនរៀងរាល់វិនាទីនោះទេ (ដើរលឿន) ដើម្បីងាយស្រួលបូកសរុប។
Basic reproduction number ដែលសរសេរកាត់ថា R0 វាជាតួលេខដែលទស្សន៍ទាយអំពីចំនួនសត្វល្អិតចង្រៃ ឬមេរោគថ្មីៗដែលនឹងកើតចេញពីសត្វល្អិតមួយក្បាល។ ប្រសិនបើវាមានតម្លៃធំជាង ១ នោះសត្វល្អិតនឹងកើនឡើងរាលដាល តែបើវាតូចជាង ១ នោះសត្វល្អិតនឹងផុតពូជបន្តិចម្តងៗ។ ដូចជាមនុស្សម្នាក់កើតផ្តាសាយទូទៅ បើគាត់ចម្លងទៅមនុស្សតិចជាងម្នាក់ នោះជំងឺនឹងបាត់ទៅវិញឯងៗ តែបើចម្លងទៅមនុស្សលើសពីម្នាក់ វានឹងរាលដាលពេញភូមិ។
Holling type II functional response រូបមន្តក្នុងអេកូឡូស៊ីដែលពិពណ៌នាពីឥរិយាបថរបស់សត្វល្អិត ឬអ្នកប្រមាញ់ ដោយបង្ហាញថាអត្រានៃការស៊ីចំណីនឹងកើនឡើងនៅពេលមានចំណីច្រើន ប៉ុន្តែវានឹងឈានដល់កម្រិតឆ្អែតមួយ ទោះបីជាមានចំណីកើនឡើងប៉ុណ្ណាក៏ដោយ ក៏អត្រានៃការស៊ីលែងកើនឡើងទៀតដែរ។ ដូចជាមនុស្សយើងចូលញ៉ាំអាហារប៊ូហ្វេ ទោះបីម្ហូបមានច្រើនរាប់តោនលើសលុប ក៏យើងអាចញ៉ាំបានត្រឹមឆ្អែតក្នុងកម្រិតទំហំពោះរបស់យើងដែរ។
Pest Free Equilibrium (PFE) ចំណុចលំនឹងតាមបែបគណិតវិទ្យាដែលតំណាងឱ្យស្ថានភាពអវត្តមានសត្វល្អិតចង្រៃទាំងស្រុង។ ក្នុងស្ថានភាពនេះ ប្រព័ន្ធកសិកម្មរក្សាបាននូវភាពស្អាត ដោយសារកត្តាបរិស្ថាន ឬរយៈពេលសម្រាកដីបានសម្លាប់សត្វល្អិតនោះដល់កម្រិតសូន្យ។ ដូចជាបន្ទប់មួយដែលគ្មានស្រមោចសោះ ហើយទោះជាយើងបើកទ្វារចំហរទុកចោលក៏ស្រមោចលែងមកដែរ ព្រោះយើងបានសម្អាតគ្មានសល់ជាតិផ្អែម ឬអាហារក្នុងនោះ។
Inter-season duration ពេលវេលាជាក់លាក់ណាមួយ (គិតជាខែ ឬថ្ងៃ) ចន្លោះពីការប្រមូលផលរួចរហូតដល់ការចាប់ផ្តើមដាំដុះដំណាំជុំថ្មី ដែលក្នុងអំឡុងពេលនេះ ដីត្រូវបានទុកចោលឱ្យទំនេរដើម្បីផ្តាច់ប្រភពអាហាររបស់ណេម៉ាតូត ធ្វើឱ្យពួកវាវិនាស។ ដូចជាការបិទហាងមិនលក់ដូរមួយរយៈ ដើម្បីឱ្យកណ្តុរ ឬកន្លាតដែលធ្លាប់មកស៊ីកាកសំណល់ រត់ចេញ ឬងាប់អស់ដោយសារអត់អាហារ មុននឹងយើងបើកហាងសាជាថ្មី។

៦. ប្រធានបទពាក់ព័ន្ធ (Further Reading)

ប្រធានបទ និងសំណួរស្រាវជ្រាវដែលទាក់ទងនឹងឯកសារនេះ ដែលអ្នកអាចស្វែងរកបន្ថែម៖

  • mathematical modeling in epidemiology and agriculture
  • Internet of Things (IoT) applications in developing countries
  • discontinuous Galerkin methods for partial differential equations
  • cryptography and secure e-voting protocols
