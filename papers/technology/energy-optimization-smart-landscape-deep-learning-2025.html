  • ការអនុវត្តយន្តការយកចិត្តទុកដាក់ (Attention Mechanism) ដើម្បីផ្តោតលើលក្ខណៈសំខាន់ៗនៃទិន្នន័យ
  • ការប្រៀបធៀបដំណើរការម៉ូដែលជាមួយក្បួនដោះស្រាយផ្សេងទៀតដូចជា SVM, ELM, និង LSTM ដោយប្រើប្រាស់ទិន្នន័យសាធារណៈ។

  • វាមានប្រសិទ្ធភាពខ្ពស់ជាងម៉ូដែលប្រពៃណីផ្សេងទៀត ដោយម៉ូដែល SVM មានកំហុស 26.27%, ELM មាន 12.09% និង LSTM មាន 2.95%។

២. ការវិភាគលើប្រសិទ្ធភាព និងការចំណាយ (Performance & Constraints)

វិធីសាស្ត្រ (Method) គុណសម្បត្តិ (Pros) គុណវិបត្តិ (Cons) លទ្ធផលគន្លឹះ (Key Result)
Support Vector Machine (SVM)
ម៉ាស៊ីនវ៉ិចទ័រគាំទ្រ (SVM)		 មានភាពងាយស្រួលក្នុងការប្រើប្រាស់សម្រាប់ការទស្សន៍ទាយទិន្នន័យទូទៅ។ ពិបាកក្នុងការចាប់យកលំនាំទិន្នន័យដែលមានភាពស្មុគស្មាញ និងប្រែប្រួលខ្លាំង ដែលធ្វើឱ្យមានកម្រិតកំហុសខ្ពស់។ មានកំហុស MAPE: 26.27% និង MAE: 11.94
Extreme Learning Machine (ELM)
ម៉ាស៊ីនរៀនកម្រិតខ្ពស់ (ELM)		 មានល្បឿនរៀនលឿនជាង SVM និងមានលក្ខណៈសាមញ្ញដោយសារមានតែមួយស្រទាប់កំបាំង (Single-hidden-layer)។ រចនាសម្ព័ន្ធសាមញ្ញពេក ធ្វើឱ្យមានការកំណត់សមត្ថភាពក្នុងការរៀនពីលក្ខណៈពិសេសស្មុគស្មាញនៃទិន្នន័យថាមពល។ មានកំហុស MAPE: 12.09% និង MAE: 9.62
Long Short-Term Memory (LSTM)
បណ្តាញចងចាំរយៈពេលវែង-ខ្លី (LSTM)		 មានសមត្ថភាពខ្ពស់ក្នុងការដោះស្រាយ និងចងចាំភាពអាស្រ័យនៃទិន្នន័យរយៈពេលវែងក្នុងទិន្នន័យតាមលំដាប់ពេលវេលា (Time-series)។ មានភាពស្មុគស្មាញក្នុងការគណនាខ្ពស់ ចំណាយពេលយូរក្នុងការបង្វឹកទិន្នន័យវែង និងខ្សោយក្នុងការទាញយកលក្ខណៈពិសេសក្នុងតំបន់តូចៗ។ មានកំហុស MAPE: 2.95% និង MAE: 3.2
Improved Temporal Convolutional Network (ITCN)
បណ្តាញប្រសៃប្រសាទ TCN ដែលបានកែលម្អ (ម៉ូដែលស្នើឡើង)		 កាត់បន្ថយភាពស្មុគស្មាញនៃប៉ារ៉ាម៉ែត្រម៉ូដែល និងពង្រឹងសមត្ថភាពចាប់យកលក្ខណៈទិន្នន័យបានច្បាស់លាស់ ទោះបីជាមានទិន្នន័យប្រវត្តិដើមតិចតួចក៏ដោយ។ ទាមទារការរៀបចំរចនាសម្ព័ន្ធស្មុគស្មាញ (រួមបញ្ចូល Depthwise separable convolutions និង Attention mechanisms) ដែលត្រូវការអ្នកជំនាញដើម្បីអនុវត្ត។ ល្អជាងគេបំផុតដោយមានកំហុស MAPE: 1.69% និង MAE: 1.92

វិធីសាស្ត្រព្យាករណ៍ការប្រើប្រាស់ថាមពលនេះមានសក្តានុពលខ្ពស់សម្រាប់អនុវត្តនៅកម្ពុជា ជាពិសេសក្នុងការគាំទ្រដល់ការអភិវឌ្ឍទីក្រុងឆ្លាតវៃ (Smart Cities)។

  • អគារពាណិជ្ជកម្មកម្ពស់ខ្ពស់នៅរាជធានីភ្នំពេញ: អាចប្រើដើម្បីគ្រប់គ្រងប្រព័ន្ធម៉ាស៊ីនត្រជាក់ និងភ្លើងបំភ្លឺឆ្លាតវៃក្នុងអគារការិយាល័យ ដោយទស្សន៍ទាយម៉ោងដែលត្រូវការប្រើប្រាស់ភ្លើងច្រើន ដើម្បីសន្សំសំចៃការចំណាយអគ្គិសនី។
  • សណ្ឋាគារ និងរមណីយដ្ឋាននៅខេត្តសៀមរាប: អាចបង្កើនប្រសិទ្ធភាពនៃការប្រើប្រាស់ថាមពលនៅក្នុងសួនច្បារអគារ (ដូចជាប្រព័ន្ធស្រោចស្រព និងភ្លើងលម្អទេសភាព) ស្របតាមទិសដៅទេសចរណ៍បៃតង និងកាត់បន្ថយការបញ្ចេញកាបូន។
  • តំបន់សេដ្ឋកិច្ចពិសេស (SEZ) ដូចជានៅក្រុងព្រះសីហនុ ឬរាជធានីភ្នំពេញ: ជួយរោងចក្រឧស្សាហកម្មក្នុងការទស្សន៍ទាយ និងកាត់បន្ថយការប្រើប្រាស់ថាមពលដែលមិនចាំបាច់ ដែលជួយបញ្ចុះថ្លៃដើមផលិតកម្ម និងគាំទ្រគោលនយោបាយសេដ្ឋកិច្ចបៃតង។

សរុបមក ដើម្បីអនុវត្តការសិក្សានេះប្រកបដោយជោគជ័យ កម្ពុជាចាំបាច់ត្រូវជំរុញការបំពាក់រង្វាស់អគ្គិសនីឆ្លាតវៃ (Smart Meters) ឱ្យបានទូលំទូលាយសិន ដើម្បីប្រមូលទិន្នន័យឱ្យបានគ្រប់គ្រាន់សម្រាប់ការហ្វឹកហាត់ម៉ូដែល AI នេះ។

៤. ផែនការសកម្មភាពសម្រាប់និស្សិត (Actionable Roadmap)

ដើម្បីអនុវត្តតាមការសិក្សានេះ និស្សិតគួរអនុវត្តតាមជំហានខាងក្រោម៖

  1. សិក្សាពីមូលដ្ឋានគ្រឹះនៃទិន្នន័យតាមលំដាប់ពេលវេលា (Time-Series Data): ចាប់ផ្តើមរៀនពីរបៀបសម្អាត ការបំពេញទិន្នន័យដែលបាត់បង់ និងការធ្វើ Normalization លើទិន្នន័យថាមពលនិងអាកាសធាតុ ដោយប្រើប្រាស់បណ្ណាល័យ Pandas និង scikit-learn នៅក្នុងបរិយាកាស Python។
  2. ស្វែងយល់និងសាកល្បងម៉ូដែល TCN ជារចនាសម្ព័ន្ធមូលដ្ឋាន: សិក្សាពីរចនាសម្ព័ន្ធរបស់ TCN ជាពិសេសមុខងារ Dilated Causal Convolutions តាមរយៈការអនុវត្តកូដគំរូនៅលើ PyTorch ជំនួសឱ្យការប្រើប្រាស់ LSTM ដើម្បីយល់ពីរបៀបដែល TCN មានល្បឿនគណនាលឿនជាង។
  3. អនុវត្តការបញ្ចូលយន្តការយកចិត្តទុកដាក់ (Attention Mechanism): សាកល្បងសរសេរកូដបន្ថែម Multi-head Attention និង Convolutional Attention ទៅក្នុងម៉ូដែល TCN របស់អ្នក ដើម្បីឱ្យ AI ចេះថ្លឹងថ្លែងនិងផ្តោតលើទិន្នន័យអាកាសធាតុ ឬលក្ខណៈអគារណាដែលមានឥទ្ធិពលខ្លាំងលើការប្រើប្រាស់ភ្លើង។
  4. ប្រមូលទិន្នន័យក្នុងស្រុកនិងធ្វើការសាកល្បងផ្ទាល់: ទាញយកទិន្នន័យអាកាសធាតុរបស់ប្រទេសកម្ពុជាពីប្រភពបើកចំហរដូចជា OpenWeather API រួមជាមួយនឹងទិន្នន័យប្រើប្រាស់ភ្លើងនៃអាគារសកលវិទ្យាល័យរបស់អ្នក រួចវាយតម្លៃភាពសុក្រឹតរបស់ម៉ូដែលដោយប្រើរង្វាស់ MAE និង RMSE។

៥. វាក្យសព្ទបច្ចេកទេស (Technical Glossary)

ពាក្យបច្ចេកទេស (English) ការពន្យល់ជាខេមរភាសា (Khmer Explanation) និយមន័យសាមញ្ញ (Simple Definition)
Temporal Convolutional Network (TCN) ជាបណ្ដាញសរសៃប្រសាទសិប្បនិម្មិតកម្រិតខ្ពស់ដែលរចនាឡើងយ៉ាងពិសេសសម្រាប់វិភាគទិន្នន័យតាមលំដាប់ពេលវេលា (Time-series data) ដោយប្រើប្រាស់បច្ចេកទេសត្រងទិន្នន័យបណ្តោះអាសន្ន ដើម្បីចាប់យកទំនាក់ទំនងនៃព្រឹត្តិការណ៍ពីអតីតកាល។ ដូចជាការតាមដានមើលរូបភាពវីដេអូបន្តបន្ទាប់គ្នាជាច្រើនសន្លឹក ដើម្បីស្វែងយល់ និងទស្សន៍ទាយថានឹងមានអ្វីកើតឡើងនៅវិនាទីបន្ទាប់។
Depthwise Separable Convolution ជាវិធីសាស្ត្របំបែកការគណនាក្នុងបណ្ដាញសរសៃប្រសាទជាពីរដំណាក់កាលដាច់ដោយឡែកពីគ្នា (កាត់តាមជម្រៅ និងកាត់តាមចំណុច) ដែលជួយកាត់បន្ថយភាពស្មុគស្មាញ និងកាត់បន្ថយចំនួនប៉ារ៉ាម៉ែត្ររបស់ម៉ូដែលធ្វើឱ្យវាដំណើរការបានលឿនជាងមុន។ ដូចជាការបែងចែកការងារចម្អិនម្ហូបទៅឱ្យចុងភៅពីរនាក់ ដោយម្នាក់ជំនាញខាងហាន់សាច់ និងម្នាក់ទៀតជំនាញខាងឆា ដែលធ្វើឱ្យចំណាយពេលតិចជាងការធ្វើការងារទាំងពីរនេះដោយមនុស្សតែម្នាក់។
Attention Mechanism ជាយន្តការក្នុងវិស័យបញ្ញាសិប្បនិម្មិត (AI) ដែលអនុញ្ញាតឱ្យម៉ូដែលចេះកំណត់ទម្ងន់ទិន្នន័យ និងផ្តោតការយកចិត្តទុកដាក់តែទៅលើផ្នែកណាដែលសំខាន់បំផុតនៃទិន្នន័យបញ្ចូល ដោយមិនខ្ជះខ្ជាយពេលលើទិន្នន័យដែលគ្មានប្រយោជន៍។ ដូចជាពេលអ្នកកំពុងអានសៀវភៅក្រាស់មួយក្បាល ហើយអ្នកយកប៊ិចហ្វឺត (Highlighter) មកគូសបញ្ជាក់តែពាក្យគន្លឹះសំខាន់ៗ ដើម្បីងាយស្រួលយល់ និងចងចាំ។
Multi-head attention ជាយន្តការបំបែកការយកចិត្តទុកដាក់ (Attention) ជាច្រើនក្បាលស្របគ្នា (Parallel) ដើម្បីជួយឱ្យម៉ូដែល AI អាចទាញយកលក្ខណៈពិសេសៗ និងស្វែងយល់ពីទំនាក់ទំនងទិន្នន័យពីជ្រុងជ្រោយខុសៗគ្នាក្នុងពេលតែមួយ។ ដូចជាការដាក់កាមេរ៉ាសុវត្ថិភាពច្រើនគ្រាប់នៅតាមមុំខុសៗគ្នា ដើម្បីតាមដានសកម្មភាពនៅក្នុងបន្ទប់តែមួយឱ្យបានច្បាស់គ្រប់ជ្រុងជ្រោយ។
Dilated convolution ជាបច្ចេកទេសនៃប្រតិបត្តិការ Convolution ដែលពង្រីកវិសាលភាពនៃការចាប់យកទិន្នន័យ (Receptive Field) ដោយការរំលងចន្លោះទិន្នន័យខ្លះៗ ដែលជួយឱ្យម៉ូដែលមើលឃើញទិន្នន័យបានទូលាយដោយមិនចាំបាច់បង្កើនចំនួនប៉ារ៉ាម៉ែត្រគណនា។ ដូចជាការឈានជើងវែងៗរំលងកាំជណ្តើរ ដើម្បីអាចឡើងដល់ជាន់លើបានលឿន និងមើលឃើញទិដ្ឋភាពបានទូលាយជាងការដើរម្តងមួយកាំ។
Adaptive Parametric ReLU ជាអនុគមន៍សកម្ម (Activation Function) នៅក្នុងបណ្តាញប្រសៃប្រសាទ ដែលជួយកែសម្រួលតម្លៃទិន្នន័យអវិជ្ជមានដោយស្វ័យប្រវត្តិតាមរយៈមេគុណដែលអាចរៀនបាន ដែលធ្វើឱ្យម៉ូដែល AI អាចបត់បែនខ្លួន និងរៀនពីទិន្នន័យបានកាន់តែប្រសើរ។ ដូចជាឧបករណ៍កែតម្រូវចរន្តអគ្គិសនីស្វ័យប្រវត្តិ (Stabilizer) ដែលជួយទប់លំនឹងភ្លើងមិនឱ្យដាច់ ទោះបីជាចរន្តភ្លើងធ្លាក់ចុះក៏ដោយ។
Mean Absolute Percentage Error (MAPE) ជារង្វាស់គណិតវិទ្យាដ៏ពេញនិយមមួយសម្រាប់វាស់ស្ទង់កម្រិតភាពត្រឹមត្រូវនៃម៉ូដែលទស្សន៍ទាយ (Regression model) ដោយបង្ហាញទំហំនៃកំហុសគិតជាភាគរយធៀបនឹងតម្លៃជាក់ស្តែងពិតប្រាកដ។ ដូចជាការបាញ់ស៊ីប ប្រសិនបើអ្នកទាយថាបាញ់ចំកណ្តាល១០០% តែការពិតបាញ់ខុសខិតចេញក្រៅបន្តិច នោះកម្រិតចំងាយដែលខុសនោះគឺជាភាគរយកំហុសនៃការទស្សន៍ទាយរបស់កាំភ្លើង។
Global Average Pooling (GAP) ជាប្រតិបត្តិការបង្រួមទិន្នន័យនៅក្នុងស្រទាប់បណ្តាញ Convolutional ដែលវាគណនាយកតម្លៃមធ្យមនៃទិន្នន័យនីមួយៗក្នុង Channel នីមួយៗ ដើម្បីជួយកាត់បន្ថយទំហំទិន្នន័យ និងការពារបញ្ហា Overfitting (ម៉ូដែលទន្ទេញចាំទិន្នន័យ)។ ដូចជាការយកពិន្ទុមុខវិជ្ជាជាច្រើនរបស់អ្នកសិស្សម្នាក់ៗមកបូកបញ្ចូលគ្នាហើយចែកជាមធ្យមភាគ ដើម្បីទទួលបានពិន្ទុតំណាងតែមួយគត់ដែលបង្ហាញពីសមត្ថភាពរួមរបស់សិស្សនោះ។
